# Sustained blood MPM capacity evidence

This package preserves a synthetic accepted-packet capacity check for the existing GPU MPM receiver. It does not establish seconds-scale operation, physiological bleeding rates, blood free-surface behavior, pooling, or floor contact. The test uses the source-pinned high-shear Newtonian proxy and existing MPM handoff; it is not a new fluid solver.

Run-010 completed 132 accepted packets at 1.1 µL each (145.2 µL total) over 132 × 0.25 ms = 33 ms. The 128-slot receiver ended with 122 active particles and 145.2 µL represented. It asserted external and represented volume, mass, O2 and CO2, linear momentum, origin and COM-relative angular momentum, the coalescence loss ledger, and exact rejected-step rollback/retry at frame 120. Recorded errors were momentum 9.49707e-08 and angular 1.83403e-08; ledger loss was 5.83301e-16 J. Apple M6 runtime was 142.70 s. See `run-010/result.json` and `invocation.json`.

Run-010 is historical evidence for the earlier kinetic-energy admission bound. Run-014 repeats the 132-packet case using the stricter source: signed APIC kinetic loss with a 16-FP32-epsilon relative allowance and a 1e-30 J floor, matching the strict bulk-energy check; the GPU candidate scan and write path reject energy gain beyond that bound. Run-014 passed the same conservation and rollback assertions in 143.30 s, with 122 active particles, 145.2 µL represented, 5.83301e-16 J loss, momentum error 9.49707e-08, and COM/origin angular error 1.83403e-08. Its exact source and invocation are under `run-014/`.

Failed attempts are retained without promotion: run-008 rejected at accepted step 118 when exact-F-only merging exhausted capacity; run-009 timed out at 300 s after progress through frame 240 of 256 and did not reach conservation assertions. Floor attempts 011–013 all failed. Run-011 authored floor_z=-5.9 m by confusing the integer node minimum with metres. Run-012 corrected the floor to -0.15 m but rejected at accepted step 0 (matter code 6, grid node 467; diagnostics -0.05, 1.984187, 0, 1.984187). Run-013 moved initial support above the plane but rejected at accepted step 1 (matter code 6, node 663; diagnostics 0, 1.138235, 0, 1.138235). Floor contact remains unqualified; no faster-descent retry is implied.

`candidate-source/` holds the current stricter source and is not yet qualified. The `run-010/source` directory holds source files copied with that run. Its source-pins file records their identities and the tested binary/runtime hashes; binaries are intentionally omitted from this compact package. `tools/` contains current reproduction helpers and is not represented as the exact historical builder revision used by run-010.
