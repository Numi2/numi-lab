## Parallel private-query failure selection

Replace the private full-contact Armijo narrowphase failure scan by a parallel active-candidate pass, atomic minimum slot, and constant-work deterministic finalizer. It preserves upstream failures, selects the same first failing candidate and publishes its complete tuple. Scratch cost is four bytes per environment. Reset/selection/finalization dependencies have explicit barriers. Poisoned inactive padding, multiple environments, canaries, overflow and invalid selections are tested against the retained serial reference.

Optional GPU microbenchmark: NM_CONTACT_FAILURE_SELECTION_BENCHMARK=1 build-native/matter/numi-matter-fgmres-true-residual-native-check. Three matched pairs, five repeats per sample, alternating order and warmup; parallel samples include selection reset and barrier. Median selection-only healthy cost: 657,111 candidates, 105.451 ms serial versus 0.211 ms parallel; 4,000,000 candidates, 642.212 ms versus 1.281 ms. An immediate slot-zero failure is slower in the parallel path (roughly 1 us serial versus 0.211/1.281 ms parallel); this result is retained.

This is a conditional private full-contact Armijo path, which this full Human trial does not enable. It is not the active production collision bottleneck. Root-zero profiled stage sums are 14.5421 s before and 14.5442 s after; no whole-Human speedup is established. The remaining encoded Newton tails are expensive and are being investigated separately.
