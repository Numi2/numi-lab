# Whole-body skin/fat integration evidence

This experimental integration builds the closed skin/fat shell with three nodal surfaces and two material bands with 6,996 nodes and 27,714 tetrahedra, shared interfaces, source ancestry, and persistent GPU contact state. The independently inspectable inner-skin and deep-fat surfaces use layer masks 128 and 256. The published native evidence below exercises only short bounded runs; it does not establish sustained whole-body contact, circulation, or stability.

The optional whole-body path composes cooked FEM nodal mass moments with a residual rigid-body reference. It infers one global residual rigid scale so the assembled reference preserves the source model's total mass, then uses the stock tissue-mass compiler and rigid-mass rebase. This is an inferred bookkeeping reference, not a fit to measured properties of a person. Source segment mass budgets are accounting inputs, not valid donor weights or one-to-one physical assignments for the cooked tissue nodes.

The mass routine accumulates symmetric upper-triangle moments around a central origin. Physical validity guards are unchanged, and the routine does not pad inertia. Strict CPU regressions, compiled with warnings as errors, replay the conservation case and all 33 donor partitions from the retained 1.3 MB native mass input against the stock compiler; both pass. This CPU result does not qualify native whole-body behavior.
