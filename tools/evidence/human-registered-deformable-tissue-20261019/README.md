# Registered passive tissue candidate: preflight evidence

This package records an opt-in, source-derived regional deformable-tissue candidate and a paired native clean/reject-retry mechanics check. It is prepared for scoped publication review only; this directory does not modify the repository, index, branch, or remote.

The application source and registered-organ asset header are pinned by SHA-256 in the manifest. Preparation inputs retain BodyParts3D record identities and source-face ancestry for the right kidney (FJ3147), left kidney (FJ3145), and spleen (FJ2561). The spleen repair is a bounded local inferred clearance adjustment in the registered world-Float32 frame. The included exact source-boundary and neighboring-surface checks report inherited crossings separately; they do not establish containment or anatomical correctness.

The native pair enabled the regional skin-fat shell (64-face patch), passive prostate proxy, bilateral kidneys and spleen, passive bilateral optic-nerve proxies, existing ACL rows, cavity-wall/aortic-wall object, and existing FEM objects. Ten FEM objects emitted node/tet summaries. The paired accepted FEM node/tet captures have 6,254 node rows and 25,108 tetrahedron rows per case, byte-identical across clean and late-reject/retry; both executions passed the existing rollback markers. This is a short experimental mechanics and rollback result, not sustained qualification.

The legacy object name `Human/BodyParts3D/stable-9/reduced-cavity-wall-v1` maps to the aortic wall in the existing aortic-wall owner. Its 532-node/1,584-tet emitted nodal mass (0.007059265134 kg) matches the reported cooked aortic-wall mass (0.00705926513 kg); it is not an extra uncaptured object.

Limitations remain explicit: the skin-fat FEM is regional, not whole-body; organ and nerve materials/attachments are passive inferred proxies, not fitted anatomy; neural conduction is not represented; and 106 inherited spleen/diaphragm crossings remain unresolved as anatomical interfaces. No clinical or whole-body anatomical qualification is claimed. The runtime opt-in remains default-off.
