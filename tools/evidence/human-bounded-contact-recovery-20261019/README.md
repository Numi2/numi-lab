# Bounded deformable contact recovery
Matter remains the GPU owner of tissue forces, collision state, and accepted/candidate rollback. This patch tightens the VT interval fallback's Lipschitz bound to relative corner motion and adds the missing EE interval fallback after legacy, endpoint, and separating-plane recovery. Both retain a Float32 arithmetic margin, coordinate roundoff, unchanged thickness, and a fixed 64-evaluation cap. Unresolved queries reject. The original supplemental plane limiter and shared line-search CCD remain unchanged. No CPU per-step implementation or new simulation state is added.

Qualification on SSH Numi, Apple M6:
- Corrected direct GPU test 003: static clear, endpoint contact, transient crossing with clear endpoints, and a true 20-micrometre near miss preserve all printed legacy-certified result fields. The captured-operand reconstructed EE query changes uncertified to certified clear. Reconstructed start coordinates may differ from the original compiler's contracted expression; this is explicitly not a bit-exact original-call replay. Probe001 used mismatched argument order; probe002 also had invalid ordering and was not run. Both are invalid evidence and retained at their invocation paths.
- Prescribed-pressure anatomical reduced aortic wall plus incoming FEM tissue: force output is byte-identical to the published passing baseline, including late rejected-step exact rollback and accepted retry. The largest retained contact force is 0.701559001 N. This is a 1.5 ms fixed-boundary regional test, not sustained haemodynamics.
- Strict short kidney/spleen contact: four accepted steps, 35 positive contact rows, 1.798 N summed average normal force, exact late rejected-step rollback and successful retry. Net momentum change is 5.45e-7 N s; this is a short numerical check, not a sustained conservation qualification.
- Longer registered kidney/spleen synthetic collision: controls pass; six approach steps (1.5 ms) accept, then frame6/Newton10 fails with the same residual/alpha diagnostic as the published baseline. This patch does not solve that longer nonlinear globalization limit.
- Complete native scene: one 0.25 ms accepted step, physiology CSV byte-identical to prior baseline, matched body/physiology clocks. 55.06 s launch-to-exit includes initialization; no steady execution speed claim. This scene loads aorta/fascia/ACL layers, not all ten optional tissue objects. No visual verification was performed.

The relative-motion bound follows convexity: any barycentric triangle point or pair of segment points has relative velocity bounded by the maximum endpoint-relative velocity. Every interval must clear the midpoint distance minus its radius and roundoff before a clear sweep is certified. Fixed work and fewer unnecessary subdivisions are implementation properties; an integrated performance improvement is not measured.

Open: sustained multi-tissue convergence, full ten-object native qualification, general skin/fat/nerve contact qualification, dynamic circulation-driven wall loading and sustained blood liquid coupling, and the full human long runs. Regional force and rollback results do not establish those capabilities.
