# MPM accepted-step external finalization scope

This source-level increment lets the existing Matter finalizer own rollback for a narrowly admitted MPM-plus-vascular world. The caller supplies the same-command-buffer external owner status; the existing Matter status gate then controls MPM particle/material rollback, topology/scheduler reconciliation, vascular rollback, and callback publication. The implementation admits only nonadaptive MPM objects with global contact disabled and both object contact-disable flags set. It permits the fixed MPM material-parameter arena but rejects reset pointers/strides, identification, learned updates, topology mutation, FEM, rigid, adaptive, and active contact. Preallocated deformable-contact capacity is scratch only under that compiled contact-disabled proof.

The fixture exercises an active particle under a late external rejection after 256 microsteps, byte-compares accepted physical arenas to the initial snapshot, retries acceptance in the same runtime, and compares the result to a clean accepted control. It also retains the earlier rejected preflight attempts; those failures are diagnostic history, not qualifications. The passing fixture is a bounded native rollback/retry regression, not a production or full-scene qualification.

`rebuild.sh` records the exact source-root layout used on `numi`. The receipts bind source, binary, shader, and runtime library hashes. `abi/check_public_header_abi.sh` compares the callback view from the parent header against this appended MPM-arena version and checks that existing prefix offsets are unchanged.
