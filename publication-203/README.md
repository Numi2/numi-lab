# Numi Human hand and wrist: remesh and layer-transfer evidence

This is an offline reference-pose construction checkpoint, not an accepted physical skin, a moving native scene, a complete anatomy result, or clinical validation. It extends the independently verified P202 checkpoint at https://github.com/Numi2/numi-lab/tree/a931e064681f211973b32047b52a0372918562f9/publication-202, which contains the 806 baseline, 541 layer file, all-bank audits and supporting source inputs.

The pinned 806 baseline has 977 exact raw skin/bone triangle pairs, 651 mapped parent/bone identities, zero exact nonadjacent skin self-pairs and 125 sampled skin-node/bone inside identities. The 43/16 candidate dd31bdffbb689c8caed7bcc46229b89e23f77096aca6e780005c6a69529e432c removes one skin node and two faces, while preserving two historical material charts under independent coverage and ancestry checks. Across all 185 banks it has 977 raw and 651 mapped crossings, and zero self-pairs. Its inside sample count is 124 only because the removed node was inside the radius; that witness remains unresolved. It was rejected by the layer gate: two changed faces fail authored prism orientation for both skin and fat. No geometry or physical admission was granted.

The 43/16 local ranking's first receipt is deliberately retained and labeled invalid: it paired remapped face indices with pre-remap point coordinates. The corrected v2 ranking was regression-checked against the full dd31 audit. Of 84 legal single-edge collapses, 19 passed local changed-face layer checks and none reduced mapped crossing identities without new mapped identities. Thus no crossing was cleared by that ranking.

The private topology-independent layer-transfer helper reproduces all 27 baseline layer arrays byte for byte, explicitly composing the 21,212 -> 13,518 -> 10,145 -> 8,776 source mapping. Negative tests reject missing/stale material ancestry. It calculates surface offsets and diagnostic prism checks; it does not generate a conservative tetrahedral mass ledger or grant native admission. Existing baseline skin/fat cell failures remain.

The retained native identity preflight constructs an in-memory paired skin/fat object, but no archived matching per-tetrahedron mass and geometric-overlap ledger connects that native 2,411-row boundary to the 806 mesh. The native-donor receipt records the exact assets, binary, partial surface transfer and missing mapping. No physical steps were performed for this checkpoint. Disk, runtime and source statuses must be rechecked before continuing.
