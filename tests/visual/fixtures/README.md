These are deterministic zero-policy contract fixtures generated before the
visual depth-validity semantics change. `0.npolicy` has no visual observation;
`1.npolicy` contains eight masked-depth values. They are not trained policies.
The regression checks that the former still compiles, the latter is rejected
under the new visual observation fingerprint, and rebinding succeeds. Their
world and task are generated by the checked-in Franka fixture in
`../observation_fingerprint.cpp`.
If the containing branch has changed the compiled task fingerprint, the test
first verifies that the original pack is incompatible, then adjusts only its
task binding in memory while keeping the old observation fingerprint. This
isolates the observation migration; it does not claim that the original pack
is otherwise compatible with that branch.
