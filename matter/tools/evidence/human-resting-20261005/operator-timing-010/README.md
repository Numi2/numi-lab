On the SSH Mac mini (Apple M4 Pro), the existing integrated resting scene accepted 128 steps at 2 ms with the new opt-in operator instrumentation. The frozen build010 source is build009 plus the timing patch. `invocation.json` binds the source files, executable, libraries, shaders, assets, configuration and environment; `execution.json` records exit 0 and no changed inputs. The complete native movie and source diff remain at `/Users/n/numi-human-resting-evidence-20261005/integrated-profile-cycle-010-movie`.

This checks instrumentation in the integrated runtime, not anatomical acceptance, five-minute endurance or physiological qualification. The 10.363 s wrapper time includes initialization and recording and is not a steady-state speed result. CPU geometry audits ran concurrently. The first no-movie attempt is retained separately as `integrated-profile-cycle-010`: the headless host had no window drawable, so it exited before physics. Build010's clean configure initially failed because its default Brain source path was absent; the successful build explicitly uses the existing integration Brain checkout.

The cycle sampler schedules eight samples for each of 16 named stages, with compile-time coverage checks. A path that does not execute a stage emits no sample for it: this run did not enter `kinematics_prepare`. Borrowed callbacks report host encoding duration and, on a device that supports blit-boundary timestamp counters, the GPU elapsed envelope. This Mini reported that envelope as unavailable. An envelope can include overlapping work and is not an exclusive kernel duration. No solver iteration count, tolerance, force or physical state calculation is changed.
