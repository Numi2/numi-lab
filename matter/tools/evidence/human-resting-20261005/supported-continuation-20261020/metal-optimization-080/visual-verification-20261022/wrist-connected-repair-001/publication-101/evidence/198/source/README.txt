Nearest complete-bank first-union target proposal
================================================

The generic builder consumes an exact matched candidate NPZ, complete exact face/bone report, and corresponding audit-130 query receipt. It reconstructs strict interior barycentric samples for reported crossings, classifies each against all 185 complete bone banks, then selects the nearest complete triangle over the initially containing banks in world Euclidean metric. Emitted bank-local Float32 triangles are transformed with the raw affine inverse: solve(M, local + offset) + body position.

It sends that direction through the existing exact all-bank first-empty-union ray/parity logic and exact Float32 endpoint checks. The result is a construction target proposal, not an anatomical outward normal or clearance/physical admission. No fit or native physical step is part of this tool.

Example:
python build_nearest_face_union_targets.py --candidate /absolute/candidate.npz --surface-report /absolute/audit-159/report.json --query-receipt /absolute/audit-130/query/query-receipt.json --output-dir /absolute/new-output

source-pins-and-run-config.json pins the prepared pass-001 input pair from local-witness-backtracking-188-run001. It is configuration only; this increment did not launch the builder because geometry slot 189 was active. The generated report will pin candidate, report, query receipt, exact bank exports, reader, predicate, and sample helper at execution time.
