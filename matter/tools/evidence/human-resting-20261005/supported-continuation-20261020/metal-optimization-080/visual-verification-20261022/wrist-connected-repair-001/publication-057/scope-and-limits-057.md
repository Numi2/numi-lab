# Publication 057 scope and limits

This package is a hash-pinned evidence snapshot prepared against live `origin/main` 9226d20147fbb1cfed7fe5a4c1ce96a0ee13413f. It is a draft for review, not a candidate activation or qualification.

Nine files totaling 5,675,553 bytes are omitted from this package because they are byte-identical to files already published in 056. Their exact repository paths, 056 commit, byte counts, and SHA-256 hashes are recorded in `payload-files-057.json` under `inherited_files`; the base commit is 9226d20147fbb1cfed7fe5a4c1ce96a0ee13413f. This avoids duplicating the edge-split artifact and registered-pose file.

D37 is a private/unadmitted geometry and donor-rebind candidate. The generated tables preserve its remap and material accounting. Its 61,950-row registered CSV (expected SHA-256 `b766fd63b13bf87384ec5a0893356dcc139b7f8d079110096972f9d98f3cc4ad`) was regenerated locally byte-for-byte from the bundled exporter source and body-frame file. Reproduction requires the candidate NHSKIN from publication-056 and the 23 MB identity-004 source CSV retained outside this package; both are exact hash-pinned dependencies. Therefore this bundle alone is not a self-contained recovery archive for that CSV.

The 014 geometry represented by publication 025 is a whole-body shell-bounded background/construction volume (69.600804 L), with one generic region attribute and construction-closure faces. It is not a physical skin/fat mesh. D37 separately reports 15.104914 L across physical skin and fat columns. The 025 solver attempts are retained as rejected/incomplete evidence; large candidate NPZs are omitted and their exact hashes, required inputs, and rerun commands are recorded.

The 018 edge-split artifact has a retained original builder report with status `no_passing_bounded_edge_split_found` because a parent-area comparison missed its local threshold by 9.36 ppm. The independent Float32 roundoff certificate bounds that error, and the exact Float32 surface audit reports 38,106 faces, zero degenerates, and zero self-pairs. This is a local surface result only. Original material ancestry and mass transfer are still blocked: the transfer audit found folded 017 parent tets, no per-node original-013 reference simplex, and no skin/fat interface. The 256-child overlap prefix has 39 uncovered children (minimum coverage 13.13%) out of 147,230 changed cavity children; it is incomplete and does not establish mass closure.

The 024 source-preflight emitted exact native surface geometry and positive Float32 cells, but did not qualify physical behavior. The subsequent 1 ms run failed at the common-field stage before any accepted step. It is a dynamic release initialization (`support=0`, `balanced=false`), not supported resting initialization. The source exact-surface check and compiled-cell check do not establish cross-structure clearance or physical/native admission. The 283 MB run package and duplicate 23 MB source CSV are omitted and hash-pinned.

The COW-009 cleanup trial is retained as evidence only; it did not retire or delete source data. All existing checkout changes remain untouched. Publication preparation stages only this directory through an alternate Git index, without commit or push.
