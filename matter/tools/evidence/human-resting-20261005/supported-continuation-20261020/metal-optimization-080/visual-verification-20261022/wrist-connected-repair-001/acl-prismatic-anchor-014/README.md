# Prismatic knee anchor registration and matched skin-pose diagnostics

The ACL registration frame now includes the admitted prismatic joint displacement in the parent joint frame. The model includes knee sliding rows; expecting coincident untranslated anchors rejected nonzero flexion before the tissue constructor ran. The existing 0.2 mm residual gate remains unchanged. The native caller passes the same configuration used to construct its body poses. Omitting coordinates selects the model defaults, which must match the supplied poses.

The regression checks rotated nonunit axes, explicit and default coordinates, nonfinite coordinates, invalid axes, wrong travel and transverse registration error. `regression-final-result.json` binds the passing test to the exact final header and test source. The clean native build uses the main-51821 source plus this caller fix and an environment-gated existing skin-pose serializer, with no new physical state or force owner.

Clean native neutral and bilateral knee q=.25 captures emitted 61,950 registered skin rows and matching 86-binding pose snapshots. Reconstruction error is at most 2.3842 micrometres. The former ACL gate is absent; NHEQ maximum coordinate correction at the knee pose is 3.66e-9. A shoulder-elevation .5 control is byte-identical to the prior clean013/dirty012 diagnostic. These captures are static construction diagnostics, not accepted physical steps. All terminate later at the existing inner-fat-layer self-intersection admission gate. Other scalar pose overrides are under investigation and are not claimed as active motion qualification.

No layer admission, density, material, contact, acceptance or dynamics tolerance was relaxed. Inferred ACL reference geometry is still constructed at the selected initialization pose; this change does not establish pose-independent physiological rest length or validated range of motion.
