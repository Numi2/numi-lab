This increment contains a standard PAX tar.xz archive of 33 failed or unselected candidate NPZ files, totaling 80,396,008 uncompressed bytes. It covers 210, 215 passes 001–012, 217 local-backtrack passes 001–016, and round-002 joint-local-backtrack attempts from 219. The 210 set includes one unbacktracked proposal candidate and nine backtrack candidates; its raw LP file is excluded.

The selected 215 pass-013 candidate (SHA-256 f5b82d77ec9896496ec4d5e9f37b99d4c26564a97b9669c0de1a16bd979d461a) and selected 217 pass-017 candidate (SHA-256 0e0c5d2a285f75ee82800439eb21c0ea2bb0727b43c4c3ef40710630340f666d) are excluded. Every archived member was streamed through tarfile.extractfile and verified without extracting to disk.
