# Shared MyoSim + Human/FEM actuation seam (release bundle)

This bundle contains a clean-main source patch and the bounded shared-owner wiring trial. The source change permits selected tendon activation to run through the already-existing persistent Human/Matter transaction, obtains the one-time initial root placement from the existing support owner, and avoids requesting legacy support reactions while preserving the authored release posture. Existing support, source, state, and solver gates remain enabled.

The composed app source is based on the `apps/numilab_human_myosim_visual_probe.mm` bytes at remote-main base `75bd5ba2ff33d3a4875b5303395755ab817faa0f` (SHA-256 `43631d28c83f608f9613744e1c43bc97e9707a659323796d19d33a647c1430ba`). Remote main later advanced to `eb31b83f58941b3aa3ba22047afb7a5f2f18979a`; its app file has the same SHA-256. The three ordered patches reconstruct the composed source exactly (SHA-256 `1e4006ea13ec68ace628658ecaadde941a6bfc63e5fefb8161b9e758cb422c58`).

The source compiles with `-Wall -Wextra -Wpedantic -Werror` and links against the pinned ABI14/Metal build in `preflight/build-result-abi14.json`. A one-step test with selected biceps/brachialis/brachioradialis IDs `[232,233,295,296]`, activation increment 0.5, and a matched zero-increment baseline both reached t0 and FEM initialization, then failed before accepting a physical step with Matter status 10. The nonvascular residual was `4.66936996e-4` against the unchanged `1.24999997e-5` gate in both runs; vascular residual passed. This isolates the observed failure from the selected increment for this pair, but not the internal per-muscle fiber/force state because the current logs do not emit it. The shared scene remains unqualified for physical motion.

The release placement is a single initial translation of `5.8899256694944224e-6 m` from the existing support-plane owner, with root quaternion and limb coordinates preserved. Initialization is explicitly unbalanced (`RMS residual 0.321712868398`, maximum acceleration residual `65.1741826254`, no support force); this is a release transient, not equilibrium. No full-body, contact, grasp, clinical, or biological qualification is claimed.

## Exact bundle files

`bundle-manifest.json` hashes every included file. `patches/001-shared-owner-mode.patch`, `patches/002-ground-aligned-placement.patch`, and `patches/003-selected-release-recruitment.patch` apply in that order. `patches/composed-clean-main.patch` is a single equivalent patch. `source/` holds the final clean app source. `preflight/` holds the source preflight and ABI14 compile/link record. `runs/activation-0.5/` and `runs/activation-0.0/` hold invocation, result, common failure receipt, stdout, and stderr. `runs/actuation-vs-zero-assessment.json` records the comparison and diagnostic limits. Large native `.mrvpack` outputs and binaries are intentionally left at their original evidence paths and are not part of this source publication bundle.
