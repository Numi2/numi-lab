# Compose regional weight repairs without overwriting other joints

The existing NHSKIN reference-rebind tool accepts multiple weight repairs against one pinned ancestor. Disjoint rows compose, identical overlapping rows are idempotent, and conflicting rows fail with a deterministic vertex witness. Source ancestry, registration fingerprint and binding transforms must match. The source is inverse-rebound once to preserve its reference surface. This mode imports weights only; geometry and topology changes require their own provenance and admission.

All 14 owner tests pass. An actual source test rejected an arm candidate that inherited a superseded finger repair at vertex 2008. Extracting its 585 arm-row changes against its own exact origin, then composing these with the 28-row accepted-source finger repair, preserved the neutral reference within 59.76 nm. The resulting candidate retains known shoulder/elbow crossings and strain failures and is unadmitted. It is not a new default skin or a physical/ROM qualification.
