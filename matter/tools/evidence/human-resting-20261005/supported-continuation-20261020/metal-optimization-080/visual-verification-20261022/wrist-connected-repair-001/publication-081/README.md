# Publication 081 — static layer-splitter hardening

This evidence-only increment updates the isolated canonical copy of `human_skin_fat_layer_reconstruction.py` and its tests. It fixes cancellation in clipped-face area calculations by translating polygon vertices to a local origin before summing cross products. It also adds optional `retained_sides` selection. The default `(-1, +1)` keeps the previous output. When selecting one side, the splitter first builds both halves, validates positive Float64 children and full per-parent volume/mass conservation, computes retained and excluded per-parent ledgers, then filters. Every returned cell still must have a strictly positive Float32 determinant; an empty selected result is rejected. Unused intersection points after filtering are counted in diagnostics.

`retained_sides` tests use a healthy positive tetrahedron and a separate tiny negative-only exterior tetrahedron whose Float64 volume is positive but whose Float32 cell collapses at its world offset. Retaining the positive side passes only after both parents are fully accounted. The default and the request to retain the collapsed negative side fail closed. This fixture is not a mixed cut-interface example: a collapsed cut triangle is shared by both halves and would invalidate either side if returned.

The combined inherited P079 suite with these two replacements passed **253 tests and 11 subtests** on `numi.local` using Python 3.13.16 and pytest 9.1.1. The exact command, canonical hashes, and output are in `evidence/test-suite-004/`.

The full-084 regression uses a deterministic nonphysiological plane only to exercise the splitter. It produced 8,402 vertices, 37,492 tetrahedra, and 1,042 shared-edge intersections from the 7,360-vertex / 32,796-tetrahedron 084 source. Output boundary triangles matched exactly (10,622 expected and emitted; no missing or unexpected faces; maximum face incidence two). Reference parent-volume relative error maxed at 7.26e-13. All emitted reference and mapped-current Float32 cells had positive determinants. Sixteen cells had owner quality below the 1e-6 warning threshold; the minimum was 4.87e-10 and remains diagnostic only. The output bytes match the previous default regression exactly. See `evidence/full084-split-004/` and `evidence/near-vertex-audit-004/`.

The earlier rounded-current-volume attempt is retained under `evidence/failed-rounded-volume-001/`: it stopped before writing a candidate because Float32 rounded child-volume sums failed a partition check. The later regression checks exact mapped-current Float64 volume partition and reports Float32 volume drift separately, while retaining strict emitted-cell positivity.

This work is static geometry construction evidence only. It does not construct or admit skin/fat anatomy, establish biological layer semantics, alter native runtime state, or qualify a physical step. The 084 asset and the synthetic scalar plane are pinned in the reports; the source asset is inherited from the existing 084 evidence rather than duplicated here.
