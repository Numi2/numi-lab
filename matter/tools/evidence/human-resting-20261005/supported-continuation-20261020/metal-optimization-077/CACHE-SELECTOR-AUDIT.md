# Cache selector and shader-statistics audit

Baseline: revision 245a7610ab21ed7c510bb4b8594e8f4b4b99de31 on numi. This is a read-only source audit; no GPU run or build was performed here. The lead's checker/runtime edits were present in the working tree and are outside this note.

The full direct stateless path and parallel cache columns use one selector. evaluateAlgorithmicStressTangent calls evaluateTangentVectorWithCandidate; columns 1-8 call that same helper directly. The helper selects the canonical compressible neo-Hookean tangent only when its compiler tag is present, the material is generic stateless bytecode with three parameters, forbidden state/dissipation/implicit programs and flags are absent, and no compensated tangent output is requested. If deformationLow is present, all nine entries must be zero; any nonzero low word falls back to bytecode. Thus there is no column-1–8 policy bypass at this revision.

The native checker change reported by the lead compares canonical-tag-selected and forced-bytecode direct/cache results over nine affine basis directions and six deterministic random directions, for all three canonical materials. The lead reports these selector parity cases pass, with maximum relative error below 8.51e-7. It covers arbitrary directions and the tagged-versus-bytecode choice. It does not establish the nonzero-low-word branch: add a reference-displacement-gradient fixture that proves at least one low word is nonzero, then compare tagged fallback against explicitly tag-cleared bytecode for direct and cached paths over basis and fixed-seed random directions. Keep a zero-low-word fixture to exercise the fast path. Include high-offset coordinates and rotated frames.

The installed Command Line Tools select /Library/Developer/CommandLineTools; xcrun --find metal resolves to Metal toolchain 32023. metal-objdump is unavailable, and metal -help exposes no register, spill, or occupancy report option. Available pipeline reflection can report limits such as maximum threads and static threadgroup memory, but not per-kernel spill counts. Treat spill/register usage as unknown; do not interpret missing counters as zero spills.

A bounded stateless follow-up is to precompute the canonical tangent's shared deformation invariants once per element (determinant, inverse transpose, and log determinant) for the nine cache columns, then benchmark that against the current repeated evaluation. A stronger bundle could form the 9-by-9 tangent map once and emit all columns; it trades repeated arithmetic for 81 coefficients and must be measured for occupancy and memory cost. Keep compensated nonzero-low inputs on bytecode. The current Human audit reports zero eligible materials among 20, so this path has no demonstrated Human workload or throughput benefit.

For a useful performance measurement, use a larger source-derived synthetic mesh with a confirmed eligible material, fixed state and directions, and exact cache-output comparison. Run warm paired A/B trials with the canonical switch off/on; time the prepare, column-build, and finalize kernels and report per-entry distributions. The current four-entry native parity fixture is correctness evidence, not a throughput benchmark. The compiler already applies per-scalar common-subexpression reuse; this bundle idea concerns sharing deformation invariants or the full tangent map across the nine direction evaluations.
