# Native whole-body study adapter admission

The existing intervention instrument now has a `run-native` entry point for a
frozen Human owner launch receipt. It runs `numi-human-native` with its native
viewer and movie, preserves the common asset identities, binds each arm's own
world fingerprint, and computes the same accepted-state observations used by
the reduced physiology diagnostic. It contains no simulation implementation.

Seven arithmetic, receipt, and runtime-log regression tests passed on the SSH
Mac mini. The retained six-second `cardiac-native-002` trace also parsed as
6,000 accepted steps on Apple M4 Pro. That short trace has insufficient complete
breath boundaries for a complete-breath ventilation estimate; it is reported
unavailable. The run has a known right-atrial geometric fold and is not qualified
anatomical evidence. These parser checks are not a new intervention experiment.

`retained-native-parse.json` binds the tested adapter and the parsed trace/log by
SHA-256. `tests.log` records the seven test outcomes. All Python execution was on
the Mac mini; the Air was used only to edit and transfer source and evidence.
