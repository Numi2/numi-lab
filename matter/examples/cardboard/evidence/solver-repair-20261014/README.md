# Complementarity derivative repair

The generic material compiler now evaluates the derivative of the exact
smoothed Fischer–Burmeister expression without subtracting nearly equal
numbers on its inactive branch. For `rho=sqrt(a*a+b*b+epsilon*epsilon)` and
`a>=0`, it evaluates `a/rho-1` as
`-((b/rho)^2+(epsilon/rho)^2)/(1+a/rho)`. Negative arguments retain the ordinary
well-resolved form. This preserves the authored equations, physical material
parameters, and solver tolerances.

The actual control-step-19 / Newton-3 capture traced the first large error to
that generated local derivative. At elastic tet 838, the former FP32
calculation introduced a false plastic chain: its derivative error was
68.99%. The repaired generated bytecode reduces that error to 0.0005232%.
Across 14,400 captured candidate inputs, the largest FP32 versus generated
FP64 derivative error is 0.02830%, below the 0.1% gate. This comparison holds
the captured candidate state fixed; it does not qualify the accuracy of the
native material projection.

The repaired native run passes the original rejection at step 19. Its captured
assembled action differs from the independent FP64 reference by 0.007624%,
below the 1% gate after exact FP32 input reconstruction. It then rejects at step 22 during residual descent, so it
does not complete loading, withdrawal, release, and relaxation. The centered
finite difference remains unresolved and no absolute noise floor has yet been
measured. Mesh and timestep convergence remain unqualified.

The clean `a9d801c` source plus this isolated patch builds and passes 1,425,357
CPU interpreter checks, including positive/negative complementarity branches
and the captured elastic regression. The native paper instrument passes its
existing stress, plastic-memory, and frame-objectivity regression checks. Its
legacy finite-difference threshold is 3%; a passing legacy check is not the
new 0.1% derivative qualification.

Component-scaled local residuals are available only as an explicit opt-in.
They preserve the exact residual zero set but currently fail at 365 of 14,400
replayed native inputs, all by exhausting 16 local iterations. They are not
qualified for production. The retained failures guide a safeguarded return-map
repair. No kraft/NSSC hardening, damage, or fracture measurements have been
invented to make these numerical tests pass.

The GPU instrument also accepts `--replay-captured INPUT OUTPUT LINER MEDIUM`
and the optional `--scaled-residuals`. Each input row has a safe key, `liner`
or `medium`, nine deformation-gradient entries, nine direction entries,
thirteen accepted state entries, and thirteen captured candidate entries. It
recomputes the candidate from accepted history; it does not prescribe the
captured candidate as the answer. Output files must be new. Rejected partial
states and terminal projection diagnostics are retained.

`qualification.json` separates the verdicts.
`external-artifact-manifest.json` binds full raw captures, histories, sealed
predictions, and source/binary snapshots retained in
`/Users/home/cardboard-implementation-20261014`. Compact observations are
copied alongside this file. Capture-on and capture-off production histories
are byte-identical across all 47 exported production files. Earlier defective
instrument fields are explicitly excluded from qualification; their original
records remain retained.
