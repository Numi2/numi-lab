# Cardboard release and resolution analysis package

This package contains five fail-closed analyzer reports, the current analyzer and its test source, and a residual-contract source map. Native runs, accepted states, compressed meshes, receipts, and deduplicated source archives live in the parent evidence package under `../runs/` and `../source-snapshots/`; per-run `source-archives.json` files resolve exact source hashes.

The paired endpoint screen uses a 10% relative threshold at common phase endpoints, with denominator floors of 1e-8 for volume-weighted plastic-strain RMS and 1e-6 N m for reaction moment. Widthwise refinement stays within these narrow thresholds. Temporal and lengthwise refinements exceed them. Thickness refinement was rejected at step 112 and has no complete paired endpoint; it remains inconclusive. This is numerical sensitivity evidence, not convergence proof or physical validation.

The analyzer run receipts bind probe/runtime/header versions that predate the current `femMechanicalResidualBuffer()` export and free-node force CSV columns. Current source is mapped in `source-snapshots/SHA256SUMS.json` to the parent's compressed archive and is not claimed to have produced these runs. Their observations do not contain the new free-force columns, so the reports assess plastic strain and reaction moment only. Current source review confirms the borrowed buffer holds the final assembled residual; xyz is impulse (N s), including inertia and contact, and constrained rows may also be populated by contact. The probe’s accepted constraint-tag filter selects free FEM rows before division by its one-substep dt, yielding a force-balance residual in N. This remains different from the 1e-4 mixed certificate, whose environment-wide generalized norm mixes FEM/field/MPM/rigid/support units and is divided by max(last Newton FGMRES initial norm, 1).

The CPU-only `initial-rest-fp32-audit-002.json` compares the FP32 `Ds * rounded inverse` arithmetic path with exact `I + grad(u)` at zero displacement. It estimates small elastic stress from the authored material tangents; CPU multiply roundings bracket plausible behavior but do not reproduce Metal instruction selection and do not establish causality for a rejected solve.

See `package-index.json` for classifications and source mapping; `reports/` contains complete JSON outputs. The source archive map for every run is under `../runs/<run>/receipt/source-archives.json`.
