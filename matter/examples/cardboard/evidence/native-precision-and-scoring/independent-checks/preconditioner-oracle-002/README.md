# Cardboard regional tangent preconditioner oracle 002

This record adds package round-trip and yielded-state checks to the direct
Metal diagonal oracle. The prior attempt remains unchanged in the sibling
`preconditioner-oracle/` evidence folder.

The targeted test built and passed on Apple M4 on 2026-10-06. The recorded
CTest output is in `logs/LastTest.log`; the target build and runner summary are
in `logs/preconditioner-build-004.log` and
`logs/preconditioner-check-004.log`. The run dispatched the preconditioner
kernel directly with `physical_steps=0`.

The package check compiled the nondefault regional-tangent preconditioner and
local material Newton budget 16, wrote and reread a package, validated the
layout, and required both fingerprints and both nondefault controls to survive.
It passed for both paper materials.

The elastic and yielded material-point diagonal comparisons were:

| Material / state | Entries | Max relative error | Max absolute error |
| --- | ---: | ---: | ---: |
| Liner, initial state | 12 | 2.72786e-05 | 54.3262 |
| Medium, initial state | 12 | 2.69773e-05 | 41.7709 |
| Liner, yielded state | 12 | 4.15745e-05 | 15.6455 |
| Medium, yielded state | 12 | 2.02512e-04 | 389.301 |

The yielded states were generated by the independent FP64 Hill oracle at
`F = diag(0.99, 1, 1)`. Both had returned `q=1` and positive plastic work:
liner accumulated multiplier 0.00235114 with work 0.0538882 MPa; medium
accumulated multiplier 0.00521895 with work 0.0490112 MPa. The GPU diagonal was
compared against centered finite differences of force projected from those
same accepted states. The acceptance threshold is 2.5% relative error.

This verifies a local preconditioner arithmetic path and package persistence.
It does not establish improved FGMRES convergence, a successful assembled FEM
load step, or physical cardboard validation; those are separate solver and
material evidence questions.
