# Cardboard constraint reaction and springback observables

`box-grip-reactions.csv` records one row per authored grip group and environment for each attempted shipping step. A row is valid only when the entire native transaction is accepted. Its mechanical constraint channel reads Matter's prescribed-node reaction buffer, which contains the continuum, cohesive, external-load, gravity, and inertia terms assembled for the accepted endpoint. The separate contact channel reduces the same final rigid and deformable contact samples used by the production residual. Rigid proxy impulses are negated and divided by each object's timestep; deformable residual impulses use the production contact/source timestep scaling. The two FEM-side channels are added once for the reported support force and moment. Moments use the accepted FEM node positions and the centroid of active tag-3 grip nodes. The finite-mass proxy reaction remains in its own native body ledger. Human attachment tag-2 reactions are excluded and remain owned by the separate Human attachment path.

The runtime contact reduction is read-only and runs only for the final certified primal-contact candidate. It writes a separate `femConstraintContactForceBuffer`; it does not change the nonlinear residual, contact history, proxy reactions, or accepted state. A failed transaction produces invalid reaction rows with blank numeric channels, rather than reusing a prior buffer value.

`box-score-springback.csv` compares the last accepted, supported held geometry captured immediately before temporary clamp release with the accepted endpoint after release settling. The floor support remains present, so this is clamp-release springback under the declared support condition. Wall/joint angles are fitted from the source blank at both endpoints; flap angles use the same flat source reference for both. Each row is observable only when both endpoint fits satisfy the configured RMS residual and coverage limits, the released transaction sequence is accepted, all temporary and prescribed node constraints are gone, and the final free-node speed is within the existing settle limit. An unattempted, rejected, or unsettled release writes rows with `springback_observable=0` and an explicit reason. It never substitutes an action-relative `box-score-angles.csv` measurement for a held-to-released delta.

`cardboard_reaction_observables_check.cpp` is a CPU arithmetic check for impulse signs, deformable timestep scaling, environment bounds, Human exclusion, accepted-position moments, and channel addition. It does not exercise the Metal contact reduction or qualify a physical grip, crease, springback, or box assembly. The native target must still verify a rigid and a deformable contact action/reaction against the corresponding proxy/contact ledgers on an accepted constrained grip.
