# Source-166 reference Jacobian repair

This reference-only overlay fixes a cancellation defect in differentiating the independent reader's rationalized Fischer-Burmeister (FB) residual. It leaves the rationalized **residual value** and all projection, line-search, and strict-gate policies unchanged. It does not change native Metal or solver code.

The authored row is `phi = sqrt(dl^2 + y^2 + eps^2) - dl - y`. Its derivative is assembled analytically:

```text
dphi = (dl/root - 1) d(dl) + (y/root - 1) d(y)
```

For positive `dl`, the first coefficient uses `-(y^2+eps^2)/(root*(root+dl))`; for positive `y`, the second uses `-(dl^2+eps^2)/(root*(root+y))`. Those equivalent forms avoid subtracting nearly equal values. The `y` gradient uses `-Hill-flow` for normal stresses, `-2*Hill-flow` for shear stresses, and the two authored hardening/history coefficients for states 13 and 14. All other Jacobian rows and the residual calculation retain source166-002 behavior.

At tet 846's exact captured elastic trial seed, `dl=0`, the rationalized denominator is `1.0953666745999648542e-14`, just above the old `1e-14` branch cutoff. Source166-002's complex-step quotient derivative was about `1.86138e7`; the patched row gives `-1`, matching the direct 80-digit derivative. It also matches the 80-digit FB row at the resolved MP root. The source166 reader now projects tet846 in native469's center state and the returned reference state differs from the independent 110-digit MP state by `2.37e-14` L2.
