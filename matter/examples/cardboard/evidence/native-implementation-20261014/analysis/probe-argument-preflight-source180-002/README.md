CPU-only native argument admission before mesh/Metal creation. --validate-only runs the existing parser and cross-option checks, emits a strict JSON contract, and returns before execute or capacity-file loading. It does not claim file admission, native environment-selector admission, memory admission, or physical qualification. This catches the real native479 forbidden resume+checkpoint combination without a GPU attempt. No solver/physics changes.

CMake registers the CPU-only check when Python is available.
