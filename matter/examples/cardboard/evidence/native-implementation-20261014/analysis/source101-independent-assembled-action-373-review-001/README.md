# Independent review of the 373-v3 correction-scale erratum

The dynamic state-scale expression in frozen source101 `common.metalinc` is `max(abs(acceptedState), abs(candidateState), scaleFloor)` per state. The solver sets `scaleFloor` from material parameter index 26, which these assets name `fb_epsilon`. It solves `J * delta = -r` after column scaling by these state scales and row equilibration by the weighted L1 row norm; its stopping quantity is the infinity norm of the dimensionless correction `delta/stateScale`.

The v3 audit computes the same mathematical quantity. This review independently solved both the direct system and the row/column-equilibrated system in FP64 after the bounded residual-descent continuation. Both produce a maximum scaled correction of `1.94362983304928e-8` (direct) / `1.943629833049281e-8` (equilibrated), at tet 781, below the `2e-8` criterion. The full 1,728-row correction and scaled-residual vectors exactly match the sealed v3 NPZ (`max abs difference 0` for each). The initial iteration still has 1,031 rows above the correction threshold; one residual-descent Newton continuation brings all rows below it.

The maximum independently weighted reference residual is `1.3490895735317928e-10`, below its `2e-10` reference check. The authored equations use a uniform residual scale of 10; conservatively, this bounds the production unweighted residual norm by at most `1.3490895735317928e-9`, below even the minimum compensated projection tolerance `2e-8`. The residual bound is derived from the equation scale and reference norm; it is not an observed native local solve.

This verifies the dynamic correction coordinate and the bounded FP64 reference gate, not a native float32 projection. The root v3 report has no false correction-gate result, but its own input bindings do not include `common.metalinc` or the frozen-source manifest; this review supplies both exact hashes. Its `maximum_paper_iterations` field reflects the stock reference projector count and should be read alongside the separately recorded one-step continuation, rather than as a total including that continuation. The assembled action is a single rejected-direction comparison (0.74204294%); no physical transactions or general solver qualification are claimed.

The independent reference emitted the same eager-`np.where` divide-by-zero/invalid warnings observed in the small-epsilon replay; they were not suppressed.
