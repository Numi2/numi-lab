# Retained-input comparison after FB value repair

All 3,456 accurate-policy points return valid stress and tangent projections.
All 26 prior nonzero medium action comparisons now meet the 0.1% norm gate;
all six prior rejected liner points converge. Default-policy words remain
identical to run296. The complete report is lossless `report.json.gz` with a
tested restoration and hashes in `summary.json`.

These are one captured action per point. The 1,728 zero directions do not
qualify derivatives without measured absolute floors. The original NumPy
reference also stops too early at some near-yield points; its results are
preserved, with the independent higher precision correction recorded separately.
This package does not qualify all directions, element assembly, contact,
complete trajectories, mesh/time convergence or material calibration.
