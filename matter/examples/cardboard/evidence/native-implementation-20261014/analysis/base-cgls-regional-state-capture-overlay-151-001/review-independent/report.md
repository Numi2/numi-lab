# Independent review: source151 regional CGLS capture

## Verdict

The source151 observer is physically read-only by construction: it snapshots the selected state/regional buffers through blit copies into new private shared buffers and writes files only in completed-command-buffer callbacks. The regional snapshot copies the candidate FGMRES arrays, RAP arrays and selected selector-specific smoother/graph buffers; no production operator, accepted history, or physical state buffer is written by these capture routines. The feature remains opt-in and bounded by the existing 96 MiB combined capture ceiling. I reran the reader's standard-library contract suite: 17/17 tests pass. This is parser/observer review only; there is no actual selector-5 sidecar payload or native arbitrary-vector apply output in the package.

## Selector-5 readiness

The prospective schema has enough *array kinds* to build a selector-5 CPU map reader for a non-augmented same-generation capture: effective `P`/`AP`, base RAP factors, candidate fixed tags, graph patch descriptors, sorted membership, scalar row map, node-to-patch CSR, coverage, original local matrices, LU, pivots, and factor-valid words. Source149 kernel paths establish the composition `S = H + (P - H AP) R^-1 P^T`, where `H = G D E`; `D = F + F(I - A_p F)` is the single production refinement pass and `G` averages overlapping patch outputs. In exact real arithmetic, `D^T = 2F^T - F^T A_p^T F^T`, and the transpose of the coarse-corrected map is `H^T + P R^-T(P^T - (AP)^T H^T)`. A future reader must preserve the actual mask, selector variant, and patch averaging order.

The current capture cannot yet support a rigorous augmented same-generation replay. The restart tag has `(control, substep, Newton, restartCycle)`, but the manifest has no selected/consumed restart cycle. `read_regional_capture.py` compares only the first three tag components (`candidate/tools/read_regional_capture.py:423–434`); source149 restart augmentation is consumed in the next cycle after the cycle that writes its generation (`fgmres.metalinc` restart-mode formation/selection). Thus tag component `.w` needs a consumer-cycle relation, not merely a current-Newton check. The state record `NMFGMRESStateGPU` contains diagnostics and nonlinear fields but no restart-cycle index. Do not accept augmented arrays for replay until capture binds the selected cycle.

The reader is a structural parser, not a proof of a graph factor/action. It checks selector-5 hash syntax, descriptor/row/CSR consistency, pivot indices in range, and boolean factor-valid words; it does not compare topology/free-mask hashes to actual compiled topology inputs, recompute the graph layout FNV checksum, require valid pivot permutations, or finite-check every graph matrix/LU element. It also does not emit selected-environment graph factor status as a replay-admission verdict. A downstream consumer must independently bind source topology and free mask, validate factor permutations and finite values, select a healthy environment, and reject invalid patch factors.

Finally, the source151 schema has no actual same-generation selector-5 capture fixture in its validation package and source149 has no production selector-5 arbitrary-vector output or transpose kernel. The current source149 reference therefore appropriately leaves selector 5 unsupported. Its selector-3/4 manufactured reference remains bounded CPU evidence only: 7/7 tests pass and the three production source-file hashes match the source149 contract. No selector-5 map/transpose result is promoted by this audit.

## Boundaries

No source151/frozen runtime was edited. The selector-5 reference was not expanded into a synthetic map-only implementation because that would not satisfy the requested same-generation evidence condition. A future version can implement the replay when it has (a) the selected restart cycle, (b) a source-bound topology/free-mask input matching the captured hashes and layout checksum, (c) validation of numerical factor state, and (d) a native arbitrary-vector selector-5 output to compare.
