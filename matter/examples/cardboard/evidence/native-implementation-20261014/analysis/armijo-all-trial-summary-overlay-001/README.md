# All-trial Armijo summary capture overlay

This diagnostic overlay adds a selected-root/selected-Newton readback of every bounded full-contact FEM Armijo trial. It is based on frozen source115 and changes only `matter/src/runtime.mm`. It does not change kernels, residuals, acceptance, tolerances, or production history.

Set both `NM_FEM_COUPLED_TRIAL_SUMMARY_SELECTOR=root:iteration` and `NM_FEM_COUPLED_TRIAL_SUMMARY_PATH=prefix`. The selector is zero-based. The existing full-contact residual-Armijo and source-scope guards still apply; the summary cannot share the bounded readback with center, operator-FD, or full-trial capture. Files are written as `prefix.summary.bin` and `prefix.summary.json` with exclusive creation.

The capture records eight stage-status snapshots per trial: geometry validation, bulk/material mechanics, cohesive residual, rigid contact, deformable sweep CCD, deformable endpoint narrowphase, completed full residual, and measured predecision state. It also records loop-entry and predecision metrics, postdecision metrics plus the raw FEM/environment line-search fractions, one global status per trial decision, and final selected-state arrays. Loop-entry metrics distinguish inactive slots after an earlier accepted trial. `stage_and_decision_status_copy_count` counts the eight stage copies plus the postdecision global status for each trial; it excludes the entry and final status arrays. The final selected fraction is copied from the production environment line-search buffer; it is not reconstructed.

The packed layout is little-endian and trial-major, then stage, then environment. For line-search budget B and environment count E, the descriptor count is `8 + 5*B` (168 at B=32). With the current 48-byte status record, 16-byte metric vector, and 4-byte environment fraction, the payload extent is `E*(180 + 532*B)` bytes (68,816 bytes at E=4, B=32). Runtime admission independently checks exact source-buffer extents, checked 64-bit products/sums, the existing 32 MiB aggregate cap, device `maxBufferLength`, and the 192-array cap before recording. The byte formula and stage count are source-bound by the portable contract test.

Validation performed: `tests/test_contract.py` passes against the frozen115 runtime/header and overlay. No C++/Objective-C++ or Metal build and no native/GPU run were performed for this overlay; it is ready for root integration and source-bound build/parity testing, not solver qualification.
