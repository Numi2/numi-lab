# Source220 checker endpoint identity repair

This isolated overlay repairs a diagnostic admission predicate only. Source558 failed after ten exact input rows were loaded because its p23 endpoint check demanded a change in packed F[0]. The source547 row declares basis column 2, so the endpoint changes packed F[2] and corresponding Fdot[2]; F[0] is correctly unchanged. The immutable input confirms that only packed words 2 and 20 differ for the p23 endpoint (word 11, the F-low companion, remains the center value), with the exact generated high/low/rate relation verified by the new CPU admission check.

The overlay validates all eight p22–p25 endpoints against declared basis, sign, epsilon, and dt, and requires every other packed input word to match center bit-for-bit. Accepted-state and source547 input SHA binding are unchanged. The final native-only assertion checks F[2] and Fdot[2] after CPU admission validates all endpoint words.

No material equations, solver policy, tolerance, iteration budget, source547 input, or production code changes. Native558 is preserved as a failed diagnostic preflight. The modified Objective-C++ translation unit passed clang syntax-only with the source220 include paths, target headers, policy macro and -Wall -Wextra -Wpedantic -Werror. This does not build or link the checker and does not dispatch Metal.
