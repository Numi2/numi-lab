# Source186 opt-in candidate: scale-invariant IPC feature mollifier

This package contains a one-file external overlay against frozen source185. It changes only `matter/src/metal/contact.metalinc::ipcFeatureMollifierDifferential`; source185 and the shared checkout are unchanged.

The prior implementation measures `|a|^2 |b|^2 - (a·b)^2`, a quantity with units of length to the fourth, then compares/clamps it against `kGeometryFloor = 1e-12`. This makes the angular mollifier depend on mesh units. The frozen implementation first returns zero whenever the product is at or below that floor. The source-extracted baseline regression confirms that orthogonal 0.5 mm edges return 0, while orthogonal 5 mm edges return 1.

The candidate robustly normalizes each finite nonzero edge by its maximum absolute component, computes dimensionless `sin^2(theta) = |u × v|^2`, and applies the same C1 polynomial `r(2-r)` with `r=clamp(sin^2(theta)/1e-3,0,1)`. It returns exactly zero value and gradients when either edge has exact zero length. Nonfinite inputs or an unrepresentable active physical gradient return NaNs so callers’ existing finite checks reject the candidate. The gradient differentiates the cross-product expression, then applies the tangent projection `(I-uu^T)/|a|` or `(I-vv^T)/|b|`; this avoids differentiating one rounded angular expression while evaluating another.

CPU validation extracts the production function body from the candidate and compiles/calls that body with a small vector compatibility layer. Across edge scale factors 0.1, 1, and 10 it checks value against an independent double oracle, scale-adjusted gradients against an independent analytic chain rule, central finite differences, exact-zero degeneracy, parallel zero, orthogonal saturation, and nonfinite fail-closed behavior. It also compiles and runs the source-extracted frozen baseline at 0.5 mm and 5 mm as a negative control. Results: candidate max value error `2.70684283e-08`, max scale-adjusted analytic-gradient error `4.60538299e-06`, max scale-adjusted finite-difference-gradient error `0.00151096886`; baseline shows the expected 0 versus 1 scale-dependent output.

A standalone Metal kernel calling the production function compiles successfully with the candidate overlaid on a temporary source185 include tree. This was compile-only: no metallib was linked and no Metal device or GPU dispatch was used. The compile emitted two pre-existing `-Wsometimes-uninitialized` warnings in unchanged `fgmres.metalinc`; they are retained in `metal-compile-receipt.json` and are outside this overlay.

Apply `overlay.patch` only to the exact base bound in `source-overlay.json`. This is an implementation candidate, not native solver qualification. The separate nearest-point and segment denominator defects remain outside this package; the parent is auditing those independently.
