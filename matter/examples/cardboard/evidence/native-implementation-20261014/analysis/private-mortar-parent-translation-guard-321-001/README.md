# Whole-parent mortar contact skip candidate

This package extends the exact-tiling-only candidate based on source snapshot `source-center-action-twoenv-restart-099` (parent revision `35bfb518c542a306f563cc364ef8496837068b9a`). Apply `whole-parent-identity.patch` only after the exact-tiling patch from `analysis/exact-mortar-tiling-only-source099-001`. The patch changes three files; CMake registration is inherited unchanged from that base. See `manifest.json` for source-file and build-artifact hashes.

The contact path skips ordinary complement CCD only when both sides independently prove exact full Q25 cohesive coverage, their parent triangles use the same exact vertex permutation at both endpoints of the linear sweep, and every partition cell is paired one-to-one by the same cohesive face index with exactly matching computed 3D start and end vertices. Cell positions are evaluated with the same FP32 barycentric-to-world mapping used by CCD. This last check prevents independently complete but cross-wired patch tilings from being treated as a bonded pair. Any uncertainty or mismatch falls through to existing CCD.

The CPU suite passes 24 checks, including the exact fan and four-tile partitions, whole-parent linear-sweep identity, an alternate-barycentric adversarial path, correct permuted parent storage, and negative controls for swapped patch IDs, cross-wired physical cells, and a one-ULP endpoint difference. CMake builds the existing `numi-matter-mortar-exact-tiling-check` target and its CTest passes. The complete Matter Metal source compiles and links to a metallib; the compiler reports two pre-existing FGMRES maybe-uninitialized warnings (`sharedValid` and `refinementValid`). No GPU/native run was made, so this remains an unqualified candidate.

The guard is deliberately narrow. It does not suppress contact for relative motion, opening, shear, deformation, incomplete coverage, more than four partition cells, non-Q25 cells, or computed FP32 world-point mismatches. The prior local initial-witness exemption is excluded: one CCD witness cannot certify the rest of its feature query. This package does not claim multi-patch shipping qualification.
