# Source 159-003: bounded local closure and accounting repair

This isolated overlay extends sealed source 159-002 over immutable source 157. It only changes the post-run accepted inside-surface diagnostic and its host memory accounting; it does not alter the FEM, contact, cohesive, solver, assembly, or acceptance equations.

The wall coverage domain is now panel-local. It is formed from accepted nodes referenced by exterior broad faces classified to that authored wall panel, then clipped against the accepted cavity-facing plane. A global object-node hull had admitted adjacent flap and neighboring-panel score-edge nodes: the synthetic nominal wall domain measured 0.0681 m² instead of its 0.0600 m² panel. The panel-local topology mask prevents that inflation. The accepted coverage union is tested over the full convex wall domain, so an interior opening cannot hide under aggregate rest-area coverage.

For each end, the footprint still comes only from accepted wall planes. The width axis is oriented from authored major flap panel 0 toward panel 2. That gives the two accepted authored free-edge fits a stable signed ordering under rigid rotation, reflection, and face winding. The only permitted exposed region is the corridor between those two accepted edge lines, with a maximum 1 mm separation. The 1 mm is an explicit engineering screen, not a measured kerf. Exact clipping must cover the rest of the wall/end domain; the separate 1% dimension-target comparison remains unchanged and is not used as an opening allowance.

Coverage arithmetic reports an area floor equal to the larger of clipping roundoff and twice the source FP32 coordinate ULP times domain perimeter. Inputs whose largest accepted position ULP exceeds 10 micrometres fail closed because local opening checks would no longer be resolved. This is a numerical resolvability bound, distinct from the 1 mm seam allowance and the 1% target comparison.

The grid-work counter now includes both triangle-to-cell posting passes, both cell-directory passes for every constructed grid, and query posting scans. Work accumulates across the whole measurement and rejects above 32,000,000 units. Grid-build postings had previously been bounded per grid but were missing from the aggregate count.

Workspace accounting now has separate bounds for three V2-per-surface-face retained free-edge samples, recursively retained candidate lists, and clipped footprint polygons, in addition to four end-plane projections, one wall projection, the panel-local node mask, wall hull/triangulation scratch, and existing topology/grid storage. At the nominal synthetic count (1,477,728 tetrahedra, 528,444 nodes, 1,054,876 surface faces), the checked estimate is 1,028,812,212 bytes, below the unchanged 1 GiB cap. The synthetic scale preflight contains no accepted geometry, material state, blank provenance, or physical assembly; its resident fixture bytes and modeled scratch estimate are reported separately.

## Validation

`tests/run_validation.py` runs local geometry and memory contracts at `-O0` and `-O3`, then Objective-C++ syntax-checks the modified probe against the source-157 compile command. `tests/run_scale_preflight.py` checks nominal topology and memory/workspace arithmetic at `-O3`. `tests/check_patch_application.py` applies the patch in a disposable temporary directory and verifies exact candidate hashes. No full source build or GPU/native simulation was run.

The synthetic checks include a one-millimetre wall slit occupying 0.333% of the wall, a valid 0.5 mm authored seam, a rejected 2 mm seam, uncovered area outside the seam corridor, mirrored/reversed geometry, explicit grid-build, empty-cell-query, query-posting and candidate-list bounds (including a successful exact subdivision case), a coarse-FP32-coordinate rejection, and the panel-local domain regression. These test geometry algorithms only. Actual shipping geometry, complete assembly closure, calibration, and physical qualification remain unexecuted.
