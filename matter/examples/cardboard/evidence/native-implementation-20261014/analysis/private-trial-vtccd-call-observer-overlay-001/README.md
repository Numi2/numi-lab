# Exact private VTCCD call observer, overlay 001

This diagnostic-only overlay binds one exact `vertexTriangleCCD` invocation inside the production `nm_contact_narrowphase_deformable` kernel. It records the helper's actual endpoint arguments and returned `hit`, `certified`, `toi`, and `separation` for one selected private Armijo trial, candidate slot, primitive pair, vertex, and direction. It does not replay or approximate the helper, modify solver/contact status, or alter acceptance.

The selector is `NM_FEM_COUPLED_TRIAL_VTCCD_AUDIT_SELECTOR=root:iteration:trial:environment:slot:primitiveA:primitiveB:vertex:direction`. It must match `NM_FEM_COUPLED_TRIAL_CAPTURE_SELECTOR` and requires a full private-trial capture in `both` or `post` phase. The one-record private Metal buffer is 336 bytes. The capture adds one typed array, below the existing 192-array and 32 MiB limits. `attempt.w` packs `direction * 3 + vertex`; all six start/finish points are in left-then-right primitive order. Normal, barycentric coordinates, and witness point are meaningful only for a certified hit; otherwise the zero-initialized fields are explicitly invalid. `attempt.x == 0` means the selected candidate/feature call was not reached.

For the retained source121 failure, the exact summary-selected trial is 21, slot 173, primitive pair 36/123, vertex 2, direction 1. To compare the first feasible trial, repeat with trial 22. The two runs must use the same physical arguments and differ only in output directory and the two diagnostic selector values. Expected capture tuples are `1201:9:21:0:173:36:123:2:1` and `1201:9:22:0:173:36:123:2:1`.

Validation here is compile-only. The ObjC++ runtime passed strict syntax checking and the complete Metal translation unit compiled. Metal reported two existing `-Wsometimes-uninitialized` warnings in `fgmres.metalinc` (`sharedValid`, `refinementValid`); neither is in this overlay. No GPU run or physical/contact qualification is claimed. The next native run should verify that the inline record is emitted and bind its result to the source121 retained failure state. The trial21 unresolved CCD return is not by itself proof of collision.
