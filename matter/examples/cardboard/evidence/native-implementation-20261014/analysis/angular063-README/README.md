# Angular free-BOX source overlay (frozen 063 base)

This isolated overlay applies to frozen source commit `5fd4486ea2bcbe903782509a769ce3935b790e55` and the exact snapshot manifest recorded in `source-overlay.json`. Apply `angular-063.patch` only to that base. The patch contains four files: the contact and FGMRES Metal implementations, two runtime argument bindings, and a CPU formula test. The runtime delta is limited to the new candidate-buffer binding for `nm_fgmres_apply_free_rigid` and the accepted-node/bridge/current-body bindings for the swept validator.

The implementation is limited to one non-articulated six-DOF free BOX. Candidate endpoint orientation uses the same normalized quaternion update and small-angle series as MetalWorld. Armijo alpha-path and full physical-timestep geometry are reconstructed from the exact tested candidate; conservative advancement includes the proxy center offset in the angular radius and rejects uncertified paths. The smooth frictionless tangent covers face, edge, and corner features, including SO(3) left-Jacobian effects, witness/normal motion, inverse-inertia response, and torque.

The independent CPU oracle now handles negative and mixed-sign local features. Eleven checks cover signed face/edge/corner finite differences with fixed-seed directions, angular inertia, scene/candidate orientation endpoints, small-angle integration, alpha-path and physical rotating-sweep bounds with an offset proxy, friction rejection, and the shader's displacement-scaled normal differential. Metal compilation, metallib generation, and Objective-C++ syntax checking all passed; exact artifact hashes and commands are in `source-overlay.json` and `validation-receipt.json`. No native GPU run was performed.

Active frictional free-BOX samples fail closed because the six-row tangent does not yet differentiate the friction/contact-history law. Feature transitions, impact-stiffness branches, articulated or multiple free bodies, adaptive rate subdivisions, MPM, and mixed/cohesive contact remain excluded. This overlay does not qualify shipping-box impact or full rotational contact.
