# Measure the V1 landing adapter's actual hover response

The 0.25-to-0.15 algebraic offset change removed an apparent mathematical bias but drove the bird approximately 0.20 m ahead of the landing target in the physical trial. The closed-loop controller includes nonzero feed-forward and coupled flight dynamics, so an algebraic zero error is not necessarily a physical hover. Before further descent tuning, measure a matched sweep of post-waypoint-five adapter offsets 0.18, 0.21, 0.24 and 0.27, holding the privileged target height at 1.30 m so this is a free-flight alignment diagnostic. Use the same full-start development J scene and seed, 16 substeps, 2200 ticks, unchanged V1, body, toe mechanics, actor and routing. Preserve the existing 0.25 translation before waypoint five.

For every arm require identical first-episode q/v through waypoint five to the retained toe-memory baseline; record failed steps, first termination/collision and accepted-step obstacle clearance. Compare horizontal root error relative to the existing foot-aligned target, RMS error, forward velocity, tilt, and vertical state over ticks 1900–2200; retain every outcome. These are matched development trials, not held-out evidence, a landing, a demonstration or a proof of robustness. Any later choice is exploratory and must be independently tested in actual descent with the full-perch observer.
