# Localized route adaptation: waypoint gain, landing failure

On the used development layout and seed, all eight teacher-off first episodes reached all five waypoints, compared with seven of eight for the previous actor. Two lanes subsequently suffered physical failure. One lane had final bilateral opposing foot support, but this is not an autonomous sequence qualification. The correction data include the evaluated lane, so these results are not held-out evidence. Landing and release require further testing.
