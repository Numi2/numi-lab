The target observer found a strong association between control-boundary target changes and joint motion, but not causation. In a research-only chunk-size-one setup, preserve each lane’s preceding accepted target in an extra trajectory region and linearly interpolate knee and ankle targets across the 16 physics substeps. No direct forces or visual animation are added. A sham with the same extra storage and action code, but unchanged physics target use, must exactly reproduce all retained q/contact substeps before the candidate is interpreted. A first-episode reset initializes history from the new target. This experimental memory scheme is not qualified for general chunk sizes, rollback, or production use.

Replay the same used-seed teacher-off 300-interval development walk with the retained instrumented host. Compare exact sham parity, every observed q and contact, unsupported substeps, foot-clearance bouts and boundary versus within-interval second-difference proxies for both knees and ankles. Reject if parity, physical coverage, support, or the motion-proxy and locomotion checks worsen.
