# Exploratory route-prefix actor

This supervised development experiment trained on 447 sampled observations from one physically reached J recovery prefix and reserved 112 samples from that same trajectory as an in-trajectory diagnostic. It excluded the landing segment. Corrective-label loss decreased over 120 epochs; the diagnostic mean absolute command errors changed from [0.0207, 0.1730, 0.0790, 0.9861] to [0.00594, 0.0491, 0.0182, 0.0320]. These correlated samples are not an independent holdout, and reduced imitation error does not establish navigation performance.

The initial actor-only pack could not be opened by the generic PPO learner because it had no critic. A critic/log-variance scaffold was added only to construct the supervised learner; it was not used in the loss. Its actor outputs were identical to the original at sampled inputs. The native residual evaluator then correctly rejected the trainable pack because it requires a deterministic actor-only pack. The deterministic export removes the scaffold and matches the trained actor outputs exactly on the sampled inputs; the rejected attempt is retained in `crow-v15-prefix-eval-20261110/actor-pack-rejection`. Teacher-off full-start evaluation is separate and must determine whether navigation actually improved.
