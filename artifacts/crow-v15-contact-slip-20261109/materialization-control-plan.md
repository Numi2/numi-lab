The isolated host-library variant materialized correct articulated foot velocities before task completion. The active velocity-feedback controller then changed physical states, as intended. To isolate whether materialization itself changes the original gait through observations, rewards or later solver state, repeat the same 350-step two-lane reference with the original feedback-live shader (no velocity correction) and the materializing host library. Compare the full selected-lane q, v, body states, actor observations and reward with the original-library feedback-live recording. Retain any difference and both physical outcomes. This is an exposed nominal behavior control and cannot qualify full navigation, landing, grip or other tasks.
