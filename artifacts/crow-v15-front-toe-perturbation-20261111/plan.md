# Perturbed starts for contact-driven toe hold

A 1,000-tick independent replay of the single development start passed the stationary terminal grip/support gate but had intermittent earlier grip. Test the same controller on the eight previously checked physically separated development starts, with paired lanes: candidate contact-driven front-toe feedback versus the matched fixed-front baseline. Starts vary longitudinal position by +/-6 mm, roll by +/-0.04 rad, and longitudinal velocity by +/-0.025 m/s. Run 1,000 ticks each without resets using the same 16-substep body and solver. Require each candidate to have 100 consecutive terminal bilateral opposing-grip and support samples, no other-body support, bounded speed/tilt, grip-pose overlap at most 0.5 mm, and no solver failure; require exact reproduction of the 1,000-sample single-start reference, early candidate/baseline matching, and equality of all initial shape records to the previously audited separated starts. This is a robustness screen, not release, in-flight landing approach, full route, time-step convergence or real-bird calibration. Preserve every outcome and use no unused layouts.
