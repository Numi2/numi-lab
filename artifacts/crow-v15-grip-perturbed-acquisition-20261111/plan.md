# Grip acquisition across perturbed perch starts

Local rear-toe tuning did not meet both the endpoint-overlap and continuous-force criteria in a single developmental start. Before further tuning, measure how the strongest force-continuity near miss acquires and releases under different initial physical conditions. Keep rear relief 0.014 rad/tick, reclosure 0.008 rad/tick and high/low normal-cone thresholds 0.006/0.002 N s after release, with all body, other controls, perch, solver, and 16-substep mechanics unchanged. Lane 0 must reproduce every saved state from the corresponding prior lane. At reset only, the other 15 lanes vary root x or height by up to 2 mm, roll by up to 0.01 rad, forward speed by up to 0.01 m/s, or combinations within those limits. Apply no subsequent state changes or external force. Record every start and allow 1500 continuous ticks.

This is a falsification-oriented diagnostic, not a promotion test: report how many acquire the existing 50-sample release gate, form a clear unloaded left-foot release with opposite-foot support, and regain 100 terminal samples of supported opposing horizontal force. Also retain the existing strict <=0.5 mm endpoint-overlap and no nonfoot-contact criteria; the unperturbed reference is already known to exceed the overlap limit, so none can establish overall qualification. Record terminal state and each failure, including falls or never acquiring. These are constructed stationary perch starts, not physically reached arrival states, other-foot release, a complete course, independent final layout, or biological validation.
