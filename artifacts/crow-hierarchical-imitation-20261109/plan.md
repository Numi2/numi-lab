# Full-route command imitation, initial trial

Train the separate four-command actor on the 24 physically qualified first episodes from three development layouts. Retain only each manifest-qualified lane, exclude the uninitialized first action label, and sample every fifth accepted control step through all five waypoints and landing. Use lanes 0–5 per layout for fitting and lanes 6–7 for a within-layout development validation; neither is a final-layout test. Balance six waypoint stages in the supervised loss, fit only the first four normalized command outputs, and retain the baseline head/beak outputs with a separate distillation term. Use deterministic shuffling and fixed 0.0001 Adam learning rate for 60 epochs; no critic or PPO gradient participates in this trial. Record input hashes, stage counts, per-command validation errors and output policy hash. Evaluate the resulting actor teacher-off from full starts in physical simulation and judge full-route supported finishes, not imitation loss. Student-visited correction is a separate DAgger step.
