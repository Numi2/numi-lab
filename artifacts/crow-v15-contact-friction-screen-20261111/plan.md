# Exploratory v15 toe/perch friction screen

Question: is toe/perch friction a limiting factor in a previously observed grip and release failure? The existing v15 hip-roll, two-segment-toe model uses shared uncalibrated material friction values 0.8 static and 0.6 dynamic for both foot/toes and perch; this contact path combines the two materials by geometric mean. Prior gait contact-point observations had nonzero tangential speed, while a separate supported-perch case lacked rear-toe contact. Slip, insufficient force, geometry, balance and controller timing are competing explanations; no biological coefficient is known.

Retain the existing stationary staged-release probe, eight constructed development lanes, body, gait-independent contact controller, 550 control intervals, 32 physics substeps, solver iteration settings and explicit narrow perch. First rerun the original material and require exact q/v parity against the archived staged-release trace; if parity fails, the comparison is invalid. Then repeat the same starts with only the physical foot/toe material replaced by 1.8 static and 1.35 dynamic. Against the unchanged 0.8/0.6 perch this sets effective contact values to 1.2/0.9 by the solver geometric mean, 50% above baseline. Other body and scene material assignments remain unchanged. The coefficients are exploratory and are not species-calibrated.

Before the high-friction test, predict that at least one of eight lanes will satisfy the existing combined supported release and terminal regrip gate, compared with zero of eight in the retained baseline, without more falls, additional nonfoot contacts, native failures or degraded contact-observer coverage. Retain all outcomes and report individual lanes, supported opposition, release clearance, contact and fall metrics. Reject this coefficient as a complete grip-and-release fix if any gate fails. This stationary development test does not establish takeoff, flight, autonomous landing, object manipulation or biological realism. Do not use final reserved seeds or layouts. Stop after the matched control and candidate.
