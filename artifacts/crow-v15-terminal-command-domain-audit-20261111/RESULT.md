# Terminal command screen versus frozen flight evidence

In the retained localized-route development run, reconstructing the terminal guidance speed command from same-numbered endpoint pose, velocity and logged final-goal error yields 140–474 samples per lane below 0.15 m/s during the observed phase-one approach, out of 275–798 matched phase-one samples per lane. Reconstructed per-lane medians range from 0.135 to 0.146 m/s; reconstructed values in this run were nonnegative. The frozen controller evidence covered separate speed commands from 0.15 to 0.85 m/s and specified disturbances, not arbitrary combined commands or a perching approach. Below-range commands are therefore outside that particular screen, not automatically unstable.

The telemetry is sampled at accepted control endpoints; the source uses task state on the following control step, and this reconstruction has not been checked against applied-command instrumentation. These results identify a qualification gap and are not evidence of the cause of a fall. The flight controller source remains unchanged; additional terminal-command qualification or a demonstrated feasible approach is necessary before full-sequence claims.
