# Contact-triggered release and return

The isolated -.15 rad knee release reproduced both 13-interval clearance windows, then both birds fell at intervals 268-269 after continued one-foot balance. Preserve this failed case. On those same two constructed starts, keep the acquired-grip and release rules unchanged, but after ten consecutive accepted intervals in which all left foot/toe collision boxes are at least 1 mm from the perch and the left foot has no final-substep impulse while the right foot has support and opposing toe contact, return the left leg to its original target. Clear the left toe contact latches so it recloses only when actual contact returns. No body teleport or external force. Require the original strict ten-interval release test, then bilateral supported opposing grip throughout the final 100 intervals, no fall, no nonfoot impulse, all substep measurements, and compare pre-return q/v to the isolated run. The geometric gate uses separating-axis box distance, to be independently checked against the analysis. This is a development stationary release-and-regrip probe, not flight arrival, walking, or full landing.
