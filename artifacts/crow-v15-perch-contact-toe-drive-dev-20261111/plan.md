# Perch-specific two-segment toe drive candidate

The physical descent generated perch contact but the 38-velocity body had no corresponding GPU toe-drive branch. This isolated candidate maps all 16 toe joints to bounded position targets and advances each foot's closure ramp only from accepted contact between that foot/toe and the actual perch after the five waypoints. It decays on loss of contact. Body offsets are specific to the fingerprinted experimental 33-body model and must be checked independently. This is not a release policy: no explicit release request is implemented. Compare with the unmodified descent candidate, require unchanged first-episode flight before perch contact, verify body/dof mapping and contact association, and independently measure sustained opposing normals, weight support, no failure and re-release before any promotion.
