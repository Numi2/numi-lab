# Experimental hip-roll pre-release shift

Test the 35-body prototype using physical hip roll position drives, no injected forces. Eight lanes use four target amplitudes (0.10, 0.18, 0.26, and 0 radians) with two constructed starts each. After fifty bilateral support readings, ramp both hip targets over 75 control intervals, wait 100 intervals from shift onset, then release only after ten consecutive bilateral support readings and regrip using the existing contact-driven toe controller. This early experiment is not a gated autonomous controller: the fixed wait tests the sign and range of actuation, and no target has been qualified. Native substep contact observation is remapped for the two inserted bodies; validate against named endpoint contacts. Evaluate toe clearance, opposite-foot support, bilateral return, body balance, and trace the shift itself. This body adds 20 mg and must undergo full flight and contact requalification. The experiment does not touch reserved layouts.
