# Correction: exploratory front-toe target exceeded modeled joint range

Review of `c_api-round-perch.cpp` shows prototype toe DOF limits of [-0.3, 1.2] radians, effort limit 0.02 and drive gains 0.1/0.003. The experimental stronger front-toe law is `min(0.04*frontRamp, 1.30)` with a counter that can reach 32 for the front toes; this can request a proximal position of 1.28 radians, outside the +1.2 rad modeled limit. Actual recorded joints were approximately +1.2, but the current evidence does not establish the details or correctness of the solver's limit enforcement. Accordingly no experiment using that target is an acceptable final actuator controller; the corresponding outcomes and videos remain valid as development observations, not qualifications. Previous labels of the command as bounded did not mean it respected the modeled joint limits.

The next test caps front proximal target at 1.20 rad, retains the original distal multiplier 0.75, and uses the same aligned round fixture. It must satisfy the existing first-episode physical gates and explicit target-limit audit; a single local pass would still not qualify an autonomous original-course landing or general robustness.
