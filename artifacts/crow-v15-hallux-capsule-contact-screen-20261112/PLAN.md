# Rounded rear-toe contact proxy: matched physical screen

The retained-state geometric screen found that a capsule using the existing 5 mm toe width could raise the near-hinge collision surface during toe flexion while preserving neutral 18 mm longitudinal extent and neutral plantar height. Test the actual contact behavior on the original 40-DOF v15 body with only four rear-toe collision boxes changed to x-aligned capsules (radius 2.5 mm, axis half-length 6.5 mm, center z -6.7 mm). Preserve joint topology, anchors, actuator properties, body masses and inertia, collision exclusions, materials, offsets, all other shapes, actor weights and action transforms. This is an engineering collision proxy, not a measured American-crow digit or muscle model. Recompute bounding radius and audit shape changes.

Before any long test verify the default policy contract rejects the modified world; independently compare non-world observation/action hashes and all radius entries; diagnostic-only rebind unchanged weights after that audit, with explicit acknowledgement sensor values can change. Run same-binary box control and require exact reproduction of retained amplitude sweep on the used seed; run a two-step capsule smoke, then a 300-step 8-lane 16-substep no-reset contact trial with the same per-lane amplitude sweep. Retain every failure. Require complete first episodes and all previously specified support, gait, low-toe, point-speed and rear-first order gates versus held control; record capsule-specific self-collisions and contact pairs, and do not score after first failure. A short pass is not a biological qualification, nor walking, takeoff, flight, grasp or landing completion.
