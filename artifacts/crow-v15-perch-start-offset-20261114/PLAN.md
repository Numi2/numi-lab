# Dynamic sensitivity to a 2 mm rearward start

At one retained grip-loss posture, a fixed-pose SAT grid found four common-foretoe near-surface settings at -2 mm model x translation versus one at the original placement; this does not establish dynamic feasibility or grip. Test whether that small initial position difference affects the actual contact-driven constructed release and return. Lane 0 is the existing baseline and lane 1 begins 2 mm rearward relative to the same fixed perch. All other initial q/v, controller commands, actuator limits, friction, geometry, solver and pitch gains remain identical. The initial conditions deliberately differ, so this is not a matched-state controller ablation and cannot establish that the late grip failure is caused by foot placement.

Run 450 intervals, archive exact q/v and controller/physics traces. Check control-lane parity against the earlier retained baseline; report whether each lane establishes bilateral support, releases, returns and obtains the registered 100-interval terminal bilateral opposing-toe grip, with no fall, nonfoot impulse or toe-speed-limit hit. Report support streaks and first failures even when no candidate passes. This is a controlled sensitivity test, not a walking, landing or mission qualification, and must not be used to select the reserved mission layouts/seeds.
