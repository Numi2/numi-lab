# Rear-toe torque counterfactual failed

Doubling only the modeled stance right rear proximal toe effort limit from 0.02 to 0.04 N m from the initial state did not produce a usable grip. Both identical treatment lanes had only one qualified single-foot release interval, did not reach the return state, and first fell below 0.1 m root height at interval 363. The unchanged archived control had 43 release intervals, returned, achieved an 11-interval bilateral grip streak and fell at interval 370. Both treatment lanes reached the 12 rad/s toe-speed threshold before falling. All 450 states and all 32 contact, toe-velocity and modeled toe-effort substeps were present with no observer or nonfoot impulse errors.

The first accepted state different from the prior control was zero-based interval 23, so the changed limit influenced the earlier trajectory; this is not a same-state intervention at the later grip failure and does not isolate a unique cause of that failure. Treatment right rear proximal effort reached the new 0.04 N m cap and remained there throughout intervals 280–360. It is an exploratory parameter sensitivity, not a biological torque measurement. The increased limit is rejected, the prior model limit is retained, and source, exact executable, input hashes, controls, full outputs and failures are preserved. Contact/state epochs remain independently unverified; this does not establish walking, takeoff, landing or mission qualification.
