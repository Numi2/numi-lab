# American crow: finite nutritional intake transaction

Native Metal prerequisite for lifelong embodied intelligence. This checkpoint
does not complete the ecological environment, qualify a feeding policy, model
solid food mechanics, or restore a complete world.

The FiniteResourceContext extension runs on MetalWorld's accepted post-commit
stream. Physical mouth/head poses and jaw coordinates determine open-close
gesture intake from body-anchored volumes. Integer micrograms transfer from
finite patches into a capacity-limited nutritional crop. Holding closed cannot
repeat a bite. A miss consumes the gesture. Overlapping patches give one debit.
Rejected physical steps do not advance the ledger or its lifetime clock.
Ordinary task resets cannot refill resources. The module never writes physics.

On macmini M4 Pro, four physical trials each used eight lanes and 448 control
steps / 8.96 seconds. Canonical starts consumed exactly 45,000 micrograms in
three bites per lane; head-yaw misses consumed zero. Chunks 8 and 64 produced
bit-identical ledger state. Reset-after-depletion preserved that depletion.
All physical trials had zero physics failures and physical terminations.
The bounded checker took approximately eleven seconds including context and
pipeline creation; it is not a sustained training throughput measurement.

Synthetic GPU controls independently check rejected physics, pre-dynamics
exclusion, overlapping sources, held closure, exhaustion and crop capacity.
Resource-only checkpoints preserve the clock and jaw latch and reproduce the
same future resource trajectory under identical synthetic physical inputs.
Their identity binds the world and complete resource program. Restore rejects
truncation, bit corruption, trailing bytes, changed world identity, and a
conservation violation even after its checksum is recomputed. Rejections leave
the accepted resource state unchanged. SHA-256 authenticates accidental
corruption, not an adversarial writer who controls both data and checksum.

All prospective plans, results, action-derived lane accounting and resource
checkpoint bytes are retained here. Trials 01-04 are negative results. The
first manual run lacked a required reset-mask stream; its original native
directory contains its plan but no captured stderr. Trial 02 retains the
specific reset-mask diagnostic; trial 03 exposed the author's incorrect FK
output dimensions. Trial 04 used randomized starts: several mouths missed
the small fixed intake volume, correctly consuming no food. This is not a
failed conservation mechanism and is not behavioral qualification. The v2
prospective plan separates canonical transaction admission from randomized
search. Trials 05, 06 and 07 passed; the last also uses ARC in the checker.

The six native CTest checks passed, including run/task compilers, robot catalog,
active-head mechanics, first-episode evidence, and finite resources. Fourteen
Python crow harness checks passed; some are synthetic qualification fixtures,
not biological or behavioral results.
