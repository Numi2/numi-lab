A telemetry-only replay confirmed that during grip the hybrid solver detects the 5 mm toe overlap and applies normal impulses; the accepted rigid shapes still overlap. Test whether increased velocity-solver work changes the same v15-body single-perch case. Vary only velocity iteration count 4, 8, 16 and 32; preserve hybrid CCD, all bird CCD flags, SAT shader, timestep, two final iterations, physical geometry, material, joint drives and controls. The 4-iteration arm must reproduce every logged state sample from the matched hybrid case. Report all solver failures, simultaneous grip/support, release, terminal support, normal impulse and independent SAT gaps. Compare maxima during opposing grip as well as all closing/holding samples. More iterations can destabilize coupled friction; improvement at this one start only motivates broader matched tests and does not qualify a production solver or autonomous sequence.
