# Collision-matched isolated grip comparison

The speculative original and open-toe controls reproduced all their prior logged trace samples exactly. Both hybrid/SAT arms completed all eight starts without reported solver rollback; the original speculative closing control reproduced its step-21 rollback in case 4. With hybrid/SAT and original closing, only 2/8 starts met the simultaneous supported-grip, release and final-support sequence. Four starts had at least three simultaneous opposed-grip and supported endpoints. Worst independent accepted-pose toe–perch SAT gap at opposed grip was -5.034 mm, similar in magnitude to the full-route result and substantially deeper than the speculative bench's -0.505 mm. The open-toe hybrid control retained final support in only 4/8. The two cases that passed the sequence still had 4.8 mm worst grip overlap and do not qualify physically.

The test changed collision flags, hybrid CCD and the SAT shader together; it does not isolate which causes the difference. It matches the full host's relevant collision mode and shader but still uses a different stationary scene, fresh contact cache, start state and controller. The measurement samples accepted control endpoints, not substep peaks; the shape overlap is not calibrated biological deformation. No held-out layout or continuous landing is established.
