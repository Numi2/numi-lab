# Matching the full v15 collision configuration in the isolated grip bench

The previous exact-dimension toe studies used the default speculative CCD and default collision shader, but the full autonomous crow host uses hybrid CCD, enables CCD on all bird shapes, permits 16 events, and uses a research SAT collision shader. Those earlier bench rollbacks and controller rankings cannot be directly attributed to the full host. Compare the original speculative baseline with this combination of actual full-host collision settings.

On the same eight supported development perturbations and exact v15 toe/perch dimensions, use four arms: original closing with speculative/default collision, original closing with all bird CCD flags plus hybrid CCD and the full-route SAT metallib, open toes with speculative/default collision, and open toes with hybrid/SAT. Preserve the 4 substeps, four velocity and two final iterations, toe stiffness, body and contact actuation. Set hybrid CCD capacity and event limit to the host values. The two speculative controls must exactly reproduce prior traces; retain every rollback and status. Measure simultaneous opposed grip plus bilateral support, release, terminal 25-step support and independent accepted-pose OBB SAT overlap. This changes the CCD mode, shape flags and collision shader together to match the full host; the contribution of individual changes is not isolated. The single stationary-perch scene, its initial poses, controls, capacities and contact cache still differ from a full route, so this is not route or biological validation. Unused layouts remain untouched.

The first batch was stopped after six cases when the open control internal release schedule was found to differ from the original open control. The incomplete trace and source are retained. Repeat after restoring the original simultaneous release schedule for both open arms; the disabled toe targets themselves were unchanged.
