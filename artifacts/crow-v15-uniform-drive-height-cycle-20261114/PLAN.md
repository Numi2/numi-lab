# Uniform-drive climb and descent cycle

The common-role uniform-drive straight and opposing-turn screens passed eight lanes on used seed 20261126. Test a continuous altitude cycle in all eight lanes, using that exact straight task and actuator world except for the height command schedule. Command 0.55 m initially, ramp to 0.80 m at 16–16.5 seconds and back to 0.55 m at 26–26.5 seconds. The fixed schedule is a diagnostic, not a general runtime command interface.

On the training layout with teacher off, no scheduled resets and 16 substeps, compare each lane against its own uniform-drive straight reference through interval 790, before the height commands diverge. Use the established finite/coverage, contact, speed, tilt, effort and height checks over the full 1,800 intervals. For every lane report the mean height in intervals 650–780, 1050–1200 and 1650–1800; require each later window's mean absolute tracking error to its respective 0.80/0.55 m target at most 0.05 m, and a mean rise and subsequent fall each at least 0.12 m. Report command reconstruction error, first failure and all exceptions. Keep all outcomes. This is not qualification of general commands, disturbed recovery, leg-powered takeoff, landing or unseen-layout mission completion.
