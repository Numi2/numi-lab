# Sensitivity to a sectional-flow modeling assumption

The current v15 wing calculation uses full three-dimensional incoming-air speed for the wing-element dynamic pressure, while angle of attack uses chord and normal projections. Classical two-dimensional blade-element approximations instead use the velocity perpendicular to the span (NASA rotor theory: https://ntrs.nasa.gov/api/citations/19790013868/downloads/19790013868.pdf). Spanwise flow can nevertheless contribute to real flapping-wing lift (https://ecommons.udayton.edu/mee_fac_pub/126/), so neither approximation is assumed to be biologically correct.

Evaluate the same 72 retained flight endpoint q/v states through the existing wing kernel and a diagnostic variant which removes spanwise incoming velocity before the wing force calculation. Preserve everything else, and identify inputs, source and binaries by hash. Require the original results to match the prior audit and both evaluations to repeat identically. Report sampled wing force and root-yaw-moment differences as model sensitivity only; not a calibrated correction, net whole-body load, integrated wingbeat, simulated trajectory, or basis to promote the variant. The sampled endpoints are dependent and not a representative animal dataset.
