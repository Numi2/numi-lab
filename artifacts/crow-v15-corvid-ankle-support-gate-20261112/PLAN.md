# Support-gated stance ankle phase

All fixed increases in ankle phase magnitude produced brief both-foot unloading. In the same .125 hip, .10 knee stance controller, test .11/.115/.125 ankle magnitude only while the opposite foot has accepted contact; otherwise revert to the .10 baseline. Accepted contact is delayed by one 20 ms control interval. Keep original controls, matching baselines and the same per-foot contact speed, progress, toe limit, simultaneous unloading and physical stance-phase measurements. This tests an engineering control hypothesis, not a calibrated biological gait.
