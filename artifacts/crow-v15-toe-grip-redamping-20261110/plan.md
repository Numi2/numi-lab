# Toe pinch after duplicated damping removal

The developmental isolated perch pinch had 8/8 perturbed starts with opposing fore/rear contact loads and subsequent commanded release on the former toe body. That body included duplicate per-toe world damping, since removed to restore flight. Repeat on the otherwise identical eight-hinge toe model with the toe world linear/angular damping set to zero. Use the same centered 50 mm box, 150 native 20 ms control periods with four physics substeps, and all eight combinations of +/-4 mm root x offset, +/-0.025 rad roll, +/-0.015 m/s initial x velocity. Compare four arms per start: force-gated closure and release, rear-only, sensor-zero control, toe-collision-off control. Per active trial require both feet to show at least three consecutive accepted endpoints of opposite front/rear normal impulses exceeding 0.00005 Ns each, followed by loss after a physical release command; require the sensor-zero and collision-off arms not to advance to grip. Preserve all case/arm contacts, phase, joint angles, root state, failures and source. Exact reproducibility is restricted to the native build and shader libraries; no unknown outcome is deleted. This is a seeded already-supported isolated pinch, not a physically reached landing, ongoing dynamic balance, full route or calibrated crow anatomy. Follow-up must incorporate physical landing and release.
