# Symmetric actuator response during unassisted flight

Eight previously used seed-20261127 training-course starts, same smooth contact-latched push and body moments disabled from time zero. Lanes 0–1 are untouched controls; 2–3 receive positive/negative symmetric sweep target offsets; 4–5 positive/negative symmetric pronation; 6–7 positive/negative tail target. Offset 0.25 normalized action is ramped in over 9.0–9.5 s through normal bounded joint drives, no new wrench. Compare each lane against its own matched unmodified run and verify exact trajectory/contact parity through 9 s; log all joint speeds and contact and inspect altitude, attitude, forward/lateral velocity, physical failures and any scene collision through 16 s. This is an exploratory model response screen on a used course, not an obstacle-free qualification, realistic aerodynamic calibration, or evidence of completed navigation.
