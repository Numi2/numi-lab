# Continuous capture development test

Test a clipped position-and-height correction fitted to earlier constructed-perch screens. Lanes 0 and 1 reproduce controls; other lanes include previously difficult starts and one new within-range combination. This uses privileged initial perch-frame state and uncalibrated high friction, so it is not an autonomous landing. Require clearance, supported opposing grip, return, stable bilateral final grip, no falls or non-foot contact, and exact control parity.
