# Gradual balance recovery after toe release

The prior high-traction constructed-perch test found two lanes with sustained release but an individual foot briefly lacked load during the final regrip window. That controller maintains the weight-shift hip-roll target after the foot returns. Test whether ramping this joint target back to neutral over 1, 2 or 3 s after the existing contact-conditioned return improves bilateral loading. Keep lanes 0–1 unchanged controls and all original body, material, contact sensors, release and grip gates. Require exact controls and an exact pre-recovery trajectory for each lane, the original supported 10-interval release, 100-interval supported bilateral regrip without falls or nonfoot impulse, sensor validation and complete substep coverage. Eight constructed development lanes, not a real landing or biological validation; high traction remains uncalibrated.
