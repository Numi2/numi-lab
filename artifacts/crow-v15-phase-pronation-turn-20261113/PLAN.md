# Phase-gated pronation turn identification from leg launch

The fixed-state Metal audit found phase-dependent differential-pronation yaw sensitivity on both banked used-seed lanes, with substantially less mean roll coupling during positive left-flap velocity. The phase relationship was selected posthoc from those same data, so the following is a new development experiment, not held-out confirmation. A fit to the retained states suggests positive flap velocity when 0.55*sin(phase)-0.83*cos(phase)>0; it is an approximate clock-phase proxy, not a measured velocity. Using the unchanged all-body-wrench-ablated leg-launch straight-flight source as baseline, add equal and opposite physical pronation target offsets up to 0.04 rad, using smoothstep(-.2,.2,0.55*sin(phase)-0.83*cos(phase)) for phase gating, an onset/offset ramp from 12 to 24 seconds and opposite command signs in lanes 6/7. Retain their prior launch onsets, the baseline lateral feedback, body, aerodynamic kernel, model damping, run configuration and all other actions. No bank or sweep turn command is added. Run used seed 20261126 only; retain all output and compare each candidate with its own archived same-seed straight-flight baseline, including exact state/action prefix through the onset. Require first-episode completion, the unchanged leg-launch, ground-contact, nonfoot, speed, altitude, flap and support gates, pronation targets and accepted positions within the actual +/-0.35 rad limits, measured pronation joint speeds <=25 rad/s and efforts <=0.1501 N m, full expected effort/target observations, and signed differential peak heading >=0.10 rad in opposite directions while peak lateral deviation from baseline remains <=2 m. Report actual tracking error and fraction of actuator saturation rather than treating commanded targets as achieved motion. This is a development identification test; passing would not establish perturbed-start recovery, qualified flight, autonomous navigation, biological realism or landing. Stop treating a lane as valid after its first termination; preserve failures. No reserved layouts or seeds will be used.
