# Stage-aware corrective training

Inspection of the frozen controller revealed that waypoint stages 0-1 execute actor channels 0-3, stage 2 executes 4-7, stage 3 executes 8-11, and stage 4 executes 12-15. The preceding trainer only fitted channels 0-3 and additionally anchored channel 15, so it could not directly correct most executed late-stage commands. Before any new trial, decode the actual active expert block from the teacher labels in each recorded rollout, train that block against the four teacher commands, anchor only channels 16-17 and the existing early-stage output, and preserve stage balancing and the source qualification gates. Teacher labels in channels 0-3 are copied into the active expert block by the native shader. Log per-source block counts and any discrepancy against transition-reported stage; exclude failed episodes and landing labels. Freeze the output and evaluate teacher-off full starts on both development layouts before any tuning. K/L remain unused.
