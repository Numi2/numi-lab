# Per-wing aerodynamic load observer

Instrument the existing obstacle-free host without changing the aerodynamic or task shaders. On each substep in control intervals 451–500 and 701–750, copy the body-wrench buffer immediately before and after the existing flapping-wing kernel, plus the source q/v. The difference is the force/torque contribution of that kernel for each wing and the root; the wing wrench is about the corresponding body COM. Check body indices against the replay model and record the source-state and observation phase explicitly. Run the exact 800-step bank-screen command and compare every retained sparse q/v/policy sample with the uninstrumented bank run. Rejected parity, incomplete records or GPU error invalidate the observation. Report applied per-wing loads, wing q/v and integrated signed angular impulse proxies with their reference frames; do not interpret root torque alone as total wing-generated body moment because the wing forces act at moving lever arms and joint reactions matter. Instrumentation is diagnostic only and does not qualify the flight or promote a controller.
