# Aerodynamic load replay diagnostic

Replay sparse retained flight endpoint q/v samples from the two matched wing-steering runs through the same corrected experimental GPU flapping-wing kernel, with the resolved v15 body's bilateral wing parameters, tail and fuselage. Read the wing-body wrenches and re-express wing torques about the modeled root using native forward kinematics. Compare left and right resultants and yaw moments between the two runs. This uses the simulation's own force model and is not an independent aerodynamic measurement or a full microstep integral; no aerodynamic coefficients are fit or changed. Source, binary, model program and retained input hashes must be identified, and values checked for finite outputs and exact sample coverage. This is a diagnostic, not a flight qualification.
