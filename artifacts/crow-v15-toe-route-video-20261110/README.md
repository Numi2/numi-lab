# Toe-equipped routes: incomplete replay

Two previously exposed development layouts, recorded from reset-free accepted simulation states from the causal contact-triggered takeoff test. Both reach five waypoints; layout I then strikes the perch with its body and layout J exceeds the tilt limit. The respective failure frames are excluded; the video stops immediately before failure and labels it. It does not demonstrate a supported landing or toe grip/release. It samples every second accepted state at 25 fps, preserving real-time speed. The renderer does not map the simulated toe joints; feather and support-plant presentation are estimated. Exact replay hashes, source artifact and rendering provenance are in provenance.json.

The run used incorrectly bound navigation camera assets; see the warning overlay and visual-binding fix evidence. This is not evidence of correctly registered visual navigation.
