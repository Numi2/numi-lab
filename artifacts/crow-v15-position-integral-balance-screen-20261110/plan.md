# Position-error integral balance

Accumulating pitch alone eventually drove the bird backward. Compare the exact lean-aware 20-second reference with two candidates that, only once both toe targets have opened and foot support is detected, accumulate the signed position error relative to the existing lean-aware target. The integral updates at the 20 ms control interval, is bounded to +/-0.1 m s, can unwind when the error reverses, and contributes to the existing bounded hip position target with gains 0.5 or 1.0; pitch, toes, contact and joint bounds stay unchanged. This is a control experiment, not biological calibration. Require exact 1000-state reference parity and candidate parity through tick 117, supported opposing grip and release, <=0.5 mm worst grip-conditioned overlap, no solver failures, and every one of the last 850 samples supported with open toes. One stationary development start does not qualify acquisition, flight or untouched layouts.
