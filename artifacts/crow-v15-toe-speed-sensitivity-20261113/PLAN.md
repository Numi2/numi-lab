# Toe velocity limit sensitivity: development diagnostic

The no-walking-toe launch trial produced 74 rear proximal toe post-substep speeds >=11.99 rad/s; none were near that threshold in the copied pre-contact candidate velocity, and 58 had positive normal impulse on the same toe segment. The model configures 12 rad/s on each toe degree of freedom; source contains velocity clamps. This does not establish which exact active kernel or constraint caused each result.

Diagnostic intervention: change only the v15 toe velocity-limit parameter 12 to 24 rad/s in the same observer C API model builder, leaving toe masses, position/effort limits, drives, contacts, controller, 160 ms push and all other settings unchanged. This is an intentionally uncalibrated numerical sensitivity test: it is not a recommended physical modification and cannot qualify the v15 body or biological realism. Use the same previously field-parity-qualified target/contact observer, 8 lanes, seed 20261127, 400 steps, 16 substeps, with suppressed wing amplitude; lanes 2–7 prespecified. Run one bounded candidate, retain all lanes, no final seeds or layouts.

Validity: verify the c_api source differs from its exact previous observer by the one limit edit, bind all binary/input hashes and confirm complete first episodes and no overflow/errors. Because a changed limit could affect earlier walking, require recorded state/action/contact parity with the original model through step 345 for a paired push-window interpretation; if parity fails, retain the run and report it as a different-history model sensitivity, not a causal push comparison. Require 368 target samples. Record threshold events at >=11.99 and >=23.99 rad/s, max actual speed, foot impulse 348–365 and 348–375, root rise, unloading, nonfoot contacts and work proxy. The original-model active-crouch comparison changes body settings and is descriptive only. Preregistered sensitivity prediction: if the 12 rad/s cap materially suppresses these events, one or more comparable lanes will reach speed magnitude >12.1 rad/s in steps 348–380 under the higher limit. This observation alone does not demonstrate a realistic or useful takeoff; all six must independently meet the prior lift and impulse screens under a physically supported model before further qualification. Retain every outcome.
