# Counterfactual aerodynamic yaw sensitivity

The corrected v15 simulation turns poorly and existing aerodynamic replay sampled only sparse instantaneous loads. Use the same GPU aerodynamic kernel, v15 model fingerprint and previously retained flight states to evaluate local perturbations of wing sweep and pronation coordinates while holding other sampled positions and velocities fixed. Report resulting left-plus-right wing yaw torque about the body and finite perturbation size for each state; include a repeatability check and baseline equivalence against the earlier evaluator. These are counterfactual static evaluations, not applied rollout forces, integrated yaw impulse, actual achievable trajectories, biological data or proof of controller authority. Never adjust model coefficients or promote a controller from this diagnostic alone.
