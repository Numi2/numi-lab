# Isolated 40-body free-space dynamics probe

The two-segment, eight-digit prototype preserved the tested neutral-body invariant checks but failed native GPU admission because 33 bodies exceed the existing 32-body ABA limit (its 38 velocity coordinates remain within the existing 40-DoF limit). In an isolated build only, raise the ABA body-array and host admission bound to 40 while keeping all other library objects and the original DoF/q bounds unchanged. Compile a matching ABA Metal function and run the same 36 invariant cases and 12 GPU-versus-CPU cases, with all sixteen added coordinates actuated and repeated native results exact. Retain the initial rejection and build failure. This only explores the standalone free-space dynamics path; no contact solver, production ABI, route, flight, performance or perching claim follows, and no main source header is edited.
