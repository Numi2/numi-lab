# Isolated 40-body dynamics: accuracy gate failed

The original 33-body two-segment-toe prototype passed the 36 neutral aggregate invariant comparisons, then the unmodified native GPU path correctly rejected it against the 32-body limit. The initial compile failure is retained in the adjacent two-segment prototype directory. With an isolated host admission bound and matching ABA Metal function of 40 bodies, the 33-body/38-DoF model ran, all added toe coordinates moved, and repeated GPU output was exact. Its worst GPU-versus-independent-CPU scaled acceleration error was 5.84104e-5, above the preregistered 5e-5 limit; the test therefore failed. The maximum was lane 0, DoF 20, CPU 0.000144338 and GPU 0.0000859190. A 25-body control on the same wider isolated build passed with maximum error 3.60113e-5. Several 33-body samples also exceeded 5e-5 in DoFs 15 and 18. This localizes the accuracy regression to the wider model and/or its numeric conditioning, but does not establish a specific cause.

This does not admit the widened engine, toe model, contact solver, flight or landing. The isolated host library reuses other existing objects and is not an ABI-compatible production capacity change. No performance or biological claim is made. Exact build inputs, diagnostics, logs and hashes are retained; the normal project source and shaders were not modified.
