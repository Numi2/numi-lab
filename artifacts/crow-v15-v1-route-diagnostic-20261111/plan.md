# Frozen V1 flight adapter compatibility diagnostic

The existing navigation actor was trained with the V2 flight adapter. Test whether it has any usable compatibility with the selected walking and leg-powered launch and V1 flight adapter on the already-exposed J development course. Use the existing V1 connected flight shader, toe-body runtime, existing corrective navigation actor and landing actor; teacher disabled; one full start, 16 physics substeps, no resets, 3000 ticks. Record every accepted state, replay, collisions and clearance; report the first failure or last waypoint and the observed state. This is an exploratory compatibility diagnostic with an actor trained for a different command interpretation, not a qualification of flight, landing, or either final held-out layout. Do not alter or inspect the reserved K/L layouts.
