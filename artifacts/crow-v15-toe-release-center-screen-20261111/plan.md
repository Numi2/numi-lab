# Perch-centered body position for release and regrip

The retained regrip trials lose opposing toe contact after the releasing foot returns and then pitch forward. The release-phase gain sweep alone did not prevent this. Test whether a more rearward body-position setpoint improves contact geometry: compare center targets -12, -25, -40 and -60 mm for two constructed starts each while retaining the original .5 hip-feedback gain, .2 s velocity damping, acquisition, geometry-triggered release and return logic. The -12 mm lanes must reproduce the existing control. Position targets remain bounded and drive actual joints; no external support forces or teleports. Require 10 supported clear release intervals, sensor parity, final 100 intervals of bilateral opposing grip, no fall/nonfoot impulse, complete observations and no solver errors. This is a developmental stationary perch screen, not flight landing or biology qualification.
