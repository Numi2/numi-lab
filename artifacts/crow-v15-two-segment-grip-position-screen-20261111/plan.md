# Batched stationary toe-grip position screen

Two preceding stationary starts indicated a narrow reach problem: the original x position contacted only rear segments, while a -10 mm shifted start brought front segments into contact. Test eight simultaneous, independently simulated lanes using the same 33-body two-segment model, neutral leg drives and contact-triggered toe controller. Initial x shifts relative to the original are 0, -2, -4, -6, -8, -10, -12 and -14 mm; all other start conditions are identical. Each lane runs 350 control steps with 16 substeps and no intermediate reset. Record all accepted q/v, per-segment oriented poses, endpoint contact and full substep impulses. Lane zero must exactly reproduce the prior single-lane grip screen, including controls and accepted q/v; otherwise report parity failure.

For each lane require 50 consecutive intervals with bilateral upward impulse >= half body weight, no nonfoot impulse, tilt <=0.35 rad, root speed <=0.12 m/s, opposing signed normal forces on front and rear digits on both feet, and <=0.5 mm endpoint oriented-box penetration. Report each lane, including falls, incomplete grip and first losses. These are intentionally constructed development starts, not physically reached arrivals, held-out cases, walking, release or autonomous navigation. Preserve all samples compressed in Git.
