# Staggered reset test for separate contact sensor, preregistered

Compare aliased and dedicated sensor hosts using the same existing v15 body, policy, negative ankle feedback and seed 20261126. Enable the runner's staggered per-lane resets across 300 steps; seven of eight lanes have scheduled resets by the end, and lane 7 resets during the prior sensor window. Record the same q, v, states, toe contacts, active-window sensor values, and lane-5 replay. Check exact same-lane parity at logged precision against the prior host, report reset counts, inspect lane 7 sensor values immediately around reset, and retain failures. No reset-specific correctness claim is made solely from equality to the old implementation. The dedicated publisher should leave the sensor invalid outside its episode window. Checkpoint schema compatibility and rollback remain separate untested issues. This is a development run, not a continuous mission.
