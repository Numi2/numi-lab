# Native mixed-route task

The mixed route is available as `v15-waypoint-expert-navigation`, with its own task ID, fingerprint and schedule flag. It uses the v15 body and frozen flight law, the visual route actor except at waypoint index two, and a goal/proprioception expert during that waypoint; the landing actor takes over after all five waypoints. The actor is therefore not a pure visual navigator. Both output heads map to the same bounded speed, lateral, heading and height commands.

The old task's policy packs are rejected by the new contract. Rebinding explicitly preserved every actor weight and transform and verified unchanged world, observation and action fingerprints; only the task fingerprint changed. In a matched development run, the integrated build reproduced all first-episode outcomes and all sampled physical states of the experimental implementation. The evidence observer reproduced the ordinary build's outcomes and all 3,000 recorded q states in a full checked trajectory. The controller source SHA-256 remains aa2fe10901cb0494d80ae445902303a17ce0e73d030072bab09461d8f3593ebe.

Four targeted runtime/embodiment checks passed, and the runtime rejected a stochastic/critic policy even without a base actor. This stage-selected contract is deterministic execution only: generic PPO training is explicitly rejected because its likelihood and loss need a stage-aware action mask. Teacher labels can be recorded for the active specialist outputs; this does not itself implement that training objective. Clearance evidence is a control-step endpoint sample rather than a continuous-time minimum. Current performance is development evidence only; reserved final layouts remain untested.
