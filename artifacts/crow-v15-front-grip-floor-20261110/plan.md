# Supported front-toe grip floor

On matched original-body J and I release windows, endpoint observations showed bilateral front/rear opposition in 86/100 and 74/100 samples. The raw commanded front closure averaged 1.0259 rad when J had bilateral opposition versus 1.0038 when it did not; I values were 1.0519 and 1.0345. This correlation does not establish causation. Test whether retaining a 1.08 rad minimum front closure target only after the existing supported landing phase improves opposed contact, leaving the toe geometry, drive gains, release logic, gait, push and frozen flight law unchanged. This is a different current-body/full-start test than an earlier 0.98 rad floor experiment that failed on another controller trajectory.

Freeze the candidate and run matched original J and I full starts with the original stage-aware actor, teacher off, no intermediate reset and no tuning between cases. Require five waypoints, no physical/solver failure or nonfoot perch contact, 95/100 bilateral opposing impulse endpoints before release on each, release and sustained support. If endpoint results pass, replay with ranged substep observer and require at least 390/400 opposing substeps in the corresponding pre-release window, no missing status samples, and parity with the tested trajectory. Preserve both failures and successes. A pass would be a limited development result, not unused-layout or biological qualification.
