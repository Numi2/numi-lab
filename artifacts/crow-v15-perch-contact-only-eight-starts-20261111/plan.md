# Eight perturbed starts with a contact-based return trigger

If the two-start trial does not reveal an unsafe failure, test the same +0.02 rad precontact placement and contact/phase return decision on the previously tested eight constructed perturbed starts. Record full accepted state, 32-substep contact and toe velocities, clearance and regrip. This remains a stationary component test: balance uses exact root position in the known perch frame, and the v15-derived body and hip properties are experimental. It does not establish autonomous sensor availability or successful flight-to-landing.
