# Isolate teacher commands from foot forces

The previous teacher stored speed and lateral requests in nutrition.xy, but the contact-driven gait publishes accepted foot loads into those same fields at the end of each control step. That overwrote the guide before it could steer. For this research-only teacher diagnostic, preserve those contact fields and encode the two bounded teacher commands at millimetre/s resolution in nutrition.z; heading is taken from accepted commandExtension.x and target altitude from nutrition.w. Decode the same teacher values for both the frozen flight-law adapter and the teacher labels. The integer encoding is checked for all 601,601 supported millimetre bins. Also replace the explicitly hardcoded support-COM mass entries with those of the estimated-wing body; this does not validate the rest of the support model. Repeat the same two used courses and eight starts per course with teacher enabled, 4500 steps, physical collisions and logging, preserving every failure. This is a privileged demonstration search; before any imitation, prove that a student visiting states sees uncontaminated observations and matches teacher-off behavior at full student authority. Final unused layouts remain untested.
