# Release posture leg kinematics

The stronger contact-driven weight-transfer test activated the existing release command but rarely cleared the left foot. At sampled release times the measured knee position did track its target, so inspect the geometry before changing targets. Reconstruct the same corrected-axis 35-body native model and all retained states before each lane's first fall. Verify baseline left- and right-foot FK positions against the trace to 1e-6 m, and then perturb each left hip pitch, knee and ankle coordinate independently by +/-0.01 rad with all other q/v held fixed. Calculate derivatives of left-foot position relative to whole-body COM, especially vertical and fore-aft, and report them at selected pre-release and early release states as well as observed actual positions. Record inputs, native binary, runtime, error and outputs. This is a fixed-state Jacobian, not a prediction of contact-constrained movement, proof of grip, physical validation or a controller qualification. The retained experiment used constructed starts and no reserved layouts or seeds.
