# Contact-onset toe reflex

The corrected four-substep sensor detects the bilateral toe-perch impact, but the current logic starts only the rear ramp on first load and requires an existing rear ramp before front closure. The impact lasts less than one control step, so a front ramp can remain zero when load is already gone. Test a bounded contact-onset reflex: when either foot's measured control-step average load exceeds 0.2 N, advance that side's rear and front closure ramps immediately by 16 units; otherwise let them fall by the existing three units per step. Preserve per-joint target limits, drive effort bounds, all collision physics, no pre-curl, frozen flight law, and the 25 consecutive loaded-step handoff. Pre-waypoint-five flight keeps neutral toes. On the same eight used starts per development layout, predict at least 12/16 survival through step 4500, at least four runs with ten consecutive bilateral averaged-load readings, and at least one run with three consecutive bilateral opposed toe-contact endpoints. Require 25 impulse-free control steps to restore toe angles below 0.05 rad before any claim of release. This is a guided experiment, not an autonomous or biologically validated sequence.
