# Longer obstacle-enabled diagnostic for the continuous leg release

On the same v15 body and used development scene, uniformly use the .04 s wing delay and .40 s continuous release-to-flight blend from the takeoff screen. The .40 s setting is a representative engineering setting, not a claim of optimal or biologically calibrated timing; the earlier per-lane experiment tests whether its short-window prerequisites replicate. Use the teacher-off route actor and the normal obstacle collisions without intermediate resets, for a 1200-step horizon on two used development seeds. This is diagnostic exposure, not held-out evaluation or a substitute for qualifying the flight controller.

Use the read-only substep observer to record every nonroot joint speed, foot/toe contacts, scene contacts and accepted state. Verify exact same-lane state and contact parity with the previous continuous-release run for all lanes through step 570, and for lanes 2–3 through step 625 where the uniform blend is identical. Record first-episode end, failure/waypoint status and any scene-contact body IDs with preceding attitude, velocity and actions. First or last contact does not necessarily prove a fatal collider and no minimum clearance is established. Compare a collision-disabled, policy-rebound run if this trial fails before attributing failure to routing. No teacher-off waypoint count establishes a supported landing.

## Correction before interpreting the runs

Source inspection found an inherited development-only `oracleCommand` override in the experimental shader. From 9–9.5 s onward it substitutes fixed speed, zero turn, and a lane-dependent height schedule for the route actor command when the navigation task is active. The original wording above that describes route-actor control is therefore incorrect during this interval. The teacher flag is disabled, but the flight command is scripted, not autonomous route selection. Retain these trials only as bounded-command obstacle-enabled versus obstacle-disabled diagnostics. Waypoint flags from either run cannot establish autonomous navigation; repeat any mission evaluation after removing the override and checking accepted commands.
