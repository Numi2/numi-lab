# Correction: obstacle-free route and contact-log scope

The isolated two-segment runtime `build/crow-v15-two-segment-frozen-flight-dense-contact-20261111/c_api.cpp` explicitly sets `collisionMask=0` for all five `crow_course_` shapes, including the perch. Therefore every route, teacher, and handoff trial using that runtime or a library built from that source was obstacle-free with a non-colliding course perch. The five-waypoint, eight-lane teacher result in `crow-v15-teacher-height-long-dev-20261111` is a navigation-command development result only; it does not demonstrate obstacle avoidance, collision clearance under physical contact, or a supported landing. The same limitation applies to `crow-v15-two-segment-contact-flight-route-dev-20261111` and its first-gate diagnosis. Ground walking and takeoff still had their separately measured ground contacts; the isolated narrow-perch release benches used a separate physical perch and are not full-journey landings.

The retained `CROW_SUPPORT_SAMPLE` endpoint contact array intentionally filters to `locomotion_ground` and `crow_course_perch`. Consequently any earlier `first_endpoint_non_ground_contact` field derived solely from that array could see the perch but could not witness gate or slalom contacts; zero such records cannot establish absence of obstacle contact. A separate diagnostic variant `crow-v15-course-endpoint-contact-observer-20261111` removes that logging filter only. In a deliberately obstructed collision-enabled control it matched 1,041 accepted endpoint scene contacts to the exact last physics-substep pair and impulse, with identical q/v/actions and all previously logged substep records. The deliberately obstructed control terminates by contact and is not a route result or numerical-failure claim.

`crow-v15-course-collisions-enabled-20261111` is an isolated correction that removes the collision-mask override and rebinds unchanged actor weights to the new fingerprints. Subsequent collision-enabled results must be evaluated independently; no prior result is relabeled. The box-distance diagnostic reports sampled endpoint clearance, not a guaranteed continuous minimum.
