# Toe armature one-variable screen

The obstacle-free paired screen passed 160/160 lanes on the original v15 body and missed the speed gate in 160/160 with the toe prototype. The prototype uses 5e-5 kg m^2 joint armature per toe for numerical stability, while the nominal toe geometric flexion inertia is approximately 1.36e-8 kg m^2; both are unmeasured estimates. Previous short support tests found smaller armature settings unstable, so test two predefined lower values, 5e-6 and 5e-7 kg m^2, with every other toe property, mass distribution, collision geometry, fixed-head flight controller, zero diagnostic policy, obstacle-off world, commands and original seed held fixed. First run eight lanes for 1600 steps per value; require no solver or physical failures, all eight original speed/heading/height gates, and no toe speed saturation in retained samples before considering any larger screen. Record first failure and all outcomes; no candidate is promoted based on this pilot. The qualification, toe grip/release and landing must be retested separately if any candidate clears the pilot.
