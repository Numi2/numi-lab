# Isolated 33-body MetalWorld contact admission

The 33-body two-segment-toe model exceeded the stock 32-body ABA limit. Its isolated 40-body standalone floating-gravity formulation passed 1,152 varied-state CPU/GPU cases and the existing G1, Franka and PSM standalone controls, but MetalWorld and contact kernels are separate. Build an isolated 40-body MetalWorld library by recompiling each host object referencing the body limit against an overlay header, and rebuilding affected ABA, parallel ABA, inverse-mass and dense-dynamics Metal variants with the same bound. Use the tested gravity reformulation only in serial ABA; parallel and inverse-mass paths are unchanged apart from capacity. Retain all other host objects and GPU functions from the existing build. No production files are edited.

First run only a short, explicitly bounded contact admission on the actual v15-derived two-segment model: one physically initialized stationary narrow-perch start, 16 physics substeps, no teleport after initialization, finite q/v and no solver failure, with contact identities and impulses recorded at each accepted endpoint. This is not a walking, takeoff, grip, release, landing, biological, performance or autonomous qualification. The wider build and any source change remain isolated until separate checks pass.
