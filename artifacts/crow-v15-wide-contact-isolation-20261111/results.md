# Isolated wider MetalWorld build

The isolated overlay raised the host and affected Metal kernel body bounds to 40; all eight affected host objects and all affected shader variants were rebuilt into a separate library. The serial ABA variant includes the separately screened uniform-gravity reformulation; parallel ABA retains its original gravity implementation. The build linked successfully and the adjacent two-segment contact admission used it with parallel ABA disabled. This is not a production change or blanket ABI, contact, numerical or performance qualification.
