# Matched post-hop wing phase identification

Earlier tests of fixed wing onsets from 7.42 to 7.56 s exposed a short modeled leg hop when the wings stayed nearly still, but the bird recontacted before the later wing beat could sustain it. The 7.42 s continuous candidate had already moved its flap 0.682 rad before the first fully unloaded interval and the held-leg control also flew. Test whether wing phase at the previously examined 7.50 s onset alters that transition without increasing physical actuator limits: in otherwise unchanged candidate lanes 6 and 7 use phase offsets +pi/2 and -pi/2 respectively for the coupled flap/pronation carrier. Both matched leg-push and held-leg arms use the identical wing command for each lane. No root override, direct body force or reset is introduced; this is a timing identification, not yet a contact-triggered controller.

Run the complete first 500 intervals on used seed 20261126 using the same bodies, existing drive effort/velocity limits, teacher-off route inputs, solver, material, all-body-wrench ablation, policies and launch observer. Require exact candidate pre-push and unaffected-lane q/v/action/contact parity, equal paired wing targets and nonshader input hashes, full contact/toe/leg/aero substep coverage and no observer errors. Measure first fully unloaded interval, any later recontact, toe-speed thresholds, nonfoot impulse, displacement and flap motion at the corrected start of the first fully unloaded interval; report positive and negative modeled aero impulse separately. Neither sustained flight in one pair nor a delayed wing command establishes leg necessity; compare the matched held-leg trajectory. Preserve all failures. A pass is neither flight qualification, biological calibration, grip, landing nor navigation on unused layouts.
