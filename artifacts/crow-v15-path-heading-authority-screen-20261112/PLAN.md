# Bounded path-heading authority screen

Repeat the +/- .35 rad velocity-heading commands on the same used seed, .55 m/s and obstacle-free scene, with gain 1.2 and differential flap limits .10, .15 and .20 in sign pairs. Controls remain identical to the retained run, direct body moments off. Measure 20–24 s heading error, peak planar speed, roll, height, caps and contacts; the largest open-loop input produced excessive lateral speed, so reject unsafe or unstable responses. First evaluate fixed-target tracking before any claimed turns, course navigation or biological qualification.
