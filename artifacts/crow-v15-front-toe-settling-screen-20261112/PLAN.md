On the isolated dedicated-sensor research body, retain the previously screened -.5 ankle feedback, +.5 hip feedback and .16 knee warp in candidate lanes. Change only the front-toe target floor in the existing own-support-gated walking branch. Lanes 0-1 remain .15 rad controls; lanes 2-3 use .10, lanes 4-5 .05, and lanes 6-7 zero. Compare each same lane and seed against the archived negative-ankle run with .15 floor. The floor uses max with another target; a zero value is still a floor and is not described as bypass. Use both already-used seeds and the same policies, inputs and 16 substeps. Retain failures.

Require exact recorded pre-intervention parity and unchanged control-lane parity. Record whole-foot support, toe-speed limits, nonfoot impulse, loaded-point speed, forward progress, recovery coverage and knee timing using the previous fixed gates. Separately compare the persistence-filtered delay from hallux-proxy loading to both hallux and middle-front-toe loading in same-lane events. A potential settling improvement requires at least two complete events per foot in both arms and a 15% lower pooled median delay within the same lane, with all preceding physical gates met. This threshold is an engineering screen, not a claimed biological measurement. A passing lane, if any, still needs independently varied starts, normal-speed study, full 3D slip, reset/rollback, and the complete mission; it does not establish grasp, landing or crow realism.
