# Grip release timing controls

The fixed 55-second release occurs after the toe-equipped bird has already fallen, although it forms more than two seconds of opposing toe loads after contact. Before running, test 45.0 s and 46.0 s commanded release on the unchanged no-balance controller and same full-start exposed layout J. Both times are fixed before the run, and analysis only counts grip before release. Verify loss of opposing loads on both feet and 25 stable final supported samples; retain failures. Timing alone is not proof of realistic grip or reliable release.
