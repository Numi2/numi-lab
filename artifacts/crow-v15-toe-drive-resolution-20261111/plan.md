# Free-space toe-drive time-step control

The same landing start and commands produce radically different outcomes at 16 and 32 contact substeps. Before attributing this to contact, compare free-space motor tracking: start the identical bird well above the ground, apply the same 20 ms rear-toe target ramp and otherwise identical implicit joint drives for 80 ticks, separately with 16 and 32 substeps. Require all ticks to complete with zero ground impulses. Compare the left and right rear toe angles at matched control times; a maximum difference over 0.05 rad is treated as meaningful drive-resolution sensitivity. The threshold is diagnostic, not a validation of the physical motor model. Record both native binaries and all samples. This is not a landing, contact, biological or full-sequence qualification.
