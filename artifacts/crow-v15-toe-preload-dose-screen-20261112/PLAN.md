# Toe-preload dose screen with standing feedback

Hypothesis: a smaller rear-toe preload could preserve the toe-speed-cap improvement while reducing the elevated sampled contact-point speeds observed with 0.20 rad. Use the same early standing feedback and eight development starts as the integrated walk; try rear-toe target amplitudes 0, .05, .10, .15, .20, .25, .10 and .15 rad across lanes. Each is paired against the same lane of the 0.20-rad integrated run; lane 4 should reproduce it exactly throughout. All lanes must reproduce the matched -0.5 standing run through 3 s. Compare unloaded substeps, toe caps, support-qualified swing bouts, travel and contact-point speeds per lane. Endpoint speeds are not integrated slip; starts differ among doses, so dose selection requires a separate matched all-start trial. No promotion or full-sequence claim.
