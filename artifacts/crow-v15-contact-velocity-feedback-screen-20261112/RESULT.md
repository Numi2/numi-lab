# Contact-velocity feedback walking screen

Neither sign nor any tested gain met the preregistered goal of reducing the substep contact-speed integral by at least 25% for each foot. Relative to the matched reference, left-foot ratios were 0.985–1.024 and right-foot ratios were 0.870–1.006. All lanes retained collective foot support during 4–6 s and advanced 0.130–0.134 m, but one gain hit a toe-speed cap. This candidate is rejected, not a qualified gait. The integral is an impulse-weighted contact-point speed proxy and does not track material slip; geometry and accepted velocity can be separated by a substep. The feedback signal itself was not separately instrumented against the offline kinematics, so this experiment does not establish that the signal was accurate or isolate why it failed.

Before intervention, all 1,600 states and 25,600 contact substeps matched the retained reference exactly. Both unchanged controls matched all 300 state and 4,800 contact substeps each. A repeat with the finer observer reproduced all 2,400 states and 38,400 contact substeps from the preliminary observer exactly. Fine velocity analysis independently checked 800 Hz endpoints and kinematics. The first run lacked substep velocities and is retained as preliminary; only the corrected repeat supports the fine comparison. Actual host hashes for each observer are recorded in their `inputs.json`; the `screen-hashes.json` host value is inherited build metadata for the gait pack and is not the loaded observer identity.

For this isolated bench, the sensor temporarily used the power state lane after reward computation. The native host encodes effort measurement immediately before task completion on each step; it restores mechanical power before the next reward. This lane reuse is experimental and is not a production sensor interface. Direct body moments were disabled. Tested development starts, uncalibrated materials, and the 2 s window do not qualify walking, takeoff, landing, flight or the full journey.

Correction from the subsequent `crow-v15-contact-feedback-sensor-audit-20261112`: the signal was the quantized zero code in all six candidate lanes for every audited frame while offline contact velocity was nonzero. Consequently this run is invalid as a test of contact-velocity feedback and cannot distinguish feedback effectiveness from sensor failure. The no-pass result and trace remain retained.
