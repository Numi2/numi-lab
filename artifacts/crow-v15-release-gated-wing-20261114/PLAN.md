# Release-gated wing handoff: development experiment

The prior 0.75–0.85 rad phase-zero wing candidates sustained flight after the leg push, but the matched held-leg arm also flew under identical open-loop wing commands. The isolated held-wing experiment separately established the push unloads the model on the used seed. Test a control rule that keeps wing drives neutral until the existing two-low plus height and upward-velocity release latch has fired, retaining the same time-based phase and per-lane amplitude candidates. Both push and held-leg arms use exactly the same release-gated control rule; only leg-extension availability differs. This tests system-level dependence on physical release feedback, not a biomechanical claim that flapping wings cannot take off from the ground. Wing commands are expected to diverge after release, so the earlier identical-wing-command leg-necessity screen is not relabeled as passed.

Run eight correlated lanes on development seed 20261126 for 500 intervals, with the original 16 substeps, existing aero, physical drives, contact, toe, body and tail settings. Before looking at results, require: matching prefix before leg intervention; only leg targets differ before the first release; candidate unloads with positive matched foot-impulse excess and no excessive pre-unload aero or flap displacement; no recontact, nonfoot impulse or toe-speed cap through interval 500; held-leg control does not unload during the diagnostic; and endpoint wing position and velocity bounds. Report all lanes, exact commands and traces, onset, failure timing, and full limitations. Lanes and the seed are developmental and correlated; passing is not flight-envelope, biological, landing, mission or held-out qualification. If this fails, retain it as a failure.
