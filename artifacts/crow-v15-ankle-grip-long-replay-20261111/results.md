# Independent long ankle-and-grip replay

The 1,000-tick single-environment run matched all 500 saved state samples from batch lane 16 exactly. It had 463 consecutive supported samples, 222 consecutive supported opposing-grip samples and a worst measured grip overlap of 0.449 mm, but then tipped and fell. Terminal support and grip were absent, so this is not a qualified landing. Joint observation showed both ankles closely following targets at the existing 0.12 rad correction bound from tick 150 onward; hip commands later approached their own bound. Rear-toe contact was absent at multiple late supported samples. These observations motivate bounded controller tests, not any claim that expanding the limit or grip force will fix the fall. No full autonomous sequence, departure, perturbation robustness or untouched layouts were tested.
