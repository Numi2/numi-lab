# Supported-grip release strategy screen

The preceding 1.0-gain case had 11 consecutive supported opposing-grip samples but fell after the rear-first release; peak grip overlap was 1.128 mm, above the existing 0.5 mm gate. On the same separated development start compare the original no-balance control, the exact 1.0-gain rear-first control, and two alternatives: simultaneous slow opening of front and rear targets (0.01 rad/control step), or front-first then rear opening (0.02 rad/control step). All use the same 16-substep physics, force-interval contact feedback, hip law and genuine actuator targets; there is no state reset or artificial force. Both controls must reproduce all 200 saved states from their respective previous arms. Report grip, post-release support, open-toe posture, failures and independent grip SAT overlap. A more stable release is only a research result: the excessive overlap remains a separate blocker, and this single case cannot qualify full landing, flight, navigation, held-out layouts or biology.
