# Match controller contact to native normal-only substeps

The retained walking-transfer probes use the last contact evidence's normal-only upward component for control, while the diagnostic observer sums both normal and tangential vertical impulse. Their values cannot be compared directly. Repeat the exact retained stronger-pitch two-lane v15 trial with an observer-only native host that additionally records per-foot normal-only vertical impulse at every substep. Record the source patch and binary hashes, and require exact all-interval state, command and contact parity with the prior run before treating this as the same trajectory. Compare each control-loop `event` normal-only upward impulse against the final substep of both the same-numbered and next-numbered observer interval; require every lane/interval to be present once and absolute error <=1e-8 N s. Record mismatches rather than choosing a convenient offset. Then compare the directly matched final-substep signal with full-interval vertical impulses, including tangential forces, to assess the proposed load-sharing feedback input. This resolves measurement alignment only and is not a walking or landing qualification.
