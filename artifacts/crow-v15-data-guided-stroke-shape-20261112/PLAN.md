# Data-guided physical wingstroke shape experiment

The selected baseline simulation has a 4.6 Hz wing-joint velocity and 9.2 Hz tail-acceleration peak. Eight carrion-crow training individuals have median dominant flight-labeled tail-tag frequencies 3.8–4.6 Hz. The 9.2 Hz signal is associated with squared wing speed; that association does not establish causal force attribution. Test a smoother unequal-duration stroke by replacing only the physical flapping target carrier after nine seconds with sin(phase + 0.7 sin(phase)), smoothly introduced between 9 and 10 s. It preserves the same phase period and target amplitude bounds. This is an engineering waveform, not measured crow joint kinematics or a fitted force law; the coefficients are exploratory, and the current modeled aerodynamics remain unchanged.

Both arms use the same compiled shader and host; the existing experimental host switch enables the waveform in the candidate. Same seed, initial conditions, original flight feedback and all other actuator limits apply. Require exact 48 pre-intervention sampled q/v/action states, complete all 16 contact substeps per realized interval, no errors or overflow. Evaluate all six lanes over 1600 intervals with the strict current engineering checks: no post-intervention nonfoot contacts or physical failures, sampled heights .65–1.15 m, abs pitch <.35 rad, sampled body-forward speed >=.5 m/s and abs sideslip <=45 degrees from interval 800 on, final +/-90 degree heading error <=15 degrees. Both directions must pass. Replayed lane 1 must complete all four predeclared 5 s tail-sensor-proxy windows and improve the fixed training-individual median acceleration-spectrum score against the same-binary sham. No flight controller is qualified on one seed, direct body moments before 9 s, or sparse endpoint samples, even if these screens pass.

The two previously checked carrion-crow held-out animals are now development context, not an untouched confirmation set for this new intervention. The actual sensor is on a tail feather and model proxy at rigid tail COM; spectral similarity cannot establish crow kinematics or physical realism. The phase waveform must be independently validated in additional biological recordings and flight tests before any promotion.
