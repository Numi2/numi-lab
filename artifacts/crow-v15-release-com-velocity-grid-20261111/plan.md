With balance preserved across release, the toes opened but the bird drifted backward and fell: COM moved from +0.0205 m at release to -0.0209 m shortly before support loss, while the controller continued aiming for -0.010 m. Compare five bounded post-release COM targets (-0.005, 0, +0.005, +0.010, +0.015 m) crossed with root-velocity coefficients 0.2, 0.35 and 0.5; blend changes over 50 control ticks after grip-conditioned release. Keep one exact baseline, body, toe control and opening rates, actuator limits, solver, existing balance gains and grip criteria unchanged. Run 1,100 ticks and require exact baseline state parity for all ticks and all candidate state parity until the tick-777 release. Require terminal 50 consecutive samples of open toes, no opposing impulse over any substep, bilateral physical support, bounded tilt/speed and no other-body contact, no solver failure, and no measured grip overlap beyond 0.5 mm. This is a single development start and a successful result still requires independent replay, perturbations, takeoff and whole-route tests. No unused layout is used.
