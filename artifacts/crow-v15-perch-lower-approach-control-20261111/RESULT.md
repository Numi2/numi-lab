# Lower approach target: rejected

Lowering the phase-one height target 0.015 m on the same used development layout and seed yielded no sustained bilateral supported landing in eight first episodes, versus one for the aligned baseline. Six reached five waypoints and had foot contact; two struck the slalom. There were no teacher controls or scheduled resets. The run is a regression and must not replace the baseline. This is one development seed, not an unused-layout test or biological qualification.
