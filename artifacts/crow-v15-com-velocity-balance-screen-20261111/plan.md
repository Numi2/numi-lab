# Early centre-of-mass and velocity balance screen

The stronger early position and pitch gains were not robust; one perturbed start briefly acquired grip but all adjusted cases fell by 900 ticks. Test two different bounded feedback hypotheses without altering the later grip controller: in supported pregrip only, use the full-body centre-of-mass position already computed by the probe instead of root position, and increase the velocity damping term from 0.2 to 0.6. Test each separately and together against the unchanged control on the same four reference, +/-2 mm position, and +0.01 rad roll starts. Sixteen lanes, 900 ticks, 16 substeps, identical model and joint limits, no external forces or resets. Match the unchanged controls exactly to the preceding trace and each intervention's initial state to its paired start. Report sustained opposition, release, falls, terminal support, toe overlap, nonfoot contact and solver failures; a brief acquisition followed by a fall is failure. This is exploratory development, not independent validation, actual flight-arrival landing or full-route qualification.
