With toe contacts included in the physical foot-support groups on a 5 cm branch, the layout J active trial generated 148 consecutive accepted samples with opposing front/rear toe loads on both feet, then pitched progressively from about 3 to 69 degrees and terminated before release. The layout I trial struck the branch with the body. All four first episodes failed; no complete sequence has been shown.

Before running, test a bounded bilateral hip position reflex on layout J, where the physical pinch was observed. Keep the v15 flight-controller source, actors, body, support sensors, toe controller, branch and solver unchanged. After waypoint five and only while both feet have previous accepted load above 0.05, request the same normalized hip command `clamp(sign * (0.75 * pitch + 0.30 * pitch_rate), -0.30, 0.30)` for both hip actuators. Pitch and pitch rate are the existing accepted-state feedback used by the frozen navigation controller. No body wrench, state change or force is injected. Because the ground-constrained reaction sign is uncertain, screen both plus and minus signs on the same layout and seed, against the archived no-reflex active trial. Keep all trials including physical failures. A sign is promising only if it retains at least three consecutive both-foot opposing-load samples and extends the pinch without exceeding tilt/physical limits; do not count progress after a physical termination. The full gate still requires all waypoints, a genuine grip then 55 s release, and 25 final low-speed foot/toe-only supported endpoints. Test layout I separately only if a candidate passes; a single exposed seed is not qualification.
