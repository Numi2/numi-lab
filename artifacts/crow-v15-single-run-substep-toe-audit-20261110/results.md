# Same-execution substep toe contact audit

The instrumented single-submission run exactly matched all 40 reference endpoint state samples and captured all 640 expected substeps. There were 67 toe/interval combinations with a positive toe/perch normal impulse in the observed window. One, a rear-toe impact at step 17, exceeded the selected 0.01 N mean-force threshold over the interval while the final-substep reading was below its equivalent threshold. None of the recorded toe contacts in this initial window met the horizontally opposing-grip normal criterion. Thus the sensor can miss an impact, but the observation does not show a missed opposed grip or explain the later controller failure. It covers only the first 40 control intervals of one development drop, not the whole 200-step behavior, full landing or biological realism. Extend the same-execution observation across the grip transition before choosing a controller change.
