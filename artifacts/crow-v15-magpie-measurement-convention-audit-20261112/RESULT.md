# Toe-specific, side-projected timing comparison

The retained seed-20261127 development baseline was reanalyzed using contact from the simulated middle front toe as a proxy for the study's third digit, and joint angles projected onto the bird's heading/vertical plane. Twenty-five complete recovery windows remained, with the same reported rejection counts as the earlier any-front-toe analysis. Using raw 800 Hz points, the median knee minimum occurred at 57.82% of modeled recovery (range 51.70–62.21%); with the earlier 21.25 ms boxcar it was 53.74% (51.02–58.72%). The earlier any-front-toe, 3D result was 57.53% raw. For these selected windows, the projected and 3D minima occurred at the same substeps, and both gave ankle-proxy-first in 16 windows and a tie in nine before smoothing. Projection and the toe-specific definition did not remove the observed timing difference.

The related-magpie paper's recovery-knee mean was 27.3% ± 7.9% SD for 16 observations; see [Verstappen et al., Table 1](https://doi.org/10.1242/jeb.203.14.2159). This is an exploratory cross-species comparison: simulated toe identities and ankle landmarks remain anatomical proxies, speed and surface differ greatly, the moving heading projection is not the study's fixed camera, and 25 windows from eight correlated lanes are not independent animals. Mean timing from a published study is not a precise American-crow target. This audit validates neither the fit nor any controller.
