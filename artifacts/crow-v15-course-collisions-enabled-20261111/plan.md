# Restore v15 course and perch collisions

Audit found that the experimental two-segment v15 c_api deliberately sets the collision mask to zero for every course object, including the perch. Consequently all retained route tests using that runtime are obstacle-free controls, and no landing there could be supported by the course perch. Build a separate runtime removing only that collision-disable branch, retaining the calibrated body and diagnostic observers. Rebind unchanged policy weights to the resulting world/task fingerprints and retain the original collision-off result. First reproduce a deliberately obstructed constructed start and verify bird-to-gate contact identity and impulse; only then run matched teacher and autonomous trials with collisions enabled. A collided or terminated trial is not automatically a numerical solver defect. No final unused layouts are used here.
