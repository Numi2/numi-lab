# Matched contact-driven leg retraction timing

In the duration sweep, 0.16 s extension generated a brief predominantly leg-driven unload, but the legs stayed near the extended target through the short airborne interval and recontacted before wing support developed. Test whether detecting unloaded feet one control interval earlier allows the physical leg drives to retract in time. This changes a contact-based release debounce, not a state, external force, actuator limit or friction.

Use matched push and held-leg counterfactuals on development seed 20261126, eight correlated lanes, 500 intervals, with identical fixed 0.16 s supported extension and 7.50 s non-leg wing onset in both arms. Even lanes retain the existing two-low-contact-interval release condition; odd lanes use the first low-contact interval, with existing rising velocity and root-height requirements unchanged. Toe targets remain the same scheduled diagnostic in push and hold. The gate can falsely interpret a transient unloading as takeoff, so this is only a targeted screen. Compare each matched pair's state prefix, wing/tail/toe command parity, full contact and velocity coverage, and leg targets at release. A pass requires predominantly leg-driven first unload, no subsequent contact through interval 500, no non-foot impulse or toe-speed limit, and a held-leg arm that does not achieve sustained unload. Record all failures, even if any transient improves. Do not use this as final controller, biological realism, walking, flight or mission qualification.
