# Matching light-contact threshold resolves sensor audit outliers

Repeat the materialized-contact-feedback experiment with only the passive log threshold changed from positive impulse >1e-7 to >1e-9 N s, matching the physical sensor's impulse cutoff in magnitude. All 2,400 endpoint states and 38,400 contact-substep summaries exactly match the archived original. Over 99 recorded final-substep samples per candidate lane, mean absolute difference between the quantized GPU feedback and independent articulated point-velocity reconstruction is 0.000320–0.000333 m/s; maximum difference is 0.00234 m/s. Previously the observer omitted very light contacts and displayed isolated differences up to 0.121 m/s on the same six trajectories. This matched-threshold repeat explains those discrepancies without changing the physical controller.

The sensor is still a delayed, quantized last-substep normal-load-weighted contact-point velocity with geometry/state staggering, not tracked material slip. The logger accepts positive impulses and the sensor uses magnitude; negative-impulse equivalence is not established. Agreement on one used seed does not demonstrate general gait quality, and the failed gain screen remains failed.
