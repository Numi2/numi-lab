# Batched contact-driven perch balance screen

Run 16 simultaneously simulated, isolated environments from the same physically separated v15 development start with the matched held-grip controller. Lane 0 is an exact unchanged reference. Other lanes form a predeclared grid of COM x targets -0.02, -0.01, 0, +0.01 and +0.02 m and post-grip blend durations 50, 100 and 200 ticks; all lie within the authored 0.025 m perch half-width. Preserve bounded hip/ankle control, actual substep toe impulses, physical contacts and body damping. All lanes must reproduce the stored single-lane reference through tick 85; otherwise the batch is invalid. Record toe poses, full-substep opposed contact and support, with independent SAT overlap and 500-tick short-screen gates. Require terminal 100 samples of bilateral grip and support, no nonfoot support, speed/tilt limits, no solver failure and no grip overlap worse than 0.5 mm. No candidate can be accepted until a separate full 1,000-tick replay and independent perturbation, release, flight and complete-course tests. This is a host-readback research screen, not a claimed production-throughput result; untouched final layouts are not used.
