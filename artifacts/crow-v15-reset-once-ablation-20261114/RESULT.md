# Duplicate reset block ablation

Removing only the second identical reset perturbation block changed the first observed state in all eight same-seed lanes. In candidate flight lanes 6/7 maximum q differences were 0.0243/0.0276 and maximum v differences 0.812/0.948; first observations are not independently captured pre-step reset states. The run used the matching host and policy hashes and the preregistered newly built shader hash. Both candidate lanes unloaded at intervals 377/376 and had no later foot load or ground contact through interval 500; observer states were finite and required 16-substep coverage complete. Native exit was zero and observer error list empty.

This establishes that the code change materially affected the run, not that its first observation is the exact reset state or that recovery, takeoff, flight, or the mission is qualified. This was a used development seed and training layout.
