# Duplicate-reset single-block ablation

The flight shader has two identical adjacent initial-perturbation blocks with identical deterministic random channels. To test whether both affect the v15 difficulty-10 run, remove only the second block from a copy of the matched release-latch turn shader, retaining the same policies, model, seed 20261126, controller, layout and limits. Run 500 intervals with teacher off and no scheduled resets. Compare the first observed q/v state for all eight lanes to the retained same-seed duplicate-block reference, and measure release/contact continuity and all native errors. A different first observed state establishes a material effect of this code change on the run but does not measure exact pre-step reset values or establish a representative disturbance distribution. If states are identical, do not assert the branch executed. This 500-interval development ablation does not qualify flight, recovery, takeoff or the mission. Retain all outcomes and do not use reserved seeds or layouts.
