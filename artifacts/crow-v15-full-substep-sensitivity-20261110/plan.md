# Full v15 toe overlap versus physics resolution

The isolated box-grip probe suggested smaller contact overlap with more substeps. Test whether this carries over to the original v15 full-start original-J development episode, using the same second routing actor, alternating-foot release shader, host, seed, 20 ms control interval, body, materials and solver iteration settings; vary only physics substeps from the accepted four-step baseline to eight then sixteen. These are independent uninterrupted first episodes, teacher off, no tuning.

For each result, report all waypoint progress, first fatal collider, solver failures, sampled minimum obstacle clearance, toe flight, walking, landing/support and release. If landing occurs, compute the same accepted-pose OBB separating-axis gaps for all eight toes during the 100 endpoints preceding release and compare with the archived four-substep baseline: the baseline's worst overlap was 4.975 mm and median per-toe overlaps ranged from 2.636 to 4.585 mm. Require at most 0.5 mm worst sampled overlap, no physical or solver failures, all waypoints, at least 0.05 m sampled obstacle clearance, supported grip and release with renewed support before considering this a candidate. A fail or missing hold remains a fail. Because numerical resolution affects the whole trajectory, any promising setting requires separate frozen-controller flight, gait and multistart requalification. These are development-only measurements; no K/L and no biological claim.
