# Physical hip and ankle response around perched state

The existing held-toe balance loses rear contact and falls; bounded reclosure restores some contacts but worsens support. Identify the response before more controller tuning. Starting from the same physically simulated drop, run five separate deterministic 240-tick trajectories: no pulse, plus or minus 0.02 rad on both hip targets, and plus or minus 0.02 rad on both ankle targets. Apply each bounded 30-tick pulse only at ticks 100–129, then restore the original control. The reference prior to tick 100 must match exactly across all five trajectories and the archived matched-balance run. Record articulated COM, body pitch and angular velocity, per-substep opposing toe contact and physical trajectory. Measure finite differences at and after the pulses; track contact mode changes, which can make the response nonlinear. These are development diagnostics, not landing or navigation qualification, no external force or state reset is introduced within a trajectory, and reserved layouts remain unused.
