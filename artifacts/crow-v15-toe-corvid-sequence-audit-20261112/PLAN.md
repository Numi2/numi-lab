# Related-corvid toe contact-sequence audit

Use the retained, same-seed 800 Hz v15 traces for the uniform gait and the negative ankle-feedback trial. The magpie study reports hallux-first touchdown and hallux-first lift-off, with digit 3 last. Test model analogues: the rear toe's two segments as hallux and the middle front toe's two segments as digit 3. These labels are proxies and contact impulse is not identical to visible touch. Use the raw normal impulses, a 1e-7 Ns per-segment cutoff, and a three-substep persistence filter. Within complete transitions from neither group loaded to both groups loaded, record which group first loads; within transitions from both to neither, record which first unloads. Count simultaneous and complex transitions separately; exclude boundary and incomplete transitions. Include individual lane/side records, input hashes, and all results. Correlated development starts and very slow gait preclude a species validation. Do not change a controller based only on these descriptive measurements.

Source: Verstappen, Aerts and Van Damme, 2000, J Exp Biol 203:2159–2170, DOI 10.1242/jeb.203.14.2159, movements of the toes. Baseline input is Git commit b72d15c94b606dee1c835f570f939938636e133d; negative-ankle input is commit f3a719864a49b01d4557c2f48223e11382d31a36.
