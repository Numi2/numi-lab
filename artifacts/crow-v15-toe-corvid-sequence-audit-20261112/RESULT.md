# Corrected toe contact-order audit

The original filter initialized both groups as unloaded, which manufactured a transition when a group was already loaded at the start of the 2-second window. That created false, left-censored events, including two apparent reversed lift-offs. The corrected filter starts from the first observed state and excludes transitions that begin at the window boundary. Synthetic checks verify the boundary case and known ordered events. `analysis-v1.json`, its code and the initial interpretation are preserved as superseded history.

With the corrected 3-substep persistence filter, the two baseline batches each showed 56 complete hallux-first touchdown sequences and 64/60 hallux-first lift-off sequences; the negative-ankle batches each showed 56 hallux-first touchdowns and 62/58 hallux-first lift-offs. These are repeated events from 16 correlated lane/side pairs per batch, not independent birds or held-out starts. Boundary and incomplete sequences are excluded. The two simulated body groups are anatomical proxies, not validated individual digits.

Order alone is misleading: in baseline, the median lag between first hallux-group loading and both groups loading was about 171 ms; in the candidate it was about 189–194 ms. The imposed gait carrier period is 500 ms. Median time from the first group unloading to both groups unloaded was 70 ms in baseline and about 100–101 ms in the candidate. The study does not provide a directly comparable timing target here; no biological error or significance is inferred from these lags. The impulse threshold, 3.75 ms persistence filter, different walking speed, group proxies and intermittent contact complicate comparison with visual toe touchdown and lift-off.

The observed ordering agrees qualitatively with the related-magpie description but does not prove foot grip, complete contact timing, crow anatomy, natural walking or landing. The negative-ankle candidate failed most joint/support gates and is not promoted. The long loading sequence and whole-foot support need investigation using actual ground contacts.

A post-hoc sensitivity check used 1- and 8-substep persistence. The observed complete sequences retained hallux-first order in both checks; the 8-substep check excluded four additional lift-offs in each 20261126 batch. These checks do not eliminate threshold, censoring or model-anatomy limitations.
