# Smooth physical return after toe release

Substep measurements found toe velocity limit hits at the first control interval of return. The existing transition abruptly resets knee lift, toe extension and foot placement targets. Compare gradual return ramps of 40, 80, 120 and 180 intervals, two development starts each, with the -0.20 rad toe-opening target. Record all substep velocities and contacts, release, subsequent bilateral regrip, balance and full weight-impulse windows. The duration sweep is a development test, not a navigation or biological qualification.
