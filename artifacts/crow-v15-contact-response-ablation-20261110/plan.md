# Contact-response pathway ablation

A collision-free-start drop developed rear toe overlap before active grip. On that same development start compare the unchanged original controller and physics while varying only contact-response computation: (0) original streamed matrix-free response with warm start, (1) unstreamed matrix-free response, (2) dense response, and (3) original streamed response without warm start. All use hybrid CCD and the same SAT shader, body, material, timestep, actuator law and iteration counts. Arm 0 must exactly match the prior separated-start case at all 200 sampled endpoints. Report rollback, grip/support/release, independently computed accepted-pose SAT gaps, and early contact evolution. The alternative paths may be unavailable or fail; retain that as evidence. No path qualifies merely by a smaller overlap: all full behavior and contact gates still apply, and changing a production contact path requires independent solver validation and requalification of flight, gait and full route. This single development start does not establish biological realism or a solver defect. No final layout is used.
