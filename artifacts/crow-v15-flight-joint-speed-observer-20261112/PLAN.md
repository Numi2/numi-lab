# Passive body and wing joint-speed observer

Add full-substep physical body and wing joint-velocity logging to the existing exact-parity open-flight observer. Use the same matching host, model, input and controller in a future repeat, compare every retained state and contact against the original, and assess 800 Hz velocities against the research model limits. This changes logging only, not forces or control. A lack of clipping alone does not establish biological realism or flight qualification.
