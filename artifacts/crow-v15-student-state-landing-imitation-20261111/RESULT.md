# Student-state and approach imitation: training only

The actor was trained using qualified development route prefixes, seven teacher-recovered student prefixes, and pre-contact approach samples from two lanes with a third for approach validation. Every original failed first episode and recovery lane 7 were excluded. The approach command targets use output slots 4–7 from step 2600, and slots 0–3 before that, matching the task command-selection rule before supported contact. A first offline fit incorrectly targeted slots 0–3 throughout approach; it was corrected before any autonomous evaluation. The corrected fit reduced average approach command error on correlated development validation from 0.227 to 0.051; these are same-layout, same-seed trajectories, with route validation lane 0 also contributing approach training. This is not generalization or autonomous landing evidence. The actor does not reproduce teacher-only contact balancing, grip or release.
