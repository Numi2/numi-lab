# Matched heading-target response

Source audit identified an existing heading-hold feedback loop acting through the ordinary pronation joints for lanes 2–7, which drives world heading to zero. This may explain the small residual heading in the differential-flap pulse; do not attribute it solely to aerodynamic coupling. Repeat the same-seed, obstacle-free trial using the exact same launch, controller and lane-specific aerodynamics as the retained same-lane controls. Change only the heading-hold target from zero to +/−0.15, +/−0.30 or +/−0.45 rad in lane pairs 2–7 from 12–18 s with smoothed start/end. Lanes 0–1 are unmodified. Direct body moments remain disabled. Compare state/contact prefix, heading, roll, yaw rate, path, height, joint caps and recovery to the exact same lanes; these are exploratory development starts and not a freeze or real-crow calibration. The existing heading feedback, altitude feedback and aerodynamic parameters are research-specific, with lane differences explicitly retained for exact pairing.
