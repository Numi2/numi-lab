Using the identical v15 controller and physics setup, build a diagnostic host which suppresses the entire flapping-wing aerodynamic kernel for all 16 substeps of control step 369 only; otherwise it is the same read-only wing-effort observer host. This suppresses wing, tail and fuselage contributions together, and is an intentionally nonphysical causal probe, not a proposed controller or model.

Run the original smooth-release push arm, used seed 20261126, eight lanes, 400 control intervals, 16 substeps, no reset. Require exact recorded q/v/actions/contact parity through control step 368 with the archived observer run, all logged contact substeps through 368 equal, identical start state at step 369/substep 0, all 3,584 wing/aero records, no error/overflow, and zero aero delta during each ablated substep. Compare first-substep pre-contact flap velocity and working-effort buffer, and model aero force to the baseline, in lanes 2–7. This first-substep comparison measures the immediate effect of removing the whole kernel at matched initial state; changes in later substeps also include evolved-state and controller feedback and cannot isolate an independent force. Preserve the ablation host source, binary, hashes, complete logs, parity checks and all failures. This used-seed probe cannot qualify takeoff or flight.
