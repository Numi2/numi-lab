# Contact-driven toe release after supported grip

The development single-start controller held support for 941 consecutive samples and passed the terminal grip gate. On the identical start and controller, request release no earlier than tick 500 and require 50 consecutive observations of bilateral opposed grip and foot load before opening. Gradually open rear toes first and then front toes, through the existing bounded joint drives, without teleportation or externally imposed force. Run 1,400 uninterrupted ticks. Require exact equality to the previous 1,000-step reference for the first 500 steps, an actual grip-conditioned release, and final 50 consecutive samples with every toe angle below 0.05 rad, each measured opposing toe impulse at most 1e-7 N s across all substeps, bilateral foot support, no other-body support, bounded tilt and speed and no solver failure. Save full toe positions, joint targets and contact traces for geometric inspection. This one-start development test does not qualify release across perturbations, takeoff from the perch, an approach landing or the complete route. Preserve failure and do not use unused layouts.
