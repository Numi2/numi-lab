Visual inspection shows a crow taking steps on a sloping branch while investigating its surroundings. Use this as a qualitative single-individual reference for visible head, torso, wings, tail and foot coordination. This is not level-ground locomotion; camera pan, perspective, feathers, shadows and obscured toes prevent confident 3D body/joint trajectories, foot-contact forces, absolute speed or generalization to a population. The movements include exploratory head motions that cannot be attributed solely to gait. Do not use individual poses or apparent neck changes as calibrated joint targets. This is not held-out validation because it has been inspected during development.
