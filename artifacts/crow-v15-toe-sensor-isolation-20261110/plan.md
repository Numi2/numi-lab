# Contact-sensor isolation with the same toe body

The articulated toe body misses speed tracking, while the rigid toe-geometry control passes; removing toe drive stiffness/damping did not repair tracking. The articulated task additionally extends foot contact groups and appends two rear-toe wrench groups, changing task-state layout. Test two predeclared diagnostic variants of the identical physical body in the obstacle-collision-off fixed-head screen: (A) remove only the two rear-toe wrench groups, retaining toe members in the foot-support groups; (B) remove both rear-toe wrench groups and toe membership in the foot-support groups. All geometry, inertias, joint drives, ground collision and frozen flight law stay fixed. Run eight matched lanes for one seed and the original speed/heading/height gates. Compare with the full-sensor toe-body baseline. A passing sensor-isolation arm would implicate task sensing or its interaction with launch; it would not by itself identify a software defect or qualify grip. Removing contact observations is a diagnostic only and not a deployment solution.
