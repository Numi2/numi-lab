# Equal-onset matched turn screen

Only if both candidate lanes pass the registered equal-onset 1,800-interval straight-flight screen on used seed 20261127, run the already-archived matching turn shader for 1,800 intervals on the same development seed. It changes only the existing bounded opposite-sign phase-gated wing differential, activated after 12 seconds. Compare each lane to its own same-seed straight run. Require exact state/action/contact parity through step 600 for both candidate lanes and through the available first episodes of the other lanes, correct host/policy and distinct expected task-binary hashes, continuous flight from first unloaded interval, full contact and actuator observation, no toe-speed threshold or physical failure, valid bounded flight and at least 0.10 rad signed heading difference in each expected direction with at most 2 m lateral deviation. Report wing/leg effort, saturation, tracking and any failure.

The two lane-specific fixed turn profiles are an experimental identification, not a general bounded-command interface. Even a pass is not full turning qualification, biological validation, frozen flight control, navigation or landing. The reference-state extraction is reproducible from the byte-reconstructible straight run, whose source SHA is recorded.
