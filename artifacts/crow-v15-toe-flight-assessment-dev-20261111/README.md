# Flight-phase toe assessment on development starts

In the first episodes of the retained strong-balance screen, all eight teacher-guided development starts had maximum absolute toe-joint speed below 0.87 rad/s from step 356 through the interval before their first observed course contact. Every expected toe-velocity substep was present. No toe-joint endpoint angle exceeded the configured [-0.3, 1.2] rad limits within the 0.0001 rad numerical tolerance. This narrows the observed speed-limit regression to the post-contact portion in this screen; it does not establish natural toe posture or qualify other starts and layouts. Landing contact still produced speed-limit hits in seven of the eight first episodes. Endpoint position checks do not rule out between-sample angle excursions.
