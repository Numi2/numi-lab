# Slower gait with contact recovery

The original 0.75-second gait retained alternating swings but every start briefly lost normal support. The 0.50-second contact-triggered recovery improved stability but endpoint slip remained appreciable. Combine the slower cycle with the same loss-of-support hold, retaining v15 body, actor, solver and 8-second walk. Measure all-substep support, clear alternating bouts, forward travel and speed on the same development seed; contact-point slip needs its own parity-checked observer. A gain in one metric does not qualify the full sequence.
