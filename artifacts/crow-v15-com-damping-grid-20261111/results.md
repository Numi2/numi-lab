# Center-of-mass and velocity feedback under grip

All 16 lanes matched the original trajectory through tick 85, and the reference exactly reproduced all 500 saved samples of the near-miss controller. None met the predeclared terminal support, opposing grip and overlap gates. Lane 5, with -0.01 m COM target and velocity coefficient 0.2, had 535 consecutive supported samples and 226 supported opposing-grip samples, but its grip overlap reached 0.658 mm and only 49 of the final 100 samples showed grip; terminal support also failed. Higher velocity coefficients destabilized these starts sooner and several lanes produced severe overlap. These are rejected development results, not a qualified landing; no reserved layout was used. The first analyzer invocation failed because the default Python lacked NumPy. Analysis was rerun using the existing isolated NumPy installation and the complete recorded trace.
