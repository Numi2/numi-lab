# Correction to build-time host metadata

The pre-run build scripts accidentally wrote the earlier 380-step logging host hash in push-wing-hashes.json and hold-wing-hashes.json. Those files are retained unchanged for audit. The actual host selected by run.py was the separately built extended 400-step logging host, identified by observer-build.json and by each run's inputs.json; its SHA-256 is `eff29637439dfbeaa458b1b55331e16c19f9a2dfffb239f0ec70c351387c1635`. The unrelated earlier observer hash erroneously printed in the build records is `a90c209bb315ebcc7a7f20bd4db9c3301720e419317608c273614b3637581a26`. The metallib and shader source hashes in those build records are unaffected. build.py is corrected for future reproductions. This metadata error does not alter the shader or recorded run.
