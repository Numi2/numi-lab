In the alignment-gated J trial the crow had 51 consecutive bilateral supported intervals but no opposed toe grip, then struck the perch with its beak. Accepted task states show both foot-contact groups loaded while both rear toes stayed near zero. The current toe-ramp signal is only the rear-toe wrench; the rear toe cannot build load before the ramp closes it. The existing landing phase also switches at a single bilateral contact before the toe counters can establish closure.
