# Reattached-foot standing balance: bounded hip-offset screen

The used-seed trimmed-shank trial fell backward with its whole-body COM projection behind the rearmost sampled loaded foot contact. Test a physics-driven leg response before changing gait: during the first 4 s, add a constant symmetric normalized hip action offset by lane, [-.30, -.20, -.10, 0, +.05, +.10, +.20, +.30]. This is an engineering sensitivity screen, not a biological gait calibration. The same shank-trim model, actuators, policy, starting states, contacts and solver remain in place. Lane 3 is an internal zero-offset control and must reproduce the preceding trimmed trial at the same lane. Eight used-seed lanes run with 16 substeps, no scheduled resets; keep full first-failure traces and report the loaded contact and stability outcome. An offset cannot establish contact feedback, real walking, or generalization. Any plausible candidate requires separate same-offset replicated starts, supported-contact feedback, and independent tests. No result implies anatomical validity of the toe-reattachment or shank trim.
