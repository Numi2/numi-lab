# Toe-joint damping contact-motion screen

The baseline's proximal rear toes carry substantial modeled normal impulse and exhibit motion while loaded. Previous distinct launch screens found fewer toe speed-limit events with increased internal toe damping but did not qualify flight. Test one exploratory value .030 versus the current .003, changing only the toe joints' damping in the v15 physical model and keeping geometry, inertias, stiffness, torque limits, 2 Hz baseline gait, solver and contact materials unchanged. The model fingerprint must change; rebind both actor packs with bitwise-identical weights and transforms, run a new preflight, and verify the compiled model's configured damping. Use the same eight development starts and the validated substep observer. Compare contact-speed integral, progress, support, cap hits, nonfoot contact and failure against retained .003 results. Require at least 25% less contact-speed integral on each foot in every lane, no worse support or limits, and at least .05 m forward progress to consider a follow-up. The value is uncalibrated and this is not flight, perch, biological or whole-sequence qualification.
