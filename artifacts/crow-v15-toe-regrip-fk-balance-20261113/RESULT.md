Observed hip targets were within the model-declared limits, and logged FK corrections matched the stated calculation; unobserved intervals cannot be checked. None passed final supported bilateral opposing grip.

At zero-based control step 255 the native run rolled back in lane 3 at substep 24 with `MR_STEP_DID_NOT_CONVERGE` (status 11); the first 256 control intervals' substep records and all prior state observations are retained. The rollback occurred after every first fall and is not evidence that a solver defect caused the failed grip. Remaining requested observations are absent, so the entire run fails; the scripts explicitly report missing coverage. This is a constructed perch test on a research-body variant, not a continuous flight landing or biological qualification.
