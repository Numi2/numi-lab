# Slower leg extension with commanded flapping suppressed: pre-run development screen

The matched and parity-verified effort observation found substantial generalized leg work (about 1.17 J net in six correlated lanes) during the 20 ms extension command but only about 0.0085 N s additional upward ground impulse versus the active crouch control; it did not identify where the work went. A previous different, wing-enabled screen suggested 160 ms leg interpolation avoided some speed-cap events in two lanes. Test whether a slower leg target transfers more impulse to the ground when commanded flapping is suppressed, while retaining the same body, earlier controller, launch timing and effort observer. This 160 ms interval is an engineering hypothesis, not a measured biological target.

Use exactly one source change from the previous push/no-flapping arm: replace the 6.96–6.98 s joint-target interpolation with 6.96–7.12 s. Keep wing amplitude zero from 6.3 s, the prior two direct body-moment actions disabled from 6.3 s, same existing v15 model and development seed 20261127, 8 lanes, 400 steps and 16 substeps. Lanes 2–7 are comparable; retain 0–1 controls. Compare to the newly parity-verified no-extension/no-flapping observer run and the prior 20 ms push observer run, without selecting lanes by outcome. Verify endpoint q/v/action/contact equality through step 345 before interpreting a treatment effect, complete first episodes, no contact-buffer overflow, and sample completeness.

Prespecified screen on lanes 2–7: compare summed signed upward foot impulse in steps 348–375, root vertical velocity at step 375, maximum sampled root rise relative to step 350 over steps 351–380, and three consecutive control intervals with both feet below total normal impulse 1e-7 N s throughout each interval. Report per-lane joint effort times coordinate change, other-ground contacts, and toe speed-cap substeps over steps 348–380. A candidate exceeds the engineering impulse screen only if it adds at least 0.05 N s relative to the paired crouch arm, and a separate lift screen requires three unloaded intervals and at least 0.05 m root rise. These are screening criteria, not biological thresholds or qualification. Report all measures even if gates fail; reject interpretation if parity or data integrity fails.

Flapping suppression retains passive aerodynamics and other wing motion; joint-effort work includes non-muscle terms; root height is not center-of-mass height; direct moments before 6.3 s and coupled contacts remain possible confounders. A screen pass does not prove leg-powered takeoff, stable flight, navigation, grip or landing. Preserve all failed runs and do not use reserved final layouts or seeds for development.
