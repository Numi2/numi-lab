# Matched original-flight task on the experimental hip-roll body

All five development lanes (straight, left, right, climb and descent commands) completed 1,600 intervals with no first-episode physical failure or reported GPU environment-step failure. Their six sampled heading, lateral-speed, forward-speed and height errors at steps 1,000–1,500 were within the earlier envelope thresholds. From observer step 300 onward there were no recorded positive ground-contact impulses and no toe substep endpoint reached the 12 rad/s cap; all 25,616 expected substep records per lane were present. Toe observer final-substep values agreed exactly with the recorded sampled endpoint velocities. Each lane did hit the toe speed cap in the earlier ground/takeoff phase, so none passes the stricter full-run no-cap screen.

The 35-body start positions differed from the older 33-body reference by 0.9–2.3 micrometers in the first sampled state; later sampled position differences reached 0.15–0.32 m, reflecting changed dynamics and trajectory, not bitwise parity. Course collisions were intentionally disabled for this flight control; only five starts were tested, with sparse body-state samples and no perturbed recovery. This does not qualify the new body/controller, the new walking/takeoff schedule, autonomous navigation, a supported landing, or biological realism.
