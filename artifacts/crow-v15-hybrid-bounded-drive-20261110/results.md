# Hybrid bounded drive: no supported grip

The original implicit-drive control reproduced all 200 prior hybrid state samples. The bounded-drive arms at toe effort caps 0.020, 0.005 and 0.001 N m completed this one stationary-perch start without reported rollback, but none achieved three consecutive simultaneous opposing grip and bilateral support, and none had terminal supported posture. Therefore no bounded-drive arm qualifies. Their lack of an opposing-grip sample makes a grip-conditioned SAT gap unavailable; it does not mean the rigid shapes did not overlap. This global actuation-mode change affects all driven joints, not just toes, and the result neither proves a motor solver defect nor evaluates a trained bounded-drive crow. It is not full navigation, biological calibration or held-out evidence.
