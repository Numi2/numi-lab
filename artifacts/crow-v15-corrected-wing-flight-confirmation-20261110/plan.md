# Estimated-wing controller confirmation plan

Freeze the candidate research shader for this test only, with the estimated wing mass, shoulder-aligned aerodynamic prototype, fixed twist bias -0.75 and flap-amplitude increase 0.28 after six seconds. Test flight on preselected seeds 18721853 and 18721889, which were absent from tracked project artifacts when checked. They are flight-development seeds, not reserved final layout/seed tests. Each seed uses 80 lanes, 1600 ticks, 4 physics substeps, standard varied ground starts, fixed head, zero actor, no obstacle collisions, ordinary ground collisions, no scheduled resets, and 0.70 m/s plus the five existing straight/turn/height modes. Require all lanes to survive their first episode, no solver failed steps, 1000–1500 sampled heading <=0.15 rad, lateral speed <=0.20 m/s, speed error <=0.20 m/s and height error <=0.15 m, maximum sampled toe rate <12 rad/s, and median climb-minus-descent height >=0.25 m per seed. Missing traces are failures. Record source, input and runtime hashes. This screen is not flight qualification for other speeds, airborne recovery, route clearance, walking, takeoff mechanics, landing, a visually guided actor, or real birds. Do not freeze for deployment until the remaining prescribed controller qualification is complete.
