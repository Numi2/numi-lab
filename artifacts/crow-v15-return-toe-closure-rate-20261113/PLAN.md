# Faster returning-toe closure after supported release

In the larger-return placement test, the returning foretoes finally developed opposing normals, but only after body tilt had exceeded the 0.35 rad supported-grip limit; the stance foot had usually lost its opposing foretoe normal. Test whether a faster bounded foretoe position-target ramp engages earlier. Use the same +0.30 rad knee / -0.60 rad ankle placement and stance-contact/posture gates in both lanes. Lane 0 retains 0.045 rad per 20 ms foretoe closure; lane 1 uses 0.090 rad per interval after release, with the same 1.05 rad cap and the existing physical joint drives and effort limits. The rear-toe command and all other inputs remain matched. No body force or kinematic override is added.

Run 450 intervals and 32 substeps from identical constructed states. Require exact q/v parity before the first actual foretoe target difference, complete substep contact observations, bounded targets and accepted joint positions, ten independently validated release intervals and 100 final bilateral opposing-grip intervals with the established tilt, speed, support and nonfoot-contact criteria. Record accepted-state toe speeds and report the limitation that toe speeds and efforts are not independently observed at every substep. Retain all failures and geometry. This single development test is neither biological validation nor an airborne landing qualification.
