# Isolated toe/perch penetration sensitivity

Accepted v15 full-trajectory SAT showed approximately 3 mm front-toe and 4.2 mm rear-toe median box overlap during a supported grip. The shapes have identity local transforms and a zero rest offset; this rigid-proxy overlap is not a biological deformation model. Investigate whether temporal resolution changes the issue before changing any production physics or controller.

Use the previously archived isolated toe-and-box grip bench with identical two perturbed starts and gradual closure/release; vary only physics substeps 4, 8 and 16 at the same 20 ms control interval, using its unchanged model, material, solver mode, velocity iterations and actuator law. Record per-contact signed separations, normal impulses, closure/release and every rollback. Compare the last ten pre-release hold samples only for cases that reach the grip phase, without silently excluding failures. This is an isolated proxy with a different box length/height and starting setup, not an exact v15 full-start replay or a biological model. A better numerical result only motivates a carefully matched v15 follow-up and flight requalification; it does not prove the full goal.
