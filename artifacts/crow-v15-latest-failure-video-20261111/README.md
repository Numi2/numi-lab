# Latest crow development failure excerpts

This 11.04-second video joins four continuous, reset-free excerpts from existing v15 development replays. It is not an end-to-end test, a reserved-layout evaluation, or evidence of a successful supported landing. Frames are 1280 x 720 at the recorded 50 Hz. The source state range and command-line settings are also recorded in the four renderer audits. The video was composed from native BirdFlow `birdflow-capture` output with caption overlays; the bird is state-driven, but feather geometry, skinning, toe bridges and support presentation are estimates. The camera removes root translation, so the recorded backward displacement is a trace measurement, not something that can be judged against the featureless ground in the walk view. Perch geometry is an explicit narrow-perch rendering override and camera-occluding geometry can be drawn as wireframes.
