# Fixed-state regrip geometry diagnostic

At the latest paired physical return trial, neither lane produced opposing front-toe contact and the sampled front gap remained large while the rear toe touched. On retained zero-based ticks 250, 270 and 290 from both lanes, use the same independently checked native v15 FK model to measure how small +/-0.02 rad perturbations of the returning hip, knee, ankle and eight toe joints change foot, nearest-front and nearest-rear box gaps. Cross-check zero-perturbation values against the independently reconstructed stored body-pose gaps. Report joint-bound issues and all model and input hashes. These are fixed-pose derivatives: they do not predict a dynamically reachable trajectory, contact force, grip, body stability or biological behavior. Use them only to design a subsequent bounded physical test.
