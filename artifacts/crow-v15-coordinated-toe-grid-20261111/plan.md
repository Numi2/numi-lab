# Coordinate front and rear toes under aft-COM balance

Actual contact moment measurements showed rear-toe reclosure added positive pitch impulse, partly opposed by front-toe contact. In 16 independent batched v15 development lanes, preserve the same -0.02 m COM reference, physical body and effort-limited leg/toe drives. Lane 0 is the no-reclosure reference, lane 1 uses the previously measured rear feedback (0.002 N s threshold, 0.85 rad cap, 0.004 rad/tick), and the remaining 14 combine it with front-toe feedback. After bilateral grip and hold tick 10 only, compare lower per-foot front impulse thresholds 0.015, 0.018, 0.021, 0.024, 0.027, 0.030 and 0.033 N s at bounded closure rates 0.001 or 0.002 rad/tick. If either front foot's impulse exceeds 0.05 N s, relax front command by 0.01 rad/tick; cap at the existing 0.85 rad. Thresholds are test values, not calibrated bird forces. Require all lanes to match the original start through tick 85 and both reference lanes to match their 500 stored traces exactly. Evaluate the same continuous terminal bilateral grip and support, contact-overlap <=0.5 mm, no nonfoot support, tilt/speed and solver gates. Survivors need independent longer, perturbed-start, release and full-route validation; reserved layouts stay unused.
