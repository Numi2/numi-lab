# Combine stance preposition with measured returning-foot placement

The ongoing stance preposition test reached its targets, released and cleared the moving foot, and the smaller-offset stance lane retained opposing support during part of return. A previous returning-foot knee/ankle placement trial stalled almost immediately when its support gate was lost. This follow-up tests whether the smaller stance preposition can maintain support long enough for returning-foot placement to execute: both lanes use +0.075/-0.15 rad right knee/ankle before release; during return compare +0.075/-0.15 and +0.15/-0.30 left knee/ankle targets. Advance return placement over at least 20 intervals only while measured stance opposition and posture gates hold; retain the same toe motion, 10-interval release clearance, material, force and position limits. These are physical joint commands, not position resets or attachment.

Require exact matching until the first preposition command, valid target and accepted joint bounds, complete 32-substep contact observation, no fall and 100 consecutive terminal intervals of bilateral upward support with opposing toe normals and safe pose/speed. Count loss of support, blocked placement, grip failure, rollback, or incomplete execution as failures. Test only a constructed perch start; this is not airborne-landing or mission qualification.
