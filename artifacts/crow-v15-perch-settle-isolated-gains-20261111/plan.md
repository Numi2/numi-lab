# Isolated early settling gains

The 8-lane sweep aborted when gain 1.5 produced a solver failure in one environment during the first contact. Run two difficult starts with each candidate gain in its own two-lane 300-interval process, in order 0.5, 1.0, 1.5, 2.5, preserving all failures so a failure at one gain cannot censor later gains. All use the same 0.4-second damping and ±0.16 rad target bound. This screen tests early grip and loss of balance; it is not a flight, landing or full release qualification.
