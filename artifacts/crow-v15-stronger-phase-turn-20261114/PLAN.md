# Stronger matched phase-gated turn identification

The prior fixed +/−0.04 rad wing-pronation differential produced only about +/−0.154 rad heading change while actuator effort was saturated for roughly 56% of observed samples. Test +/−0.08 rad, keeping the existing phase gate, actuation effort/speed/position limits, symmetric flight carrier, height/speed feedback, teacher-off state and task-body-wrench ablation unchanged. Use identical onset and same already-used development seed 20261127 and compare each candidate to its matched archived straight-flight state stream. This is a fixed-profile identification experiment, not a general command interface or a final-layout test.

Run 1800 control intervals with 16 substeps. Require exact state/action/contact parity through interval 600 and for unchanged lanes, matching host and policy identities, reconstruction of commanded wing targets, complete unique substep coverage, no observer errors, first-unloading-to-end continuous flight, no candidate physical failure, no later foot or nonfoot contact, bounded forward speed and height, toe speed below threshold and wing/pronation effort and position within existing modeled limits. For the authority screen require at least 0.25 rad signed heading change in each expected direction and at most 2 m lateral deviation in the measured 600–1200 window. Report saturation and tracking rather than using a KL-like target or declaring improved flight solely from a larger angle. Preserve failures and full raw observations. Passing this limited same-seed maneuver does not establish qualified navigation, disturbed-start recovery, biological realism or a frozen controller.
