Independent articulated kinematics found that hip and ankle both rotate the foot in the same direction, so the current opposite hip/ankle balance almost cancels its foot-angle correction while the foot tips with the body. Two used J starts each test a bounded, contact-gated pitch/rate response directed either to the ankle only or to both hip and ankle in the same direction. Use 45 mm approach offset and unchanged toe/body/flight law. Evaluate contact, foot angle, root attitude, strict terminal support and grip over 4500 steps. This is a diagnostic, not visually autonomous held-out qualification.
