# Rear-toe touchdown configuration screen

The retained 0.4 rad crouch screen showed a proximal rear toe hitting its negative speed and position limits coincident with touchdown, despite a zero target. A related-magpie study describes toes flexing in recovery then extending before touchdown; it does not measure this model's target or validate the following intervention. In eight development starts, hold crouch bias 0.4 and apply rear-toe positive-position preload [0.05,0.10,0.15,0.20,0,0.30,0.40,0.50] radians on the negative phase of the retained leg carrier, gated by opposite-foot support and ramped by phase. This tests whether touchdown posture changes the impact; it is not a biologically inferred target. Lane 4 must reproduce all records of the prior identical zero-preload 0.4-bias candidate; all lanes must match before the crouch. Record actual toe angles, speed caps and normal impulses as well as the command, support, contact-point velocity, movement, clearance, and release ordering.

Only 0–6 s is run; the mode is diagnostic, not safe for flight integration. Different preloads use different starts; any promising setting requires matched-start controls and must not be promoted without subsequent independent gait, takeoff, flight, release and landing qualification. No joint limit, collision filter or applied force is changed.
