# Contact-triggered balance gain: inconclusive, gate never activated

The eight-lane physical run completed all 450 intervals with complete contact and toe-velocity substep coverage and no observer errors. All eight lanes produced identical logged states, commands and contacts: the candidate gate requiring both opposed feet with each endpoint upward impulse above 0.001 N s never became true, so none of the 1, 2 or 4 gain interventions was applied. All had 43 qualified release intervals, an 11-interval maximum bilateral grip streak, a fall at interval 370, and the modeled 12 rad/s toe-speed cap before falling. This trial does not test the proposed gains and cannot show whether they help or hurt.

The original per-lane velocity and grip analyzers inadvertently covered only the first two lanes; their outputs are retained. Separate all-lane versions and outputs are included. The first-difference audit correctly flags the missing candidate interventions. Full substeps, model and build identity are retained; contact/state epoch synchronization remains unverified. A follow-up may test the same bounded gains using the existing lower endpoint support threshold, but must preserve the no-intervention outcome here.
