# Matched hybrid toe stiffness screen

The corrected run recorded the configured stiffness values and the original 0.10 N m/rad control reproduced all 200 earlier baseline states exactly. No arm passed the prespecified grip, release and sustained support criteria in this single development start. For stiffness 0.10, 0.05 and 0.025 N m/rad, the worst observed grip-conditioned SAT overlaps were respectively 5.034, 5.247 and 4.509 mm. The 0.0125 arm had no three-sample simultaneous opposing grip; its grip-conditioned gap is unavailable. No stiffness qualifies. These settings are research values, not biologically calibrated, and do not establish whole-sequence performance.
