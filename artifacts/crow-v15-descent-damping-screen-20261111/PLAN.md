# Controlled landing acquisition screen

Question: does the current phase-one descent compensation keep the bird bouncing above the perch after first foot contact? The retained development run contains four lanes that touched but never sustained even ten intervals of half-weight foot support; it also contains separate post-grip balance failures. The cause is not yet established.

Intervention: starting from the exact autonomous walking/launch/route/landing reference, reduce only phase-one downward-velocity height compensation from 0.35 s to 0.18 s, retaining its bounds and all phase logic, leg and toe controls, physical properties, low-level flight source and other targets. The reference and intervention must match before phase one. This is an engineering perturbation, not a biological parameter estimate.

Prediction: if excessive vertical compensation materially suppresses capture, more of the eight matched first episodes should obtain at least ten consecutive half-weight foot-support intervals and achieve the terminal 25-interval bilateral opposed-toe criterion; contact speed and fall counts must not worsen. Evaluate the same used development seed, no teacher, 3800 intervals, 16 native substeps, with all approach and contact logs, all first episodes including failures, per-substep coverage/overflow, exact source/host/policy fingerprints and accepted-state prefix comparison. Reject on solver error, new pre-landing regression or worse failures; do not promote this screening result alone. The already-observed run is the reference, not an unused-layout test. Post-capture tilt, deliberate release, long-term hold, flight-turn qualification and whole-body biological gait remain independently open.
