# Matched return placement ablation from improved stance

Prior return attempts lost stance support soon after returning-leg placement; reducing placement slew from 0.05 to 0.005 per interval delayed but did not prevent failure. Test whether that extra placement component is needed when returning from the improved -5 mm, 0.32 rad roll-cap stance. Both physically evolved lanes request return after the same existing 40-interval clearance counter, unwind lift/knee/ankle clearance at the existing rates and retain the same toe rules. Lane 0 uses the original 0.05 placement-progress increment; lane 1 disables only that extra placement progression, allowing the clearance unwind itself to return the foot. Limits, drives, gating and force model are unchanged. A return counter of 40 is an exploratory trigger and does not meet the independent 100-interval release gate.

Require exact q/v and logged-target parity to the archived roll-cap release before the first return, exact between-lane prefix before the first placement difference, 450 states with unique 32-substep contacts, bounded joint commands/positions, no errors, no nonfoot support and no pre-fall accepted toe-speed threshold. Independently require 100 strict release intervals and 100 consecutive bilateral opposing-grip, posture, support and speed intervals; report all contact, geometry and first-failure outcomes. Preserve failures. Contact/state epochs remain unverified; this constructed stationary test is not walking or landing.
