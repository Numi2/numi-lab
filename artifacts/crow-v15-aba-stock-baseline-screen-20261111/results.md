# Unmodified 32-body ABA baseline

The original host and full compiled MetalRobo library on the same 96-state 25-body screen produced a worst GPU/CPU scaled acceleration error of 6.21003e-5 at neck pitch, above the predeclared 5e-5 gate. This is identical to the isolated fast-math 25-body control. Thus the varied-state discrepancy is not solely caused by widening the body bucket. This single-step test does not establish a failure in flight or contact.
