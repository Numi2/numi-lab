# Geometry-guided physical regrip: failed

The extra contact-triggered hip, knee and ankle target offsets did not produce any qualifying bilateral supported regrip interval. The candidate fell at one-based interval 361 versus 359 in its exact matched control; both had only 41 qualifying release intervals and the controller still initiates return after 40. At zero-based tick 310 the candidate's nearest front-toe gap was 1.381 mm versus the control's 1.899 mm, while the rear toe touched. There were no post-return pre-fall intervals passing the returning-foot opposing-toe gate. The candidate reached the 11.99 rad/s toe-speed threshold in 13 pre-fall substeps; the control had none. These failures prevent promotion.

At tick 310, actual candidate-minus-control hip/knee/ankle positions were +0.03946/-0.03995/-0.01999 rad, close to the fixed-state grid offsets, but root position also shifted about +0.988 mm in x and -0.523 mm in y, with other state differences. The actual nearest front gap was 1.238 mm larger than the fixed-state prediction. This shows the static geometry does not predict the coupled dynamic outcome; it does not isolate the causal contribution of any one state change.

The control exactly reproduces all 450 prior candidate state, command and event records, and both lanes match that candidate through the first additional target at zero-based tick 300. All 28,800 contact and toe-velocity substeps are unique and finite, with no recorded nonfoot support, native or observer error. Both gzip streams validate and runtime/prebuilt hashes match. Contact/state epoch alignment remains unverified and toe actuator effort was not measured. This stationary constructed test is not walking, airborne landing or biological validation; all failure evidence is retained.
