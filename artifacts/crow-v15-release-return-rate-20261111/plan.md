# Slower contact-triggered foot return

The original contact-triggered return obtained ten qualified release intervals in both starts, then caused forward body movement and falling during rapid leg return; increasing velocity feedback alone failed or was interrupted. Preserve those findings. Keep the acquired grip, release, independently checked clearance trigger, toe latching, balance and two starts unchanged. After the measured return trigger, return the left knee target toward its original angle at .15, .012, .006 or .003 rad per .02-second interval, with the same half-opposite ankle target; the .15 case is the exact instantaneous-return control. Use two starts per rate. Require the same ten-interval physical release, 100 terminal intervals of bilateral supported opposing grip, no fall, no nonfoot impulse, complete substep records and sensor parity. Confirm the instantaneous controls reproduce the previous q/v and contacts. This is a constructed development probe, not landing or route qualification.
