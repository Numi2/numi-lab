# Common-controller climb and descent screen

Use the diagnostic-state-isolated experimental controller with 2.80 heading gain from the prior matched turn screen. Replace the turn-pulse commands with zero heading in every lane. Set all other flight settings identically: 0.55 m/s speed, 1.05 m base height, common 1.20 height gain and 0.60 unsteady-normal blend. During 12–18 s only, smoothly step the height command by +0.20 m in lanes 4/5 and −0.20 m in lanes 6/7. Lanes 0–3 retain 1.05 m. Return all commands to 1.05 m after the pulse. Use the same development seed and obstacle-disabled environment. Report absolute height and rates before, during, after the pulse, survival, direction of response and lateral motion. Because these are different but related starts, this is not a same-lane counterfactual; a no-step matched repeat is needed. The lighter observer does not establish joint-cap freedom or full flight, gait, landing, biological or unseen-layout qualification.
