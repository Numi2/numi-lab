# Integrated commanded toe release on development J

The isolated reached-state probe showed that ramping physical toe targets to zero opened the toes and removed rear opposing force while feet remained supported. Before running, test that mechanism inside the complete continuous guided v15 sequence. Use the same bounded-rebound controller, 7000-step host and previously used J seed 3193706597. Change only the toe target logic: at 120 s (step 6000) issue an external experimental release command that sets the eight toe position targets to zero. This is a scheduled diagnostic command, not an autonomous decision. Require exact accepted q/v parity with the non-release run for all pre-command frames, five reached waypoints, established bilateral toe grip before the command, actual toe opening and loss of rear opposing force while both feet remain supported, and no nonfoot collision or solver failure through 7000. Measure transient and eventual toe angles, forces and root pose. Preserve losses and compare controls; do not claim toe clearance, bird-like biology or held-out autonomy.
