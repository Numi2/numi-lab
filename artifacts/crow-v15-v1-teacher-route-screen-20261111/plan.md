# V1 privileged navigation teacher diagnostic

The legacy V2-trained actor hit slalom B in its first continuous V1 episode. A previous teacher's commanded values were overwritten by foot-load data, and its repaired V2 teacher still was not a qualified landing demonstrator. For diagnosis only, preserve the existing privileged waypoint commands in the existing task-specific metadata lane rather than the overwritten foot-load lane, and apply the same fixed launch command to both teacher and student until the existing 7–8 second handoff. Keep V1, the selected contact-gated gait and leg launch, the v15 toe body, solver, physical obstacles and existing waypoint teacher otherwise unchanged. Build both a diagnostic teacher shader and its byte-identical teacher-off control command path. On already exposed development J, run one full start with the privileged teacher and 16 substeps, no scheduled resets, for 3000 ticks. Compare pre-handoff physical states with a matched teacher-off control if available and report all discrepancies, first episode waypoints, first collision, clearance and failures. Then, only if the route is promising, screen additional I/J starts before using any successful corrective samples. No failed demonstration is valid training data. This is not visual autonomy or a held-out final trial, and no privileged teacher may be present in final evaluation.
