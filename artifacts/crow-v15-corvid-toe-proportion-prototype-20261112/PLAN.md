# Isolated related-crow-informed toe proportion prototype

The current v15 research body gives all three front digits equal 36 mm straight box extent. Hooded-crow radiographic group estimates put digit II/III near 0.70 and IV/III near 0.74; the model digit II/IV mapping is not yet established. Create an isolated probe with both outer collision digits at 0.72 times the existing middle digit and with the digit base position fixed. This 0.72 is an exploratory midpoint for an uncertain anatomical mapping, not a measurement of an American crow, not a claim about soft-tissue collision width and not a claim of individual digit or claw realism. Keep the same two segments per digit, toe segment masses, widths and heights; recompute local inertia and parental inertia subtraction from the new geometric lengths and positions. Record mass and dynamic changes rather than claiming the altered body is physically identical.

Before any task integration, compile a separate native probe; verify model validity, positive masses and diagonal inertia, unchanged total body mass, intended segment lengths, finite articulated invariants across 36 configurations, and compare deterministic native GPU and independent CPU forward dynamics for 12 free-space lanes, requiring each toe degree of freedom to move and a scaled acceleration discrepancy below 5e-5. Record energy/momentum differences versus the original no-toe body, as geometry changes make exact equality inappropriate. Hash source and binary. This is free-space mechanics only; no ground contact, walking, perch, takeoff, flight, navigation, rendering or biological qualification is implied. If it passes, build an isolated version of the current instrumented contact host and separately validate policy rebinding and dynamics before any matched gait trial.
