# Two-segment contact-triggered grip screen

Use the validated 33-body 16-substep contact observer and the same single stationary perch initial state, with no intermediate resets, for 350 control intervals. Match the original open-toe command through step 9. Thereafter, each foot latches its rear-toe closure only on a measured positive endpoint rear-segment/perch impulse; ramp proximal targets by 0.02 rad per interval to 0.55 rad and distal targets to 75% of that. Begin the same foot's front-toe ramp at 0.015 rad per interval only after two consecutive endpoint rear-impulse observations above 0.00005 N s; hold requested front closure if rear contact is later lost. All targets are bounded joint drives; no scripted body motion, external forces, contact edits, or reset are used. Leg targets remain the same neutral position drives as the admission.

Retain every accepted state and all 16-substep contact impulses, including both segments per digit. Require at least 50 consecutive intervals with bilateral foot support above half body weight, no nonfoot impulse, body tilt <=0.35 rad, root linear speed <=0.12 m/s, and opposing signed normal impulses on the front and rear digits of each foot. Independently estimate accepted-endpoint oriented-box toe/perch penetration, requiring <=0.5 mm while opposed. Report the actual first loss/failure, successful and failed conditions. This isolated hand-initialized perch start is not a reached landing, release, walking, autonomous route, robust generalization, convergence or biological qualification.
