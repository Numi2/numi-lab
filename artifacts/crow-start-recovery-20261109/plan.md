# Flight command tracking from deliberately perturbed ground starts

Prediction: the closed-loop controller that passed the matched nominal screen will recover from modest prescribed start attitude and velocity deviations and track the same bounded flight commands. This is a development experiment on unchanged v15, not the final qualification or navigation holdout.

Use the identical diagnostic controller and five commands/screens of the matched 80-lane experiment, and independently repeat 80 lanes for development seeds 20261113, 20261114 and 20261115. Commands are assigned by lane modulo 5. Cross them with eight deterministic start perturbations assigned by lane modulo 8: baseline; roll +0.12 rad; roll -0.12; pitch +0.08; pitch -0.08; yaw +0.12; yaw -0.12; and mixed roll +0.08, pitch -0.06, yaw +0.10 rad with +0.08 m/s lateral and +0.15 rad/s body roll rate. Compose each perturbation with the randomized initial root orientation, leave all articulated joint values and body physics intact, and raise perturbed starts 0.04 m so that tilting at reset does not artificially intersect the ground. Applied linear/angular velocities are generalized world coordinates; exact values and source patch will be recorded. The observer logs accepted state every two seconds and the state trace records one perturbed lane from step one.

Require zero failed environment steps, zero physical terminations and all 240 first episodes passing the original 20–30 s sampled command screen. Report each seed, each condition and each failed lane, first failure and symptoms; no retries or seed replacement. These modest ground-start perturbations do not demonstrate airborne-disturbance recovery, untested starts, continuous obstacle clearance, or landing. Success is necessary but not sufficient for qualification. Do not use final navigation layouts or seeds.
