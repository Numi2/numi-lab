# Longer contact-triggered toe memory

All 16 teacher-guided development starts survived through 4500 steps, but qualifying bilateral loading lasted no more than two steps and none entered the landed phase. On I, the observed maximum toe angle after 25 consecutive foot/toe-contact-candidate-free steps was 0.05687 rad, exceeding the predeclared 0.05 rad limit; J's corresponding maximum was 0.04133 rad. The loading prediction and free-toe condition were contradicted, so this longer-memory variant is rejected. No supported landing or autonomous result is claimed.
