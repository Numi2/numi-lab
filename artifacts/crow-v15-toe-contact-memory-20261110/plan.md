# Contact-triggered toe response with bounded memory

The isolated revised body can produce and release bilateral opposing toe impulses from supported starts, but the actual airborne approach gives at most two consecutive loaded samples and has not produced opposing grip. The current ramp gains only six counts per loaded step and decays three per unloaded step. Hypothesis: the brief bounce removes the closure command before the toe motors can reach the perch. Alternative: the limiting factor is landing kinematics/balance and longer closure will not help or will cause a flight toe regression.

Keep the active original 5x11 cm collision perch, intermediate approach height, frozen flight law, state and native physics fixed. Change only the toe debounce integrator to add 12 counts per accepted loaded step and decay two counts per unloaded step. Its target returns to zero without renewed contacts, and no kinematic pose or extra constraint is added. On the same 8 starts each in reused development I and J, for 4500 steps, predict >=12/16 survive, >=4/16 sustain ten consecutive bilateral-load samples (>0.1 N per foot, >2.2 N total), and all feet remain below 0.05 rad after 25 consecutive steps without any candidate foot/toe contact. Also audit opposing impulses per foot. Retain every result. Any >0.05 rad candidate-free toe angle is a regression for this trial; do not promote it. Autonomous final layouts, biological realism, and full supported landing remain unproven.
