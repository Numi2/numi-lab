# Configurable substep toe contact observer

The prior native observer captured only submissions 4375–4410 and omitted the lateral contact normal. Extend only diagnostic code so an explicit environment variable range selects the recorded submissions and each toe/perch contact prints all normal components. Retain original defaults and physics, solver, body, flight control and task program. Build isolated original-body and toe-damping-body hosts, record exact patches and hashes, and verify that recorded physical trajectories match the corresponding uninstrumented run before interpreting the contact records. At each substep, count front and rear opposing normal impulses separately for both feet and distinguish absent contact from an unavailable status sample. This is simulated contact evidence, not biological validation.
