# Takeoff force temporal-resolution check

The retained 16-substep launch trace has sharp force peaks sensitive to averaging. Compare it to a 32-substep run at the same 20 ms control interval, body, shader, host, actions, solver settings, policy, start seed and no-reset sequence. This is an end-to-end timestep sensitivity comparison, not a matched-state fork: state and contacts may diverge throughout the approach and cannot by themselves establish force convergence. The existing perch-grip threshold is written for 16 substeps; this study stops at interval 360 during launch, before perch grip, and cannot be used for landing or admitted as a full-sequence run. Confirm from recorded state that the perch-release/grip control has not activated.

Run a two-step 32-substep policy-contract preflight before the full run. If the runtime rejects the policy fingerprint, retain the failure and investigate the contracts before any diagnostic rebind. The 16-substep reference is the retained run only if source, binary, policy and configuration hashes match; otherwise repeat it on the same host. At each resolution report unfiltered upward impulse per dt and 25 ms moving-average peak divided by model bodyweight, plus total push impulse, full trace coverage, support, nonfoot contacts and physical failure; do not interpret this as the paper's filtered force plate quantity. The primary observational goal is to determine whether spike amplitude and total impulse change materially with timestep, not to force a match to one related bird. Preserve errors and failures.
