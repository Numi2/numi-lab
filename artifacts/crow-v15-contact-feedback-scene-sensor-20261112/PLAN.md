# Scene-aware contact feedback screen

The first feedback trial reported the same quantized zero reading for every experimental lane and frame, while independently reconstructed final-substep contact velocities were nonzero. The likely cause is that the sensor treated scene collider indices as robot-body array indices and skipped indices outside the robot body stride. Read robot state from the articulated body arena and scene state from the separate scene arena, with explicit range checks; map zero velocity to exact zero in the 10-bit encoding. Reuse the passive state-lane observer and compare its published readings against offline final-substep articulated reconstruction. Repeat the same paired signed gains in six development lanes with two unchanged controls, require exact pre-intervention/control parity, then score 800 Hz contact-motion integral, support, toe limits and progress. If sensor agreement fails, the experiment remains inconclusive. No production state interface or autonomy claim.
