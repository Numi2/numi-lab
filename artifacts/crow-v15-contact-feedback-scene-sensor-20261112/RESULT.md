# Scene-array change did not repair the contact sensor

The attempted scene-array change did not restore the signal: all six candidate lanes reported the exact zero code for every one of the 99 audited frames. The independent reconstruction measured 0.0140–0.0154 m/s mean absolute final-substep fore-aft contact-point motion. The complete 4–6 s physical state and contact trajectories in all eight lanes were identical to the no-feedback reference, and the substep contact-speed integral ratios were exactly 1.0. As the feedback signal was zero, this is not an informative test of the gains or a walking improvement. The point/velocity timing offset and impulse cutoff limit the offline measurement; the large persistent disagreement nevertheless requires investigation.

All 1,600 recorded pre-intervention states and 25,600 contact substeps matched. Every lane also matched all 300 endpoint states and 4,800 contact substeps against the reference, with no toe-speed cap, simultaneous unload or nonfoot contact during the walking window. Mapping the zero code to exactly zero removed the previous quantization bias. The next diagnostic checks the actual final contact-status buffer and strides at task completion. This is an isolated development experiment; the reused power lane and scene-index assumption are not a production sensor design.
