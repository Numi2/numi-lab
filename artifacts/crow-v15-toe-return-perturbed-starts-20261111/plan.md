# Short return under perturbed starts

A longer return lost support and caused an environment rollback in the previous batched sweep; shorter 40/80-interval ramps remained above the fall threshold until that batch stopped. Test only these two shorter ramps in eight constructed starts varying fore-aft position by up to 4 mm, height by up to 3 mm, roll from -0.065 to -0.015 rad and fore-aft velocity from -0.04 to -0.01 m/s. Measure toe speeds at every substep, support, release and regrip; retain all failures and incomplete runs. These are development states and do not use reserved layouts.
