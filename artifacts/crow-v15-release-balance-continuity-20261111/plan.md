# Preserve body balance through toe release

The initial release replay shows a sharp body-velocity jump at release because the existing phase switch immediately reverts the hip, COM and ankle balance targets to their pre-grip law. Test a single mechanistic correction: preserve the already active bounded hip, COM and ankle feedback through phase 4 while keeping contact-triggered release, toe opening rates, body, solver, force limits and all other settings identical. Independently require exact state-trace equality with the first release replay until its observed release transition. Run 1,400 ticks and require the same terminal 50 consecutive open-toe, no-opposing-impulse, supported, bounded-pose samples, without nonfoot support or solver failure. The test is one stationary development start, not proof of release under perturbations, flight, full routes or biological realism. Preserve failures and no unused layouts are used.
