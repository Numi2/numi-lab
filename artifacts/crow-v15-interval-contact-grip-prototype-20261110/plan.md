# Full-interval contact driven grip prototype

The exact-state 16-substep observer saw opposing rear-toe impulses during intervals where the final-substep signal was below threshold. In one separated-start development case, compare the existing original 16-substep controller (arm 0) with the same controller using the total per-toe oriented contact impulse over the entire 20 ms interval (arm 1). The measured signal is copied from real solver constraints, not invented forces or state injection; the associated trigger is scaled to the same nominal 0.01 N average force. Both arms use identical body, physics, timestep and initial states. A research host observer exports the last completed interval with an explicit submission sequence check. Arm 0 must reproduce all 200 saved states of the prior uninstrumented 16-substep run; failure invalidates the comparison. Record all outcomes, full-interval per-toe impulse, support, release, final posture and independent SAT gap. Require grip with support, release, sustained open-toe support and <=0.5 mm grip overlap to nominate broader eight-start tests. This single stationary drop, host-side prototype and estimated sensor are not autonomous landing, flight, biological qualification, or grounds for using held-out layouts.
