# Reactive landing toe experiment

The newly toe-equipped v15 body with neutral toes failed the four full first-episode route/landing tests. One lane collided with the perch via the body after rear-toe contact, one contacted slalom A with the left wing, and the others had no supported finish. The isolated toe experiment established short front/rear force opposition only on a centered development perch, not on the full route.

Before running, add two separate native contact-wrench observation groups for the left and right rear toes to the experimental task; do not include them in the actor's input or treat them as generic foot-support rewards. Keep the original actor input and action operators, geometry, conservative envelopes, physical parameters, frozen flight controller, walking/launch patch, and distinct body identity. Compile a new, separately fingerprinted task. Compare inherited compiled action/observation tables, layouts, old contact groups and coordinates against the previous toe task before any actor migration. Preserve actor tensors exactly in separately identified diagnostic packs.

At each accepted boundary after reaching the final waypoint, command the rear toes to close. Increase each front-toe target in steps of 0.025 rad, bounded to 0.85, only when that side's previous accepted rear-toe wrench exceeds 0.05 N; otherwise back off by 0.025 rad. Before waypoint five, use neutral toes. The controller owns the documented reserved `status.w` lane in this isolated no-impact task; verify no other current task path writes it. Write actual toe position-drive targets to the eight added native DOFs; do not inject forces, constraints, or states. Compare against a sensor-zero matched control with identical physical collisions and a neutral-toe control, retaining all failures. First do one lane on each exposed layout and require a completed first episode with five waypoints and 25 low-speed supported endpoints plus opposing loaded front/rear toe normals on each foot followed by a separately commanded release; mere waypoint completion is insufficient. This is exploratory; flight qualification on the altered body and unexposed-layout generalization remain separate.

For this bounded first experiment the release command starts at simulation time 55.0 seconds, regardless of whether a grip was achieved; it sets all eight target angles to zero. This fixed release is an evaluation stimulus, not an autonomous task decision. A full solution must choose release from its task and support state. Only completed initial first episodes count.

Before the full-route comparisons, run a matched 350-step training-layout smoke test of active and sensor-zero shaders on one lane. During this early interval waypoint five has not been reached, so toe commands should remain neutral and accepted q/v trajectories should be byte-identical. If not, investigate before interpreting any later differences.
