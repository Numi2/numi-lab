# Matched heading-feedback gain comparison

The paired +/- heading-target trial showed controllable but slow heading response and incomplete three-second recovery. Using the same seed, exact starts, flight controller, command pulses, body, empirical aerodynamic settings and limits, change only the existing pronation-heading feedback gain from 1.40 to 2.80; keep its +/-0.30 output bound and yaw-rate term. Compare against the immediately preceding per-lane same-target trial, not a different bird, height or gain. Preserve unmodified zero-loop lanes 0–1 as an observer/control. Demand exact state and contact parity before the input can differ. Measure heading/target errors, recovery, roll, altitude, motion, joint limits and contact. A gain improvement does not establish biological flight, perturbed-start capability, uniform aerodynamics, navigation or landing. The current research runs retain lane-specific unsteady-force and height-feedback settings; comparisons are within each lane only.
