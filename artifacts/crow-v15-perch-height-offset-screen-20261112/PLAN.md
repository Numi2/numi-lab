# Higher perch start: capture-offset screen

Repeat the failed +2 mm fore-aft, +3 mm height constructed start at six physical hip capture offsets 0, .005, .010, .015, .025 and .040 rad. Keep the previous controller, gain 1, all release and opposing-grip gates, and two exact original controls. This is a targeted development sensitivity screen with uncalibrated friction and known perch, not independent validation or an actual landing. Results will guide an approach policy, not establish robustness.
