# Contact-supported pitch feedback: rejected

In the two-lane constructed stationary release test, lane 0 reproduced the preceding observation-only control exactly across all 450 logged state, command, pose and endpoint-contact intervals. The first support-gate and other logged difference between lanes occurred at zero-based interval 305; states and commands matched before that point. The candidate enabled the existing bounded pitch feedback when measured upward foot support remained after return, even if the original right opposed-toe gate had dropped.

Both lanes achieved 43 qualifying unilateral-release intervals. After return the candidate achieved 10 consecutive qualifying bilateral supported-grip intervals versus 11 in the matched control, far below the required terminal 100. Its root first dropped below 0.1 m at one-based interval 372 versus 370 in the control. Both hit the modeled 12 rad/s toe-speed threshold before falling. All 450 states and 32 contact/velocity substeps per interval were present, with no logged observer errors or evaluated pre-fall nonfoot impulses. This change is rejected and does not qualify toe grip, walking, landing or a mission. Solver contact/state epochs remain independently unaligned.
