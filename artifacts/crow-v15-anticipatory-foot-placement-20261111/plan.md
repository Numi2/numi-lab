# Anticipatory physical foot placement

The matched first-contact audit found the successful start loaded rear toes, whereas an aft-offset start loaded only the soles and drifted away. A root-fixed kinematics audit shows positive hip angle moves the foot backward; in the airborne approach, correcting a rearward foot therefore requires the opposite joint direction to moving the body over an anchored foot. Test bounded per-hip prepositioning toward the 0.031 m world-x foot-center location of the successful start using measured foot kinematics and the existing joint drives. Compare three gains (3.75, 7.5, 11.25 rad/m), each limited to 0.16 rad, across four separated starts; after first measured foot load, linearly fade the anticipatory contribution over 10 control steps while leaving the existing supported balance and all toe control intact. This applies joint targets only, with no state reset or external force. Retain four exact baseline lanes. Run 500 ticks and require identical initial shapes and 500-step reference parity, at least 50 consecutive supported bilateral opposed-grip samples, no other-body support during that interval, bounded tilt and speed, no solver failure, and measured grip-pose overlap at most 0.5 mm. Survivors require long, all-start, resolution, release and route checks. No reserved layout is used.
