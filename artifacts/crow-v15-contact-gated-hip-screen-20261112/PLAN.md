# Contact-gated hip recovery screen

Constant negative hip offsets delayed the negative-pitch fall but also caused the positive-pitch start to fall. Test the same -0.08 and -0.16 rad bounds only while bilateral front-toe opposing normal impulse is absent, using previous accepted contact evidence and a bounded 25-interval ramp both on and off. Zero-offset controls are repeated. This is a privileged-contact, stationary bench diagnostic; the threshold is an engineering sensor condition, not a biological measurement.

Use the same two used initial pitches and lane pairing as the retained screen. Require all 550 intervals, complete contact/toe observations, final 100-interval bilateral opposed support, posture and toe speed bounds and no nonfoot contacts from both starts; reject candidates that pass only one start. Explicit release remains disabled, so a pass is neither release nor autonomous landing qualification.
