# Contact timing and release instrument

The eight coordinated open-loop cases show front-only and rear-only commands can generate opposite horizontal endpoint normal directions separately, but no tested combined controller generated both concurrently. We need time-resolved accepted contacts before designing a feedback law. Instrument the native resident solver at each accepted 20 ms control boundary; no host physics integration. On the same exposed box [-0.020,0.040] m, run four arms from the same starting state: fixed toes, both toe sets to 0.85 rad, rear only to 0.85 rad, and both toes to 0.85 with toe collision disabled. Command during steps 10-34 and return to zero for steps 35-59. Capture q/v, toe/box positive normal impulse components and toe angles after every accepted step. For each arm also run the identical 60-step control sequence as one native submission and compare every accepted q/v boundary with the resident chunked trace. If parity fails, do not interpret the contact timing as equivalent to the monolithic control. Retain failed steps and stop that arm on rollback. A few opposing endpoint impulses would be an exploratory signal, not qualified grip; release requires physical unloading and additional controls.
