# Exploratory perch alignment screen

Force-gated closure on the original perch failed while the body shifted rearward. Before running, test whether the horizontal support position and width account for this failure. Cross three box centers (-0.02, 0, +0.02 m) with three half widths (0.020, 0.025, 0.030 m) relative to the same initial bird pose. Use exactly the previously documented force-gated controller, body, 150 steps, solver and success criterion. Run all nine cases, including any failures, without choosing an outcome in advance. A simultaneous opposing impulse is evidence only of a short in-simulation pinch; it does not qualify release, perturbation resistance, full landing or biology. Any candidate must be repeated with sensor-clamped and toe-collision-off controls before further interpretation.
