# Explicit empty-contact observation correction

The earlier CROW_SUPPORT_SAMPLE observer only opened a log record when an accepted endpoint included a ground/perch pair. A missing row is therefore not an explicitly recorded zero-load sample. The prior exploratory launch summaries treated missing rows as empty sets; those counts cannot by themselves establish unloaded feet. The selected-lane foot-box geometric clearance is independently derivable from recorded replay body states but is sampled, not continuous.

Reconstruct the archived late observer and materialized-body-velocity host patches in an isolated library. Extend only the readout so it emits an explicit empty `contacts` array with accepted q/v and policy actions when no relevant pair exists. Retain all other physics and the existing selected-device timing. Validate physical q/v and body-state parity against each prior run for every recorded replay frame, including the perturbed launch and control; require one explicit record for each lane at each step 230-270, and verify samples with no relevant contacts now have empty arrays. Do not interpret missing, invalid or mismatched data as release. Keep original recordings and invalid counts. Then recompute preregistered per-lane launch gates with real observed rows and matching q/v. This is an observation correction, not a solver change or a grip claim.
