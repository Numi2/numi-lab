# Exploratory crouch-range test

The 0.70 and 1.0 knee-extension target candidates produced nearly the same peak upward velocity as the archived 0.36 target, with no unloaded endpoint. Their accepted-state knees reached the authored -0.1 rad joint limit, so greater extension request did not materially increase impulse. Test whether modestly deeper supported initial crouches provide additional leg travel without modifying the body, hard joint limits, motors, frozen flight controller, timing, contact gate or physics. Candidates set normalized crouch (hip,knee,ankle) to (-0.65,1.0,-0.50) and (-0.85,1.0,-0.50), versus previously measured (-0.45,0.90,-0.35); hold normalized extension knee -0.70 in both new arms. Run wing-suppressed, two lanes each on the same already-exposed layout/seed and retain all runs and failures. Two successive accepted endpoint samples must have neither foot loaded and upward root velocity at release, no nonfoot ground contact, no failed physics or first-episode physical failure. Fixed pilot is exploration, not reliable, biological, or full-route qualification.
