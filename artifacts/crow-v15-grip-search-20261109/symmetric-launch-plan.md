# Symmetric gait-to-crouch exploratory revision

The eight-lane walk-to-launch push test achieved 0/8 leg-only release gates while the stationary-start version achieved 8/8. Accepted-state traces show unequal knee angles during preparation: the prior per-foot load gate allowed one leg to fall back to a different target when unloaded, and the root translated markedly. Test a single explicitly revised handoff: stop alternating gait at 4.0 s, let the unchanged flight controller drive the legs until 4.3 s, then command both legs toward the same crouch through 4.96 s regardless of instantaneous foot loading. From 4.96 to 5.2 s, command the same extension to both legs only while the previous accepted contact reports both feet above the existing load threshold; otherwise retain the crouch. After 5.2 s, return authority to the unchanged flight controller. This is a no-latch exploratory gate; no force or state is injected. It may fail if contact releases during extension.

Run matched four arms (push/no-push, wing flapping suppressed/active) on the identical eight initial-perturbation lanes, exposed training course, seed and solver profile from the prior handoff study. All starts, gait and wing settings match within each paired arm. Measure the prior preregistered two-endpoint upward release gate, per-lane physical failure, first-episode integrity, walking displacement, and sampled left/right joint symmetry at the last pre-extension boundary. Preserve all arms. Even a passing result is not final walking realism, sustained flight, landing grip or independent qualification.
