# Slow bounded teacher descent diagnostic

The foot-aligned teacher reached all five development-J waypoints with exact q/v parity through step 1305, but the sudden post-alignment height target fell 0.12 m and the bird accumulated pitch until tilt termination before any support. Test whether a gradual eight-second descent command avoids that observed loss of control. In the same experimental teacher, ramp the high-level desired root height from perch z +0.34 m to +0.22 m over 400 accepted 0.02-second control steps after horizontal alignment. Keep the existing -0.035 m foot-alignment shift, contact-gated toe ramp, V1 flight law, body, contacts, course, actors and setup unchanged. Use the existing task-private landing phase value in the 1.0–1.4 range to hold the progress; it remains below the 1.5 threshold for post-contact wing cutoff. Preserve the existing loaded-feet transition. Test one full start on exposed development J at 16 substeps for 3000 ticks; require exact q/v parity through waypoint five against the matched-launch teacher. Report first failure, tilt and pitch history, foot/toe and nonfoot contacts, full substep support, clearance and release/regrip. This is an exploratory privileged trial, not a reliable landing, final navigation or a visual policy demonstration.
