# Duplicated start perturbation: controlled audit

The experimental task source contains two consecutive identical initial-state perturbation blocks using the same deterministic random draws and applying the same roll, leg and velocity perturbations. This is a source audit finding, not evidence of a contact solver defect. Compare the existing repeated-perturbation -0.5-feedback, 0.05-toe-preload runs with otherwise identical shaders containing just one block on both previously used development seeds. Run 3 s to observe initialization, toe caps and settling. Initial q/v are deliberately different, so no trajectory parity is expected and a lower failure count cannot establish better physical control. Preserve the existing doubled perturbations as a harder stress condition rather than quietly reducing robustness. Trace initial geometry/contact separately before attributing the first toe cap to penetration. No production model change or qualification follows.
