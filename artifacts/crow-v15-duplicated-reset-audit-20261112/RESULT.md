# Duplicate reset perturbations: sensitivity, not a physical fix

The experimental task source contains two consecutive identical reset blocks applying the same deterministic draws to root roll, six leg targets and horizontal velocity. The upstream production task source did not contain these blocks; this finding applies to the research task lineage and its reported starts. The second block repeats the same draw, rather than drawing a second independent perturbation. Joint clamping and floating-point arithmetic mean the result should not be treated as an exact simple scaling without examining reset states. The one-block version retained the same controller, model, policies, seeds and three-second duration, but starts differed by design; its first recorded samples are already after a physical interval and cannot establish initial penetration.

Both one-block runs completed 150 intervals on all eight lanes without reported physical failures or trace errors. Removing one block did not consistently improve settling. On seed 20261127 lane 0, unloaded substeps during 0–2 s increased from 110 to 960 and toe speed-cap substeps from 0 to 4; lane 1 fell from 655 to 203 and 9 to 3. On seed 20261126 lane 2, toe-cap substeps decreased from 6 to 0, while lane 1's unloaded substeps increased from 465 to 1,144. These are different initial configurations, not paired evidence that reset magnitude causes an improvement or deterioration. Some starts retained toe caps and significant vertical motion in both variants.

The duplicate makes the nominal perturbation description misleading and should be removed when the research initialization is made explicit, while preserving the doubled-draw configuration as a separate, clearly labeled stress test. Neither variant qualifies the controller. Direct measurement of the actual pre-contact reset configuration and impulse path is needed before attributing the first impact to penetration or blaming the solver. No source or policy has been promoted.
