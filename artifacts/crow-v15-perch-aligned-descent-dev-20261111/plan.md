# Align feet before physical perch descent

In the matched toe-drive trial, all eight birds tipped backward, and retained lane-one body poses show the foot centers approximately 0.05–0.09 m behind the perch after first contact while the rear toe is farther back. Hypothesis: the 0.20 m approach gate allows premature descent before the rear toe can reach the perch. Keep the frozen flier and contact-driven toe drives; bias the desired root x forward by 0.02 m and enter descent only when horizontal x error is below 0.05 m, y error below 0.15 m and planar speed below 0.20 m/s. Screen the same eight development starts for 4200 intervals; a surviving or supported trial is a censored screen, not a full episode pass. Require stable opposing toe contacts, weight support, no failures and actual release in subsequent full-episode tests. No held-out layouts.
