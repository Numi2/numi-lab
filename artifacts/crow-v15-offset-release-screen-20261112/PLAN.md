# Release from the observed -10 mm perch start

Both initial pitches in the prior -10 mm initialized-state bench screen met the 550-interval bilateral support criterion with release disabled. Test whether the existing physical controller can deliberately release and regain one foot from that same initialized root position and velocity. Eight lanes pair +0.04/-0.04 rad initial pitch with four existing toe-extension target bounds (0, -0.10, -0.20, -0.28 rad). All other physics and the original control logic are unchanged, except enabling its existing support-triggered weight-shift and release phases. These bounds are engineering trials, not measured crow parameters.

First compare each candidate to the matching no-release baseline up to just before its first shift-trigger interval using q/v and all contact substeps. Require full observations without solver error or overflow. To pass, require geometrically independently reconstructed at least 1 mm clearance of every left sole/toe box, no left contact, sustained right-foot upward support and opposed toe contacts, bounded body speed and attitude for 10 consecutive intervals, then a return and final 100 intervals of bilateral supported opposed contact, no falls or nonfoot impacts. Measure substep toe-speed caps; a cap disqualifies the attempt. The exposed controller event does not itself prove actual clearance or grip. This bench starts near rest at -0.025 m/s and is not a continuous autonomous approach or validation on a novel layout.
