# Post-release weight recentering: support improved, toe opposition lost

On eight constructed development starts, the candidate ramped the existing hip-roll shift to zero over 75 control intervals after the qualifying release ended. The reference retained the full shift. Body, higher-traction material, other controls and native solver were unchanged. All logged q/v states matched before the first release-finished event in every lane; in lanes that never finished, all 550 states matched. The run completed without simulator errors. The observer covered all substeps and agreed with named endpoint contact normals to within 1.01e-9 N s.

Both reference and candidate had zero combined supported release and 100-interval bilateral regrip passes, and two falls. Lanes 2 and 3 again released and returned the left foot. In their final 100 intervals, the reference had individual-foot upward-load failures in 1 and 4 intervals, respectively, while maintaining toe opposition. The candidate had no individual-foot upward-load failures in those intervals, but lost left toe opposition for all 100 intervals. Thus the predeclared qualification failed: the balance adjustment traded toe grip for steadier bilateral loading and is not promoted. Other lanes either fell or did not finish release.

See `comparison.json` and `high/terminal-diagnostics.json` for per-lane data and exact gates. The reported longest supported-release streaks include intervals after the controller has signaled release complete, as in the reference analysis. The candidate is a stationary research probe, not a production controller and not a whole autonomous walk, landing, object manipulation or biological validation. Source patch, probe binary, runtime hashes, full contact and state recordings, and negative results are retained.
