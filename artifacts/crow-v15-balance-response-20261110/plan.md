# Reached-grip hip response identification

Full-route changes have produced inconsistent tipping and slipping. From the accepted v15 grip state at support sample 3820 of the retained rebound-aware guide run (replay step 3819), start five matched isolated simulations with exactly the same q, v and actual perch pose. Use the same research v15 toe and wing-inertia body, SAT hybrid CCD, physical gravity, contact materials and implicit joint drives. The contact cache is fresh and the flight course is replaced by a single matching perch, so this is a local system-identification experiment, not a continuation or landing qualification.

Hold all driven joints at their reached q, including the eight toes, for 0.4 s at 5 ms samples. Apply a constant symmetric hip target change in each arm: -0.06, -0.03, 0, +0.03 or +0.06 rad. Record q/v, pitch, bilateral front/rear toe impulses, nonfoot contacts and solver status; compare initial pitch-rate and root-displacement response and the extent to which contact is retained. The zero arm is a required control. Do not select a target if observations are non-monotonic, fail physical validity, or fail to isolate a useful response. This is not whole-body, autonomous, long-duration or biological qualification.
