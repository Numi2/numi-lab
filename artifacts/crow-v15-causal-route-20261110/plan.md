# Full-start toe-equipped contact-triggered routes

The paired eight-lane exploratory launch showed that the push-trigger arm latched when both support groups unloaded and then stayed clear of the ground until 8 seconds in all lanes. The fixed-timer push arm recontacted ground in all lanes, and no-push triggered early in none. Before this test, retain the same push-trigger controller and frozen flight controller, and use 45-second commanded toe release because the earlier J run had opposing loads immediately before that release. Run one full 3000-step first episode on each development-exposed layout I and J with the prior respective seeds, no intermediate reset, and the same small reset perturbation in the launch screen. Predict all five waypoints and no head/body/wing strikes, continuous flight from push-off, bilateral opposing toe loads before release, their loss after release, and 25 low-speed foot-only supported terminal samples. Any failure on either layout fails the full gate. Record first physical failure, all contacts, final support and obstacle clearance; do not count post-failure reset states. These tests are exploratory and neither layouts nor seeds are unused. The anatomy and inferred drive parameters remain uncalibrated.
