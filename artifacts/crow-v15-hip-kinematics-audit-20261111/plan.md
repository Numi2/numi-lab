# Hip-target direction kinematics audit

In failed rear-offset starts, the body drifts farther backward despite the existing supported-phase position feedback. Measure the local left-foot and whole-bird COM x displacement when both hip target coordinates change symmetrically around the default pose, with the root held fixed in the kinematics query. This is not a contact or control experiment: it only establishes a local geometric sign, and neither proves actual foot anchoring nor isolates the dynamic cause of the fall. Retain the executable and measurements.
