# Perch-contact gated pitch-balance screen

The aligned development candidate produced 106 consecutive stable, partially supported opposing-grip intervals (at least half nominal weight; wings may provide the rest) in one lane before pitch slowly drifted backward and the bird fell. With the frozen flight law and same eight starts, screen a bounded symmetric hip response gated by measured perch contact. Four signed gains (-0.20, -0.10, +0.10, +0.20) are assigned to two starts each, so gains and starts are confounded; compare each start against its own retained baseline, not against another gain as a controlled ranking. Screen 4200 intervals. Require opposing toe impulses, actual upward support, upright low-speed body, no termination and a subsequent explicit release in a future full first episode. This is a candidate, not a qualified controller, and does not address the toe speed-limit hits.
