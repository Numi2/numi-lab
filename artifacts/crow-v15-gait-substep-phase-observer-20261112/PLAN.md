# Synchronized gait joint/contact observer

The related-magpie phase comparison used only 20 ms joint samples and an unvalidated ankle proxy; many contact groups are fragmented. An attempt to rebuild an observer failed the policy contract: its task fingerprint was incompatible. That failed run and build are retained, and no contract was bypassed. Inspection then revealed that the already retained phase-screen host had recorded q at every 1.25 ms substep throughout the 4–6 s gait. Reuse those existing accepted records and validate coverage, final-substep-to-endpoint q and lane-5 replay alignment. Reconstruct landmarks with the native kinematics model and retain all contact selection exclusions. This improves temporal resolution only; it does not solve the anatomical, species, speed or surface mismatch and is not held-out validation.
