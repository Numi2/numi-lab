# Uniform staged release across eight perturbed perch starts

The higher-traction, partial-recenter probe passed its strict release and final 100-interval bilateral grip gate in lanes 2 and 3, which used a 0.50 rad left-knee lift after ten control intervals with a 20-interval ramp. Faster, instantaneous lifts fell in lanes 0 and 1; longer delay and smaller lift variants did not finish release. Those observations confound start and command differences and do not establish robust landing.

Run one development-only follow-up with the same body, high-friction foot material, perch, 0.11 rad post-release shift, 550 intervals, native solver and measurement gates. Use the lane 2/3 gradual lift command uniformly in all lanes. Set initial root x shifts relative to the original unshifted model to 0.003 through 0.010 m in 0.001 m increments, rather than the two previously constructed 0.006 and 0.008 m values; keep initial velocities, other state, all other controller parameters and geometry unchanged. These are constructed stationary test states, not physically reached autonomous arrival states and not reserved final seeds or layouts. Some positions overlap previously observed starts; this is a development perturbation sweep, not held-out confirmation.

Predict at least six of eight satisfy the unchanged combined sustained supported release and terminal 100-interval bilateral grip gate, with no falls, nonfoot contact, observer gaps or native errors. Record each starting position and all failures. A pass is evidence only for this stationary start envelope; a separate trial using physically reached landing states, unused layouts and seeds, and the full autonomous sequence remains mandatory before any landing claim or controller promotion.
