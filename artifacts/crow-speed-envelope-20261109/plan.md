# Bounded command envelope for speed-feedback controller

Prediction: the candidate trim14 feedback can track a useful range of speeds and stronger turns while retaining flight. The speed trim error is made relative to the commanded speed rather than hard-coded 0.70 m/s; at the already tested 0.70 command this is algebraically identical. All other dynamics and body properties remain unchanged.

Use 100 first episodes, seed 20261117, normal randomized ground starts, obstacle collisions disabled, 1600 control steps and four substeps. Five lane groups modulo five: straight at 0.40, 0.55, or 0.85 m/s; left +0.06 rad/s and right -0.06 rad/s at 0.70 m/s. All target 0.85 m altitude. Reuse the same sampled screen: each of the 20 lanes in a group survives all 1600 steps, samples exist at 20–30 s every 2 s, heading error <=0.15 rad, absolute lateral speed <=0.20 m/s, speed error <=0.20 m/s relative to that group's command, and height error <=0.15 m, with zero failed simulator steps. Report all outcomes, the actual first-episode failure sites and measured control errors. Even all passing would not establish collision clearance, supported landing or the final qualification. No final navigation seeds/layouts are used.
