# Reached-state wide-perch grip screen

Start the existing continuous grip and release controller from eight q/v samples physically reached by lane 5 in a retained teacher-off development journey, translated with its stationary course perch. Use the actual course perch half-width .10 m, half-length .72 m and half-height .055 m, rather than the .025 m half-width used in earlier constructed tests. These samples come from the same used run and are correlated; only position and velocity are transferred, not solver warm-start or task-controller history. Require physical clearance, opposed contact, support, return, final grip and no nonfoot impulse or fall. The high-friction assumption and any changes between the archived source model and current probe remain limitations. This is a continuation probe, not an uninterrupted end-to-end landing.
