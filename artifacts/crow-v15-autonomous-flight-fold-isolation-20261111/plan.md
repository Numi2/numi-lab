# Autonomous flight fold isolation

Integrate the previously screened gradual physical toe curl, leg fold and bounded speed compensation into the release-inhibited teacher-off route. Disable all release outputs explicitly because their experimental packed bits overlap the fold counter. On a used development course and seed compare the complete first episodes, all-substep contact and flight speed caps against the no-fold reference. This is an isolation experiment, not a combined release implementation, flight qualification, unseen-layout test or biological validation.
