# Sensor cutoff matches the censored reference in a no-feedback screen

The two used-seed native runs completed, and all eight lanes in each exactly reproduced the same-lane baseline's 300 endpoint states and 4,800 contact substeps, with feedback disabled. In all six higher-cutoff lanes, the packed sensor reported 48–53 distinct value pairs. Over 194 per-foot samples per lane, the median absolute difference against the 1e-7 N s censored reference was 0.00022–0.00027 m/s, with no difference above 0.02 m/s. One of six old-cutoff lanes per seed had an approximately 0.045 m/s discrepancy; the remaining four had none. The matching event on both seeds must not be counted as independent biological replication.

The proposed cutoff passes the predeclared diagnostic screen, but the comparison reference uses the same cutoff: agreement does not establish that tiny physical contacts are irrelevant, that the sensor is accurate during other conditions, or that any gait has improved. Contact points and accepted q/v have potential timing offsets; the temporary task-state power alias and reset/rollback behavior remain unresolved. A separate matched test examines whether the cutoff changes the previous feedback-controlled trajectories. No walking, takeoff, flight or landing qualification follows.
