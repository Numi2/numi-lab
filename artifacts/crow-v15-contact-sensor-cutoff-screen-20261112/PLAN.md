# Matched tiny-impulse sensor cutoff test

An exploratory audit found 12 of 1,164 foot sensor/reference differences exceeded 0.02 m/s; all 12 had no per-foot reference contact over 1e-7 N s and an off same-step support flag. The live research sensor instead includes impulses over 1e-9 N s. This could reflect tiny contacts or state/step mismatch, not a proven defect. Test whether a cutoff matched to the independent observer reduces these outliers without changing simulation dynamics.

Use the existing materialized sensor host and uniform corvid-informed exploratory gait, zero contact-feedback gain in every lane, 300 transitions, 16 substeps, previously used seeds 20261126 and 20261127. Lanes 2, 4, 6 retain the 1e-9 cutoff; lanes 3, 5, 7 use 1e-7; lanes 0, 1 are original no-sensor controls. Each compares against independently reconstructed same-lane final-substep contact velocity at 1e-7 and same-step support flag. Report missing samples, quantization, median/p95/max absolute discrepancy, number above 0.02 m/s and number of unique sensor values per lane. Require all eight lanes to match the prior zero-gain baseline in all reported 300 state endpoints and 4,800 contact substeps; ensure signal recorded and varies. As an exploratory engineering screen, the higher cutoff must remove all >.02 m/s discrepancies in every tested new-cutoff lane, maintain median absolute discrepancy <=.002 m/s and have at least 20 distinct values. Compare controls and report all failures.

This cutoff matches the existing observer's censoring, which is not biological calibration or independent ground truth. The point and q/v times may differ; near-zero contacts and off-support states may still matter physically. The sensor aliases a task power state and is not production-safe. This experiment cannot qualify walking, takeoff, flight, landing or an unused layout.
