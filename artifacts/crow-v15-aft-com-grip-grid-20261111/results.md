# Rear-toe feedback with aft-COM balance

All 16 development lanes matched the reference through tick 85, and the unchanged lane matched the independent 500-tick replay exactly. No candidate passed the 500-tick screen or had terminal support. The reference had 377 consecutive supported samples and 54 supported opposing-grip samples, with 0.449 mm worst grip overlap. Several 0.002 N s feedback candidates extended consecutive supported opposing grip to 169–177 samples but reduced continuous support to 233–250 samples; the strongest 0.005 N s feedback reduced support further. Some candidates exceeded the 0.5 mm overlap gate. All were rejected. Results show a grip/balance tradeoff in this start, not a causal explanation or a qualified controller. All lane data is retained, and no held-out course was used.
