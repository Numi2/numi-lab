# Bilateral toe regulation across separated starts

All sixteen runs completed without reported solver failure. Both case-1 arms reproduced all 200 prior reference states exactly, and all authored boxes began separated from the perch: the smallest initial gap was 13.093 mm (toes 13.203 mm). The matched reference and regulated candidate each passed the behavioral screen on only 1/8 development starts, well below the required 6/8. For the single candidate grip, worst overlap was 0.449 mm (reference 0.949 mm); the other seven acquired no sustained supported bilateral grip. Several starts drifted away before toe contact. The result therefore rejects the candidate for integration or longer-support qualification; a single successful start does not establish landing or route performance. The untouched final layouts remain untested.
