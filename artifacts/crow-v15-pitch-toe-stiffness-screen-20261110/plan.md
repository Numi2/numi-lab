# Toe stiffness with pitch-coordinated grip

Lower toe position targets and effort limits failed to establish grip in the preceding 16-substep pitch-coordinated screen. Compare the same three exact controls with candidate toe stiffness values 0.05 and 0.025 N m/rad versus the original 0.10, retaining the original effort limit, damping, targets, balance, interval contact sensing, release and separated start. Log actual configured values; implicit drive/contact coupling makes this a configuration sensitivity study, not a biological material measurement. Controls must reproduce all 200 reference states. Record failures, supported opposing grip, release, open-toe terminal support and independent SAT gap. Both complete behavior and <=0.5 mm grip overlap are required before perturbation testing; one stationary development case does not establish flight, continuous navigation, held-out layouts or real-crow biomechanics.
