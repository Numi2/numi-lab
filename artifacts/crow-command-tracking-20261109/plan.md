# Development study: closed-loop flight command tracking

Prediction: a 0.60 sin(wing phase) common pronation component scaled continuously by negative bounded yaw demand, together with the previous accepted-state roll and speed feedback, permits moderate right turns while retaining straight, left, climb and descent behavior on the unchanged v15 body. This follows the phase-authority experiment, but feedback can alter the outcome.

Native obstacle-free flight, 80 lanes, seed 20261112, 1600 control steps, 4 substeps, no scheduled resets, same unchanged v15 model, actor pack, dynamics library and base controller as the phase study. Assign lanes modulo five: straight 0 rad/s and 0.85 m; left +0.03 rad/s and 0.85 m; right -0.03 rad/s and 0.85 m; straight with height 1.05 m; straight with height 0.65 m. Commands begin after 6 s; the height target remains 0.85 m before 6 s. Forward speed command is 0.70 m/s. Yaw feedback uses its original bounded proportional/rate/lateral signal; negative yaw demand gates the 0.60 sin component. Preserve normal actuator filtering and saturation.

Each lane passes the exploratory screen if its first episode survives all 1600 steps with zero physical failures, all samples at 20,22,...30 s exist, maximum absolute yaw-heading error <=0.15 rad, absolute body-yaw-frame lateral speed <=0.20 m/s, absolute forward-speed error <=0.20 m/s, and absolute height error <=0.15 m. The simulator must report zero failed environment steps. Record every lane and group; all 16 lanes in a mode must pass for that mode to pass. Also report the actual group-median height at 20–30 s to determine whether climb and descent meaningfully respond to height command, with the climb median at least 0.12 m above the descent median. Samples alone do not establish continuous safety. This is a development screen, not frozen-controller qualification; perturbed starts, independent conditions and autonomous execution remain required. No final navigation layout or seed is used.
