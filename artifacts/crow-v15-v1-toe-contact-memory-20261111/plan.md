# Short physical-contact memory for toe closure

The foot-load wing-relief trial remained airborne: accepted foot-contact signals occurred only intermittently, and the toe counters fell back to zero between touches. Test a bounded reflex-like memory in the isolated band-10 landing task. An actual accepted whole-foot load above the existing 0.05 threshold starts or refreshes a per-foot 15-control-step (0.30 s) grace period. While that short period remains, continue the existing bounded toe-closing ramp; after it expires without another load, the ramp decays at the existing rate. The timer is task-private and is cleared outside the existing landing window. No touch means no timer or toe closure. Keep the 0.20 m high-level touchdown target, alignment guard, wing relief, 20-count handoff gate, frozen V1 flight law, body, solver and physical contacts unchanged.

On one full-start exposed development-J trial at 16 substeps for 3000 ticks, compare q/v with the previous trial through the first measured contact, record every perch substep, individual toe impulses and endpoint geometry, sustained bilateral support, opposing grip, release/regrip and other-body contact. Require 50 consecutive supported-opposed intervals with <=0.5 mm worst endpoint overlap, no nonfoot collision and a measured release and reacquisition; any missing data, fall or timeout fails. A touch-triggered closure in air is not grip. This is an experimental privileged task, not final autonomy, physical biological validation or a held-out layout.
