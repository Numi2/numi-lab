# Varied-state GPU dynamics screen for multi-segment toes

The isolated fast-math ABA candidate narrowly passed the original 12 lanes (maximum scaled error 4.85849e-5 against a 5e-5 threshold); strict math failed, and neither mode is production qualified. Before any contact experiment, use 96 deterministic cases spanning root yaw, root/joint velocity, toe angle and bounded applied effort, with zero world damping and no contacts. Compare each native GPU acceleration to the independent CPU forward dynamics with the unchanged 5e-5 scaled error bound; require all 96 lanes to succeed and repeated GPU outputs to be exactly identical. Run the original 25-body model as a matched baseline. The test is exploratory; success would not establish real-world biomechanics, stable GPU simulation, contact behavior or safe production adoption.
