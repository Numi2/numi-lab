# Results

All eight already-supported developmental starts had at least nine consecutive accepted endpoints with opposing fore/rear loads on both feet; after gradual release each foot lost opposing load within 3-11 control steps. None rolled back. Four starts had fallen below the starting support height by the final sample, while four remained at support height: this is a grip-and-release test, not a supported landing, safe departure, or biological validation. The immediate-release and sensor/collision controls are retained in the prior slow-close artifact.
