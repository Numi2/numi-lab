# Wing target-velocity feedback sensitivity: preregistered

The task writes the previous actuator targets into a second trajectory slot at the beginning of the action step but unconditionally overwrites that slot with the current targets at the end. Thus it does not currently preserve a previous wing target for a target-rate controller. Test a research-only wing-specific correction: retain the previous target on flap DOFs 8/9 in lanes 2–7 after initialization, leaving the existing final copy for all other DOFs. Use its finite-difference target rate (clamped ±30 rad/s) in bounded position-and-velocity feedback, at fixed wing effort bound 3.0 and continuous 6.4 Hz target. This is a control and buffer-semantics sensitivity, not a measured crow muscle model.

Test gains (kp,kd)=(4,.05),(10,.1),(20,.2) in pairs, with unchanged v15 body and aero, no direct pitch/yaw moments, same push and crouch hold commands, same used seed 20261126, 16 substeps and 400 first-episode ticks. The new feedback is active from the initial state, so earlier experiments are matched-start, not state-matched. Run push and hold arms. Require exact paired state/action/contact parity through tick 345 and complete first episodes. New observer must show, within each lane, that logged previous wing target at step t equals logged current target at t-1, for every sampled t=336–400; otherwise the trial is invalid. Confirm all recorded wing effort <=3.0. Report whole-body COM rise, flight/recontact, support continuity, early push-minus-hold ground impulses, toe thresholds, wing tracking, saturation, modeled aero force and work proxies. Preliminary launch requires both lanes in a setting to retain support through a three-tick release, then no recontact through 400, COM rise >=0.05 m, no nonfoot impulses, <=1 toe-speed threshold substep and push-minus-hold impulse >0.05 N s in both early windows. A tracking change does not qualify flight, realistic energetics, landing or navigation. Preserve all outcomes.
