# Same-lane stronger heading-feedback screen

Only if the preceding diagnostic-state isolation experiment is interpretable, compare the same candidate with heading error gain doubled from 1.40 to 2.80 on the existing bounded pronation feedback. Keep the same +/-0.30 action-offset clamp, 0.20 yaw-rate term, targets, common aerodynamic parameters, height/speed gains, starts, seed, and obstacle-disabled setup. All eight candidate lanes must match their same-lane prior accepted states through the start of heading feedback before interpreting later differences. Retain all failures. Compare absolute target errors during 16–17 s and absolute residual heading during 22–23 s for the six turning lanes, with lateral drift, height and speeds. This screen has no joint-substep caps, perturbed starts, obstacle clearance, independent seeds, biological validation or landing. A tracking improvement alone is not flight qualification or permission to freeze.
