# Continuous accepted-support gait gate

The original integrated gait gates a sinusoidal swing with a binary last-sample opposite-foot support bit. The 0.65 amplitude variant improved one used seed but badly degraded a matched second seed; requiring a three-sample dwell and velocity-triggered holds also degraded support. Test a continuous gate using the already stored accepted opposite-foot load: zero swing below a reported load of 0.05, smoothly rising to the original full swing at 0.50; the signal units have not been independently calibrated. Retain original 0.80 joint amplitude, frequency, all physical contact and toe models, and the existing both-unloaded hold. Compare the same two previously used seeds, eight lanes each, for all 16 contact substeps, swing clearance bouts, displacement, toe limits and pre-walk parity. This is an exploratory change, not an assumption that a smooth gate ensures stability or biological validity.
