# Precontact placement screen

The two constructed starts that previously drifted forward were tested with four small precontact hip pitch offsets and contact-driven balance. Each 300-interval test was run separately on the experimental 35-body v15-derived model. See `analysis.json` and the raw compressed traces for accepted-step, release, return and toe-speed results.

This is a short developmental screen, not a demonstration of a full supported landing or sustained regrip. The release decision in this screen uses a geometry-derived clearance signal, and therefore is not an autonomous sensor implementation. A separate longer test uses a timed phase plus contact signals for its return decision. The added hip properties are estimates, not biologically calibrated.
