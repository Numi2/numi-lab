# Bounded-command flight on the hierarchical journey path

The actual conditional hierarchical journey task used the experimental 35-body crow, the 0.80 gait, the unchanged frozen flight-law source, and five diagnostic command streams (straight, left, right, higher and lower height). All five first episodes ran 1,600 control intervals without a physical termination or failed environment step. No ground-contact impulse or toe-speed-limit sample occurred from observer step 400 through the end. Contact coverage included every expected substep. Four starts met the earlier broad tracking-and-no-cap screen; lane 4 had nine toe-limit samples during initial settling, so it failed that screen.

The comparison code reports speed error against the raw 0.35 command and q-coordinate height error against the requested height. The command adapter shifts the frozen law speed error by 0.10, and rootWorldPosition includes a root reference offset, so those numbers are coarse diagnostics and should not be presented as precise command-tracking errors. There is no perturbed recovery test here. Course collider masks were intentionally disabled, the diagnostic commands replaced the actor, and the test does not establish autonomous routing, obstacle clearance, landing, biological realism or full-controller qualification.
