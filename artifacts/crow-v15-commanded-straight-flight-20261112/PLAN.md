# Explicit straight-flight command screen

Keep the obstacle-free host, ground, smooth launch and disabled body moments. Through 9 s reproduce the long-flight baseline. At 9–9.5 s, six lanes transition away from route-actor commands to fixed speed (.35, .55, .75 m/s), zero lateral and heading command, and height (.95 or 1.10 m); each speed has one lane at each height. The two remaining lanes retain the baseline command and must match it through 24 s. The same bounded symmetric sweep-speed feedback is driven by each requested speed. Run eight used-seed starts to 24 s with no scheduled resets and 16 substeps, measuring position, velocity, attitude, joint caps and contacts. Each setting has only one lane, so this is an exploratory response screen, not robustness or real-crow qualification.
