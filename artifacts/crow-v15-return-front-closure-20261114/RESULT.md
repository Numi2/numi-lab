# Returning foretoe closure: failed physical probe and native rollback

The candidate used the existing 1.20 rad maximum for returning foretoes, against a 1.05 rad control; both used the same relative-COM stance correction. The paired states matched through 252 control records before targets differed, and all 330 recorded control states exactly reproduced the archived COM-feedback candidate. Both produced a 12-interval supported release, but neither achieved any qualifying bilateral regrip interval before the recorded root fell below 0.1 m: interval 315 for control and 314 for candidate. The left opposing-contact gate failed 85 versus 64 checked intervals, but the other gates also failed, so that difference does not establish a successful grip or its cause.

The native run exited 1 at control step 330 after a GPU environment rollback in candidate lane 1 (status 11, failing substep 10); this occurred after the root-height failure. Its exact diagnostics and all partial substep and state data are archived. The native failure is not assumed to be a solver defect or explained by toe closure. Full 450-interval coverage and all registered success criteria were not met. The accepted-state toe speeds before the fall stayed below the threshold, which does not bound substep speed or drive effort. Pose/contact timing remains independently unverified for this constructed probe. This is not walking, landing or flight qualification.
