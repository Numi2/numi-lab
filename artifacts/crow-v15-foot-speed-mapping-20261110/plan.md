# Correct forward-speed command mapping

Source inspection after the two failed guidance arms found that their direct requested-speed values were mapped incorrectly. The adapter sets carrier commandExtension.z to observed forward speed + 0.25 - oracleCommand.x and commandAndPhase.x to 0.15. The frozen flight controller subtracts max(commandAndPhase.x,0.15), so its effective speed error is observed forward speed + 0.10 - oracleCommand.x. Therefore a desired speed of zero maps to oracleCommand.x=0.10, not zero. Correct only this adapter mapping in the previously registered damped experiment: oracleCommand.x = 0.10 + clamp(0.45*footError - 0.7*observedForwardSpeed,-0.12,0.12). Same approximate privileged signal, trigger, altitude and two development full starts; no controller source changes, resets or force injections. Predict reduced offset drift and improved settling, then test the full grip/release and supported landing gates. A timeout, tilt or contact failure remains failure even if waypoint completion improves.
