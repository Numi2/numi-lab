At the initial reset only, replace the existing random roll disturbance with signed +/-0.12 rad roll by lane, add signed +/-0.08 rad pitch by lane and add signed +/-0.05 m/s forward velocity by lane; retain the existing random joint and horizontal-velocity disturbances. These are initial conditions, not post-start assistance. Run all eight combinations teacher off, no scheduled resets. Require the existing complete-state, physical contact, actuator, toe, reconstruction, signed-turn and 50 mm height gates, with turning and lateral displacement measured relative to each lane's own interval-600 heading/position. Compare observed first states to the same-seed baseline and require absolute initial roll and pitch changes each greater than 0.02 rad. No prefix parity claim is possible because starts deliberately differ. Preserve all outcomes.
