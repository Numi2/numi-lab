# Phase-adjusted takeoff full development sequence

Run eight previously used seed 20261126 starts for up to 5000 control intervals, teacher off, no scheduled resets, using the 7.00 s phase-adjusted candidate and existing policies. Short-path observation found downwards modeled wing-center movement before the final loaded foot substep and positive excess ground impulse, but did not establish biological wing forces or overall reliability. Preserve every first-episode failure, support/contact trace, state and termination; compare matched prefix and examine waypoint completion, sustained opposing toe support, tilt and nonfoot contacts. These are development trials, not unused layouts. Exact gzip byte streams are written directly into independently hashed Git-sized parts to limit local storage duplication. This run does not qualify the direct body-wrench flight controller or realistic gait.
