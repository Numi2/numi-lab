# Floating-root uniform-gravity numerical reformulation

The stock 25-body 96-state dynamics also failed the unchanged 5e-5 scaled CPU-oracle gate; a fused projected-parent accumulation did not alter the strict-math result. Inspecting the ABA shader shows uniform gravity is inserted separately as a force on each body and subsequently canceled in internal joint acceleration. Hypothesis: for a floating root in uniform gravity, solving the uniform-gravity-free articulated dynamics then adding the same gravity vector to the published root linear acceleration is algebraically equivalent and avoids the cancellation; retain the existing per-body gravity path for fixed roots. External body wrenches and all other forces remain applied. Body acceleration propagated internally in the forward sweep must remain gravity-free; add gravity only to the published root output.

Test this as an isolated Metal source patch, against independent CPU double-precision dynamics with unchanged 5e-5 scaled threshold, exact replay and the same 96 varied cases for both 25- and 33-body models. No production source is modified. Passing is only a screening result: separately test fixed roots, zero and nonvertical gravity, external wrenches, long-horizon dynamics, contact solver parity, performance and the full task before any promotion.
