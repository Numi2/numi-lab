# Separate low-speed landing-brake adapter

The frozen flight law floors its forward-speed reference at 0.15 m/s and achieved roughly 0.25 m/s actual forward speed; this is not a stop. Test a separate landing-mode input adapter without changing the frozen law, body, actuators, or filters. The law consumes only the difference between measured forward speed and max(command,0.15) in its speed-control terms. Encode a desired low-speed error by supplying the law a shifted speed input equal to true measured speed + 0.15 - desired landing speed while its command field stays at 0.15. This is an explicit controller-error coordinate transform, not a claim that the shifted number is a sensor measurement. True q/v and true forward speed remain separately recorded. The adapter is experimental landing control and is inactive in the frozen normal-flight tests.

Use 80 full-start lanes, seed 20261128, normal randomized ground starts, collision-disabled course, 1600 control steps, four physics substeps and teacher off. All target height 1.15 m and zero world heading/lateral speed. From 6 s, groups by lane modulo five use desired landing speeds 0.00, -0.10, +0.05, +0.10 and the unshifted +0.15 m/s control. Require each group of 16 to survive with no physical failures or failed simulator steps, all 20–30 s samples every 2 s present, absolute heading <=0.15 rad, lateral speed <=0.20 m/s, height error <=0.15 m and true forward-speed error <=0.10 m/s. Record true velocities and all failures. Passing is only a flight-braking screen; no contact, landing, continuous safety or unused-layout result is implied.
