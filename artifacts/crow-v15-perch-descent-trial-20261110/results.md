# Exploratory perch descent

All 16 privileged guide starts reached five waypoints, then suffered body-perch collisions. First fatal contact pairs and preceding accepted root state are retained in analysis.json. An inspected lane had front-toe contact before its body collision, but not an established supported landing; accepted traces after termination include reset episodes and cannot be counted as the same sequence. No solver failures were reported. Failed demonstrations are excluded from training; neither layout is held out.
