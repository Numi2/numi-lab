# Earlier phase overlap test

The 7.50 s phase test produced a near-wing-still leg hop but both push lanes recontacted before sustained flight; one held-leg lane flew, with substantial preceding flap motion and modeled aerodynamic impulse. Test whether shifting both phase candidates 40 ms earlier overlaps wing loading with the measured short hop. The two push lanes use +pi/2 and -pi/2 respectively; the paired held-leg arms receive identical wing targets. Only the candidate onset changes from the preceding phase experiment; actuator limits, body, observer, policies and seed stay fixed. This is an open-loop development experiment, not contact-triggered control.

Require candidate pre-push q/v/action/contact parity through 368, unaffected-lane parity through 500, matching paired wing targets and nonshader hashes, full substep coverage, no observer error, nonfoot impulse or toe threshold, and uninterrupted unloaded flight after first release. Report positive and negative modeled aero impulse and flap motion at release and the matched held-leg outcome. Distinguish a continuous flight from evidence that the leg push was necessary. Use only development seed 20261126. Retain failures; a pass does not qualify flight, landing or mission. Observer-to-replay timing for these candidate lanes remains inferred.
