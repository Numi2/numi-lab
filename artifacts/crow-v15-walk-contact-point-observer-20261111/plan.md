# Accepted contact-point observer for gait slip

The initial walking screens measure support and endpoint toe clearance, but do not measure tangential foot slip. Extend only the existing host-side contact observer to record each final-substep contact's world point, preserving body state, solver, actions and controller. Re-run the uniform +.50 development gait with identical settings and compare all retained q/v, actions and contact records excluding the added coordinate against the original. Use independent native FP64 body kinematics and world contact points to estimate instantaneous tangential contact speed at accepted endpoints, with calibration against replayed body linear and angular velocities. This is an endpoint estimate, not continuous substep slip. Keep the retained uninstrumented run and reject the observation if it changes the trajectory.
