# Perch-root balance and contact latch screen

A constructed stationary v15 perch probe achieved sustained bilateral opposed grip in some starts using contact-triggered toe closure and bounded fore-aft hip feedback. In route arrivals, the current toe ramp decays whenever a contact disappears and the flight teacher does not use that root feedback. Starting from the 0.85 gait candidate and unchanged frozen flight law, screen four exploratory combinations: existing toe ramp with and without bounded hip root-position feedback, and contact-latched toe closure with and without that feedback, two starts per combination. The feedback estimates perch-relative x error by algebraically recovering the privileged teacher landing command only when that command is not saturated; it is not an autonomous sensor. Closure is triggered by actual perch contact, remains latched until episode reset in the latched arms, and this experiment has no explicit release. Run a full 5000-interval teacher-guided development horizon with collision-enabled obstacles, all-substep contact and toe-speed observation, physical support criteria, failed/censored outcomes and first-episode accounting. Gains and initial starts are confounded: paired comparison to corresponding retained starts and future independent confirmation are required. No held-out layout or final qualification is implied.
