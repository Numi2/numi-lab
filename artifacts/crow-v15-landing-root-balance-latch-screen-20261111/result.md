# Development result: perch-root feedback and toe latch

All eight teacher-guided starts reached five waypoints and first contacted the physical perch; there were no recorded observer errors or missing first-episode substeps. The 0.85 walking candidate and frozen flight-law state/action prefix matched its retained reference through interval 500. Outcomes through interval 5000: four timeouts, two tilt failures and two other contact failures. Each of the four controller arms had only two different starts, so gain and start are confounded.

The existing toe ramp plus hip feedback produced 1,315 consecutive intervals in one start satisfying bilateral opposing toe-normal, upright, low-speed and at-least-half-nominal upward impulse criteria, with no toe speed-cap hits anywhere in that start. Only five consecutive intervals met the full nominal impulse threshold; aerodynamic or other support has not been isolated. The other hip-feedback start tipped. The toe-latch-only arm achieved at most 26 consecutive half-weight intervals in one start before tipping; its other start timed out without meeting those grip criteria. Other starts did not achieve sustained partial support. Toe speed-cap hits after the walking handoff occurred in four starts, including 48 substeps in one latch-plus-feedback start. Counts and termination details are in the analysis JSON files.

This is a teacher-guided development screen: the feedback reconstructs perch-relative position from a privileged teacher command and is not an autonomous sensor. Contact-latched closure has no release, several results timed out, and no held-out layout or complete landing is qualified. The long partial-support event is useful for further investigation, not a full-weight support or biological realism claim.
