# Flight command authority correction

Inspection of the native shaders used by the recent launch studies found an inherited development-only command schedule. When fixed-flight mode is active on episode variant 10 and `privilegedCommand` is false, it blends from the actor's command to fixed speed, zero turn and lane-dependent height over 9.0–9.5 s, then continues the scripted command. The teacher flag is off in the retained run metadata, but that fact does not imply the route actor controls the flight commands. See audit.json for the exact source hashes and lines in each tested shader.

The short matched leg-extension comparisons remain valid as comparisons under this shared scripted command; they do not establish autonomous navigation. The long obstacle-enabled and obstacle-disabled runs using the same shader are flight/obstacle diagnostics with scripted high-level commands, not autonomous missions. The genuine route evaluation requires removing the override, confirming actual command authority and rerunning the physical sequence. This correction does not retroactively turn any waypoint flags into successful autonomous navigation, flight qualification or supported landing.
