# Results

Four teacher-off trials on two used J starts reached all five waypoints but fell. The latched grip drive did not prevent the original start tipping: its opposing grip lasted 117 samples before failure at step 2743. The tighter touchdown-speed gate delayed the other start from 2673 to 2778 but it never produced bilateral opposing grip. These are last-substep endpoint measurements and experimental joint targets; no supported landing or release is established.
