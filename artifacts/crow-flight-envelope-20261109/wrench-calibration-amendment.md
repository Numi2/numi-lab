# Moment-instrument equivalence failure and paired rebuild control

The original preregistered calibration failed: all three instrumented first-episode outcome arrays match their earlier counterparts, but selected lane trajectories are not byte-identical. For example, the first differing value in the negative-yaw trace differs by about 1.1e-12 and the selected root position differs by up to approximately 0.018 m at the end of the horizon. The prior moment-probe readings are invalid under the original plan and are not being interpreted.

The previous runtime and shader were rebuilt at the same time as the diagnostic instrument, so this comparison does not isolate which change produced the discrepancy. New diagnostic question: with the *same rebuilt runtime, other shader objects, v15 body, actor inputs, seed and command*, compare an otherwise identical rebuilt uninstrumented aero kernel with the instrumented aero kernel, paired by lane. Reuse the three earlier instrumented arms and run their matched uninstrumented-kernel controls. Require byte-identical selected-lane trace and identical all-lane first-episode outcome arrays for each sign. If any fails, the instrument remains uncalibrated. If all pass, this isolates the published-output instrumentation from the rebuild at this selected trajectory and permits a separately labeled *exploratory* interpretation after checking the independently specified actuator-moment calibration. It does not retroactively turn the original comparison into a pass. Stop after three null controls.
