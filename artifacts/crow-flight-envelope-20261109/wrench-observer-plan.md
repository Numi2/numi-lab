# Separate read-only wrench observer

The rebuilt null aero shader reproduced the original selected-lane trace byte for byte in all three yaw arms and matched all first-episode outcomes; the instrumented aero shader did not. Thus the first probe altered its compiled physical kernel and remains invalid.

Replace it with separate diagnostic-only GPU passes immediately before and after the unchanged flapping-wing kernel. The passes read body-wrench buffers, authored wing and tail body indices, and native body-COM poses; they publish the root body wrench before aero, wing resultant world-z moment about root COM, and root post-minus-pre torque plus tail resultant moment about root COM to three diagnostic teacher-label slots. They do not write physical state, actuator history or wrench buffers. This measures the last physics substep of each control step; body-pose timing must be checked and the outputs are not a full angular-momentum balance.

Calibration: with the same rebuilt runtime and shader binary, compare observer enabled versus disabled for all three yaw arms. Require byte-identical selected lane trajectories and identical first-episode results in all 32 lanes, zero failed simulator steps, and require the pre-aero root torque to match yaw and pitch actuator projections within 0.003 N m on at least 95% of 20.02–22 s samples. If any requirement fails, do not use the observed moments. Also cross-check the summed moment calculation using a known-value synthetic reference in an independent unit calculation. If valid, describe phase-averaged components as exploratory only. Stop after three matched on/off arms. The same development seed is intentionally reused; no fresh validation conditions or navigation test layouts are used.
