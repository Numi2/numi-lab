# Diagnostic accepted-microstep yaw-moment instrument

Question: does the normalized yaw command arrive at the native body wrench, and how do the resolved wing and other aerodynamic yaw moments compare? Instrument only diagnostic GPU outputs and runtime bindings, leaving the v15 body, action path, aero loads and solver calculations unchanged. Publish, for the last microstep of each sampled control transaction, (1) total root-body world-z wrench before aero, which contains the bounded body actuators, (2) summed wing-element world-z moment about the root, (3) root aero world-z torque plus a tail-force moment estimate about the aerodynamic root-to-tail vector. The third item is a proxy: the tail body force is actually applied at its body COM, so do not claim exact tail torque. Sample 1001–1100 control steps (20.02–22 s) to avoid treating a single flapping phase as a mean. Record state and filtered yaw action from the same control transactions. Instrumented teacher-label slots 15–17 are overwritten only after policy action application; they are measurement outputs, not actuator commands or training data.

Calibration/validity: compare same-seed, same-command instrumented and existing uninstrumented selected-lane trace byte for byte and match all first-episode outcomes, with zero failed simulation steps. Before-aero root torque must match the world-z projection of the applied bounded yaw plus pitch body torques within 0.003 N m on at least 95% of samples; use the source microstep orientation, so control-transaction state introduces small timing error. Any failed calibration invalidates moment attribution. Run matched -1, 0, +1 yaw-action arms with 32 lanes, v15 diagnostic body, roll-1.5/speed trim, 1600 steps, development seed 20261111 and first-episode accounting. Prediction: at least one non-actuator aerodynamic yaw contribution has phase-averaged magnitude >=0.005 N m in a sustained negative-yaw trial, providing an actionable explanation of authority asymmetry; otherwise revise the hypothesis. This is an exploratory instrument and is not a qualified controller or a full system angular-momentum balance. Stop after calibration and three arms.
