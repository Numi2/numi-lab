# Rear-toe walking divergence audit

The rejected 0.02 rad swing-toe experiment first differs from its matched sham at endpoint interval 215 in all eight lanes. The largest joint-position difference there is the right rear proximal toe, about -0.00361 rad; the largest velocity difference is about 0.269 rad/s. The logged policy actions are still equal, and root forward velocity differs by less than 0.00000031 m/s at that endpoint. By interval 300, the candidate root is 3.28–8.27 mm behind its matched control. This locates the initial difference but does not establish why total forward travel falls.

For example, lane 0 endpoint contact at interval 214 shows 0.00278 N s normal impulse on the left rear toe and 0.0000456 N s over the entire right foot; at 215 the corresponding sums are 0.00384 and 0.00000555 N s. These examples are endpoint contact records; the JSON also records summed foot and rear-toe normal impulses over each interval’s 16 sampled substeps. The shader gates the toe command using support status from an earlier control interval. Neither the actual gate bit nor applied toe torque was captured, so the audit cannot establish the responsible contact or drive mechanism. Test those directly before changing the controller.

This is one used development seed and an already rejected two-second gait; it is not biological validation, sustained walking or an end-to-end sequence. The first analysis attempt had an incorrect sample count assertion and was corrected before the retained report; no physics run was affected.

The existing drive-target observer provides a further check: in lane 0 at interval 215 the right rear proximal target changes from 0 to -0.01366 rad, while its recorded substep velocity reaches -0.271 rad/s (sham minimum -0.0050 rad/s). At interval 216 the target reaches -0.02 rad and velocity reaches -0.371 rad/s. By interval 225 the target is back at zero as the foot loads. These are commands and joint velocities, not measured torques; this motivates testing toe-only target interpolation but does not prove the cause of lost travel.
