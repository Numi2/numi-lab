# Result: external flight disturbance was too small

All eight first episodes survived 24 seconds without flight-period toe, body or wing velocity-cap events or nonfoot contact. The test and reference matched exactly before the perturbation. However, peak body-axis deviations in the six signed disturbance arms were 0.000429–0.000817 radians, below the predeclared 0.01-radian minimum. This is an inconclusive recovery test, not a recovery pass: subsequent near-zero tracking differences can be explained by the perturbation being too small. External 0.005 N m torque for 0.10 seconds was a test input; normal direct task body moments were disabled. The independent follow-up uses a larger declared pulse. The used development seed, unqualified aerodynamic closure and lack of perturbed-start trials prevent flight qualification.
