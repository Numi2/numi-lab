# Contact-gated regrip placement

Applying a rearward left-foot placement offset during release preserved body height in some starts but prevented clean clearance. Repeat the same isolated stationary perch test, initiating the offset only after the existing physical 10-interval clearance-and-opposite-grip criterion has triggered return. Compare four positive offsets and require the same supported release and terminal bilateral opposing grip, complete substeps, no fall or nonfoot impulse. This is not a flight landing or anatomical calibration.
