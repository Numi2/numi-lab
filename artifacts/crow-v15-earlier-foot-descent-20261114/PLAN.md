# Earlier returning-foot descent, paired control

The prior test lost stance opposing contact roughly three intervals before the returning foot achieved opposing contact; shifting body weight earlier did not fix this. The diagnostic return logic delays lowering the returning foot until both commanded toe closures reach 0.44 rad. Test a lane-specific 0.20 rad preclose threshold so the same bounded foot descent begins sooner while toes continue closing. Lane 0 retains the 0.44 rad threshold and original stance-foot center-of-mass goal; lane 1 differs only in the preclose threshold. No plant, friction, solver, contact rules, foot placement target, or joint-speed/torque limits change. Earlier descent might obstruct toe closure or worsen impact, so require matched logged prefix and measure both-foot contact, substep toe speeds, root stability and terminal 100-interval grip, including failures. This is a constructed stationary control experiment, not walking or landing qualification.
