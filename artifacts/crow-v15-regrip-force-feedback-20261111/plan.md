# Contact-force feedback for regrip after one-foot release

The exact-release force audit found the cone-gated sensor often reported no rear grip despite substantial opposing horizontal force. At the same development start, retain one unchanged baseline and test 15 bounded target-rate pairs: relief 0.002, 0.005, 0.010, 0.015 or 0.020 rad/tick and reclosure 0.002, 0.004 or 0.008 rad/tick. After the released foot has returned, each driven toe uses its actual signed normal-plus-friction horizontal impulse integrated across all 16 substeps, closing below 0.001 N s and relieving above 0.005 N s. Those thresholds span the measured median and high tail; no ground truth or body state is injected into dynamics. All other control, motion, body, solver, release timing and limits are unchanged. Before the feedback switch, every candidate must match the exact reference trace; the reference must match all 1,500 samples.

Require at least three consecutive released-left-foot samples with every toe box over 1 mm clear at accepted poses, all left toe normal impulses <=1e-7 N s over all substeps, right foot carrying at least half body weight, bounded tilt/speed and no other-body support. Require the last 100 consecutive samples to have physical support and opposing horizontal impulses >=0.0002 N s in each front/rear group of each foot; also report the original normal-cone result. Require <=0.5 mm maximum independent accepted-pose overlap across all horizontal-opposition samples, no other-body contact over any substep and no failed solver steps. This is an exploratory single development start: any survivor requires prospectively frozen replay, other-foot release, perturbations, actual arrival states, refinement and full-route tests. No reserved layout is used.
