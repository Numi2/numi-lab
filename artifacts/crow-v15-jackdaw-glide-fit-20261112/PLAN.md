# Pre-analysis: corvid glide proxy

Fit one nonnegative two-term drag polar D = a U^2 + b/U^2, in newtons with U in m/s, to the archived pre-moult jackdaw wake measurements. Total drag is the sum of the reported induced, profile and body drag. Weight source-video groups equally using the first 12 ID characters as a provisional grouping key; the original ID encoding is not documented, so group independence is not asserted. Do not use moult-stage observations for this baseline.

Reserve the entire measured speed band 9.4 <= U <= 10.2 m/s as an interpolation check before looking at fit results. Train only on pre-moult measurements outside that band. The split prevents identical speed runs appearing in both groups; it does not create independent birds and may not create independent flight sessions. Report sample counts and group IDs, MAE and signed error against the held-out band, group means as well as individual records, and speed bounds. The model is a proxy for one jackdaw, not fitted American crow coefficients or a flapping/low-speed model. This is a diagnostic input to a separate glide regime, and must not be applied to the existing slower v15 takeoff or navigation controller without a physically justified mapping and native validation.
