# Estimated toe-segment mass sensitivity

The first rear-toe speed-limit events occur during the documented 0.78 m/s drop onto the ground. The prototype assigns each 18 mm toe segment 0.05 g, without specimen calibration. Test 0.10 g and 0.20 g per segment as sensitivity cases, against the retained 0.05 g reference, with the same shapes, joints, bounds, controller and 16-substep solver. Subtract each added segment mass and parallel-axis inertia from its parent foot as in the existing prototype, preserving the authored total foot mass and inertia at neutral toe pose; fail if the residual inertia is invalid. Rebind only the unchanged zero-output policy to each resulting task contract and verify all weights/transforms. Run 80 lanes on development seed 18647357 for 250 intervals with every accepted toe velocity recorded. Require no toe speed-limit hits and no physical or solver failures; record all outcomes and initial foot inertias. This is a bounded model sensitivity experiment, not biological calibration, grip, flight envelope, release, landing, or final layout evaluation. Any selected mass needs the complete invariant, flight and grip qualification again.
