# Fingerprinted high-level navigation policy contract

The oracle adapter exactly reproduced the development teacher across 480 sampled q/v states. Build an isolated diagnostic task contract with a distinct task ID and bit for the same v15 body and frozen V1 controller. Four actor outputs mean bounded true forward speed [-0.20,0.40] m/s, lateral speed [-0.30,0.30] m/s, heading error [-0.15,0.15] rad, and height [0.65,1.30] m. The flight adapter uses accepted proprioceptive feedback; the route teacher is enabled only while collecting labels, and the teacher-free actor supplies those four commands during autonomous evaluation. Retain the current/next waypoint goal after completion for landing, explicitly as goal information; it is not an obstacle-clearance or biological-vision claim. Other actor outputs retain their existing role or are inactive. Old physical-action PolicyPacks must be rejected under the new fingerprint. Any warm start must explicitly initialize the four new action heads and record source and target tensors. First verify build, old-contract rejection, oracle parity and teacher-off command authority before collecting demonstrations. This is development infrastructure, not a completed navigator.
