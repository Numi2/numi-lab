# Discrete geometry witness and row diagnostic

The retained v1 24-case matrix was rerun unchanged with the same shader. This diagnostic uses the dynamic body's body-local contact witness, transformed by the initial identity orientation, as the pre-solve COM lever; it measures the difference between summed contact angular impulse and the model inertia times angular velocity change. The maximum accepted error was 8.59e-10 N m s. The earlier midpoint-based discrepancy is a reference-location artifact in these cases, not evidence of a solver torque error. The replay, work and other model assumptions and caveats remain as documented in v1.

All 22 acceptances and the same two status-11 rejections reproduced. The frictionless box impact has two nonzero diagonal-corner normal impulses, 0.91451377 and 0.09063549 N s, and normal residual 0.01029848 m/s. The rejected stationary-normal, sliding box has zero normal target and zero pre-solve normal velocity for all four contacts, yet two opposing-corner normal impulses of about 0.00073591 N s each and normal residual 0.00147624 m/s. This is consistent with the existing full block inverse mixing unconstrained tangential residual into the projected normal, but the capture alone does not establish a general fix or friction accuracy. An admissible normal-first variant requires independent coupled, anisotropic, stick/slip and force-free tests. Certificate and experimental-option defaults are unchanged.
