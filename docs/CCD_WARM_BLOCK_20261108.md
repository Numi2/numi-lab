# Bounded sliding block initializer

Research candidate only, based on `163c8bb2`; it is not promoted. For a small supported island with cached normal impulses, the prototype enumerates one- and two-row normal active sets using a fixed pre-solve sliding-friction direction and actual rigid/articulated response. Each proposed solution must pass predicted normal complementarity for all rows and the friction-direction check for active rows before it is used as the warm initializer. Unsupported cases fall back to the prior ray initializer; the existing final certificate is unchanged. This is an initializer, not a complete Coulomb solver.
