# Isolated single-step pre-submit host rollback candidate

The separate research owner changes only the opt-in single-control-step hook path. Before encoding it checkpoints tracker host cadence, saved render uniforms, batch metadata, active environment count and one-shot research flag. An owner-side scope guard invokes the registered abort callback on any exit after a successful prepare and before command submission; it disarms immediately on submission. The fixture refuses research cadence or mixed candidate buffers and runs synchronously. The guard does not retain or call the borrowed tracker beyond submission. GPU buffers are not checkpointed here: the guarded failure is before command submission, so encoded writes have not executed.

Run the exact non-G1 Franka direct-winner failure/retry scenario from a698ebb9c with pinned shader and authored pack and the candidate owner. Require successful empty-frame warmup, induced post-visual finish-hook failure, one abort callback and bit-identical captured tracker/frame/camera arrays, frame metadata and cadence across refusal. The subsequent ordinary retry must succeed for both environments with cadence 2/1, matching one accepted advance after the initial 1/0 warmup. Retain all snapshots, statuses, time and hashes. One process, no retries, 120-second timeout.

This tests rejection before submission only. Successful submit is not completion or physics acceptance; the candidate is not a completion-owned transaction, does not stage GPU buffers, has no mixed-acceptance or independent retry-state reference, and cannot establish rollback on command error or rejected physics. Multi-step and production behavior remain unchanged. No policy fingerprint migration or general sensor correctness claim is made.
