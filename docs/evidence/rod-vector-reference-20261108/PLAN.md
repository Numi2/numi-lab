# Rotation-independent axial rod research candidate

Question: Does a local vector-axis version of the prior unpromoted exact axial solve reproduce the existing analytical implicit straight-chain result under arbitrary rigid rotations, without admitting materially bent, transverse-moving or transversely driven states? The previous candidate admits only +x; production has a known inaccurate accepted symmetric case. Neither candidate is production.

Prior model and alternative: the x-only candidate solves tridiagonal longitudinal mechanics when its strict eligibility succeeds. If its observed success is merely due to x-specific representation, using an orthonormal longitudinal projection and vector reconstruction should restore the same solution after rotation. Alternatively projection, FP32 coordinate quantization, reactions, or eligibility may make results orientation/translation dependent.

Pre-register the candidate: derive axis from first to final original node, work in coordinates relative to the first node, require positive finite extent and finite local quantities. Admit a straight, ordered chain, zero twist/rest curvature/damping, hard unique anchors including both endpoints, no rigid/contact flags, with node/anchor perpendicular deviations and velocity perpendicular components bounded by a documented small FP32-relative tolerance. The tolerance is a numerical admission bound, not a physical exactness proof. Project predicted coordinates and anchor positions onto the axis, solve the same scalar tridiagonal equations, reconstruct vector positions and target impulses. Invalid or unsupported conditions must fall through to the retained general solver and its stretch-residual certificate. No production shader and no collision or contact option changes.

Evaluation on M6: compare production, prior x-only candidate, and new candidate in deterministic 3-node symmetric/asymmetric/moving fixtures at x, y, z, -x, normalized (1,2,3), normalized (-2,3,1). Use identical material, 1 ms timestep, 128 iterations and analytical implicit reference; require accepted position error <=1 um, speed error <=1 mm/s, each support force error <=max(1 uN,1%), and transverse position/velocity/force <=1 um/1 mm/s/1 uN. Compare each run with its own deterministic repeat. At least one non-cardinal axis must pass to support the revised model; any rejection or gate failure remains a failure. Also exercise deliberately bent and transverse-velocity inputs and compare new candidate to the prior certificate-only fallback; candidates must not take the axial path or silently publish a different result. Screen offsets 0, 0.5 and 100 m separately; failure at large offsets is retained and bars broad promotion. The 3-node reference does not qualify arbitrary rod/tissue/contact and no performance claim follows.

Stop after this fixed matrix; retain source, runtime, shader and executable hashes, raw outputs, all failures, commands and analytic checks. If preliminary axes pass, use a separate unused-rotation follow-up before promotion. Full multiple-node, moving-anchor, work/energy, mixed-owner, replay and rollback qualification are subsequent gates; no production promotion on this screen.
