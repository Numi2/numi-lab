# Multi-node axial reference and moving supports

The precision-guarded vector candidate passed its declared 3-node near-origin matrix and unused rotations, while deliberately rejecting every 100 m case; it remains unpromoted. Test whether the tridiagonal solve and reaction accounting extend beyond that special system.

Use fixed 5- and 8-node straight chains, independent axes x and normalized (3,-4,7), offsets 0 and 0.25 m, with fixed endpoints, a moving endpoint, or a moving endpoint plus a hard internal support. Perturb free-node axial positions and velocities deterministically. Same material, 1 ms timestep, zero damping/gravity, no contact, 128-iteration limit, tolerance 1e-7. Every combination is an independent deterministic fixture, repeated twice. Evaluate the exact implicit Euler axial linear system in a separate FP64 dense linear solve using exported model masses, stiffnesses, initial states and anchor targets. Compute force on each support from the internal force and the momentum needed to enforce the support motion, and compute actuator work as support force dotted with imposed displacement. Require each accepted result: every nodal position <=1 um, velocity <=1 mm/s, support force <=max(1 uN,1%), and support work <=max(1 nJ,1%); rejected or nonfinite cases fail completion. Compare guarded vector with production and prior vector controls. Retain raw outputs and all failures. The model is synthetic elastic axial mechanics, not measured material, bent/twisted rods or contact; it cannot alone promote the solver. Stop after the 24 fixtures and declared repeats.
