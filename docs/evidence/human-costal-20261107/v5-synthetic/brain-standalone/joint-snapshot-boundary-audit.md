# Joint full-state observation boundary audit

The passed real-Brain synthetic fixture uses the legacy microsecond root family. Its published aggregate is a typed publication and sensor view, not a body checkpoint. The ABI's `mrnx_bridge_v1_runtime_copy_accepted_physical_state_digest` refuses a runtime without `exactClock`, and the legacy root does not allocate the physical digest that the exact-family root produces. The current Swift `beginPhysicalRoot` submits V1; it does not implement the V3 exact-family root. The C++ exact lifecycle probe writes synthetic Brain witness and ACK records itself, so its result cannot be substituted for a genuine Brain checkpoint.

A possible explicitly diagnostic V1 boundary can use `withDomainPublicReadGate` to exclude publication changes, then obtain both `MetalArticulatedOperatorContext::flushPhysicalStateObserver` and a quiescent Matter `Runtime::snapshot()`. The Human observer only exposes root translation, q, v and MyoSim arenas and their accepted identity. The Matter snapshot rejects a borrowed open transaction and captures state including FEM, material, topology, contact and support histories; `writeMatterSnapshotArchive` and `sameMatterSnapshotAuthority` provide an existing ABI-bound persistence and comparison mechanism. Stand contact warm-start applicability excludes this fixture's disabled Stand contact and valid Human/Matter program. This suggests a route, but it is not yet an exhaustive continuation audit: the Human published-resident scalar state, adapter slot lifecycle, published HumanIO sensor payload and identities, transaction generation counters, optional owner state, and any additional state relevant to the precise configuration must be reviewed and explicitly included or ruled out. In particular candidate-reservation counters advance even when physical state is restored and must be distinguished from accepted physical state.

`MetalNumiBrainRuntime.saveCheckpoint` captures cognitive and fast state, but requires a fingerprint of a simultaneously saved owning physical checkpoint. The present fixture has no such physical checkpoint or joint atomic save protocol. Passing an arbitrary value or the aggregate transaction fingerprint would falsely assert this ownership. A complete diagnostic needs a real physical artifact and binding covering its exact Human/Matter state and identities, a closed Brain root, and a protocol preventing either owner from advancing between captures; the Brain checkpoint's binding must identify that artifact. It also needs a no-rejection control, a deliberate rejected root, and an exact retry, with independently checked Brain and physical state comparisons and explicit expected differences in transaction reservation counters. This is an investigative design, not a completed implementation or restoration claim.
