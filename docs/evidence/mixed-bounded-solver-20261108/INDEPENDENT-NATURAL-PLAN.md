# Independent projected tangential residual

After the first candidate screen, independently recompute a projected tangential natural residual from the captured contact impulse and final tangential relative velocity, using an identity scalar step of 1 N s per (m/s), rather than the shader's local preconditioner. This fixture has zero tangential row targets and zero contact regularization; this check is not valid as written for nonzero targets or regularization. For each row, hold the normal impulse fixed, project the trial tangential impulse onto the circular friction disk, and divide the trial-projection difference by the positive step. Report the maximum over each requested sweep setting and require finite values below 0.002 m/s; retain the full per-row results. This independently evaluates the captured final state, not independent rod-surface kinematics.
