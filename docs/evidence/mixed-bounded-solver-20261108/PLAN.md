# Residual-certified mixed-island solver: isolated first candidate

Starting from the previously retained split-step research shader, implement an isolated bounded fixed-point iteration for mixed islands containing rods. At each sweep, recompute the normal complementarity residual and the isotropic-friction projected tangent natural residual from the current velocities, impulses, regularization, row targets and the same cone. A group-wide reduction must make early exit uniform across shared Metal barriers. The 0.002 m/s normal and tangent thresholds are the fixture's provisional diagnostic limits, not a generally qualified production scale. Run at least the configured number of sweeps, up to the research cap, and publish a typed nonconvergence status when an eligible mixed island remains above either threshold at the cap. Other cohorts retain their requested sweep count; the loop may not change their physics. Nonfinite or unsupported certificate data fail closed. Do not change the production shader or either disabled CCD/AL option.

First use a cap of 64 and the existing 60-case native direction/work fixture. Compare against the retained unmodified split shader; 64-sweep cases must remain physically close, while configured two-sweep cases must now complete only after meeting both residual gates, retain cone and directional checks, match linear momentum within 2e-5 N s, and replay. Also build a cap-2 negative control: all previously underconverged cases must reject with status 11, while certified cases should still complete; check exposed q/v, scene and rod node/edge rollback. Save both successes and failures. Existing fixed 64-sweep reference is not a physical ground truth; do not claim force calibration, full cache restoration, multi-step stability, arbitrary cone support, or performance. Check co-scheduled independent rigid islands and fully qualified natural-residual scaling before considering promotion.
