# Main-owner policy compatibility

Compile the existing matched Franka policy-compatibility probe twice against the same main-owner headers, runtime library and TaskProgram.cpp source: once unchanged, once with a visual-observation semantics discriminator. Write old-bound visual and nonvisual zero-policy packs with the baseline executable, then require the candidate to accept the unchanged nonvisual pack, reject the old visual pack as incompatibleContract, and accept a freshly rebound visual pack without changing actor shape. Keep exact source, object, executable, dylib and pack hashes. The zero policies are contract fixtures, not trained-policy evaluation. This conditional discriminator invalidates every old visual contract conservatively because changed depth and edge samples can affect them; no automatic policy migration is implied. Failed physics, visual history rollback and other runtime transaction boundaries remain unqualified.
