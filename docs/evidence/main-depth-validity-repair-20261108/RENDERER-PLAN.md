The prior independent renderer probe assumed the research-only unsegmented switch. Adapt it to main by populating the accepted-instance table from every identity of an actual geometry pixel, exercising main's existing identity-selected depth rather than silently relying on that absent switch. The identity table is derived once from the rendered frame and used for both baseline and candidate; it is an oracle for this diagnostic, not deployment-valid perception. Recompile against the same main headers and owner dylib, and use the same main full metallib for both rendered scenes. Preserve the original probe source. Evaluate all normal/dropout frame pixels at 160x120 in four environments against the existing independent depth/edge CPU reference, with fixed 0 and 1 edge-flicker probabilities. Require valid scene coverage, truthful dropout, candidate mismatch zero within 2e-6 and nonzero edge-fill control. Record the paired original outputs, exact identity set, binary and source hashes, and any unavailable renderer prerequisites.
