# Persistent GPU-owned coupled rod: commit and failure retry

Build a research-only resident wrapper around the previously checked compensated-force straight-rest DER shader. A GPU-owned accepted record retains edge vectors and cumulative node displacements as high/low FP32 pairs, velocities, centered twist, twist rates, support reactions and accepted-step count. Each attempt prepares a separate scratch input, invokes the unchanged solver, and commits only a successful output. No host state is read or written between the ten steps of a trajectory; all attempts in both comparison arms are encoded in one Metal command buffer and read back after completion.

Run the same three 10-step cases used in `rod-coupled-metal-trajectory-20261108`: seeds 2101–2103, 3/5/8 nodes, 1 ms, one moving support advancing 1 micrometre per accepted step and the others fixed. A clean arm has ten valid attempts. Before accepted step five, the other arm has an additional deliberately degenerate first edge in *scratch* with zero local predicted motion, requiring an actual solver geometry rejection. Verify that the candidate status indicates geometry failure, the full accepted-state record is byte-identical before and after that rejection, and the retry and every later accepted full record (including all dynamic fields and last reactions) match the corresponding clean record byte-for-byte. A failed physical solve stops successful qualification; retain every output.

Compare all 30 clean accepted states to a separately advanced native-energy FP64 trajectory using the prior gates: 1e-6 m, 0.001 m/s, 0.0001 rad, 0.001 rad/s, support force max(1e-6 N,1%), local linear/angular momentum <=0.001 and independently solved reference <=0.0001; compare per-step and cumulative support work and kinetic-plus-elastic energy within max(1e-9 J,2%). Run the whole matrix twice and require byte-identical outputs including GPU state records. Preserve GPU inputs/outputs, native query trace, all statuses and complete before/after bytes at rejection. Fixed cases were previously observed; no holdout claim. All source, binary, baseline and inputs are hash-bound before the run. No tolerances or cases may be changed after results.

This is an isolated noncontact, gravity-free, straight-rest research owner, not MetalWorld integration, general rollback, calibrated tissue, dynamic rigid coupling, performance or a production repair. No fallback to the old solver is permitted. Experimental directional CCD and AL contact remain disabled.
