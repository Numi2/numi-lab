# Masked-depth feedback with rejected-step output restoration

The integrated Apple M6 MetalWorld rollout passes the predeclared combined observation and rollback checks. The fixture uses real physical steps and a stateless GPU feedback controller, with simulator-instance identity selecting pixels. It is not trained or deployment-valid perception.

Two matching 30-step, two-environment runs each produced 55 accepted and five intentionally rejected environment-steps. The raw-contact capacity was restricted to one to induce the failures. For all 55 accepted steps, the final actor output matched the post-tracker output. For three rejected non-reset steps, it matched the pre-tracker output; all three had a changed tracker candidate. For two rejected reset steps, nonvisual values matched the pre-tracker output, track and feature fields were zero, and both masked-depth histories reported far/no-return. Three steps had one accepted and one rejected environment.

On the nonsampled resets at steps 14 and 27, the reset environment supplied invalidated depth and zero action to the controller while its non-reset neighbor retained a nonzero feedback signal. The controller inputs were the post-tracker observations on all 60 environment-steps, and the final published actor rows matched the post-physical snapshots. An independent CPU reduction of each saved current depth image agreed with the GPU feedback signal within 2.051e-8; the captured action buffers matched the declared 0.01 signal scaling. The two runs were byte-identical for q/v, scene, status, reset masks, actor history, observations at all three boundaries, controller inputs, action buffers and trace.

This is a combined integration check of previously implemented paths, not a new production-code change. The result does not qualify recurrent-policy rollback, GPU-command failure, rendered pixel restoration, accepted-time sensor clocks, deployment-valid perception, physical forces, task success, or performance. The controller runs before physical acceptance; output restoration does not imply that an arbitrary stateful policy rolls back. Both experimental directional CCD and augmented-Lagrangian contact options remain disabled.

The native probe derives from the previous masked-depth feedback fixture using the recorded output-capture generator. It was built at source revision 700be5eb1 against the retained combined native library and shader identified in binaries.sha256; the library was not rebuilt for this evidence-only change. Build and trial commands are in commands.txt. captures.tar.gz contains both complete raw runs. It was independently extracted and verify.py rerun against the extracted files; archive.sha256 records the archive identity. The capture adds GPU blits, so this is not a timing experiment; no uninstrumented equivalence claim is made.
