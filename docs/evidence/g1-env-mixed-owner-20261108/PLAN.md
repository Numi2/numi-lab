# Preregistered owner-level mixed-frame candidate

This isolated owner adds a separate, explicitly invoked research method. It reads per-environment accepted clock records, applies the existing double-precision cadence calculation, saves each held depth/identity/validity/camera slice, renders the full physical batch separately for each fresh environment with that environment's own frame, sensor sequence and capture time, then assembles only that environment's rendered slices. It returns candidate per-environment metadata copied from the corresponding actual renderer metadata. It is restricted to the geometric retained-frame path with no masked depth; production callbacks, outer divergence guard, reset, policy and transaction publication are unchanged. The method is a candidate-building primitive; caller owns acceptance and rollback and the renderer's ordinary batch metadata remains nonauthoritative for mixed frames.

After two real accepted nonterminal warmup steps, independently render the same fixed observation-time pose at frame/sensor 2/1 and 0/0 with 5 mm depth noise, repeat both references and require visible, seed-sensitive target pixels. For two distinct sample/hold phase arrays at 25 Hz and 20 ms, initialize both held frames at 2/1 and invoke the new owner method outside the rollout. Test `(fresh,hold)` and `(hold,fresh)` using cadence records that produce those decisions. Compare all candidate depth, ID, validity and camera words for each environment against its corresponding retained actual-render reference, and compare per-environment candidate metadata bitwise against its selected reference. Save all plane words, candidate metadata, timestamps and frozen identities. The existing reference harness compares camera floats by `==`; this gate's candidate-to-reference camera check uses raw bits.

Run once with a 120-second cap and check pinned binaries, shaders and assets before and after. This is real owner-level rendering and selection with deliberately supplied independent phases at a fixed pose. It is not integrated into observation/policy execution, not a physics status commit, and does not establish mixed continuation, real reset, failure rollback, actor/tracker transaction, masked-depth rings or command-failure atomicity. The divergence guard stays enabled. If any prerequisite or comparison fails, retain the complete failure and do not promote it.
