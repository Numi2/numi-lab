# Preregistered isolated automatic-reset continuation gate

Starting with research evidence commit 24255f8b, use the opt-in single-step owner and the same 25 Hz moving-target fixture (20 ms control step, 5 mm depth noise, seed 4081015). Require two accepted nonterminal steps, then the real env-0 contact-capacity failure and env-1 success with env-0 marked terminal. Require the existing divergence guard to reject the next submission before observation.

Only after that rejection, enable a one-attempt research-only override and provide a working reset clock for env-0 (zero accepted steps and no held frame), retaining env-1's accepted clock. The renderer override is consumed before later validation, requires research clock and metadata buffers, and leaves default behavior and the outer guard unchanged. This fixture-only assumption about reset ownership is a hypothesis, not a new production reset implementation. Require the actual GPU reset mask to equal (1,0), read after the native task observation kernel has written it; require both subsequent world/contact statuses and submission to succeed. If any prerequisite fails, retain it and stop. The output has partial pre/post snapshots even if later prerequisites fail.

At that step env-0 should sample sensor 0, frame 0 at time 0; env-1 should hold sensor 1, frame 2 at the prior 0.04 s capture. Status-gated clocks and accepted metadata must reflect those choices. Compare env-0 depth, instance ID, validity, camera bits and metadata to an independent render at the captured observation-time body state; compare env-1 slices and metadata with the held pre-step data, and report how many reset words actually changed. Full prior actor/tracker rollback is already tested in the parent evidence. Snapshot all available planes and track words; do not infer unchallenged fields from equality.

Run the exact pinned native executable once, with a 120-second process timeout and UTC start/end, using the pinned library, shader inputs and assets in the declared manifest. Check hashes before and after. Preserve stdout, stderr, any partial/full snapshots and any failures. The initial link in the wrong working directory failed before execution; the successful link is from the original object directory and both logs are retained.

This is one explicitly instrumented auto-reset continuation, not a no-reset retry, proof of general per-environment reset policy, accepted live mixed cadence for production, masked-depth history, multi-step calls, generic command failure recovery, or deployment-ready sensing. The production guard must remain unchanged. An ordinary no-instrumentation control and a complete independently checked actor/tracker reset are outside this gate and required before promotion.
