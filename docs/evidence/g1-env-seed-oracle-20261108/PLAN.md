# Preregistered independent visual seed-helper test

Compile a test kernel by including the isolated owner's unchanged `HybridRenderer.metal` and calling its actual `frameSeed` helper. The fixture exercises two 25 Hz clock records at 20 ms: environment 0 accepts its first fresh sample at frame/sensor 0/0; environment 1 at accepted count 3 holds its prior frame/sensor 2/1. The CPU proposal must report those distinct fresh/hold decisions. Each sample has separately specified instance identity and its original batch-global pixel index; reference calculations retain these inputs because slot renumbering changes the seed. A second case checks that replacing env 1's global pixel by env 0's differs.

Run the helper in one two-record GPU dispatch, then in two separate one-record dispatches using the same inputs. Require exact equality for each batch seed, separate-dispatch seed and preregistered independent CPU XOR calculation, plus a nonidentical negative-control seed. Run once with 120 seconds and hash all inputs before and after; retain any failure. These are single-record helper references, not single-environment renderer rollouts. This does not qualify actual mixed-phase rendering, stochastic pixels, metadata publication, task resets or state continuation; the real renderer's divergence guard remains unchanged.
