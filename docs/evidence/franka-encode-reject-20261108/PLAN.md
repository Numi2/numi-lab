# Franka actual pre-submit rejection and retry diagnostic

This separate single-step fixture retains the corrected Franka direct-winner setup. After one successful empty-scene warmup it forces the research finish hook to return false after the actual visual callback and physical encoding, so the owner rejects that attempt before command submission. It snapshots the same tracker, frame and camera arrays and cadence plus batch metadata before and immediately after, then retries once without injection and records the resulting state and status. The output records any actual mutation; it does not assume one. The retry follows an actual returned owner error, but the error is deliberately induced at encoding: this is not a GPU command failure or mixed per-environment physical rejection. The frame admission input remains PRESENT throughout and no absence is inferred from pixels.

Require actual direct-winner mode, a completed warmup with zero nonempty winner pixels, rejection at the finish hook, and a successful retry with both environment statuses zero. Binary snapshots retain length-prefixed history/frame/camera vectors, 16 metadata words, and the two cadence counters at each of three boundaries, followed by winner words. These are not actor history, complete world state, or independently referenced post-retry values. Preserve failures and do not retry the test process. Run one process under a 120-second cap with immutable copied dylib, shader and asset and pre/post hash checks. No multi-step, production or policy-fingerprint behavior changes.
