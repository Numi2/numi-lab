# Rpath-corrected guarded mixed publication gate

This is a separately registered repetition of the hypothesis in franka-staged-upload-mixed-20261108/PLAN.md, after its failed control revealed the executable selected the old owner by absolute rpath. Preserve that failure. The original probe bytes are changed only by install_name_tool to point to this isolated directory, then ad-hoc signed and signature-verified. The recorded LC_RPATH, copied guarded dylib, executable, shader and task pack are pinned before and rehashed after. The source and logic of the probe and control/mixed fixtures are unchanged. The guard must also print its first-abort restored-zero bindings: a missing log makes the gate fail and prevents any following arm.

Run the CPU helper unit, then a control and, only if it and guard evidence pass, a mixed arm in independently initialized native processes. Each has a 120-second timeout; no retries. Control must show both successful validated environments. The mixed arm must show actual failed env 0 and successful env 1; all other outcomes are inconclusive. If these prerequisites pass, compare env 1 actor bytes to independent control and verify the failed env sentinel. Collect all status, raw counts, output and mismatch evidence.

As before, the sentinel is not an accepted frame, and this is a host-only projection, not a transactional owner implementation. It does not qualify actual tracker, actor history, physics, frame, cadence, automatic reset, real camera, post-commit command failure or asynchronous callback handling. Neither production defaults nor experimental promotion change.
