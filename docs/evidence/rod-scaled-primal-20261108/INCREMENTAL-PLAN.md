# FP32 incremental-coordinate force diagnostic

The 1e-6 N stopping experiment fixed the moving-endpoint position, but seven previously accurate cases stagnated or exhausted their budget, with several local forces near FP32 coordinate resolution. Test a separate candidate retaining per-node increments relative to the step input for the entire nonlinear iteration. Compute edge vectors as the input edge plus the difference in increments; evaluate the implicit inertia and soft attachments in the same representation. Convert to absolute FP32 positions only after convergence. Use the same full Hessian, block solver, objective line search, 1e-6 N candidate threshold, reference and ten fixtures. Keep both earlier attempts unchanged. External publication gates remain 1e-6 m, reaction max(1e-6 N, 1%), and 1e-5 N independently recomputed from the final published absolute coordinates.

Report both working-coordinate and reconstructed absolute-coordinate residuals; state and force must pass together. A divergence, nonpositive pivot, failed line search, unrepresentable update or missing convergence rejects. This is CPU NumPy FP32 research, not a production buffer format or proof that an ephemeral increment may be discarded without a full transaction and force-consistency audit. It omits bend, twist, contact and rigid coupling; no speed or surgical claim follows.
