# Independent energy-difference audit

For the stable-difference candidate, compare its FP32 signed per-step objective differences with independently evaluated FP64 energies of the same FP32 input edges, displacement increments and attachments. Use deterministic seed 20261108, 9/17-node curved and mixed-attachment fixtures, and increments spanning 1e-6 through 1e-10 m with both signs. Require absolute error no greater than 1e-15 J plus 0.5% of the reference difference, and matching signs whenever the reference magnitude exceeds 1e-13 J. Check the zero-update result and deliberately reverse the reported sign as a negative control. Report every failure and the number of informative signs. This tests numerical algebra in the restricted synthetic objective, not a clinical model or a Metal implementation.
