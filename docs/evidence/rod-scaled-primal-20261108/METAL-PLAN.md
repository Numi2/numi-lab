# Isolated Metal vector prototype

Implement the registered incremental-coordinate full-tangent block method as an isolated Metal compute kernel and host instrument, without changing the production rod solver. Use the same ten 3/9/17-node CPU fixtures, independently generated FP64 references and gates: all-node error <=1e-6 m, each hard and soft support reaction <=max(1e-6 N, 1%) error, and independently recomputed local force <=1e-5 N from the published FP32 positions. Require explicit status and convergence; include line-search, pivot and nonfinite failure reporting. Record Metal device, exact source and binary identities, outputs, repeat comparison, and all failures. The generated cases and CPU dense reference must not depend on candidate GPU outputs. GPU runs are correctness captures, not timings.

This is an isolated stretch-plus-attachments experiment: it omits bending, twist, contact, rod radius, stateful owner integration and coupled rigid feedback. It must not be wired into production or called a general rod repair. A later solver must account for those components, certify all required residuals and work/force transfer, and establish transactional behavior. The directional CCD and augmented-Lagrangian experiments stay disabled.
