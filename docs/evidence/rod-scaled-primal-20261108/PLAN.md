# Scaled FP32 coupled axial direction

On the same source and Apple host, test a primal, dimensionally scaled FP32 system as an alternative to the previous unscaled multiplier assembly. Solve displacement increments rather than subtracting large multiplier responses from absolute positions. Start from the prior straight-chain material and 3/5/9/17-node centered and moving cases. Use identical 1e-6 m position and max(1e-6 N, 1%) reaction gates against an independent FP64 free-node implicit equilibrium with the same unrounded physical input. Record force, state and residual errors. Compare all nodes, not just the center. Failure to meet any gate remains a failed case.

Add preregistered unused 33/65/127-node centered and moving cases, an asymmetric stationary case and a moving endpoint; report both aggregate and each result. The linear model is a straight, ordered axial chain with hard prescribed endpoints and no gravity or contact. This is a numerical direction for a later full vector coupled rod method, not a production solver, clinical model, or justification to add a special-case path to the runtime. Scaled algebraic residual alone cannot qualify accuracy. No timing or speed claim. Keep directional CCD and augmented-Lagrangian contact disabled.
