# Coupled Metal rod: short independent-reference trajectories

The unchanged compensated-force Metal candidate passed the exposed and unused one-step sets. Test three ten-step, 1 ms trajectories from holdout cases 0, 1 and 2 (seeds 2101–2103; 3, 5 and 8 nodes). Initialize both endpoint targets at the actual initial endpoints. Case 1 translates its right support 1 micrometre per step in the initial first-edge direction; the other supports remain fixed. All material, state, solver and physical gates are unchanged. Each arm must carry its own positions, velocity, twist and twist rate after each accepted step. The candidate is submitted to the unchanged Metal probe each step; the reference independently advances from its own state using Newton with numerical Jacobians from native DER energy gradients, as in `rod-coupled-bend-20261108/trajectory.py`. This is host-owned state carry, not a device-resident owner.

Before any result, require all thirty steps to complete. Per step: max position <=1e-6 m, velocity <=0.001 m/s, twist <=0.0001 rad, twist rate <=0.001 rad/s, each support-force error <=max(1e-6 N, 1% of reference), and independently evaluated local momentum <=0.001 m/s or rad/s. The native-energy reference itself must meet <=0.0001 in each momentum unit and positive scaled Hessian curvature. Compare each step and cumulative support work within max(1e-9 J,2%), and kinetic-plus-elastic energy within max(1e-9 J,2%). Preserve force-on-target dot target motion sign. A failed/missing step stops that trajectory; all cases and failure records remain. Repeat the entire study byte-for-byte, bounded by 300 seconds per run and 30 seconds per native command. Retain complete native query traces, actual GPU probe output and inputs, progress and hashes.

These are selected from the one-step holdout already observed; trajectory behavior was not previously examined, so this is a follow-up, not a new untouched initial-state holdout. The native reference uses the same discrete energy, not physical-material measurements. No contact, gravity, damping, performance, persistent GPU ownership, production publication or complete rollback is asserted. Directional CCD and AL contact stay disabled.
