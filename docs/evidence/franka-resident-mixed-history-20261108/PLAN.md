# Resident accepted-then-overflow history diagnostic

This non-G1 Franka fixture uses the isolated guarded owner and a zero policy, two environments, 16x9 off-scene direct-winner visual input and one control step per submission. It preserves the real owner and automatic terminal/reset semantics. Record the actual post-warmup resident actor-history buffer using a test-only blit encoded by the finish hook, and read tracker/depth histories, camera, depth/ID/validity frame planes, batch metadata and host cadence through the research snapshot after command completion. The input camera is off scene; this does not demonstrate visible changing pixels or meaningful track history. The policy has no recurrent layer; actor frame history is distinct from recurrent policy state.

The initial environment 1 is identical in both independently initialized arms and keeps objects far from contact. Control environment 0 does likewise. In mixed environment 0 the two boxes start at heights 0.070 and 0.075 m, horizontal positions 3 and 4 m, and downward velocity 1 m/s, with half-heights 0.025 and 0.030 m respectively. These inputs aim to give one accepted free step before a plane impact with capacity one; the warmup and mixed overflow are explicit hypotheses. If either prerequisite fails, retain it and do not infer rejected-state behavior. Every step must publish validated per-environment world and contact statuses; require both accepted in warmup and control test, and env 0 failed/env 1 accepted in the mixed test. Store all captured data before and after the test, exact statuses and raw required contact counts. Record one further normal resident continuation after the mixed failure without suppressing reset or changing physics; it is not a guaranteed retry, and its actual status determines interpretation.

Run control then mixed, one native process each with 120 seconds maximum, no retries and pre/post pinned binary/library/shader/asset hashes. Compare only declared actor-history environment slices using the task frame/history packing; retain complete visual buffers and report differences without assuming padded frame-buffer environment strides. Shared host cadence and batch metadata are not per-environment state. Snapshot bytes after physics failure describe the current owner; a mutation or equality does not alone demonstrate physical correctness or a repaired transaction. No candidate owner, asynchronous command failure, production promotion, visible-track, real-camera or recurrent-state claim is made.
