# Scene-body speculative contact witness audit

A preregistered native Metal fixture tested a dynamic sphere against a static plane at zero and positive initial gaps. At gaps of 0.6 mm and 1.4 mm, the angular velocity change calculated from the actual tangential impulse and the shared midpoint agrees with the runtime to 7.5e-9 and 3.3e-8 rad/s respectively. Using the sphere surface witness instead gives differences of 0.016995 and 0.039207 rad/s. The zero-gap control agrees with both calculations, and the separated, force-free control receives no impulse. Linear momentum errors are below 1.5e-8 N s. See `PLAN.md`, `output.json` and `analysis.json` for setup and results.

The observation is confined to this speculative scene-body path. It establishes which lever arm was used in these cases; it does not by itself establish that either contact law is physically correct, or that other contact paths behave identically. In particular, a shared application point and two separated surface application points have different angular-momentum implications. The positive-gap cases also produce tangential impulses before geometric contact; further physical-step and solver-operator tests are required before changing the implementation.

The audit was performed while the checked-out main revision was `50c7e8a1d`. The runtime library and metallib came from an existing build and are bound by `inputs.sha256`; those hashes, rather than the later evidence-only Git revision, identify the executed binaries. Repeated independent runs matched. This is diagnostic evidence, not a performance measurement or a regression gate for a future correction. `python3 analyze.py` recomputes the retained analysis from the captured output.
