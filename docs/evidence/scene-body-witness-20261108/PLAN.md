# Scene-body contact witness audit

Question: for a dynamic scene body contacting a static plane, does the accepted angular impulse use its own body-local contact witness or the common midpoint between separated witnesses? The inspected wave solver has scene-body point velocity and impulse calls using `pointAndSeparation.xyz`, while contact metadata retains separate local anchors. This is a hypothesis about specific paths, not a general defect claim.

Before the trial, run single-step, zero-gravity dynamic-scene-sphere/plane controls under the default speculative CCD mode, paired with an off-scene articulated body needed by the owner. Use two velocity sweeps, no restitution, fixed mass/inertia, isotropic friction and independently repeated owners. Include touching and positive-separation approaching/sliding cases plus a separating or force-free control. Capture initial and final rigid state, solver status, each normal/tangent direction, impulses, point, both local witnesses and manifold status. Validate which body is the scene body, its pose, nonzero impulse, positive-separation contact and repeated state before interpreting it. Record failures and exact input/source/library/shader hashes.

For each accepted case, independently sum the reported 3D impulse, and compute the scene-body angular-velocity increment from its own reconstructed pre-step local witness using `I_world^-1 sum(r_B cross J_B)`. Also compute the midpoint-based prediction. Compare both with the actual increment on the same step with absolute tolerance 1e-4 rad/s and report momentum error. A discriminating fixture requires these predictions to differ by at least 1e-3 rad/s. If the owner uses another integration pose or the fixture fails its prerequisites, classify the result as inconclusive and preserve it. This is a bounded diagnostic; it does not qualify general CCD, contact, force accuracy or performance. No solver or threshold changes are authorized by this plan. The fixed-contact CPU reference runs concurrently.
