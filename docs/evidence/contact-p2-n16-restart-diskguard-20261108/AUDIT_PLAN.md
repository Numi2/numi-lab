# Pre-analysis input audit

Registered while the fine phase was running and before its result or comparisons were available. Run `audit_before_analysis.py` only after both phase manifests exist. It checks that both phases completed without a resource stop, that their source, model and n8 prerequisite identities and output hashes match, and that the traces and normalization values are finite and have the expected shape and time ordering. A passing audit is required before invoking the previously registered `analyze.py`; it does not replace the registered physical, temporal, spatial or quadrature gates. Retain the audit output and its script hashes with the resulting analysis. If it fails, retain the reason and do not publish a comparison as valid.

`test_audit.py` uses a disposable synthetic copy of the completed coarse data as a stand-in fine phase. Eight checks passed: the synthetic valid control and seven rejected controls for nonzero exit, changed output, changed input, truncated trace, nonfinite force, zero normalization and nonmonotone time. The first test launch had a Python syntax error caused by quoting during script creation; its stderr is retained. This self-test is only validation of the audit logic and does not establish any fine-run result.
