# Preregistered visual-owner mixed physics failure probe

This is a bounded feasibility and transaction diagnostic, not policy or deployment qualification. It uses the corrected, historically matched owner and the actual compiled G1 ball-dodge task, MetalWorld, visual renderer, masked-depth SensorPack and object tracker. Two environments execute zero actions for three single control steps; two separately instantiated arms share world/task/observation/action fingerprints. Both start elevated; the intervention arm alone begins environment 0 with two nearby rigid spheres and raw-contact capacity 1. Environment 1 is untouched. Six synthetic authored packs bind the spheres; the tracker samples at 10 Hz while physics advances at 50 Hz. The binary and shader below are fixed before any run.

Run one process, timeout 120 seconds. Capture wall start/end, exit status, all stdout/stderr and hashes. No retry or parameter tuning in this study. Preparation may fail or both/neither environments may fail. A usable mixed-batch gate requires all control environments and intervention environment 1 to report success, and intervention environment 0 to report an actual physics error. If that does not happen, preserve the outcome and do not claim a transaction test. Fingerprints must agree. Compare every exposed actor component for the unaffected environment at each step against the control, exact textual values, and record any mismatch. This is an unaffected-environment check, not proof of atomic restoration for the rejected environment. Report whether there is a nontrivial visible sensor witness; otherwise history/held-frame conclusions are unavailable. Status, reset timing, all rows and any setup failure remain evidence.

The tracker and held-frame internals lack public readback; automatic reset follows physics failure. This fixture cannot independently establish rejected-environment restoration and retry equivalence. It uses oracle instance-masked depth, not deployment-valid unsegmented perception. A full per-environment candidate/commit contract covering observation, held frames, tracker, and cadence requires additional instrumentation and an explicit retry/reference design.
