# Follow-up preregistration: one finer independent mesh

The preregistered 2/4/8 study failed spatial convergence despite passing both
temporal references and preserving area. The 4-to-8 peak differs 28.4% and
impulse 3.37%. The hypothesis that n=8 approximates the refined response at
the declared tolerances is rejected. High-frequency elastic waves and contact
redistribution are candidate explanations, not established mechanisms.

Before running a new mesh, extend the independent FP64 reference to n=16 with
the same physical coefficients, geometry, clearance, initial state, output
clock and existing 0.5/0.25 us temporal checks. Predict that n=8 to n=16 will
still fail at least one of the original bin, peak, cumulative, or impulse
gates. Reject the prediction if all pass after temporal qualification. This
one additional mesh is a diagnostic follow-up, not a revision of the original
3-mesh study. Stop at n=16; a further refinement needs a separate resource and
validation plan. CPU reference evidence alone does not qualify native n=16.
