# Current-runtime axial rod control

Repeat the retained three-node, two-fixed-support straight axial rod fixture on the current main and reconciliation builds, preserving its default 1e-7 m correction tolerance, 128 iterations, 1 ms timestep, geometry, material and independent closed-form implicit reference. Build the same source separately against each runtime. Record source, executable, library and Metal library hashes, source revisions, stdout and exit codes. Each of symmetric, asymmetric and initially moving cases must publish a valid state within 1 micrometre and 1 mm/s of the independent reference and each support reaction within the greater of 1 micro-newton or 1% of its reference. A rejected case fails completion; a published state failing a physical gate is an incorrect acceptance. Retain every outcome. This test does not establish bending, contact, surgical performance or measured physical accuracy. GPU execution is not an isolated performance benchmark.
