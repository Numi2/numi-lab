# Native consumers for derived physical skin boundaries

This initialization adapter accepts the imported O/I/D surfaces and exact role-local full86 CSVs. It preserves candidate-authoring source namespaces independently of NHSKIN source IDs and parent cell labels. Exact source row identity, role counts, current donor frames, registered volume boundary nodes, full binding lanes, weight normalization and dominant frame ownership must agree. Output remains unchanged on failure.

The focused native C++ check and its CMake/CTest target passed on SSH Numi. Eleven rejection cases cover file corruption, row identity/count mismatches, source embedding leakage and binding/frame failures. Every transitive project header matches the pinned Lab main revision. Exact commands, source/binary hashes and output are retained in receipt.json.

The fixture uses three nodes per role and is not a body geometry or mechanics test. This adds no physical mass, solver or per-step state. The adapter is not yet wired to a production child-volume installation; final geometry, conservative mass mapping, native replacement and accepted motion remain pending.
