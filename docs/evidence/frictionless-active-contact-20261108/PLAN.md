# Frictionless active-contact candidate: preregistered diagnostic

Question: does the retained zero-friction block candidate respond to real closing contact without letting an independent tangent velocity change the normal impulse? In frictionless contact a common tangential translation cannot alter the normal constraint solution at a fixed configuration. A block solve followed by cone projection is an alternative explanation for the known baseline coupling defect.

Use source c0c28a626 on Apple M6, the current matching MetalWorld runtime and a shader built from its current source plus the previously retained candidate.patch; link both shaders from the same other AIR files. One 1 kg tilted box, static plane, no gravity, no restitution, no CCD, no damping, friction exactly zero, 1 ms step, and 0.1 mm positive gap within the contact envelope. Use two unused rotations (-0.37 and +0.29 rad), initial normal speeds -0.4 and -1.0 m/s, and velocity-iteration budgets 2 and 32. For each configuration use x velocities -1, 0, +1 m/s; the zero-tangent arm is the matched control. Each run repeats internally; all statuses, contact counts, initial q/v and final q/v are retained.

Before observations: all 24 candidate cases must produce contact, succeed, repeat exactly, preserve tangent x/z velocity within 1e-6 m/s and have nonzero normal response. For each set of three, candidate normal and angular velocity components must match the zero-tangent control within 2e-5 in their units. The baseline is an observed comparator, not assumed to fail. Independently calculate normal velocity at both lowest corners from the *initial* rotation and final body velocity; with positive gap g, test the closing-velocity bound -g/h within 0.002 m/s. Report the 2- and 32-iteration result separately: neither is masked if it fails. The midpoint-versus-anchor geometry and solver regularization can affect that proxy; it is a screen, not a substitute for evaluated-row residuals. Require zero angular response about the vertical direction within 2e-5 and no x/z translation impulse. Treat rejected/missing runs as failures. Run no performance measurement; retain raw logs, compiler commands, input and binary hashes.

Stop after the fixed 24 cases per shader, repeated inside the fixture. This is not full qualification for moving supports, mixed rods, one-axis friction, rollback, general active contact or CCD. Do not promote the candidate from this diagnostic alone. Experimental directional CCD and AL contact remain disabled.
