Present two successive synthetic physical-step results: the first fails environment 0 and accepts environment 1, the second accepts both. A shared host clock predicts no new frame on the first observation and a new frame for both environments on the second, even though only one environment accepted the first step. Compare with a no-failure arm and repeat runs. This is a direct synthetic-status tracker diagnostic, not a complete MetalWorld physical-failure or learning demonstration. No semantics for reset or real-time versus accepted-time sampling are assumed by the observation itself. Retain failed attempts. Do not change production code or experimental contact/CCD flags.
