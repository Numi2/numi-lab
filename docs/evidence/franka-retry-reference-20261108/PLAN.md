# Non-G1 pre-submit rejection and independent retry reference

Two fresh processes use the same pinned isolated owner, Franka pick-place task, two environments, zero policy, 16x9 direct-winner depth, empty camera scene and identical fixed seed. The control completes two ordinary single-control-step advances. The trial completes one, forces a finish-hook encode rejection before command submission, then retries once. Both must meet the direct-winner and empty-scene prerequisites and return successful world statuses for both accepted steps. This is the guarded candidate at db614ba33, not the unguarded control.

A test-only blit captures the complete logical actor-history buffer on every successfully encoded finish. After the second accepted step compare exact bytes for q, v, all 13 exposed scene-body position/rotation/velocity components, actor observation, actor history, depth and tracker histories, camera state, batch metadata, status and direct-winner words. Retain per-field lengths, hashes and first differing byte, as well as both process outputs and raw field files. Empty fields, preconditions or process failure invalidate the corresponding comparison, never silently pass it. One process per arm, control followed by trial, each with 120-second timeout, exclusive GPU and input hash pre/post checks. Do not retry either process.

This independently checks the reached post-retry boundary at these exact fields and one empty-scene fixture. It does not check all device-private physical state, contacts, nonempty visual geometry, command-buffer failure, rejected physics, mixed environment acceptance, general deterministic replay, policies with nonzero action, completion-owned publication or production behavior.
