A separate isolated owner extends the nonmutating snapshot to copy retained depth, uint4 identity, validity and compiled track binding IDs. All data are copied after command completion; phase 0 is uninitialized visual output and will not be interpreted. No production publication or solver behavior is changed. The camera and history snapshots, full scene output and contact counts are retained as before.

Run once with a 120-second timeout and preserve all output, frame bits, identities and timing. Check whether the target binding ID occurs in valid pixels and whether their depth is finite and positive; compare identity channels and track confidence with the actual tracker shader predicates. Report visible pixel counts and distinguish missing geometry, occlusion, incorrect IDs, invalid depth and unresolved alternatives where the data permit. Compare the full actor/status stream with the prior instrumented run at printed precision to bound instrumentation effects.
