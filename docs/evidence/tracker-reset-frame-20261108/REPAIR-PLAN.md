# Reset-frame containment: design and qualification

The direct 25 Hz probe showed that a reset can consume a prior-episode frame; the 50 Hz same-renderer arm sampled the new scene. Implement a per-environment GPU freshness bit: a newly encoded batch frame marks each environment fresh; a reset with no new frame invalidates only that environment until the next actual batch frame. A stale object track must have zero visibility and zero position/velocity, and a stale masked-depth frame must contain the existing far/no-return value and zero features. Do not shift the nominal sampling clock, fabricate a new render, alter another environment, or claim full renderer/physics transactionality. Snapshot and restore the new per-environment state on failed physical outcomes with the other tracker histories. Retain source/binary identities and the negative baseline.

Before promotion, use the 25/50 Hz direct fixture on old and new runtimes with matching initial geometry and repeat both. Extend it to a third stale step before fresh capture, both object tracks and masked-depth, per-env non-reset control, reset on sampled step, post-sample recovery, synthetic failed-step restoration, and no-hook/host-abort behavior; do not suppress failing conditions. Run the existing native visual suite on main and integration, plus the real mixed-capacity physical fixture. A synthetic status is not a real episode, and the masked-depth direct-winner and materialized paths need separate testing. A complete real reset and policy continuation remain separate if not tested. Resource/overflow, buffer ownership, failed encode and per-command serialization must remain safe. No AL or experimental CCD selector is enabled.

Additional failure gate identified during review: a failed environment cannot safely restore an old "fresh" bit after this observation has overwritten its cached pixels with a newly rendered frame. On any failed physical step that rendered a batch frame, mark that environment's cache invalid until a later capture; if no frame was rendered, restore its previous freshness bit. This is conservative containment and does not restore renderer pixels. Test both cases, including a sampled failed reset followed by an unsampled observation, and verify successful neighbors stay fresh.
