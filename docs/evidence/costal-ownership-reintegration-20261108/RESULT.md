# Split costal ownership: current integration

The existing NHTBIND2 work from the isolated thorax branch is integrated into the combined source and staged for main. The decoder accepts explicit per-node mass donors and independently specified sternal/rib attachment bodies while retaining NHTBIND1 single-body semantics. The compiler and v5 runtime partition cooked node mass by its declared donor, validate the endpoint anchor against the appropriate bound body, and account for articulation body offsets. The no-body-contact adapter uses typed empty Metal arguments while active body interaction retains its BVH requirement. This is opt-in authored ownership infrastructure: a synthetic binding does not create or identify anatomical ribs, establish their relative joints, calibrate cartilage, or qualify clinical mechanics.
