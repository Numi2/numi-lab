# Preregistered single-step selective sensor-state candidate

This isolated research fixture installs the previously tested pre-observation and post-physics hooks. Before observation, it checkpoints actual per-environment actor history/output, object-track history and retained depth/identity/validity/camera frames into private GPU backups. After task completion, a separate test-only Metal kernel uses each environment's GPU world and contact status to restore failed slices and retain successful slices before result publication. Test-only host counters advance by each published success. The candidate applies only to this six-track, 140-value actor, 16 by 9 camera, zero masked-depth task and exactly one control step per submission; every assumption is checked. Normal physics-error termination and automatic reset remain unchanged. The kernel and owner instrumentation exist only in the isolated research copy.

The current renderer still has batch-wide host cadence and random sensor sequence. Therefore this candidate checks host accepted-step counts before each submission and refuses the next step once mixed success makes them diverge. It is a fail-closed bounded experiment, not an independent-cadence implementation, retry solution, general sensor transaction or production fix. A command-encoding or GPU failure must invalidate the session; no command-failure atomicity is claimed. The synthetic visible target and physically real delayed overflow are the same as the preregistered no-hook fixture.

Run instrumented then no-frame-snapshot control, each with a 120-second timeout; retain complete inputs, GPU library hashes, status, actor outputs, per-environment actor-history bits, tracker and frame bits, counters, times and errors. Require visible target on accepted steps 1 and 2, a real mixed capacity failure on step 3, and successful control. Compare failed environment exact tracker, actor-history, depth, identity, validity and camera bits after rejected step against its prior accepted snapshot; compare the successful environment's corresponding values with a same-step control. Actor-output restoration must match its prior accepted value in the failed environment at the output's printed precision. The no-frame-snapshot process is an instrumentation check, not an unmodified-policy control. Retain all mismatches and failure conditions.

Frame comparisons at this 10 Hz cadence exercise a held frame, not a new render on the rejected step; no masked-depth ring exists here. Counts diverge after failure and no further step is attempted. The study cannot qualify resampling, independently advancing frame cadence, reset continuation, exact retry, multi-step command buffers, other sensor types or deployment perception.
