# Quarter-domain P2 reference qualification

The 16 GB host and previously measured 3.2 GiB n16 full-domain memory make an unrestricted finer run unsafe without a resource study. Before attempting any new full-episode refinement, test a quarter-domain reformulation of the existing fixed continuum P2 FEM–plane reference. Reflection symmetry is about the two vertical midplanes; x and y normal displacements/velocities are constrained there, all other mechanical boundaries and the plane law remain the original ones. The physical full body is reconstructed by four reflections. Do not assume that the original tensor tetrahedral mesh is itself reflection symmetric: construct the comparison full mesh by reflecting the exact quarter tetrahedra and merging coincident nodes.

For n=2,4,8 full-equivalent spatial intervals, compare the reconstructed full mesh against the constrained quarter model at the initial free-fall state and a smooth, reflection-symmetric nonuniform P2 contact state. Compare material/contact/gravity potential, total plane force, minimum sampled gap, deformation validity, mass, and the complete three-component mass-solved acceleration field at every quarter P2 node. Require matching contact quadrature order, fourfold area scaling, zero mirror-normal acceleration, absolute/relative tolerances declared in the analysis script, and repeatability. Include an intentionally symmetry-breaking deformation as a negative control, which must not be accepted as representable by the quarter model. A passing algebraic comparison qualifies neither temporal refinement nor the 0.25% force gate, and it does not show equivalence to the original full tensor mesh. Record all failures; make no changes to production Matter, collision or contact algorithms.
