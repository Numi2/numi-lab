# Symmetric P2 contact reference: scoped equivalence and mesh limits

This is a CPU diagnostic on the `ssh numi` Apple M6, not production Matter or an AL experiment. It investigates whether a reflection-symmetric quarter-domain version of the already retained, fixed physical frictionless FEM-plane model can reduce the resource cost of further reference work. The contact law, material, density, gravity, geometry and initial clearance are unchanged. Both experimental production options remain disabled. The previously failed n8/n16 force-reference gate remains failed.

The model is the retained independent P2 neo-Hookean continuum, not an analytical truth. `fem_p2_dynamics.py` is byte-identical to the source retained at commit `1b6689d3efbb2c8637e9210fcd0c6dbdf4df0d95`. `symmetry.py` builds a quarter mesh and *separately assembles* a full mesh of four reflected copies with coincident nodes merged. Reflection-normal displacement and acceleration on the quarter planes are constrained. Extensive quantities are multiplied by four. This construction does not assume that the old tensor mesh is reflection symmetric.

The preregistered static comparison and exact-repeat are in `PLAN.md`, `symmetry-final.json` and `symmetry-final-repeat.json`. For n=2,4,8, free-fall and active-contact states pass the declared energy, force, total mass, minimum sampled gap, Jacobian, and every mapped 3-component acceleration gates. The largest relative acceleration difference is 3.19e-14. Mirror-normal acceleration is exactly zero in the constrained solve. The explicit asymmetric-displacement negative control was rejected at all three mesh sizes. The two earlier attempts (`symmetry.log` and `symmetry-retry.log`) evaluated the comparisons but failed before producing JSON, because a NumPy int32 was not serializable. They are retained as failures; `symmetry-before-serialization-fix.py` captures the initial source. The final script adds scalar serialization and makes the asymmetric-state rejection explicit. Its two JSON outputs match byte for byte.

`DYNAMICS-PLAN.md` preregistered a 4.5--10 ms full-episode comparison on n=4 with the same fixed-law configuration and DOP853 settings on both meshes. The two paths finish with positive sampled gaps and Jacobians. The maximum 1 ms force-bin difference relative to the reflected full-mesh peak is 1.10346e-6, and the final impulse difference is 6.39112e-8 relative. Maximum sampled momentum difference is 1.80e-10 N s and final work difference is 1.77e-12 J. These pass the declared 0.25% force/impulse gates for equivalence between these two discrete systems only. `dynamics-n4.json` retains the full traces; elapsed fields are diagnostic and not performance evidence. The first bin represents 4.5--5 ms divided by 1 ms, matching the earlier 4--5 ms bin because there is no prior contact.

`DYNAMICS-N8-PLAN.md` preregistered the same full-episode test at n=8. The force-bin difference is 3.62707e-7 of the reflected peak, and the final impulse difference is 7.81545e-8 relative. The minimum sampled gap is 9.29442e-5 m and minimum sampled Jacobian is 0.96878 across both paths. `dynamics-n8.json` retains the full traces. This is one dynamic n=8 run, not a repeatability or temporal-refinement qualification.

`compare_tensor.py` compares the reflected-full result with the retained, separately triangulated tensor mesh under the same fixed law. At n=4 the binned-force difference is 4.22864% of reflected-full peak, and final impulse differs by 0.42194% relative to tensor. At n=8 the binned-force difference narrows to 1.87522% of reflected-full peak and final impulse differs by 0.21293% relative to tensor. The binned-force difference still exceeds 0.25%. Both tensor runs have zero sampled force and impulse before the 4.5 ms restart. These are different discretizations, not an equivalence test, and the comparison is not a replacement for temporal or spatial refinement. The tensor data are exact copies of the previous `contact-p2-n4-order18-20261108/coarse.json` and `contact-p2-n8-order18-20261108/coarse.json` artifacts on the retained contact-reference branch. See `tensor-comparison.jsonl` for results when both runs are available.

This establishes only a controlled symmetry construction for these states and episodes. Sampled gap checks do not certify all space and time; the two integration paths have not independently established converged force against an external continuum reference. The older tensor n8/n16 spatial-gate failure is not waived. A finer symmetric comparison would need separate temporal and spatial refinement, law and quadrature checks, resource bounds and comparison against a converged independent reference before use for force qualification.

Reproduction requires Python 3.13, NumPy 2.3.4, SciPy 1.16.3, scikit-fem 11.0.0, and a single BLAS thread. From this directory run:

```
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 python symmetry.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 python dynamics.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 python dynamics-n8.py
python compare_tensor.py
python verify_repeat.py
```
