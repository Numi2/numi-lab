# Reflected mesh dynamic comparison, declared before execution

Advance independently assembled n=4 quarter and exactly reflected full FEM P2 meshes through the same 4.5--10 ms fixed-law contact episode, from the same analytical free-fall displacement and velocity. Use the existing explicit DOP853 reference settings (rtol 1e-8, position atol 1e-12 m, velocity atol 1e-9 m/s, maximum step 16 microseconds), exact same physical material, gravity, normal plane law, quadrature and output times. Constrain only mirror-normal components on the quarter mesh. Compute normal force, impulse, work, minimum quadrature gap, minimum material Jacobian, and total z momentum; scale extensive quarter observables by four. Compare 1 ms impulse-derived binned forces to the full-mesh peak and final impulse relatively. Require both below the pre-existing 0.25% spatial force criterion, positive gap and Jacobian, and success through 10 ms. Also compare force traces, momentum and contact work. This is an equivalence test on a reconstructed symmetric mesh, not a continuum refinement or proof about the original tensor tetrahedralization. Preserve noncompletion and any discrepancies. Run without GPU contention; do not change the experimental runtime laws.
