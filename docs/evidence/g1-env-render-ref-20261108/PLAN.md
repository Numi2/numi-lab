# Preregistered actual-render reference feasibility

This read-only-in-purpose diagnostic creates the retained two-environment visual task with 5 mm depth noise, runs two real accepted nonterminal physics steps, and then ends the rollout. An isolated test-only owner getter retains the actual observation-time projected body buffer. It uses that fixed body buffer and the real `MetalHybridRenderer::encode` path to render the whole batch at frame/sensor 2/1 and then 0/0, followed by independent repeated reference renders for each setting. Original world-instance identities and batch-global pixel indices are preserved. Capture times are frame times multiplied by the 20 ms step.

Require both warmup statuses successful and nonterminal; retained bodies, render command and snapshot must succeed. Require repeated full-frame depth, identity, validity, camera and batch metadata to match bitwise for each setting. In each environment the target must be visible in both settings and at least one common visible target-depth pixel must respond to the different frame/sensor seed. Record complete plane words and metadata, process time, and before/after hashes; run once with 120 seconds and retain all failures. This uses two sequential full-batch renders as separately repeated per-environment-slice references, not single-environment renderer instances or a production mixed-cadence renderer. It will not qualify frame selection, failure rollback, reset, independent metadata publication or live mixed continuation; the owner guard is untouched. If feasibility passes, these frozen-pose references can serve as inputs to a separately registered real renderer sample/hold composition test.
