# Forced failure after joint contact solve

Use the same source, library, initial fixture and revised candidate. Build an otherwise identical research shader that changes the wave island status to solver failure only at control step 10 after the normal joint solve and velocity updates have executed. Compare a clean ten-step run with an eleven-step run that reaches ten accepted steps then the injected failure; require status failure on the last step, no advancement of q/v/full rod-node state on that step, and exact byte equality of final q/v, scene bodies and rod nodes/edges between the two runs. Repeated and capture-free outputs must match within each arm. Save actual complete bytes or collision-resistant hashes plus raw outputs and source identities, not only a success flag. Record whether the joint block was exercised before the injection. This tests only exposed final owners; hidden contact cache, external owners and a live retry require separate evidence. If the failure does not occur after an exercised joint update, or the trajectory differs before injection, do not claim restoration.
