# Preregistered Franka renderer depth-validity and edge reference

This task-independent native fixture derives from the retained Franka pick-place hybrid-renderer probe. It compiles the existing camera-aligned Gaussian scene and two sampled four-environment WorldFamilies: ordinary sensor response and 100% depth-sensor dropout. The actual fast renderer produces 160×120 depth, identity and validity planes. Require normal valid depth and, in the dropout arm, visible geometry without depth-valid pixels. No G1 task is run.

The real renderer's private depth/identity/validity buffers feed the unchanged original and candidate depth-history kernels. Four dispatches per scene compare both kernels at edge-flicker probabilities 0 and 1 with an independently computed CPU reference: depth-valid finite positive samples normalize over 0.1–5 m; no-depth pixels stay far unless edge flicker is enabled and an adjacent depth-valid sample supplies the minimum neighbor depth. Use no other corruption and a 2e-6 absolute output tolerance. Require every candidate value to match, and require a nonzero reference edge-filled region in the ordinary scene. Original mismatch counts are retained, not a pass criterion. With the actual 160×120 image, this exercises the uncached (>256 pixel) plane path, not the direct-winner shortcut.

The output binary consists, for each scene in normal-then-dropout order, of one native bool dropped flag, one uint32 total pixel count, total float32 renderer depths, total uint32 renderer validity flags, then four total-length float32 output planes in order original/candidate for flicker 0 then original/candidate for flicker 1. Retain process outputs, source, hashes, UTC timing, and the compressed binary trace. Run one process within 120 seconds on an exclusive GPU; do not retry failures. The renderer is real but the downstream observation is directly dispatched, not an integrated physics/policy rollout. This cannot qualify direct-winner dropout, different renderer profiles, general camera calibration, actor fingerprints, rejection transactions or physical perception.
