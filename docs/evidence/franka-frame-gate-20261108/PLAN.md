# Preregistered non-G1 owner frame-admission feasibility

This isolated research fixture uses the actual Franka pick-place task owner, zero policy, real visual tracker and physics, with two environments, a 16×9 instance-selected depth program and a camera mounted far above the scene. A research-only getter reports whether the actual tracker selected the direct geometric-winner path; that is a mandatory prerequisite. The existing low-level owner hooks are explicitly installed only for this fixture. No G1 task is run and no production default is changed.

The caller supplies an immutable per-environment capture-status array before a step. A test-only prepare callback accepts the whole batch only if every supplied status is PRESENT; any MISSING or unknown status refuses before native task observation and physics encoding. This conservatively rejects the entire batch and does not attempt per-environment retry or partial publication. The array is explicit fixture input, not inferred from depth, identity or geometry. A production provider would need to own and synchronize it; command completion and physics-acceptance publication remain separate unsolved contracts.

With statuses (PRESENT,PRESENT), require a successful native step and a direct-winner buffer whose low 32-bit triangle indices are invalid for all 288 pixels. This establishes a renderer-produced empty scene while its caller explicitly declared frames present; absence of winners alone is never used to decide frame status. Then submit statuses (MISSING,PRESENT), require refusal in the prepare hook and exact unchanged private depth/track histories, retained frame planes and tracker cadence across refusal. Finally restore (PRESENT,PRESENT) and require one successful continuation. Exact snapshots and winner words are written to the binary evidence when the prerequisites succeed. A failure to build the scene, reach direct mode, obtain empty winners or complete physics is a retained prerequisite failure, not proof of transaction behavior.

Run once in an exclusive GPU slot with a 120-second cap and pinned binary, dylib, shader and visual-pack hashes. This tests only a fixture-supplied host admission boundary. It is not actual capture completion, independent per-environment publication, physical state restoration, policy fingerprint migration, direct-winner missing-frame propagation in production, real camera input or deployment qualification.
