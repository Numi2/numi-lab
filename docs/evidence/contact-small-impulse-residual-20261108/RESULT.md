# Correct normal-residual reporting for small positive impulses

The production temporal-cone status used a fixed `1e-7 N s` cutoff to decide whether a contact impulse was active. A real positive impulse below that cutoff was treated as zero, so a separating normal equation could be reported as zero residual. This is a diagnostic correctness defect: the status did not reliably represent the equation being solved for small-mass contact.

The correction uses the active-row equation for every strictly positive impulse, in the packet, distributed and ordered temporal-contact residual calculations. A zero impulse retains the one-sided inactive-row residual. The correction changes reporting; it does not change the contact update, reject underconverged steps, or establish correct force, friction, CCD, or mixed-island convergence. In particular, high reported residuals in these accepted fixtures remain real unresolved solver failures. The diagnostic is not a complete complementarity certificate for every capped or coupled constraint.

The preregistered native fixture uses the same oblique frictionless box and plane, two orientations, two iteration budgets and three tangential speeds, with masses 1e-7, 1e-6 and 1 kg and consistently scaled inertia. The independent reconstruction uses the captured contact witness, evaluated row and the final body velocity. At 1e-7 kg the baseline produced eight cases with falsely zero reported residual, with the largest independently calculated residual 1.85356 m/s. All 36 exposed records apart from the residual matched between baseline and corrected shader exactly; each case also repeated exactly. After the correction all 36 residuals agree with the independent reconstruction within 5.75e-8 m/s. The baseline and corrected shader shared the same integration library and all other linked AIR inputs. `compare.py`, `analyze.py`, the raw outputs and fingerprints retain the comparison; this only checks exposed fields, not hidden owner state.

A new permanent native CTest independently reconstructs the row residual and requires positive sub-1e-7 N s impulses with nonzero residual to be exercised. It fails on the original metallib (recorded in `regression-before.stderr`) and passes on the corrected shader. A fresh main-checkout build also passes that regression, the existing Wave32 status-reduction test and the existing MetalWorld contact probe. The latter includes overflow and multi-environment checks; its printed timings are not a controlled performance benchmark. Distributed and ordered paths receive the same expression correction, but the new full-step fixture specifically tests the selected production packet path rather than claiming exhaustive coverage of every scheduler.

The first corrected run was invalid: its newly compiled main-checkout probe used main headers with an integration library whose `MetalWorldStepConfig` layout differs. All 36 cases failed before the intended physics run. Those outputs are retained with `wrong-abi-` prefixes. The corrected comparison used the same integration-header probe and integration library on both arms. The separate CMake main build compiles and links the main source, header, library, shader and permanent regression together. `v1-` files retain an initial equivalent three-line shader correction before factoring the common expression into a helper.

Plans, commands, build logs, native status outputs, SHA-256 inputs and analyses are retained. Native binaries and intermediates remain on `ssh numi`; they are not claimed as a self-contained release artifact. Both experimental directional CCD and augmented-Lagrangian options remain disabled. The next task is the documented mixed rod–rigid convergence/acceptance failure and its sustained force and full transaction qualification.
