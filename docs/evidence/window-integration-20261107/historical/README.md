# Historical producer fixtures

`main/` was written by a generator built on 7 November 2026 from the
`LearningPacks.cpp` and recursively included `include/metalrobo` headers at
main commit `304fd4be5013effeb997813139c24fce811cd988`. Its task header is
version 17; its actuator header is version 2 and carries main's Millard tag 7.

`numisolver/` was written by the same generator built from the corresponding
files at numisolver commit `698dd34fb77ba93d4a82a826e548fbd28b735371`.
Its task header is version 19 and its actuator header is version 2 with the
unambiguous body-wrench tag 6. The historical numisolver writer explicitly
rejected an attempted measured-surface tag 7: its artifact validator capped
the accepted kinds at body wrench. That rejected call is retained in
`numisolver-generation.txt`; no rejected pack was published.

Each executable was built separately with Apple Clang using:

```sh
clang++ -std=c++23 -ffunction-sections -fdata-sections -Wl,-dead_strip \
  [-DNUMISOLVER_LINEAGE] -I <historical-include> generate.cpp \
  <historical-source>/src/core/LearningPacks.cpp -o <generator>
```

The sources were obtained with `git show <commit>:<path>`; no GPU or runtime
world was initialized by the generators. `SHA256.txt` pins generators, primary
source files, generator source, and resulting packs. The main tag 7 requires
explicit provenance when read by the integrated branch. Numisolver's attempted
tag-7 case remains a synthetic compatibility test because its writer did not
emit that artifact.

These are minimal controlled producer fixtures. They do not cover the full
variety of historical user packs, policy-to-task identity, trained policies,
or saved simulation state.

The separately retained native-policy-v5.pack was generated by
generate-policy.cpp against this integration branch's LearningPacks writer
and read back by that native reader. It contains nonempty actor tensors and a
version-2 two-task contract. The window metadata test reads it in addition to
synthetic malformed inputs. It is a controlled fixture, not a trained policy
or evidence of an end-to-end training run.
