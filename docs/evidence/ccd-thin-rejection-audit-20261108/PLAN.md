# Retained thin-impact event diagnosis

Before analysis, use the retained full-step observation and its compressed native event trace from the published CCD acceptance evidence. Select the legacy search selector at caps 16 and 128, both scales, and the two thin impacts, together with matching thicker impacts as controls. For every rejected thin run identify the first event pass reporting unresolved, the immediately preceding successfully resolved boundary, accepted q/v restoration, prior accumulated physical time, remaining time, contact count and normal impulse. Reconstruct in FP64 the support gap and normal velocity of each recorded contact point from the captured candidate pose and velocity. Report these values without assuming the exact unrecorded stopping condition. Compare independent repeated event sequences and preserve mismatches; the trace belongs to rejected trial paths, not published trajectories. A negative post-response point velocity is a diagnostic, not alone proof that the contact solver failed its own target. No budget, source or acceptance rule changes are authorized by this audit.
