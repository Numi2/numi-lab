# Tracker batch timeline across submissions

A tracker observation previously used the local control-step slot as the renderer frame identity and capture timestamp, while its camera cadence used a tracker-owned sequence that continues across submissions. Thus splitting a rollout could restart frame labels and alter any sensor response keyed to frame identity. The unchanged runtime fails the new native regression: after a rejected encode, the second observation reports sensor sequence 1 but frame 0 and time 0. The failure is retained in `baseline-ctest.log`.

The renderer now receives the tracker observation sequence for frame identity and its product with the configured control period for capture time. Buffer indexing and physical-step checks still use the submission-local control slot. The existing host-abort test now also checks frame identity and time; all 22 visual CTests pass on the Apple M6. The tested source patch and binary hashes are retained.

Two additional native comparisons were run before the final regression-only edit. In the direct tracker fixture, identical inputs with second local slot zero versus one produced identical saved metadata, tracker observations, depth and validity. In the two-environment zero-action Franka world, a two-step submission and two one-step resident submissions both had zero physical failures. Final q, v, scene bodies, all actor observations, final rendered depth, validity and frame metadata match byte for byte. World status records differ only in `controlStep`: 0/1 for one submission, 0/0 for split submissions. `verify.py` checks the retained arrays and that distinction. The instrumented probe sources are saved; their temporary executables were overwritten by the final regression build, so no hash for those executables is claimed. The single-slot direct comparison is not itself a physical rollout; the world comparison is a real bounded native physical rollout, not training.

This repairs the **batch scheduled-observation timeline**. It is not an accepted-time clock per environment: a rejected physical step can still advance the batch clock, renderer buffers and output publication remain incompletely transactional, and the fixtures use oracle instance identities. Timing, latency, deployed perception and learned policy quality are not qualified. Experimental directional CCD and augmented-Lagrangian contact remain disabled. No performance measurement was made.

The initial script to add the assertion aborted before writing because its second source match failed; the subsequent test edit and unchanged-runtime failing result are retained. An initial temporary comparison probe was replaced with the tested permanent source before the final CTest build.
