# Masked-depth feedback through actual MetalWorld resets

The preregistered test passes for a deterministic stateless visual-feedback controller at integrated source `341d21574f379a06d85d9e9fc30406d96faab15b` (main tracker code `2203970e6`). The GPU action program reads the correctly located current masked-depth plane from the Franka actor observation, reduces mean nearness, and writes 0.01 times that signal to action index 0; its other eight action components are zero. A blit independently captures the actual action buffer after the compute dispatch. This program is a diagnostic controller, not a trained, recurrent or deployed policy. Instance selection uses oracle renderer identity, not learned perception.

The real two-environment MetalWorld fixture runs 30 steps at 20 ms with four substeps, a 10 Hz camera and intentionally insufficient contact capacity. The compiled task has 34 proprioceptive/track values with three temporal slots and a 38,424-value masked-depth suffix (two 160 by 120 frames and 24 features). Tracker binding uses track offset 27 and visual offset 102. The sensor has 35% dropout and the depth path retains its authored pixel corruption. The test captures the actual callback inputs, independently captured action output, GPU reset masks, tracker history at three callback boundaries, q/v, scene and statuses.

| 28 | 0 and 1 | Both environments cleared before their actions. | Both accepted. |

The run contains 55 accepted and five rejected environment-steps; the capacity failures are intentional. Published failure status is preserved, not treated as simulation success. Earlier visible signals and the step 15 fresh capture are positive controls. The last nonsampled step also remains masked. Each of the 60 independently captured action vectors matches the trace, with only index 0 potentially nonzero. A separate CPU double-precision reduction of every captured depth plane differs from the GPU float reduction by at most `2.051e-8`; the prescribed action relation is verified. The two final complete runs match byte for byte in q, v, scene, status, reset masks, actor history, all policy inputs, actor output, action traces and captured action buffers. Adding the independent action-buffer copy did not change the preceding two runs' corresponding outputs.

This qualifies the defined reset/feedback observation contract for this fixture only. It does not qualify episode replay, recurrent-policy state, successful manipulation, calibrated sensing, force accuracy, per-environment sensor clocks, renderer pixel rollback, failed-step actor-output rollback or GPU-command failure recovery. The full nonzero sensor signal does not imply a correct physical estimate. Performance was not measured. The experimental CCD and augmented-Lagrangian options remain disabled.

## Reproduction and provenance

[PLAN.md](PLAN.md) predates the runs. [probe.cpp](probe.cpp) derives from the earlier retained [actual-reset fixture](../tracker-reset-frame-20261108/world_probe.cpp); [make_probe.py](make_probe.py) and [action_capture.py](action_capture.py) document the exact changes. The first two runs preceded the independent action-buffer copy; runs 3 and 4 include it. All four logs are retained alongside the raw outputs in `captures.tar.gz`. Extract it next to [verify.py](verify.py), then run `python3 verify.py`; [verification.log](verification.log) is the native result. Results were produced on `ssh numi`, Apple M6. The same sensor-selected geometry and initial conditions are used throughout; the changed control path is not compared for physical equality to the earlier zero-action fixture.

A further source inspection found that `MetalHyperPolicyRuntime` updates phase and previous-action buffers during action encoding and `MetalWorldDeviceActionProgram` has no physical-step acceptance callback. This is a risk requiring an actual failure/retry experiment; this stateless test neither demonstrates nor repairs recurrent-state rollback. Capacity allocation and initialization on aborted submissions also need independent verification. Preserve the existing experimental boundaries while investigating.
