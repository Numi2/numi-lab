# Thin-impact evaluated-row capture

Before implementation and execution: extend the existing opt-in, read-only single-floating-body CCD event trace to capture bounded IR normal rows, evaluated normal rows, point Jacobians, and contact status residuals in the same command-buffer snapshot as candidate q/v, impulses and contact points. The normal production path and all acceptance decisions must be unchanged. Check buffer sizes before copying. Add no GPU writes except trace blits. Retain original source, shader, executable and modified-source hashes and the compiled result.

Use the existing physical probe, with legacy selector, cap16, 250 and 177 rad/s thin impacts at scales 1 and 0.5, plus corresponding thicker impacts and thin near-miss controls. Do not raise budgets. For each completed pre-rejection event, reconstruct in FP64 Jv from the captured articulation endpoint Jacobian and candidate velocity, compare against geometric point velocity with body orientation, and report evaluated target, regularization, recorded normal impulse, inequality residual and status-reported residual. Confirm the row belongs to the same contact and selected configuration; if the buffers are stale, mismatched, or candidate velocity belongs to another stage, label the capture inconclusive. Retain byte-identical replay and exact rejected-state restoration, and require identical outputs with trace off and on. This is diagnostic; no solver-law or search change is authorized. Record any build, instrumentation, matching or calibration failures. The independent P2 CPU reference runs concurrently, so timings are not performance results.
