# CCD event solver-row diagnosis

This native, preregistered, opt-in read-only capture adds evaluated normal rows, contact Jacobians and reported residuals to the existing event trace. The actual shader is unchanged. For the single floating box against a static plane in hybrid CCD at production search cap 16, independent FP64 evaluation of each captured row using the captured Jacobian and candidate velocity agrees with the solver-reported maximum normal residual within 2e-5 m/s. Independent point-velocity calculations agree with the Jacobian to the same tolerance. All twelve selected cases reproduce their previously retained outcomes; trace-on and trace-off final q/v and reported physical outcomes agree, and independent repeats and rejected q/v restoration pass.

At scale 1, the 250 rad/s thin fixture has a reported residual of 1.8151 m/s at the last successful event before the unresolved-cast rejection; the 177 rad/s fixture has 1.0907 m/s before event-budget rejection. At scale 0.5 the corresponding residuals are 0.9075 and 0.4955 m/s. The impulse is nonzero and evaluated regularization is zero in these captured rows. This verifies incomplete normal-equation satisfaction at those event boundaries; it does not identify the cause of the solver behavior or prove that a particular correction will resolve the full step.

The thicker impact controls ultimately complete but also show substantial intermediate-event normal residuals. At scale 1 their reported maxima at the first event are 4.3056 and 2.6991 m/s. The earlier independently checked clearance of accepted trajectories remains valid within its stated scope, but those tests do not establish accurate normal contact response. The thin near-miss controls complete without impulse. No force accuracy, general collision or performance claim follows.

The full 288-case acceptance regression was repeated with the augmented trace. Its existing acceptance and restoration assertions pass, while the separate all-impact-completion gate remains **false**. `full-regression-world-steps.json`, `full-regression-analysis.json`, and the compressed trace retain that outcome. This was not a new performance measurement.

The first version of the selected probe retained aggregate outcomes but did not print full final q/v for cross-run comparison. Its inputs and outputs are retained with `-v1` suffixes; the original v1 executable was overwritten during the improved rebuild, so its binary hash cannot now be independently rechecked. The second version records final q/v and supplies the reported trace-on/off comparison. Binary, source, shader and fixture hashes for that version are in `inputs.sha256`; the preceding runtime library was separately saved and hashed in `before.sha256`. The P2 CPU reference ran concurrently. No experimental contact or advancement method was promoted.

From this directory, run `python3 analyze.py ../ccd-acceptance-resolution-20261107/retained-evidence.tar.gz` to reproduce `analysis.json`; decompress `on.stderr.gz` to `on.stderr` first. The next change needs to explain and repair this normal-response error without sacrificing friction, frame consistency, useful impacts, force-free near-misses or transactional restoration. The residuals here are a failure to investigate, not permission to relax a threshold or simply increase a fixed iteration budget.
