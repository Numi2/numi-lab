# Exact-model comparison workspace

A shared experiment card now retains one objective and intervention set across
registered model versions and supported conditions. `numi wet-lab context`
returns model/specimen/population/condition identities; `propose` and `edit` accept
`--models` and `--conditions`. All edits use the same revision token as the canvas.
Unknown models cannot fall back to v0.3. Unsupported conditions and objective
features retain an editable blocked card with explicit corrections. Each
executable axis binds assay/runtime/weights, specimen identity, population,
condition and objective coverage. Replacing a model artifact after proposal is
rejected before execution.

Execution creates ordinary NumiVivo records through the existing owners. All axes
are sealed before a separate authorized reveal. Native replay, cancellation,
stopped-operation recovery, immutable seals and draft revisions remain the same
lifecycle. Switching a comparison axis retains candidate, gene and camera and
uses shared scales over its retained model readouts. Preview, sealed prediction
and revealed observation are distinct; there is no animated biological trajectory.

The spatial source currently admits **one measured endpoint condition**. Cellular
Tm/Thaps/DMSO conditions cannot be relabeled as tissue inputs. Receiving-population
preservation remains blocked by unresolved sections and controls. The corrected
spatial model is an exposed-development candidate, not biological promotion.
Safari remains blocked pending an authorized local WebDriver configuration.

Local contract checks: 11 shared-state/compatibility tests; JavaScript syntax.
End-to-end qualification and model results are recorded separately after execution.
