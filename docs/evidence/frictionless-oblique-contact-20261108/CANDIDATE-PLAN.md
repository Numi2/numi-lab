# Frictionless block correction: isolated candidate

The preregistered production-path diagnostic found the clear box with -1 m/s tangential velocity gained 0.33209279 m/s normal speed and -4.56603479 rad/s spin despite zero friction and no closing motion; the mirror direction and stationary control did not. Two contacts were generated and all cases returned success. This is a measured result from the source 070f42617 runtime, not an inference from the solver formula.

Hypothesis: the normal component of an unconstrained 3-by-3 update includes tangent RHS terms; subsequent zero-friction projection removes the tangent response without recomputing the normal response. For exactly zero friction in both axes, the admissible block has only a normal impulse. In an isolated shader, zero normal/tangent cross terms in each local effective matrix before the existing inversion, covering Wave32 packet, distributed Wave32 and ordered rigid paths. Keep the existing normal regularization, complementarity projection and relaxation, and do not modify either experimental CCD/contact option. No production code is changed in this first check.

Run the exact registered four-arm diagnostic against baseline and candidate with identical library, model, velocities and shader dependencies. Expected: stationary and both sliding arms remain motionless normal to the plane with unchanged spin, within 1e-6, while the closing control has nonzero normal response and every run is repeatable. This diagnoses a discrete contact constraint; the contact envelope is not evidence of impact. Retain both results and do not call the closing contact force accurate without a separate residual/impulse reference. If the test passes, use unused orientations, moving inputs, articulated/rigid and rod contacts, finite-friction controls, independent normal complementarity, rollback and existing regression suites before considering production. The correction has no claimed improvement for nonzero friction, general impact completion or convergence.
