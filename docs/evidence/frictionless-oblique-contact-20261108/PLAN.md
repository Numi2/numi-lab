# Oblique frictionless contact: normal/tangent coupling diagnostic

Question: can a purely tangential velocity drive a normal impulse in the current MetalWorld contact path when friction is exactly zero? The existing 3-by-3 unconstrained local solve followed by a friction-cone projection makes this plausible but source inspection alone does not prove a runtime defect.

Before executing, use main-equivalent integrated runtime at source 070f42617, a single 1 kg free floating rigid box against a static plane, no gravity, no damping, no CCD and zero material friction/restitution. The box is tilted about z so its corner has an oblique lever arm; place it just inside the collision envelope while geometrically clear of the plane. Hold geometry, timestep, contact parameters and solver settings fixed. Use +x and -x tangential velocities with zero normal/angular velocity, plus stationary and closing controls. Independently, a clear rigid box with zero normal velocity and angular velocity remains clear under pure translation parallel to a plane; it should receive no normal impulse or rotation. The closing control should show nonzero normal response. Check contact was actually generated, report geometric gap, initial and final q/v, contact status and normal impulse; repeat each arm for determinism. If no contact appears, the fixture cannot test the hypothesis; record failure rather than infer correctness. Zero friction eliminates tangential impulse but does not by itself establish correct normal response. Keep both experimental CCD and augmented-Lagrangian options disabled. This is a correctness diagnostic, not performance or full CCD qualification.
