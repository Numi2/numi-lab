# Independent free-end 3D qualification plan

Predeclare a separate nine-case, single-step numerical check before generating or running it. Use n=3, 5 and 8 nodes, each at h=0.0005, 0.001 and 0.002 s, seeds 92101 through 92109 in that order. Use the same homogeneous native-energy rod as the retained supported 3D qualification (length 0.11758755785232791 m, radius 2e-5 m, EA 2.3818718058345718 N, density 1100 kg/m³, Poisson ratio 0.35). Give each node an independent Cartesian initial-position perturbation of amplitude 0.002 times rest edge length and an initial velocity sampled uniformly from [-0.004, 0.004] m/s per component; each twist is uniform in [-0.02, 0.02] rad and each twist rate uniform in [-0.01, 0.01] rad/s. Use NumPy default_rng, in the stated order; gravity is (0,-9.81,0) m/s². No attachment, damping or contact. Record exact generated inputs.

Independently solve the same full free-position and twist backward-Euler equations in FP64. Evaluate rod forces through the existing native FP64 energy/gradient implementation; form a central finite-difference tangent and independently solve the Newton equation. Record failure rather than inventing a reference if this solve does not converge and certify its tangent. Compare with the Metal research API. A case passes only if both complete and position error <=1e-6 m, velocity error <=0.001 m/s, twist error <=1e-4 rad, twist-rate error <=0.001 rad/s, each native recomputed local linear residual <=0.001 m/s, each native angular residual <=0.001 rad/s, and total linear momentum balance <=1e-12 kg m/s. The residual differences obtained from the native gradient's two finite-difference scales must be <=0.0001 in the same units. Deliberately perturb one output velocity by 0.002 m/s and require the local residual check to fail. Use float-represented timestep and gravity in the FP64 equations because these are the actual runtime inputs. Run twice, preserve exact inputs, outputs, reference results, source and binary hashes, and errors.

These are still numerical checks of a homogeneous research rod, not MetalWorld integration, friction, contact, checkpointing, a physical calibration or a guarantee of convergence on other states.
