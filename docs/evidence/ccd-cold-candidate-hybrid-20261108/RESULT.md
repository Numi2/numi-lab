# Retained four-contact candidate on hybrid CCD

The previously retained four-contact research shader was tested without modification on the same 12 selected hybrid box-plane cases and production cap 16 used in the event-row diagnosis. It completes the 177 rad/s thin impact at both scales, where main rejects, but still rejects the 250 rad/s thin impact at both scales with unresolved CCD. The candidate passes the force-free near-miss checks; all ten accepted candidate trajectories pass the existing scoped FP64 segment-geometry observer. The selected trace-on and trace-off final q/v and reported outcomes match; repeated final q/v and rejected q/v restoration pass. These facts do not qualify full state restoration or force accuracy.

The candidate fails the preregistered normal-residual gate: its scale-1 thicker 250 rad/s impact has a 0.4411 m/s residual at its first successful event, confirmed by independently multiplying the captured Jacobian and velocity. Its first successful 250 rad/s thin-impact event has a near-zero normal residual but the following cast still rejects. Thus the current retained failures are not explained by one numerical issue: resolving normal rows can improve a case without guaranteeing certified progress on the remainder. This is a scoped diagnostic, not a successful solver promotion. The shader also retains the previously reported mixed rod-rigid residual failure.

The first two geometry-observer launches failed because the default and system Python environments lacked NumPy; both failures are retained. The same observer then ran successfully in the already existing reference environment, whose Python and NumPy versions are in `observer-environment.txt`. No thresholds or trajectories were changed. `analysis.json` checks the preregistered gates and raw rows; `geometry-v3.json` retains the separate trajectory result. No timings are interpretable as performance because the P2 CPU reference was running concurrently.

To reproduce the row analysis, decompress `on.stderr.gz` to `on.stderr`, then run `python3 analyze.py ../ccd-event-row-diagnostic-20261108`. The main baseline's `on.json` is retained in that neighboring evidence directory. The candidate shader, probe, runtime and geometry-observer hashes are in `inputs.sha256`. Neither experimental advancement option nor augmented-Lagrangian contact was enabled.
