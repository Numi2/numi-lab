# Preregistered fresh-frame and device-cadence diagnostic

This separate single-step research fixture changes the nominal sensor rate from 10 Hz to 50 Hz while retaining the same physical scene, bound policy, restored actor/track/frame buffers and normal physics-error reset contract. Thus the renderer is requested to sample a fresh frame on every 20 ms step. The isolated candidate additionally stores per-environment accepted-step count and last accepted sensor sequence in a GPU-visible buffer, updated by a status-gated Metal kernel; it checks the counts are equal before each next step and otherwise refuses encoding. The current renderer still uses its original batch-wide host sequence, not these per-environment device clocks; this is clock accounting and fail-closed quarantine, not independent-cadence rendering.

Run three processes in order: no-candidate no-op-hook baseline, candidate with frame snapshots, candidate without frame snapshots, each with 120-second limit. Retain exact output, frame/track and actor-history bits, per-environment device clocks, timestamps and identities. Require visible target, two accepted steps, a real mixed contact overflow on step 3, and successful control. The baseline must demonstrate a newly rendered step-3 frame different from the step-2 frame in failed environment 0; otherwise fresh-frame restoration is inconclusive. If so, require that candidate's failed-environment step-3 retained frame, tracker and actor-history bits exactly match its accepted step-2 state while successful environment 1 matches the baseline/control step-3 bits. Device clocks must be (2,1) in rejected environment and (3,2) in successful environment. Compare candidate runs at printed actor/status precision. Preserve every mismatch and failure.

The candidate stops immediately after failure and does not test a continuation attempt, automatic-reset completion, exact retry, independently sampled mixed-cadence rendering, masked-depth history, multi-step command buffers or command failure. Production behavior is unchanged; this synthetic oracle-instance scene does not qualify deployment perception.
