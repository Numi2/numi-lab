# Fixed-area contact reference reintegration

An isolated branch based on integration revision `55769faca` carries the previously retained default-off reference-area FEM–plane implementation from `cac0c53c2`. The augmented-Lagrangian and directional CCD experiments remain disabled. This branch is research infrastructure, not a promoted contact law or native midpoint implementation.

On Apple M6 via `ssh numi`, the rebuilt branch passed three existing native checks: planar reference areas, physical residual policy, and residual/rollback regression. Its 2-division fixed-area 10 ms control at 62.5 microseconds completed 160/160 steps. The retained original and new traces match exactly in all exposed fields after excluding only wall and GPU timing. Their source/world and runtime fingerprints, every 1 ms force bin, total normal impulse, minimum gap, local residual and momentum diagnostics match; identity mismatch rejection, forced rollback, and restore/replay checks passed. These checks concern the instrument's captured state, not all runtime owners. The new binary and shader hashes are in `inputs.sha256`; the original source and native identities remain in the earlier [reference evidence](https://github.com/Numi2/numi-lab/tree/815030b9e/docs/evidence/contact-area-reference-20261107).

The original 0.25% temporal force gate remains **failed** for the native backward-Euler law. Matching that result is baseline reproduction, not force qualification. The area law is restricted to an immutable coplanar FEM patch and one static, frictionless plane; it uses lumped reference areas, not a general surface quadrature. Its default is off. Independent spatial convergence, physical calibration and production contact behavior remain unproven.

The branch also imports the previously independently authored FP64 fixed-mesh reference, midpoint discrete-functional test and copied transaction contract from `815030b9e`. Four CPU tests pass. The reference midpoint at 15.625 microseconds differs from the refined fixed-mesh RK4 reference by 0.08549% in 1 ms force bins and 0.010997% in total impulse, below the 0.25% comparison gate. These are CPU results on one fixed mesh, not native Matter results or a spatially converged physical reference.

All plans and input identities are retained. `compare.py` checks the recorded native traces without external files; native output and both CTest logs accompany this report. Build and native timing are not performance evidence.
