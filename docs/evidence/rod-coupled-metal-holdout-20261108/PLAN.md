# Unused coupled-rod Metal states

Test the unchanged compensated-force Metal candidate from `rod-coupled-metal-force-20261108` against twelve previously unused states, generated by the retained FP64 `make_case` with seeds 2101–2112 and node counts cycling 3, 5, 8, 9. The generator fixes the same material, 1 ms step, initial-geometry formula, initial velocity and twist distribution, hard endpoint schedule, and alternating world offsets 0 and 0.5 m. These seeds are new to this candidate; all cases are synthetic and use the same family and generating code as the exposed set.

Before running the candidate, solve each case using the retained FP64 coupled reference and independently evaluate the reference state with the compiled native DER energy gradients at both retained difference scales. Every reference must converge, be finite, meet local linear and angular momentum <=0.0001 m/s and rad/s, have gradient-scale disagreement <=0.0001 in those units, and have support reaction error <=max(1e-6 N, 1% of native reference). Fail the reference stage and retain evidence if any case fails; never drop or replace a case. Save input, reference, native inputs and output before executing Metal.

Predict the unchanged candidate accepts and passes all twelve using the original physical gates: 1e-6 m position, 0.001 m/s velocity, 0.0001 rad twist, 0.001 rad/s twist rate, per-support force max(1e-6 N,1%), independent native-energy local linear and angular momentum <=0.001 m/s or rad/s and gradient-scale agreement <=0.0001. Check that deliberate 0.002 perturbations to one free-node velocity and one edge twist rate fail the respective local gates on each accepted passing state. Run the complete fixed matrix twice and require identical per-case results. A rejection, invalid result or missing result fails the candidate prediction; no substitutions, changes to tolerances, or retries after results.

This is one-step validation of a limited straight-rest isotropic, frictionless and contact-free model, not a persistent MetalWorld transaction, longitudinal qualification, biological calibration, generalized rod solver, production repair or performance benchmark. The candidate and both experimental CCD/AL options remain outside production. Source, inputs, binary, gradients, references, results and failures are retained with hashes.
