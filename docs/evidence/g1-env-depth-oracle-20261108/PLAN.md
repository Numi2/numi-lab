# Preregistered mixed sample/hold depth-helper reference

This standalone test compiles the actual renderer's `frameSeed` and `measureDepth` helpers into a research-only selection kernel. It supplies 16 pixels for each of two logical environments, retaining distinct instance identities and original global pixel indices. Environment 0 samples frame/sensor 0/0 at fixed 0.45 m; environment 1 holds a prior 0.5 m frame produced with frame/sensor 2/1 while its proposed current geometry changes to 0.7 m. The authored depth-noise sigma is 5 mm and output quantization is 1 mm. These are synthetic helper inputs, not sampled live geometry or sensor calibration.

First generate the prior valid frame, then calculate both sample/hold records together. Compare all 32 words exactly with two separate 16-pixel reference dispatches with the same original per-record identities, indices and inputs. Require all held words to equal the previous frame. As sensitivity controls, changing env 0's frame seed must change at least one fresh pixel and forcing env 1 to sample the altered geometry must change at least one held pixel. Run once with a 120-second timeout and verify every frozen hash before and after; retain failures. This qualifies only the actual seed and depth-measurement helpers under a synthetic research selection kernel, not production renderer per-environment cadence, independent rendered scenes, failure restoration, resets or mixed continuation. The outer divergence guard remains.
