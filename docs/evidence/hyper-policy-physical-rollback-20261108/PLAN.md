Before execution, run an actual compiled deterministic HyperPolicy and a two-environment Franka resident with the previously qualified mixed-contact-capacity failure setup, intentionally limited to one raw-contact slot, 30 control steps, 20 ms, four substeps, and CCD disabled. Keep actor action modest, use an advancing phase and action-rate limiter, and capture phase state and previous physical actions immediately before policy encoding and immediately after each physical step. The capture is a read-only diagnostic accessor in a scratch-built runtime; it must not change the production source or physics. Record the actual reset mask at each step and per-environment world/contact statuses and task terminations. Repeat independently and retain all failures.

The decisive condition is a committed rejected environment-step with reset mask zero, preceded by an observed state. Its post-physics phase and previous action must equal its own pre-policy values, while accepted neighbors must retain their candidate state. An automatic reset on the next step is not evidence that the rejected step was transactional. Compare all ordinary output arrays and statuses against a non-instrumented run with the same policy, task, input and runtime base; disclose any mismatch. This does not establish recurrent learning quality, calibrated sensing, performance, GPU-command-error recovery, or a matched no-reset retry. If the actual control trajectory does not produce the intended mixed result, preserve it and do not claim the test passed.
