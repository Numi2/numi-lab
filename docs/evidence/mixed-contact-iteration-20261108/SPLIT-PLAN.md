# Isolated projected-row correctness candidate

The per-row trace identifies a frictional rod row with positive normal impulse and a positive separating normal equation. Its complementarity residual persists at 64 fixed sweeps. Test, only in an isolated Wave32 shader, a scalar normal correction plus an isotropic tangent gradient and cone projection for uncapped, isotropic friction. The tangent step uses an absolute row-sum bound of its regularized local block; the existing island relaxation and impulse application remain unchanged. Other cones retain the existing update. This is a numerical hypothesis, not a production fix or a claim that rod and rigid contact are physically qualified.

Run exactly the existing 42 zero-gravity mixed cases and compare all status, impulses, velocities, normal residuals, momentum and deterministic repeats. First determine whether 64-sweep normal residual improves below 0.002 m/s for all cases and whether all two-sweep failures are corrected; retain regressions. A meaningful Coulomb and physical qualification requires separate independent sliding-direction, work, active-contact, rod-state and multi-step tests. Passing this narrow normal gate would not authorize deployment. Do not alter iteration caps, rollback, acceptance, CCD or either disabled experiment. Do not benchmark speed.
