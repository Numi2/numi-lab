# Limited-family initial upload abort gate

This independently registered candidate narrows the initial-empty-cache guard to configurations without valid Millard, multicopter or device-physics programs, keeping those unqualified program families on their existing path. Source base, owner archive, compiled exact-task zero policy and real pre-submit observation callback follow the retained private result in initial-upload-policy-main-20261108. Source and every executable/owner/shader input are pinned. It intentionally does not rerun the shared fixture: unchanged baseline and candidate controls both failed before callback in that mode, and shared remains unqualified.

Run independent baseline private control/retry then candidate private control/retry, each bounded to 120 seconds. Require validated control success, actual callback rejection in each retry, candidate retry physical success, and exact q/v/scene/actor bytes against both its independent control and baseline control. Preserve baseline retry failure or any unexpected result. Stop on a failed candidate/control prerequisite. Separately register the existing full-step CCD acceptance and kinematic rollback scripts against freshly linked candidate-owner probes and identical pinned shader. Their outcomes will check unrelated owner behavior, not visual, actuator, force or performance accuracy. Record all failures and hash-check inputs after each run.

This is a single initial empty-cache fixture; nonempty bindings, shared mode, device-physics, Millard, multicopter, post-commit command failure, mixed sensor histories and performance are not covered. It remains unpromoted until results and changes are independently reviewed.
