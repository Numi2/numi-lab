# Reset amendment after the first suite run

The first candidate restored the entire pre-tracker row on all failures. The existing reset-frame test correctly rejected that policy: when the row buffer is reused and a reset accompanies failure, the saved visual fields may belong to the previous episode. Preserve the failed pre-reset attempt and the failed suite output. Revise the contract: after a failed reset, restore the pre-tracker nonvisual values but write invisible/zero track history, far/no-return masked depth and zero depth features; after a failed non-reset retain the pre-tracker row. Accepted output remains unchanged. Use the actual reset mask and the same declared binding and depth layouts as the tracker. Test the mixed-status shader with both reset and non-reset failures, offset and canaries; rerun the existing reset and non-reset tracker fixtures. This amendment precedes executing the revised shader and does not claim complete generic task or renderer rollback.
