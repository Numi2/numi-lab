# Mixed-island friction screening, declared before execution

The retained normal-complementarity screen did not test sliding direction. Before any runtime change, compare the unpromoted split-step research shader with a trace-only variant of exactly that shader. Trace each contact's final normal and tangent relative surface velocity in the already completed residual loop; export it through diagnostic contact fields. Confirm that removing only the trace fields yields byte-for-byte identical exposed results to the uninstrumented shader for each configuration. The diagnostic runs a one-step, zero-gravity mixed rod/sphere/plane fixture with the retained initial overlap, 1 ms timestep and no CCD. Sweep iteration counts 2 and 64, friction 0 and 0.5, incoming normal velocities -1, 0 and 1 m/s, and five initial sphere tangential velocities (+x, -x, +z, -z and zero; magnitude 1 m/s). The rod starts at rest. Run each fixture twice within the probe and retain all outcomes, including noncompletion and failed checks.

For every active row require finite values, nonnegative normal impulse, membership of the isotropic Coulomb cone, and, for frictionless rows, zero tangential impulse. For friction 0.5, evaluate tangential impulse dot final relative tangential velocity (m/s times N s = J): positive values exceeding 1e-6 J fail the dissipation-sign screen. If both the tangential impulse and final slip exceed 1e-5 in their respective units, also report angular alignment with negative slip and cone saturation; require alignment error below 0.01 rad and relative cone-bound error below 0.01 for rows with final slip over 1e-3 m/s at 64 iterations. A regularized solve may have a small nonzero sticking velocity, so these thresholds are diagnostic assumptions, not a proof. Report normal residual gate 0.002 m/s separately; never waive a failure because another check passes. Require repeatability and exposed total linear-momentum error under 2e-5 N s. Inspect the sphere-plane relative surface velocity independently from body velocity and angular velocity for that row; never infer a rod velocity independently from the instrument itself. Retain baseline and traced output, exact input hashes, compiler commands and any errors. The test does not claim full work/energy consistency, realistic contact forces, spatial or temporal convergence, full rollback, multi-step stability, successful surgical work or performance. No candidate is promoted based only on this screen.
