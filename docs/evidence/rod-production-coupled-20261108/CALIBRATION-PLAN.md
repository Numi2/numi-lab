# Separate unloaded instrument calibration

The exposed production matrix has no passing physical case, so its 0.002 m/s velocity perturbation cannot establish detection relative to a passing baseline. Add a separate three-node straight, exactly rest-length, zero-velocity, fixed-end, zero-gravity control at 24 iterations. Keep the existing material, native energy instrument, 1 ms step, and 0.001 m/s local momentum gate. Require the unmodified accepted state to pass and an otherwise identical check with the free middle-node velocity increased by 0.002 m/s to fail. Record both residuals and all actual state/force values, independently repeat the native run, and retain any failure. This is a calibration control added after seeing the production results, not an untouched test and not a production-solver repair.
