# Production Metal rod versus coupled reference

Question: does the published standalone Metal rod step satisfy the coupled straight-rest stretch/bend/twist reference, including reaction and local momentum, or does the existing net-sweep stopping criterion admit inaccurate states? This is an exploratory follow-up using the 12 already exposed cases in rod-coupled-bend-20261108/solve-cases.json and its retained reference, not a held-out qualification or benchmark.

Run each case independently at both the production default of 24 iterations and the diagnostic limit of 128, with the same 1 ms step, hard endpoint targets, material, initial position, velocity, twist, twist rate, zero gravity and zero damping. Capture native host and GPU status, publication, complete output states and reactions. Rejected cases remain failures of useful completion; never interpret their output as an accepted state. Validate the control instrument with finite values, exact case counts, native energy evaluator exit, and a deliberately perturbed velocity negative control.

For every accepted state, compare position <=1e-6 m, velocity <=0.001 m/s, twist <=0.0001 rad, twist rate <=0.001 rad/s and each attachment force <=max(1e-6 N, 1% of reference magnitude). Independently apply two-scale finite differences of the native energy to the published state and check each free-node linear and edge angular momentum residual <=0.001 m/s or rad/s, with gradient-scale agreement <=0.0001 in the same units. Report completion and all errors independently; no tolerance or case retuning. Repeated independent invocation must agree byte-for-byte for all results. A negative control that changes a free-node velocity by 0.002 m/s must fail the local-momentum gate.

Record the executable, owner library, Metal library, source, inputs, platform, commands and outputs by hash. Stop after two passes through the fixed matrix or any missing/nonfinite native observation. Neither an accepted status nor lower iteration count establishes the gates. This uses standalone host publication and CPU readback, not a resident MetalWorld trajectory, persistent GPU transaction, contact, performance, or physical calibration. Existing experimental CCD and augmented-Lagrangian options remain disabled.
