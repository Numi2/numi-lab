# Costal compiler and runtime attachment agreement

The costal payload decoder rejects a node whose attachment flags select both sternal and rib endpoints or contain unknown bits. The public in-memory costal compiler previously did not enforce that invariant: a direct caller could provide flags 3 and receive a successful cooked result even though the shared runtime ownership validator rejects the same source. The prerepair CPU regression failed with "accepted malformed source attachment flags 3". This is an in-memory compiler contract defect; it is not evidence that the runtime accepted a malformed serialized payload.

The compiler now rejects ambiguous or unknown attachment flags and checks the final rebased cooked attachment table using the same source-to-body ownership validator used at runtime admission. Failure returns a clean failed result rather than partial mass partitions. Legacy single-body binding remains supported, and the valid two-body synthetic fixture still cooks. Runtime admission separately verifies attachment positions and velocities against rebased Human body poses; this change does not replace that check.

On ssh numi, Apple M6, the expanded CPU costal compiler and existing binding CTests pass. The new regression checks direct in-memory flag values 3 and 4; the existing controls check valid split ownership, altered body identity, a missing donor, fixed-root refusal and relative point Jacobians. A separately executed native standalone passive adapter control passed acceptance, rejection and replay with the same valid cooked two-body synthetic source. The actual NumanX owner probe then passed one accepted-state replay and a four-accepted-step plus forced-rejection sequence; its log records byte restoration of the observed root/q/v/MuJoCo arenas, Matter authority and rejected HumanIO. The test inputs, owner and control are synthetic, and no biological force or physiological motion claim follows.

No full anatomical rib/sternum mapping, calibrated material, meaningful breathing, full Human standing, sustained tissue/contact qualification, or surgical task is established. The experimental split binding still needs source-verified anatomical bodies, relative mobility and mass partition. Both experimental CCD and augmented-Lagrangian contact options remain disabled.

The native owner executable and Matter/MetalRobo shaders were built together from the matching main checkout. Source and binary SHA-256 hashes are in sources-and-binaries.sha256. Raw owner logs and CPU CTest output are retained here. The baseline excerpt is the failing CTest output as observed before the compiler correction; it was not saved as a complete raw log.
