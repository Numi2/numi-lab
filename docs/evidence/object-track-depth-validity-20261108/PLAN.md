The object-track reducer currently admits any nonzero validity word. A present frame with selected geometry but no valid depth can therefore be mistaken for a depth measurement. In the existing two-environment 16x9 Franka materialized-image fixture, separately compile the same scene/camera with sensor depthDropout=1. Require a separate full-render reference to retain selected geometry but no valid depth in each environment. The real tracker must report zero confidence and zero position/velocity for every history slot in both compact history and actor observations, while masked-depth output contains only the far value. The prior valid-depth, direct-winner and stride tests remain controls. Record baseline and candidate outputs. A kernel-level synthetic test will additionally exercise missing FRAME, missing DEPTH, and valid mixed pixels. Migrate observation fingerprints of all actor programs with object tracks, preserve non-track policies, and verify old contracts reject.
