# Synchronized seeded rendering and capture-time metadata gate

This separately registered opt-in owner slice forwards the synchronized accepted observation sequence as the actual renderer frame index and uses `acceptedSteps * controlTimestep` as capture time. The renderer still receives one batch-wide sequence: this does not enable divergent sampling. Both environments must agree with the existing batch clock, and the original outer divergence guard remains. The fixture sets 5 mm depth-noise sigma on the authored camera, so the renderer's stochastic-depth seed path is enabled. This artificial parameter is diagnostic, not sensor calibration. Both arms use the same modified visual contract, geometry, timestep and zero policy.

After two nonterminal accepted steps, seed the clock with the observed preceding scalar frame identity `(acceptedSteps=2,lastSensor=1,captureStep=0,captureTime=0)`. For step 3, candidate capture time is the float representation of `double(2)*double(0.02f)`, and the actual renderer's metadata must report frame 2, sensor 2 and the identical capture-time bits. Candidate and accepted records follow real world/contact status; on failure retain all four prior words and on success accept `(3,2,2,captureBits)`. All-clear control step 4 must likewise show frame 3, sensor 3 and `double(3)*double(0.02f)` time, with matching records. Observe the visible-target and actual mixed-overflow prerequisites, exact tracker/actor/frame restoration, and refusal of the next mixed submission; compare observed and unobserved output at printed precision. The standalone renderer metadata is still batch-wide and therefore its speculative value after the mixed step is not the failed environment's accepted metadata: only the per-environment accepted record is status-gated in this slice.

Run observed and unobserved processes once each, each limited to 120 seconds; stop on error, preserve all logs and hashes, and compare frozen inputs before and after. No actual post-divergence renderer execution, per-environment seed selection, reset, masked-depth ring, command-failure atomicity or deployment sensing is claimed. A later 25 Hz mixed-phase study must compare exact seeded pixels, sample/hold choices, capture metadata and histories against independently controlled same-identity references, while treating automatic reset and an isolated no-reset retry as distinct tests. Until such a study is implemented and passes, the divergence guard is not removed.
