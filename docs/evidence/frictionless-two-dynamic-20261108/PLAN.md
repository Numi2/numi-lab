# Two-dynamic-body frictionless contact: preregistered screen

Question: does the isolated normal-block candidate preserve frictionless response and internal momentum exchange when the support is dynamic? The earlier plane fixture does not establish this. Compare current integrated production shader with the exact isolated candidate from the active-contact experiment using the same runtime and linked shader inputs. Do not modify production source.

One 1 kg floating articulated box tilted about z approaches a 2 kg horizontal dynamic scene box, in zero gravity, without friction, damping, CCD, restitution or external effort. Both start above a distant static plane; the initial box gap is 0.1 mm within the contact offset. Timestep 1 ms. Vary tilt -0.37 and +0.29 rad, relative horizontal speed -1, 0, +1 m/s, relative normal velocity -0.6 and 0 m/s, and configured velocity iterations 2 and 32: 24 configurations per arm; each repeated by the native owner. Observe actual contacts, q/v, scene states, status, contact impulses and evaluated targets. Require the candidate's two dynamic bodies to retain their horizontal velocities within 1e-6 m/s; normal/angular velocities and impulses must agree within 2e-5 across the three tangential-speed arms at each matched setting. Closing controls require positive impulse; nonclosing controls must have velocity changes below 1e-6. Independently calculate total linear momentum before and after and require maximum absolute component error <=2e-5 N s. Reconstruct a normal complementarity screen using both initial body positions, each final angular/linear velocity and captured world witness, target and regularization; require <=0.002 m/s and agreement with reported normal residual <=2e-5 m/s where the witnessed frame is consistent. Report each budget separately, and all failures and absent contacts. This single-step diagnostic is not a general force, torque, swept-collision, owner-rollback or mixed-rod qualification. Stop after the fixed cases; use no timing claims. Experimental CCD and AL remain disabled.
