# First coupled Metal candidate screen

The isolated Metal Newton implementation `a654fb1af` completed and passed all declared physical gates for both exposed three-node cases, including the prestretched case that the published XPBD solver accepted inaccurately. The straight and 100 nm microbend cases had maximum local momentum residuals 1.67e-9 and 4.86e-9 m/s and maximum support-force errors 1.04e-8 N. Each passed the 0.002 m/s velocity-perturbation negative check. The ten curved/twisted cases rejected with candidate status 4 (line-search exhaustion) after 3–7 iterations; their final internal angular residuals were 0.00584–0.0391 rad/s, above the 0.00025 internal limit and the independent 0.001 gate. No rejected candidate was published or evaluated as accepted. All 12 records repeated byte-for-byte.

This is a promising isolated candidate for the two tested cases, **not** a production repair: it has no production state owner, contact or rollback path and completes only 2/12 of this exposed matrix. The independent native-energy comparisons and full per-case output are in `results.jsonl`. The code contains an angular-precision suspect: it adds an FP32 angular correction to an FP32 initial angle before subtracting neighboring angles. A revision will represent the angle relative to a common reference, preserving small adjacent differences; this is a hypothesis about the observed line-search stall, not yet a proven cause. The original code, pretrial hashes, failed build logs and screen are retained in Git history and this directory. No performance claim is made.
