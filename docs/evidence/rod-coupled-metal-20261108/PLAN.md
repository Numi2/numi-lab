# Coupled Metal rod candidate: pretrial plan

Implement an isolated one-thread Metal Newton solve for the same straight-rest, isotropic DER discrete energy and coupled position/twist equations checked in `rod-coupled-bend-20261108`. Use FP32 with compensated edge-length arithmetic and local displacement coordinates, dense diagonally scaled Hessian/Cholesky, and a bounded residual-reducing line search. Hard point targets eliminate the endpoint coordinates; full position/twist cross derivatives remain active. Explicitly fail on invalid geometry, nonfinite quantities, nonpositive Cholesky pivots, line-search exhaustion or nonconvergence. It has no contact, damping, gravity, curved rest geometry, dynamic body coupling, persistent owner or production dispatch path. It must not fall back to the known inaccurate XPBD path.

First screen exactly the existing 12 exposed one-step inputs, with 30 Newton iterations and a maximum 12 backtracks, and compare to the retained separately native-energy-checked reference using the same gates as `rod-production-coupled-20261108/PLAN.md`: 1e-6 m positions, 0.001 m/s velocity, 0.0001 rad twist, 0.001 rad/s twist rate, per-support force max(1e-6 N, 1%), plus independent native-gradient local linear/angular momentum 0.001 m/s or rad/s and two-scale agreement 0.0001. At least one baseline-pass velocity perturbation must be detected; otherwise instrument calibration is incomplete. Reject/invalid counts are failures of useful completion. Repeat the complete matrix exactly and retain all outputs. A failed screen rules out promotion, not the general coupled method. No changes to production or either disabled experimental option are authorized by this screen.

The screen is exploratory and reuses exposed cases; no runtime or performance claim, untouched holdout, state restoration, source API integration or biological validation is established. Bind source, compiled shader and executable, native-energy executable, reference inputs, build flags and device. Stop at the fixed cases; no threshold tuning or unrecorded retries.
