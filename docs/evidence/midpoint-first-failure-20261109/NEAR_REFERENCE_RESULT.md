# Near-contact reference, n=8

The independent 95 micrometre initial-gap reference passed the same 0.5 versus
0.25 microsecond temporal gates. It retains the unchanged 100 micrometre
activation band and reference-area coefficient. The initial normal force is
0.232086 N and is included in the reference peak; the minimum gap over the
10 ms reference was 92.0730 micrometres. This is a deliberately prestressed
initial barrier state, so its positive contact work is not by itself evidence
of spurious energy. A native trajectory and comparison are still required.

The modified reference passed the energy-gradient self-test and reproduced the
previous n=8, 0.25 microsecond output byte for byte when no initial-gap override
was supplied. The exact executable is retained in the build directory under
`evidence-near-reference`; source and binary hashes, both trajectories and the
temporal analysis are retained here. This qualifies time resolution for this
mesh and case only, not spatial convergence.
