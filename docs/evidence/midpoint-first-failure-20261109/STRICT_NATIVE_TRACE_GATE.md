# Strict control-trace integrity gate

Before accepting a 007 control or any resulting cost comparison, independently audit each completed control trace. Reject non-finite numeric fields anywhere in the output; require a complete accepted sequence with successful statuses and certificates, positive clearance, consistent fixture mass and nonnegative force, and verify that each recorded force and normal impulse agree at the printed precision. Bind the compressed trace to its successful execution record and revalidate the time-qualified n=2 reference including force bins, area weights, mass, clearance and impulse accounting. This is an input-integrity gate, not a replacement for the existing force, momentum, replay or timing gates.
