# MetalWorld half-step candidate kinematics

MetalWorld’s borrowed candidate service now has a distinct half-substep kinematics operation. It integrates the same source coordinates and supplied velocity increment as the existing private candidate query, using half the pass timestep. It rejects an unrepresentable half timestep before dispatch. The existing full-substep query remains separate. The operation writes only borrowed scratch coordinates and projected body poses; it does not alter the authoritative q/v or publish a force.

A native MetalWorld test uses an actual fixed-root, one-degree-of-freedom prismatic slider and asks the owner for both candidates in one pre-dynamics pass. With h=1 ms, source velocity 0.02 m/s and supplied velocity increment 0.007 m/s, the half and full scratch coordinates and body heights were 13.5 µm and 27 µm. The test also verifies that a half timestep underflow is rejected and that the owner’s ordinary free-motion final q/v remain consistent with its existing endpoint-velocity integration. The slider baseline and two existing coupled late-failure rollback tests pass alongside the new owner test. The rollback tests exercise the existing legacy coupled path, not this new query’s acceptance or a midpoint transaction.

This is a narrow intermediate interface, not a completed midpoint step: Matter does not yet request it, it has no coupled FEM/contact solve or midpoint endpoint publication, and no two-owner impulse, torque, work, clearance, replay or failure claim follows from it. For arbitrary rotational joints it provides the owner’s existing half-duration kinematic interpolation, not a certified continuous collision bound. The unsupported dynamic Matter midpoint guard remains intact. Raw outputs, four test results and source/executable/library/shader hashes use the `slider-half-candidate` prefix.

A follow-up exercises an off-center point query through the same real owner and verifies that the half- and full-step point Jacobians are both (0, 0, 1), as required for this prismatic axis. This validates the borrowed point-mapping contract for this fixture, not contact force or torque. The four focused tests again passed; `slider-half-jacobian-*` retains this version and its hashes.
