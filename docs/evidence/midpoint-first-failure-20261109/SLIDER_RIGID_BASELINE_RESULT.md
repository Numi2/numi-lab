# Native rigid slider free-motion baseline

The real MetalWorld owner ran a genuinely free 10 g body on a fixed vertical prismatic joint, with initial vertical velocity +0.02 m/s and gravity -9.81 m/s². One intentionally large 1 ms step produced velocity 0.0101900 m/s and position 10.1900 micrometres, consistent with the current endpoint-velocity update. A midpoint update would produce 15.0950 micrometres for this constant-acceleration case, a 4.9050 micrometre difference. This establishes the owner behavior that the future shared midpoint transaction must change or explicitly account for; it is not a coupled FEM contact result, a performance result, or a whole-environment rollback test.

The owner and its existing Matter physics probe were built from this research checkout under a free-space guard. The baseline input source, native executable, owner library and Metal shader are hashed in `slider-rigid-baseline-inputs.sha256`; the result and logs have prefix `slider-rigid-baseline-001`. The first probe compile failed because the metallib path was placed on the step configuration instead of the owner configuration; the exact compiler error is retained in `slider-rigid-baseline-build-001.log`. The corrected compile and native run passed.
