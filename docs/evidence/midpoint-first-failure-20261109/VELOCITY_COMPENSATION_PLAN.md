# Precision repair feasibility: full transaction requirements

At the retained step 407, the independent nearby-search diagnostics indicate
that merely repeating the current FP32 velocity reflection is insufficient for
the captured state under the existing physical norm. Consider a narrowly gated,
separately opt-in compensated-velocity midpoint research mode. It is not a
reason to weaken the acceptance limits or promote the current correction.

For each FEM node the accepted velocity would be an authoritative high/low
pair v_n = v_hi + v_lo. The midpoint stage remains the solution of the same
constant-mass discrete equations. Reflect the stage as a compensated pair,
then independently certify x_(n+1)-x_n = h v_m and
M(v_(n+1)-v_n) = h f_m using both velocity limbs and the same material and
physical reference-area contact law. The stage residual must itself use the
accepted low limb; simply attaching one after the solve would certify a
different equation. Every force, motion, impulse, work and physical residual
measurement must use the represented high-plus-low velocity where appropriate.

The low limb is physical state, not diagnostic metadata. A valid implementation
must include it in GPU accepted/candidate/checkpoint ownership, exact rollback,
RuntimeStateSnapshot validation and restore, source/device fingerprints,
physical digest, independently measured momentum and contact work, saved-state
seals and deterministic continuation. Reject nonfinite or malformed limbs and
ensure default runtimes and old non-opt-in snapshots retain their existing
semantics. The existing dedicated buffer may only publish after the same
whole-step acceptance as FEM. Extra GPU commands must remain on the borrowed
transaction command buffer. No new CPU fallback may become authoritative.

The restricted mode currently excludes moving rigid owners, friction,
stateful materials, attachments, topology changes and multi-environment
execution. Audit every stage-residual path, ordinary/indirect command encoding,
contact evaluation and snapshot/export consumer before enabling it, and keep
unsupported paths fail-closed. In particular, do not repurpose an unrelated
padding lane or assume its value survives another owner. The low limb must
participate in rejection/retry and in any state equality check.

Preregistered acceptance: reproduce the n=8 3.90625 us initial state and
complete the 10 ms requested force-bearing rollout; independently validate
full-step momentum, kinematics, clearance, reference force bins, sampled peak,
impulse and cumulative impulse using the original gates. Include near-contact
starts, a forced rejection before retry, and exact restoration of both limbs.
Compare both mode-disabled behavior and previously accepted n=2/n=4 control
trajectories. A passing captured step, a separate arithmetic kernel, or a
smaller residual without the full transaction and force gates is not completion.
The n=64 reference and matched-cost comparisons remain separate requirements.
