# Bounded native midpoint precontact correction experiment

The independent stage-reflection-constrained calculation found one candidate
below the original full-step momentum limit on the captured precontact state.
Test whether a real Matter transaction can reach an independently valid state
without changing geometry, material, contact law, timestep or tolerances.
Prediction: a local, neighboring-FP32 stage correction followed by a complete
force/residual recomputation will allow the previously rejected n=8, 3.90625 us
step 203 to be accepted. Reject that prediction if native acceptance, the
independent full-step equations, nonpenetration, physical certificate or
restoration/replay fails.

The correction is scoped to the already opt-in midpoint research fixture and
only runs when its unchanged original momentum certificate would fail and all
nodes are well outside the contact activation band. Its state changes remain
transactional. It must perform normal force reassembly and all existing final
contact, clearance and full-step certification after any correction; no status
is overridden. No augmented-Lagrangian or interval-local CCD option is enabled.
Keep the old binary, shader, baseline evidence, and the disabled-by-default
midpoint setting. Retain failing attempts.

Qualification begins by reproducing the previously failing transaction with
identical scene and checking independent FP64 momentum and midpoint kinematics,
accepted geometry, status and complete restoration/replay. Then continue the
full 10 ms n=8 rollout, including actual contact, and compare force, peak,
impulse and cumulative impulse with the already temporally qualified n=8
reference using the preregistered gates. Re-run n=2 and n=4 to ensure successful
paths and their original physical outcomes are unchanged when no correction is
needed. Any rejection, failed force gate, performance regression, or unsupported
coupling remains visible. This precontact-only candidate is not a contact-onset
fix, an accuracy-adjusted performance win, a spatial-convergence result or a
two-owner midpoint implementation.
