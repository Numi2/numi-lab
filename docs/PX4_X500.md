# PX4 X500 native flight foundation

`numi drone source --output <directory>` acquires the pinned PX4 Gazebo X500
source, verifies its revision and file hashes, and emits an immutable source
contract. `numi drone flight` runs the first native Apple Silicon qualification.

The runtime is data-driven. `MRMulticopterModelGPU` and rotor records are
generic fixed-layout inputs: a GPU dispatch advances persistent motor-speed
state, applies PX4's source thrust, reaction torque, rotor drag, rolling moment,
and wind-relative cross-axis airspeed terms, then the existing native free-body
integrator advances the body. No per-airframe Metal kernel or host
per-environment control loop is introduced.

The current X500 configuration is sourced from the pinned SDF: the base and
four rotor-link masses are reduced into one COM-centred rigid airframe, rotor
poses are expressed from that composite COM, and motor rise/fall constants,
maximum speed, thrust coefficient, moment constant, rotor drag, and rolling
moment coefficient are retained. The CPU FP64 actuator oracle and Metal wrench
kernel must agree before the flight probe accepts a run.

The hover qualification is native GPU simulation evidence only. It does not
yet qualify a real X500, wind-tunnel aerodynamics, rotor angular-momentum
coupling, sensor fusion, controller tracking, collision/CCD in flight, or
hardware safety. Those require pinned external comparisons and then separately
armed physical-flight evidence.
