The independent discrete reference and 0.001 m/0.001 m/s accuracy gates are unchanged. Compare one and 32 independent environments on this Apple M6 using MetalWorld GPU batched execution and MuJoCo 4.0.0 CPU in a single serial host thread. This is an explicitly serial MuJoCo baseline, not a tuned maximum-throughput comparison.

Both model compilations and runtime initialization are outside the timed interval. Each timed run includes resetting its environment states, executing all steps, returning final states, and failure handling; Numi's fixed zero-effort input is prepared before timing. Include all work for rejected attempts and report their physical outcome rather than excluding them; calculate speed only if all environments pass the unchanged physical gates.
