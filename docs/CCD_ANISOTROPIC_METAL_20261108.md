# Bounded tangent-metric projection: direct helper evidence

This unpromoted research variant replaces radial clipping in the normal-first helper with a tangential quadratic projection using its regularized conditional inverse. It uses 32 bracketed multiplier iterations and checks local finiteness, positive-definite metric, ellipse feasibility and KKT residual. Failure returns a nonfinite candidate, which the source paths check before publication; device-level world status and state restoration for this specific failure have not been tested. The local numerical check is not a global friction convergence certificate. The final normal certificate is unchanged. The independent FP64 reference and its limits are in CCD_ANISOTROPIC_FP64.

The revised nine-case direct Metal wrapper returns (-1.38032901,-0.202282593) N s for the admissible positive anisotropic case versus FP64 (-1.380329003885,-0.202282574792); the largest component difference is 1.9e-8 N s. Frictionless, interior stick, capped normal and the near-singular regularized normal controls returned the retained analytic results. One-axis cones at positive and zero normal return nonfinite candidates, as does an extreme positive coefficient ratio for which FP32 scale cannot represent the required bound. The one-axis case is outside the validated ConstraintIR domain, not a demonstrated production defect. The duplicate-row helper model remains an oscillation counterexample; it is not a full distributed-world test.

The first seven-case v1 gives the same anisotropic result and the positive-normal unsupported failure. Review then identified that the v1 guard returned zero on an unsupported one-axis cone with zero normal; v2 checks the domain before returning for zero normal. Preserve both. An initial attempt to build with Metal 3.0 failed with undeclared `nextafter`; the successful build used the owner Metal 4.0 recipe. No device work ran during the failed build.

This helper test does not qualify world-level rollback, supported friction matrices, singular or ill-conditioned scenes, moving links or full physical contact evolution.
