# Paired normal-row contact experiment (held)

This research-only candidate extends the bounded priority-row pass for frictionless distributed islands with a two-contact nonnegative quadratic update. It retains the all-path normal complementarity certificate and applies the earlier simultaneous candidate when an island has friction. Singular two-row systems do not use the free pair solve; finite impulse caps use the scalar candidate. This is not a general convergence proof, and mixed friction, cap behavior, articulated, rod, and complex geometries require independent qualification.

In the 72-case native matrix, 70 cases are accepted. The two rejections are 33-contact one-sweep impacts already shown to violate the normal certificate. All 257-contact incoming cases pass the retained fixture's normal, impulse, momentum and friction gates, including the production two-sweep configurations. Replay is identical and rejected q, v, scene and contact cache are restored for this fixture. The paired output gate is tests/ccd/world/paired_result_gate.py. These are bounded fixture checks, not general force or friction certification.

The 257-contact owner-shaped frictionless impact matches the independent FP64 reference at two sweeps: impulse 0.081749998 N s, residual zero, contact kinetic work -0.003341531 J, and zero measured momentum imbalance. The 33-contact owner-shaped impact still rejects at 1, 2, 3, 8, 16, 32, and 64 sweeps through the separate non-distributed wave path. Consequently this is not a useful-simulation repair across its full domain.

A single diagnostic run measured about 48.7 ms GPU time for the 257-contact aligned two-sweep fixture and 186.1 ms for the mixed-normal two-sweep fixture. These one-run values are not a controlled performance study. They indicate substantial work, not a speed improvement. No performance promotion is warranted.
