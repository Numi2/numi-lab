# Populated-cache injected projection failure

A test-only shader injects an unsupported one-axis cone into a sentinel contact only when a staged kinematic target introduces tangential velocity. This path is not exposed by current collision compilation and the instrumented shader must never be deployed. A resident world first accepts a quiet step that populates 33 or 257 contact manifolds; a target-bearing step then invokes the injected failure. On both fixtures the failure returns status 3 and restores q, v, scene state, manifold counts, and the complete allocated manifold header and point buffers byte-for-byte. A subsequent neutral step matches an independently initialized control on those same fields. A separate non-instrumented shader accepts the target and applies it. This is evidence for these explicit resident transactions, not a claim of every possible rollback boundary or production reachability.

The original output records active contact count but not queue flags; therefore it does not itself prove which queue processed the injected 257-contact failure. A separate queue-labeled run is required before claiming distributed-path qualification. Both experimental CCD and contact-law options remain disabled; the solver candidate remains unpromoted.
