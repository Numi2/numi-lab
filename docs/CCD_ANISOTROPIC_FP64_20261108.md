# Independent anisotropic tangent reference

The normal-first helper currently clips the proposed tangent impulse radially to an anisotropic ellipse. That preserves cone admissibility but can violate maximum dissipation. For the retained admissible helper case, normal impulse 2 N s, coefficients (0.8,0.2), incoming tangent speed (3,4) m/s and unit tangent response, the independent FP64 constrained quadratic solve gives tangent impulse (-1.380329003885,-0.202282574792) N s and post-slip (1.619670996115,3.797717425208) m/s. The impulse matches the independently computed maximum-dissipation direction to 4.5e-16 N s. The earlier actual Metal helper instead produced (-0.294861674,-0.393148899) N s. This is a helper-level comparison, not a demonstrated production MetalWorld failure: current collision compilation emits equal U/V friction.

The reference solves the 2D positive-definite tangent-metric quadratic with a bracketed scalar multiplier and checks the ellipse and KKT equations. Across 1,000 seeded SPD matrices and positive unequal limits, maximum FP64 KKT residual is 1.43e-14 and maximum cone excess 2.23e-16. A one-zero coefficient is outside the validated ConstraintIR contract and is not tested as a supported case. These checks do not establish GPU precision, full coupled-contact convergence, or the validity of any runtime fallback. All thresholds and options remain unchanged.
