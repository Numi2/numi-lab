The two historical box rejections were recorded on a later unpromoted research solver, not clean main. This matched clean-main run at bb58f524 accepts the frictionless box impact with 0.99990210 N s normal impulse, 9.79e-5 m/s residual and -0.499999995 J work, consistent with the 1 kg inelastic normal-impact reference within the declared tolerances. The historical 0.0103 m/s frictionless rejection therefore does not justify transplanting the research pair solver into main.

Clean main does accept an incorrect force-free sliding response: a horizontal box with zero normal velocity and zero target acquires 0.00147182 N s normal impulse and loses 0.00073458 J kinetic energy. The candidate in this branch makes one bounded change to the non-distributed wave update: if the existing normal impulse is exactly zero and the current normal equation requests no positive impulse, use zero for the whole Coulomb impulse. This retains the zero-capacity cone and prevents the full block inverse from turning tangential slip into a spurious normal force. It does not add the separate experimental acceptance certificate or enable either experimental option.

In the pinned 25-case geometry comparison, the candidate passes the predeclared normal impact, impulse, witness torque, work and replay checks; the previously incorrect sliding box and a 1.5 mm-clear moving box have exactly zero impulse and work. The clean baseline fails the former. Both shaders accept all cases. Baseline and candidate each pass only 35 of 36 cases in the independent two-sweep local maximum-dissipation check: the fast-sliding four-contact box impact accepts despite local error as large as 0.00051810 N s versus a 0.00013548 N s limit. The candidate does not affect that impact; it is not broadly friction-qualified and must remain unpromoted. A force-free discrete near miss is not swept CCD qualification. Exact q/v/scene replay is checked for these cases; populated-cache rejected-step restoration and broad anisotropy are not qualified by this result.
