# Mixed cone admission: retained counterexample

The test-only shader injects evaluated ground-row cone values after contact generation in an otherwise ordinary zero-gravity, three-node rod/sphere mixed-island resident with a populated manifold. The host ConstraintIR validator disallows negative and nonfinite friction, and the inspected generated contact paths set the normal cap to zero; these injections establish downstream behavior, not public-path reachability. Original production contact and CCD options remain unchanged.

A high-speed series injected a 0.1 N s cap, negative U coefficient (-0.5), and NaN U coefficient. All three cases rejected twice and captured pre-state and independent neutral continuation matched, but all had significant normal-complementarity failures too, so this did not establish invalid-cone rejection.

In the separately preregistered lower-speed series, the stationary control accepted. The 0.00001 N s cap case accepted with ground impulse 5.5556e-6 N s and a reported normal residual 9.4446e-5 m/s, within the existing absolute certificate but not force-qualified. The negative U coefficient was observed as -0.5 and the first and second steps accepted: an invalid-cone admission defect in the isolated research candidate. The NaN U case rejected both times with status 3 and captured state plus subsequent independent neutral continuation matched. Its normal residual also exceeded the certificate, so that run does not completely isolate which check prevented publication. Captured state covers q/v, scene, rod nodes/edges, and manifold counts/headers/points; hidden state and resets are outside its scope.
