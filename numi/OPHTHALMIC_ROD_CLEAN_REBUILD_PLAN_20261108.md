# Clean-source standalone rod reproduction plan

Create an isolated checkout of the exact source revision that contains the direct multi-anchor rod candidate, without modifying other owners' worktrees. Build its owner library and complete metallib through the repository's native CMake targets in a new build directory. Record the clean source identity, configuration, toolchain, build logs and new library and shader hashes. Recompile the already registered held-out and split-replay instruments from their pinned source against those rebuilt artifacts and rerun the same gates and inputs. Any changed artifact receives a new identity: do not claim byte reproduction of the previous task-local library or metallib merely because behavior agrees.

The earlier binaries had hash-identified provenance but no demonstrated clean rebuild; preserve those results even if the new build or validation fails. This experiment tests reproducibility only for the standalone, uncoupled straight-rod fixture. It does not validate resident MetalWorld, contacts, surgery or material behavior outside the declared axial interval. No timing claims are authorized. Resource limits and GPU ownership must be coordinated with the active contact and other correctness work before starting.
