# Rod precision boundary and local-state design

The retained 128-node stress shows why evaluating a reaction in a separate, higher-precision temporary while publishing only rounded FP32 world positions would be inconsistent: the published adjacent-node geometry itself cannot represent any force within the declared gate for that fixture. A production repair needs a state representation and contact interface that preserve the necessary local information, or it must explicitly reject a requested accuracy it cannot represent.

The current resident MRRodNodeStateGPU contains an FP32 position and velocity; rod/tool witness points are also stored in world coordinates as FP32. MetalWorld maintains initial, reset, active ping-pong and checkpoint rod arenas. A change limited to the standalone axial kernel would not preserve precision through resident continuation, geometry queries, contact anchors, rendering or checkpoint restoration.

A possible narrowly staged design is a per-component origin plus FP32 local node offsets, with the origin and offsets both part of the authoritative resident state. Derive differences and forces in a common local frame, form rod/tool witnesses and Jacobian lever arms without first collapsing the pair to large world-coordinate floats, and define explicit conversion at external boundaries. Update every input, reset, active, checkpoint, import/export, snapshot identity and continuation path as one ABI/versioned transaction. Support rebasing only through an exact, audited state transformation; preserve topology and contact history identity. A double-precision host input must not silently lose its small offset before the local representation is created.

Required tests include translation invariance at 0, 1 and 16 m against the same physical model; force from the published full state, local momentum, velocity, work/energy and repeated continuation; bend, twist and moving rigid/rod contact; out-of-domain precision failure with complete restoration; and identical results through save/restore. Preserve both world and local identity in output and never infer contact validity from visual reconstruction. The public error policy must state physically meaningful absolute and relative force and motion requirements; an ULP-based certificate can only be a conservative input to that policy, not a replacement for it.

This is an implementation direction, not an implemented or qualified capability. It requires an owner and ABI audit before changing code. The current straight axial candidate and stretch guard remain isolated research branches.
