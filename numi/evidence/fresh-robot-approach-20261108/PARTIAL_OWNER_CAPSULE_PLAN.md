# Source-bound partial owner capsule: pre-run plan

Purpose: create an independently inspectable record of published state and actual compiled-world fingerprint after each accepted boundary of the existing two-stage synthetic same-resident control. This is an instrument for identifying missing state, not a checkpoint importer, restart, atomic cross-owner snapshot, force qualification, or physiological validation. The capsule explicitly declares `complete=0` and `restorable=0`; no code is provided to seed a resident owner from it. Any capture or verification failure fails the diagnostic rather than publishing a complete claim.

Use the previously recorded step-1389 synthetic starting TSV and its separately pinned Matter sidecar. This is a reconstructed starting state with incomplete predecessor-owner history and must not be relabeled as the separate historical v3 step-1870 tissue-bridge checkpoint. The capsule binds the actual starting TSV name, byte count, hash and step, its stage checkpoint, Matter sidecar and rigid cache. The external run record must additionally pin SHA-256 of all source, executable, libraries, shader, material, starting TSV and starting Matter sidecar before and after execution. The `compiled_world_fingerprint` must be emitted from the actual compiled object used by the run; it must never be inferred from or added to historical evidence.

Hypotheses and gates: use the same-resident entry/advance fixture, unchanged safety and physical gates and no authored reset. Capture after each accepted stage, and require nonzero actual owner identity, exact component dimensions and checksums, and independent SHA-256 verification of all nine raw components and the three published sidecars. Verify both stage fingerprints agree and each input binding matches the pinned step-1389 starting TSV. Compare existing physical and witness outputs with the previously retained same-resident control. Stop and retain any error or mismatch. Acceptance of this diagnostic does not establish full restoration or equality of any unrecorded owner state.

Known missing or unverified domains include convex caches, reset state, owner transaction state, other private owner state and an atomic reservation spanning Matter and MetalWorld. The previously captured manifolds and witness slots are readbacks; device seeding, completion-boundary import, exact no-step resident readback and failure-safe owner publication remain unimplemented. Contact and surgical rod forces remain unqualified. A later no-step experiment must use a freshly captured source-bound state, must establish all required state and device ownership, and must not retrofit the older TSV with a fingerprint.

CPU verification: `python3 test_partial_capsule.py` tests valid partial metadata and rejects altered, truncated or absent components, altered Matter, missing identity and a falsely restorable claim. The standalone verifier recomputes each FNV64 and outputs a SHA-256 for each file; its small synthetic test files are test inputs and not surgical evidence. No native run, compiled executable or device result exists for this candidate until separately recorded.
