# Synthetic rod/tool no-step witness seed: native result

On the Apple M6, the separately recorded source and fixture at `2b71f3c8d0a1c206d6c9ebb551161a0139b6959c` completed the predeclared rod/tool no-step seed gate. The run uses one environment, a five-node strand, a sphere, speculative CCD, and no Matter state. The compiled world fingerprint was `2573094028256544495`. The input artifact hashes are in `inputs.sha256`; exact executable, library, Metal library, fixture source, and plan are retained in `artifacts/`. Run output and all captured device-state arrays are retained in `run.log` and `raw/`.

Two independent initialized owners each completed the initial step and the following step. The initial witness arena had 32 slots, two valid witnesses, and two with nonzero impulse. Both trials produced identical captured arrays at both steps. Seed admission validated the full no-step readback; the single subsequent seeded step matched the uninterrupted owner byte for byte for the captured q/v, scene, rod nodes and edges, complete rod witness arena, manifold arrays, and rod, contact and world statuses. The convex cache in this fixture was empty, so equality of that cache is not evidence for nonempty-cache restoration. Independently comparing the retained output files also confirmed those equalities.

Wrong world, changed configuration, truncated witnesses, nonfinite node, invalid pair, collider and topology identities, nonfinite witness impulse and geometry, invalid active flags, and stale checksum were rejected without publishing a destination. An injected post-command readback mismatch also rejected, after which the exact seed was accepted on the same context. An occupied destination and a changed-configuration continuation were rejected; the subsequent exact continuation matched. The injected mismatch is a host comparison control, not a real Metal command failure.

This is an isolated research candidate and synthetic replay test. It does not establish correctness of contact forces, nonempty convex-cache restoration, Matter or tissue coupling, a historical suture checkpoint, long-term replay, concurrent owners, anatomical validity, or a complete surgical workflow. The candidate has not been promoted to production. The historical surgical checkpoint remains unqualified.

To check the exact retained inputs, run `cd artifacts && shasum -a 256 -c ../inputs.sha256`; to repeat the fixture on a compatible Apple Metal host, run `DYLD_LIBRARY_PATH="$PWD" ./probe /path/to/new/output-directory` from `artifacts/`. The destination must not already exist. An identical result on another machine is not assumed.
