Repeat the separate no-rod, no-Matter convex/cylinder seed fixture with the original geometry, controls and gates. Require the first boundary to have a positive accepted manifold count in addition to populated convex cache and accepted contact. Preserve the full capacity-packed manifold headers, points and counts. After an exact device-readback seed and one step, compare all three manifold arrays as well as q, v and convex cache byte-for-byte with the uninterrupted control; save each raw buffer before asserting. If the source manifold is empty, reject the trial without tuning the fixture in place.

Before the successful seed, set an explicitly diagnostic-only fault flag which allows the actual upload/readback command to complete and then deliberately trips the existing readback-mismatch gate. Require a failure status and no published resident. Immediately retry with the same context and a fresh valid seed; require successful seed and subsequent byte-exact continuation. This verifies a post-submission rejection and slot cleanup; it does not simulate or claim a Metal command-buffer execution error, device loss, timeout, concurrent submissions or atomic multi-owner failure. Real GPU command-failure injection remains unqualified. Pin source and all runtime artifacts before a coordinated correctness-only GPU window and retain every failure. Surgical, rod and Matter states remain excluded and prior surgical capsules remain non-restorable.
