It must initialize an unpublished fresh arena, upload q, v, scene, full manifold buffers and the populated convex cache, then read back each byte in the same completed command before publishing the resident. Failure must leave the destination token empty; an occupied token must be rejected without overwriting it. The synchronous diagnostic waits for the Metal command; it has no timeout contract and is not an atomic multi-owner operation.

Capture the accepted first boundary, reject altered world identity, configuration identity, truncated cache and a bit-flipped cache with stale checksum, and confirm no destination token becomes valid. The no-step implementation itself must verify all imported device bytes before it publishes the token. Retain all statuses and inputs whether the comparison passes or fails.

The checksum detects accidental corruption and is not authentication. An accepted continuation is limited to this synthetic model and one step; it does not prove force or geometric accuracy, comprehensive rollback, fault-injected GPU failures, timeout handling, transactional Matter integration, full owner completeness, or exact recovery of any historical checkpoint.
