# Standalone local-frame rod experiment

The world-FP32 stress remains an incorrect accepted result, and the [local-state design](ROD_LOCAL_STATE_DESIGN_20261108.md) is not implemented in the resident owner. Test a separate, explicitly invoked host-side helper for the **standalone, uncoupled, no-self-contact, no-tool-contact** rod API only. It will select one double-precision origin per environment, translate the input positions and attachment targets before the unchanged native solver's FP32 upload, and reconstruct final double-precision world positions after a successful complete result. Velocities and reactions remain in the common orientation; no contact witness or rigid state may be translated or silently omitted. Unsupported coupling must explicitly reject and leave the caller output unchanged. This helper is not wired into the default production path or MetalWorld.

Pin the helper and unchanged candidate shader before testing the previously registered 5/17/128-node matrix at offsets 0, 1 and 16 m against the original requested FP64 geometry, unchanged state and force gates. Also test multiple environments with distinct origins, several accepted steps using returned state, same-input replay, reversed and invalid geometry, and explicit rejection and unchanged output for tool, rigid and self-contact modes. A success establishes only this host-mediated standalone path, not device-resident snapshots, contacts, surgical coupling or physical material validity. Keep the earlier world-coordinate and rounded-input failures.

The first preparation attempt stopped before compilation because the sparse worktree had not materialized the existing stress source. The preparation was repeated using the same already pinned source from its owning worktree; no test ran in the failed attempt.

The first compilation stopped on an inaccessible internal Vec3 alias; the attempted executable launch consequently also failed before dispatch. Both errors are retained. The isolated helper now uses the public array representation and will be separately repinned before running.
